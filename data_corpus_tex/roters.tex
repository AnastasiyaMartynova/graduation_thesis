Для оценки производительности системы скважин используется
так называемый коэффициент продуктивности (productivity index $\sf PI$),
который определяется отношением скорости притока к депрессии давления \cite{roters:bib:Dake}:
\begin{equation}
{\sf PI}=\frac{Q}{\bar{p}-p_w},
\label{eq:PI}
\end{equation}
где $Q$ "--- дебит скважины, $\bar{p}$ "--- среднее давление в резервуаре, $p_w$ "--- давление в стволе скважины. 

Коэффициент
продуктивности зависит только от гидродинамических характеристик резервуара и расположения скважин в нем.

В нефтяной инженерии резервуаров обычно используется формула, в которой среднее давление $\bar{p}$ выражается
через безразмерный коэффициент формы контура питания скважины $C_A$ (Dietz shape factor)
\cite{roters:bib:Dake} следующим образом \cite{roters:bib:Dietz}:
\begin{equation}
\bar{p}-p_{w}=\frac{Q}{4\pi\chi}\ln\frac{4\Delta}{\gamma C_A r_w^2},
\label{eq:d_Ca}
\end{equation}
где $\gamma=e^c=1,781$; $c=0,577$ "--- постоянная Эйлера.
Он позволяет определить среднее давление в области питания скважины в зависимости от геометрической формы этой области.
В работе \cite{roters:bib:Dietz} величина коэффициента
формы была вычислена для ряда решёток (прямоугольная, равнобедренно"=треугольная,
ромбическая) и сравнена с коэффициентом формы для идеального кругового
контура.

Аналогично работам из области вихревой динамики \cite{roters:bib:ONeil,roters:bib:Tkachenko}
для двоякопериодических систем скважин была построена математическая
модель с привлечением эллиптических функций Вейерштрасса. Данная модель
задает комплексный потенциал, являющийся двоякопериодической функцией,
в виде
\begin{equation}
\varphi(z,\,\bar{z})=\ln\sigma(z)+\frac{\alpha z^2}{2}-\frac{\pi}{2\Delta}z\bar{z},
\end{equation}
где $\sigma(z)$ "--- сигма"=функция Вейерштрасса, $\alpha={\pi}/{2}-2\eta_1$,
$\eta_1=\zeta\left(\omega_{1}/2\right)$ "--- квазипериод дзета"=функции
Вейерштрасса, $\Delta$ "--- площадь ячейки для выбранного типа решётки. Подробное описание модели представлено в~статье \cite{roters:bib:Ast_Roters}.

Вещественная часть данного потенциала определяет поле давления, а
его производная "--- поле скоростей. Данная математическая модель позволила
вычислить распределения поля давления и поля скоростей в решётках
произвольных конфигураций и определить контуры питания скважин, расположенных
в узлах решётки.

В итоге для коэффициента продуктивности скважины было найдено явное выражение:
\begin{equation}
\label{eq:PI_itog}
{\sf PI}=2/\ln\Bigl(\frac{4\Delta}{\gamma C_A r_w^2}\Bigr),
\end{equation}
где $r_w$ "--- радиус скважины.

Для одной скважины, расположенной в параллелограмме периодов, коэффициент формы может быть рассчитан следующим образом:
\begin{equation}
\label{eq:Ca_cmn}
C_A (\tau)=\frac{16\pi^2}{\gamma}\text{Im}\tau\Bigl|(q q_1)^{1/6}\prod_{n=1}^{\infty}
\left(1-q^{2n}\right)^2\left(1-q_1^{2n}\right)^2\Bigr|,
\end{equation}

где $\tau=\omega_1/\omega_2=\lambda e^{i\theta}$ "--- отношение периодов решётки,

В случае, когда в параллелограмме периодов расположены две скважины c одинаковым дебитом $Q$,
коэффициент формы каждой их них может быть найден благодаря установленной зависимости:
\begin{equation}
C_A^{(2)} (\tau)=\frac{\gamma}{8}\frac{R_{12}^2}{\Delta}\left(C_A^{(1)}(\tau)\right)^2,
\end{equation}
где $C_A^{(2)}$ "--- коэффициент формы для одной из двух скважин, расположенных в параллелограмме периодов; $C_A^{(1)}$ "---
коэффициент формы для одной скважины в параллелограмме периодов с дебитом $2Q$; $R_{12}$ "--- выражает расстояние между двумя скважинами:
\begin{equation}
\ln R_{12}={\rm Re} \ln \Bigl(\sigma (z_1 - z_2) - \frac{\alpha(z_1 - z_2)^2}{2}\Bigr)-\frac{\pi}{2\Delta}|z_1-z_2|^2.
\end{equation}

Значения коэффициента $C_A$ полностью совпали со значениями, вычисленными
Дитцом и  Писманом \cite{roters:bib:Peaceman} путём численного суммирования бесконечных
условно"=сходящихся рядов для некоторых типов решёток. Результаты представлены в таблице.



Таким образом, полученное представление для коэффициента продуктивности \eqref{eq:PI_itog}, \eqref{eq:Ca_cmn}
позволяет анализировать производительность двоякопериодических систем добывающих скважин для решёток произвольных конфигураций.
