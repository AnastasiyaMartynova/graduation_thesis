\workabstract{Предложен численно"=аналитический метод вычисления интегралов, используемых при построении ортогональных моделей.
Данный метод позволяет повысить точность ортогональных моделей за счёт полученных алгебраических и рекуррентных соотношений
для используемых интегралов. Проведен сравнительный анализ различных ортогональных функций, являющихся частными случаями базисов Якоби и
Сонина"--~Лагерра, при решении поставленной задачи.
Приведена реализация разработанных алгоритмов на примере построения корреляционной ортогональной модели в базисе Лагерра. }

The given method allows to increase the accuracy of orthogonal models due to obtained algebraic and recurrent relations for integrals used. Comparative analysis of various orthogonal functions which are the specific cases of Jacobi and Sonin--Laguerre bases is carried out when solving the posed problem. Realization of the developed algorithms is given by the example of construction of correlation orthogonal model in the Laguerre basis.
}

При построении ортогональной модели функциональной характеристики $f (\tau )$ необходимо:
1)~выбрать ортогональный базис $\psi _k  ( \tau, \gamma )$; 2)~определить число членов ряда $m$ и~параметр масштаба
ортогональных функций $\gamma $; 3)~рассчитать коэффициенты Фурье ортогонального ряда $\beta _k$, удовлетворяющие минимуму взвешенной
квадратичной погрешности аппроксимации в общем случае [1, 2]:
\begin{equation}
\label{prosha:eq1}
\Delta =\int_0^\infty  \biggl[ f (\tau) -\sum\limits_{k=0}^m \hat \beta  _k \psi _k  (\tau, \gamma )   \biggr]^2\mu  ( \tau , \gamma  )d\tau
 \to \min ,
\end{equation}
где
\begin{equation}
\label{prosha:eq2}
\hat \beta_k =\hat \beta_{k,1}
=\frac{1}{ \| \psi _k  \|^2} \Phi \bigl( \hat f  ( \Delta \tau \cdot i  ) \psi _k  ( \Delta \tau \cdot i, \gamma  ) \mu  (\Delta \tau \cdot i, \gamma), \tau _{k\,\max }, N  \bigr)
\end{equation}
"--- оценка коэффициента разложения
\begin{equation}
\label{prosha:eq3}
\beta _k =\frac{1}{ \|\psi _k \|^2}\int_0^\infty f (\tau ) \psi _k  (\tau , \gamma )\mu (\tau , \gamma)d\tau ;
\end{equation}
$\tau _{k\,\max } $ "--- максимальный интервал корреляции;
$\Delta \tau $ "--- шаг дискретизации; $i \hm \equiv 1, 2, \dots, J_{\max }$;
$J_{\max } = {\rm ent} [ \tau _{k\,\max }/ \Delta \tau ]$ "--- число ординат, необходимых для построения
функциональной зависимости;
$N$ "--- объём выборки;
$\Phi (\,{\cdot}\,)$ "--- функционал, зависящий от численного метода интегрирования;
$\mu  (\tau , \gamma )$ "--- весовая функция ортогонального базиса;
$ \| {\psi _k }  \|^2$ "--- норма ортогональных функций.

Выражение (\ref{prosha:eq1}) представим в виде [3]
\begin{equation}
\label{prosha:eq4}
\Delta =\Delta _{\min } +\Delta _1,
\end{equation}
где
\begin{equation}
\label{prosha:eq5}
\Delta _{\min} =\int_0^\infty f^2 (\tau )\mu (\tau, \gamma) d\tau  -
\sum\limits_{k=0}^m \beta _k^2  \| \psi _k  \|^2
\end{equation}
"--- минимальная погрешность аппроксимации;
\begin{equation}
\label{prosha:eq6}
\Delta _1 =\sum\limits_{k=0}^m \Delta _{\beta _k } ^2 \| \psi _k  \|^2
\end{equation}
"--- погрешность аппроксимации, вызванная оценкой коэффициентов разложения;
$\Delta _{\beta _k } ^2= ( \hat \beta  _k -\beta _k   )^2$.

Из выражений (\ref{prosha:eq5}) и (\ref{prosha:eq6}) видно, что значение погрешности $\Delta _{\min } $
уменьшается с~увеличением числа членов разложения ряда $m$, в~то время как
значение погрешности $\Delta _1 $ возрастает [1, 2].
Следовательно, для уменьшения результирующей погрешности аппроксимации (\ref{prosha:eq4}) необходимо
минимизировать составляющую (\ref{prosha:eq6}).

Решение этой проблемы можно получить,  применяя следующий подход.
В общем виде,  используя линейную интерполяцию $f ( \tau  )$,
можно записать:
\begin{equation}
\label{prosha:eq7}
f (\tau)=\sum\limits_{j=0}^{J_{\max } -1}  ( a_j +b_j \tau  )\delta _j ,
\end{equation}
где $\delta _j = \left\{ \begin{array}{cl}
 1, & \text{если } \tau \in [\tau _j, \tau _{j+1}], \\
 0, & \text{если } \tau \not\in [\tau _j, \tau _{j+1}]
\end{array} \right.$ "--- индикатор состояния.
Тогда, подставив (\ref{prosha:eq7}) в (\ref{prosha:eq3}), получим
\begin{equation}
\label{prosha:eq8}
\hat \beta_{k,2} =\frac{1}{ \| \psi _k \|^2}
\sum\limits_{j=0}^{J_{\max } -1}
 \biggl( a_j \int_{\tau_j }^{\tau _{j+1} }
\psi _k  (\tau , \gamma )d\tau  +b_j \int_{\tau _j }^{\tau _{j+1} } \psi _k  (\tau, \gamma ) \tau d\tau \biggr) .
\end{equation}

Для оценки коэффициентов разложения (\ref{prosha:eq8}) необходимо определить интегралы $\displaystyle \int \psi _k  (\tau , \gamma )d\tau $
и~$\displaystyle \int \tau \psi _k  (\tau, \gamma )d\tau $.



Представим решение данной задачи для ортогональных функций Лагерра $L_k  (\tau , \gamma )$ и Лежандра ${\rm Leg}_k  (\tau , \gamma )$,
являющихся простейшими представителями ортогональных базисов Сонина"--~Лагерра $L_k^{ ( \alpha  )}  (\tau, \gamma )$
и Якоби $P_k^{ ( \alpha , \beta )}  (\tau , \gamma )$ с~нулевыми параметрами ортогональных базисов
$\alpha $, $\beta $ и~единичной весовой функцией $\mu  (\tau, \gamma )$~[3].

Для решения данной задачи воспользуемся рекуррентным соотношением
\begin{equation}
\label{prosha:eq9}
L_k  ( \tau , \gamma  )=\frac{  2k-1-\gamma \tau }{k}L_{k-1}  (\tau , \gamma )-\frac{k-1}{k}L_{k-2} ( \tau , \gamma  ).
\end{equation}
Здесь  $L_0  ( \tau , \gamma  )=\exp\bigl({-\frac{\gamma \tau }{2}}\bigr)$,
$L_1 ( \tau , \gamma  )=\exp\bigl({-\frac{\gamma \tau }{2}}\bigr) ( 1-\gamma \tau  )$, причём
\begin{equation}
\label{prosha:eq10}
\frac{dL_k  (\tau , \gamma  )}{d\tau }=-\gamma L_{k-1}^{ (1)}  ( \tau, \gamma  )-\frac{\gamma }{2}L_k  (\tau, \gamma )
\end{equation}
и
\begin{equation}
\label{prosha:eq11}
L_k^{ (1)}  (\tau , \gamma)=\sum\limits_{\nu =0}^k L_\nu  (\tau, \gamma ) .
\end{equation}
В (\ref{prosha:eq10}) полагается $L_0^{ ( 1 )}  ( \tau , \gamma  )=L_0( \tau , \gamma  )$.

Проведя ряд преобразований над выражениями (\ref{prosha:eq9})--(\ref{prosha:eq10}), получим рекуррентные
соотношения для интегралов$\displaystyle \int \psi _k  (\tau , \gamma )d\tau $
и~$\displaystyle \int \tau \psi _k  (\tau, \gamma )d\tau $:
\[
\int L_k  ( \tau , \gamma  )d\tau  =-\frac{2}{\gamma }L_k ( \tau , \gamma  )
-2\sum\limits_{\nu =0}^{k-1} \int L_\nu  ( \tau , \gamma  )d\tau ,
\]
\begin{multline*}
\int \tau  L_k  ( \tau , \gamma  )d\tau  =-\frac{k+1}{\gamma}
\int L_{k+1}  ( \tau , \gamma  )d\tau  + \\
+\frac{2k+1}{\gamma } \int L_k  ( \tau , \gamma  )d\tau  -\frac{k}{\gamma }\int
L_{k-1}  ( \tau , \gamma  )d\tau ,
\end{multline*}
где ${\displaystyle \int L_0  ( \tau , \gamma  )d\tau  }=-\frac{2}{\gamma}\exp\bigl({-\frac{\gamma \tau }{2}}\bigr)$.

Подобным образом для ортогональных функций Лежандра будем иметь следующие
рекуррентные соотношения:
\begin{equation}
\label{prosha:eq12}
{\rm Leg}_k ( \tau , \gamma  )=\frac{2k-1}{k} \bigl( 1-2\exp({-2\gamma \tau })  \bigr){\rm Leg}_{k-1}  ( \tau , \gamma  )-\frac{k-1}{k}{\rm Leg}_{k-2}  ( \tau , \gamma  ),
\end{equation}
\begin{multline}
\label{prosha:eq13}
 \frac{d\,{\rm Leg}_k  ( \tau , \gamma  )}{d\tau }=\frac{d\,{\rm Leg}_{k-2}  (\tau , \gamma  ) }{d\tau }-
\gamma \Bigl[
(2k+1) {\rm Leg}_k  ( \tau , \gamma  )-\\
-2 (2k-1){\rm Leg}_{k-1}  (\tau, \gamma  )
+ (2k-3){\rm Leg}_{k-2}  ( \tau , \gamma  ) \Bigr ],
\end{multline}
где
$${\rm Leg}_0  ( \tau , \gamma  )=\exp(-\gamma \tau ), \quad
{\rm Leg}_1  (\tau , \gamma  )=\bigl( 1-2\exp({-2\gamma \tau })  \bigr)\exp(-\gamma \tau );$$
$$\frac{d\,{\rm Leg}_0  ( \tau , \gamma  )}{d\tau }=-\gamma \exp(-\gamma \tau ), \quad
\frac{d\,{\rm Leg}_1  ( \tau , \gamma  )}{d\tau}=-\gamma \bigl( 1-6\exp(-2\gamma \tau )  \bigr) \exp(-\gamma \tau ).$$
Из выражений (\ref{prosha:eq12}), (\ref{prosha:eq13}) следуют искомые рекуррентные соотношения:
\begin{multline*}
\int {\rm Leg}_k  ( \tau , \gamma  )d\tau  =
\frac{2 (2k-1)}{2k+1} \int {\rm Leg}_{k-1}  ( \tau , \gamma  )d\tau - \\
- \frac{2k-3}{2k+1}\int {\rm Leg}_{k-2}  ( \tau , \gamma )d\tau
-\frac{1}{\gamma (2k+1)} \bigl[ {\rm Leg}_k  ( \tau, \gamma   )-{\rm Leg}_{k-2}  ( \tau , \gamma  ) \bigr ],
\end{multline*}
\begin{multline*}
\int \tau \,{\rm Leg}_k  ( \tau , \gamma  )d\tau  =\frac{2(2k-1)}{2k+1}
\int \tau {\rm Leg}_{k-1}  ( \tau , \gamma  )d\tau  - \\ \end{multline*}
\begin{multline*}
- \frac{2k-3}{2k+1}\int \tau {\rm Leg}_{k-2}  ( \tau , \gamma  )d\tau  -
\frac{1}{\gamma (2k+1)} \biggl[ \tau \bigl( {\rm Leg}_k  ( \tau , \gamma  )- {\rm Leg}_{k-2}  ( \tau , \gamma  )  \bigr)   - \\
- {\int {{\rm Leg}_k  ( \tau , \gamma  )d\tau }
+\int {{\rm Leg}_{k-2}  ( \tau , \gamma  )d\tau } }  \biggr],
\end{multline*}
где
\[
\begin{split}
 \int {\rm Leg}_0 ( \tau , \gamma  )d\tau  &=-\frac{1}{\gamma} \exp(-\gamma \tau ),\\
\int {\rm Leg}_1  ( \tau , \gamma  )d\tau  &=-\frac{1}{\gamma}\Bigl( 1-\frac23\exp(-2\gamma \tau )  \Bigr) \exp(-\gamma \tau );\\
\int \tau {\rm Leg}_0  ( \tau , \gamma  )d\tau  &=- \Bigl( \frac{\tau }{\gamma }+\frac{1}{\gamma ^2}  \Bigr)\exp(-\gamma \tau),\\
\int \tau {\rm Leg}_1  ( \tau , \gamma  )d\tau  &=-\Bigl( \frac{\tau }{\gamma }+\frac{1}{\gamma ^2}  \Bigr)\exp(-\gamma\tau )+2\Bigl(\frac{\tau }{3\gamma }+\frac{1}{9\gamma ^2}  \Bigr)\exp(-3\gamma \tau)
.
\end{split}
\]



Полученные аналитические выражения, представленные в~виде рекуррентных
соотношений, позволяют вычислять коэффициенты разложения высоких порядков
при реализации на ЭВМ.
При этом погрешность вычисления коэффициентов
разложения в~данном случае зависит лишь от шага дискретизации, являющегося
исходным параметром при обработке информационных массивов.

Заметим, что с учётом выражения (\ref{prosha:eq7}) возможна более точная оценка минимальной
погрешности аппроксимации (\ref{prosha:eq5}) при аналитическом взятии
соответствующего интеграла с~последующей подстановкой пределов интегрирования, а именно
\[
\Delta _{\min } =\sum\limits_{j=0}^{J_{\max } -1}
\int_{\tau _j}^{\tau _{j+1} }   ( a_j +b_j \tau )^2\mu  (\tau , \gamma)d\tau -
\sum\limits_{k=0}^m \beta _k^2  \| \psi _k  \|^2 .
\]


Сравним представленные методики определения коэффициентов разложения (\ref{prosha:eq2})
и~(\ref{prosha:eq8}) при проведении имитационного моделирования, состоящего в~построении
ортогональной модели нормированной корреляционной функции (НКФ) вида $\rho_x  ( \tau  )=\exp(-\lambda  | \tau  |)\cos \omega _0 \tau $
с~показателем колебательности $\mu =\omega _0 /\lambda =5$,
объёмом выборки $N=5000$, $\Delta \tau =0,0816$ и $J_{\max } =37$ с~помощью
ортогональных функций Лагерра и оценке погрешностей, соответствующих
выражениям (\ref{prosha:eq1}), (\ref{prosha:eq4})--(\ref{prosha:eq6}).
Заметим, что согласно РТМ~25~139--74~[4], имитационное моделирование проводилось по 29 экспериментам.

На рис. 1 представлены результаты оценки коэффициентов разложения $\hat \beta _{k,1} $ и $\hat \beta  _{k,2} $,
соответствующие выражению (\ref{prosha:eq6}), при заданном диапазоне изменения $m\in [0, 30]$ и~значении
параметра $\gamma =\sqrt {\lambda ^2+\omega _0 ^2} =4,899$ [1, 3].

Из рис. 1, {\sl б} видно, что при дальнейшем увеличении числа членов рядов
отклонения $\Delta _{\beta _k } ^2$ уменьшаются, и~величина этих отклонений
при прочих равных параметрах ниже более чем на порядок.
Отсюда следует, что вклад погрешности вычисления коэффициентов,
вызванной случайными отклонениями, в результирующую погрешность аппроксимации
значительно снижается.

На рис. 2 приведены квадратичные погрешности аппроксимации (\ref{prosha:eq1}) при оценке
коэффициентов разложения по различным методикам.


Из рис. 2, {\sl а} видно, что из-за убывания минимальной погрешности аппроксимации
(\ref{prosha:eq5}) погрешность вычисления коэффициентов разложения возрастает
(\ref{prosha:eq6}). Поэтому существует некое оптимальное значение параметра $m$, при котором
достигается минимум"=миниморум суммарной погрешности аппроксимации~[1].

В свою очередь, рис. 2, {\sl б} демонстрирует выполнение равенства Парсеваля~[3],
согласно которому результирующая погрешность аппроксимации (\ref{prosha:eq1}) уменьшается
с~увеличением $m$.

Следовательно, полученный результат позволяет строить ортогональные модели с
некоторой допустимой либо наперёд заданной погрешностью \linebreak \mbox{$\Delta \leqslant \Delta _{\text{доп}} $. }
По заданной погрешности $\Delta_{\text{доп}} $ определяется
необходимое число членов разложения, которое может быть достаточно большим.

Проведём сравнительный анализ широкого спектра ортогональных функций при
решении задачи построения ортогональной модели теоретической
НКФ вида $\rho _x  ( \tau  )=\exp(-\lambda  | \tau  |)\cos \omega _0 \tau $
с~показателем колебательности \mbox{$\mu =5$}, $\Delta \tau =0,0816$ и $J_{\max } =37$  с~использованием
предложенного подхода при одном~и том же числе членов разложения ряда $m=30$.

Как показали полученные результаты, значительных различий при построении
ортогональных функций в различных базисах не наблюдается.
Однако ортогональный базис Сонина"--~Лагерра, как частный случай функции Лагерра,
является более приоритетным по ряду причин.
Одна из таких причин "--- удобство выбора параметра масштаба $\gamma $.
Во-первых, параметр масштаба не зависит
от числа членов разложения ряда $m$, следовательно, нет необходимости
пересчёта $\gamma $ при изменении $m$.
Во-вторых, при большом значении $m$ область нахождения локальных оптимумов, близких к минимуму"=миниморумуму,
значительно расширяется.
Следовательно, квазиоптимальный алгоритм подбора
параметра масштаба дает значения, близкие к оптимуму, без усложнения
процедуры вычисления [5].
