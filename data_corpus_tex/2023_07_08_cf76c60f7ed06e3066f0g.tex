В нуклонном каскаде в результате одной реакции нуклон с энергией $E_{0}$, сталкиваясь с ядром, порождает два новых нуклона с энергиями $E^{\prime}$ и $E^{\prime \prime}$. Пусть

\[
w\left(E^{\prime} / E_{0}, E^{\prime \prime} / E_{0}\right) / E_{0}^{2}
\]

\begin{itemize}
  \item сечение этой реакции, $w\left(\varepsilon^{\prime}, \varepsilon^{\prime \prime}\right)=0$ при $\varepsilon^{\prime}+\varepsilon^{\prime \prime}>1$, и
\end{itemize}

\[
\alpha=\int_{0}^{1} d \varepsilon^{\prime} d \varepsilon^{\prime \prime} w\left(\varepsilon^{\prime}, \varepsilon^{\prime \prime}\right)
\]

\begin{itemize}
  \item интенсивность реакции (число реакций в единицу времени). Для производяшей функции
\end{itemize}

\[
G(\varepsilon, z ; t)=\sum_{n=0}^{\infty} P(\varepsilon, n ; t) z^{n}
\]

Я. у. ( $G$-уравнение) ветвящегося процесса, описывающего нуклонный каскад, имеет вид:

\[
\begin{gathered}
\frac{\partial}{\partial t} G(\varepsilon, z ; t)+\alpha G(\varepsilon, z ; t)= \\
=\int_{0}^{\infty} d \varepsilon^{\prime} d \varepsilon^{\prime \prime} w\left(\varepsilon^{\prime}, \varepsilon^{\prime \prime}\right) G\left(\varepsilon / \varepsilon^{\prime}, z ; t\right) G\left(\varepsilon / \varepsilon^{\prime \prime}, z ; t\right) .
\end{gathered}
\]

Здесь $n=\left(n_{1}, n_{2}\right), n_{i}=0,1,2, \ldots, z=\left(z_{1}, z_{2}\right), z^{n}=z_{1}^{n_{1}} z_{2}^{n_{2}}$ и $P(\varepsilon, n ; t)$ - вероятность того, что на глубине $t$ в вешестве имеется $n_{1}$ частиц с энергией большей $\varepsilon E_{0}$ и $n_{2}$ частиц с энергией менышей $\varepsilon E_{0}, P(\varepsilon, 0 ; t)=0$,

\[
\begin{gathered}
\sum_{n:|n|=N} P(\varepsilon, n ; t)=P\{\xi(t, \infty)=N\}, \\
|n|=n_{1}+n_{2} .
\end{gathered}
\]

При условии, что каскад порождается одной первичной частицей с энергией $E_{0}$, начальное условие для процесса имеет вид:

\[
P(\varepsilon, n ; 0)=\delta_{I n_{1}} \delta_{0 n_{2}} \theta(1-\varepsilon)+\theta(\varepsilon-1) \delta_{n_{1} 0} \delta_{n_{2} 1},
\]

то есть

\[
G(\varepsilon, z ; 0)=\theta(1-\varepsilon) z_{1}+z_{2} \theta(\varepsilon-1),
\]

$\theta(x)$ - функция Хевисайда.

Аналогичный смысл имеют и Я.у. для производяшей $G$-функции, описываюшей электрон-фотонный каскад, к-рый состоит из последовательности реакций образования электрон-позитронных пар и излучения протонов. Однако ввиду того, что каскад состоит из двух типов частиц, то для описания соответствующего ветвящегося процесса необходимо ввести двухкомпонентную функцию $P$ и соответственно двухкомпонентную $G$-функцию.
