\section{Введение}

В работе  исследуется нестационарная модель системы массового обслуживания с~одним сервером 
и~двумя классами требований, а~также одномерный ПРГ, по\-лу\-ча\-ющий\-ся из нее 
и~опи\-сы\-ва\-ющий чис\-ло требований в~исходной сис\-теме.

Для оценки скорости сходимости используется обобщенное понятие логарифмической нормы, 
введенное в~\cite{multid}. Для удобства напомним, как оно вводится. 
Рассматривается система   дифференциальных уравнений вида
\begin{equation} 
\label{ur0100}
\fr{d\vy}{dt}=H\vy(t)
\end{equation}
в пространстве $l_1$  в~предположении  существования и~единственности 
решения задачи Коши для любого начального условия~$\vy(0)$.

Тогда верна следующая оценка:
\begin{equation}
\fr{d \|y\|}{dt} = \sum\limits_i \fr{d |y_i|}{dt} \le \sum\limits_i\left(
h_{ii}|y_i|+\sum\limits_{j\neq i} |h_{ij}||y_j| \right) \le \beta^* \|y\|,
\label{lognorm1}
\end{equation}
 где
\begin{equation*}
\beta^*= \sup\limits_i\left(h_{ii}+\sum\limits_{j\neq i} |h_{ji}|\right).
%\label{lognorm2}
\end{equation*}

Отметим, что элементы~$h_{ij}$ матрицы~$H\hm=(h_{ij})$ могут зависеть как от времени~$t$, так и~от~$\vy(t)$.


 Из (\ref{lognorm1}) следует
\begin{equation*}
\|y(t)\| \le e^{\int\nolimits_0^t \beta^* \, du} \|y(0)\|. 
%\label{lognorm3}
\end{equation*}
При этом, если~$H$ является ограниченным при всех $t\hm\ge 0$ линейным оператором из~$l_1$ в~себя, 
$\beta^*(t)\hm=\gamma(H(t))$ совпадает с~логарифмической нормой~\cite{gz04, Zeifman1995}.
Таким образом,~$\beta^*(t)$ представляет собой обобщение логарифмической нормы 
для нелинейной системы уравнений.

В разд.~2 рассмотрено описание модели, в~разд.~3 и~4 
изучен процесс, описывающий число требований  в~системе, а~затем связанный с~ним одномерный процесс. 
В~разд.~\ref{chpr} рассмотрен пример, иллюстрирующий изучаемый подход.

\section{Оценки для процесса~{\boldmath{$X(t)$}}}
\label{ch5ne1a}

Возьмем два разных неотрицательных решения системы~(\ref{mainsys})   
$\vp^*(t)$ и~$\vp^{**}(t)$ с~единичной нормой. Тогда 
$$
\sum\limits_{i} (p^*_i(t)- p^{**}_i(t))= 0\,.
$$
 Это означает, что на решение системы не будет влиять изменение 
целой строки в~матрице~$A$ на одну и~ту же функцию.
Следовательно, оценку скорости сходимости можно свести к~изучению скорости сходимости системы
\begin{equation*}
\fr{d(\vp^*-\vp^{**})}{dt}=(A-C)\left(\vp^*-\vp^{**}\right).
%\label{mainsys2}
\end{equation*}
Здесь матрица $C$ состоит из одних нулей за исключением самой верхней 
строки, каждый элемент которой равен неотрицательной~$c$.

Для использования логарифмической нормы введем диагональную матрицу 
$$
D=\mathrm{diag}\left(1,k_1,k_1,k_1 k_2,k_1 k_2, k_1 k_2, k_1 k_2, k_1 k_2 k_3, \ldots\right).
$$ 
На главной диагонали произведения $k_1  \cdots k_s$ встречаются~$2^s$~раз.

\textbf{Найдем условия нуль-эргодичности.}

Для этого возьмем в~$D$ все $k_i\hm<1$ и~$c\hm=0$.

Если взять все $k_i$ одинаковыми и~равными~$k$, получим:
\begin{equation*}
\alpha(t)=\min \alpha_i(t)=\min\left( - (k-1)(\la_1+\la_2)- 
\left(\fr {1}{k}-1\right)\max(\mu_1,\mu_2)\right).
\end{equation*}

Очевидно, что если $\max(\mu_1,\mu_2)\hm<\la_1+\la_2$, то всегда можно подобрать $k\hm<1$, при 
которых~$\alpha$ положительно.
%
Отсюда получаем теорему.

Для этого возьмем в~$D$ все $k_i\hm>1$.

\section{Сведение к~одномерному процессу рождения и~гибели}
\label{ch5nel1p}

Рассмотрим теперь новый процесс $\tilde{X}(t)$, 
определяющий  число требований в~системе. В~отличие от~$X(t)$ в~проекции теряется информация 
о~порядке требований в~очереди и~учитывается только число требований в~системе. 
Для исследования будет применяться подход из статьи~\cite{multid}, где было показано,
 что при фиксированном начальном условии интенсивности проекции для многомерного 
 ПРГ при больших значениях времени можно рассматривать как  соответствующие 
 характеристики для одномерных ПРГ. Там же получены условия нуль-эр\-го\-дич\-ности, 
 слабой эргодичности и~оценки сходимости для полученных  одномерных процессов. Тео\-ре\-мы, приведенные 
 в~\cite{multid}, справедливы и~в рассматриваемой ситуации  для одномерного процесса, 
 получающегося для модели $M_t/M_t/1$ с~двумя  классами требований.


Из соответствующих уравнений прямой системы Колмогорова получаем
$$
\fr{d(p_0)}{dt}= -\left(\la_1+\la_2\right)p_0+\mu_1p_1+\mu_2p_2,
$$
откуда
$$
\fr{d(p_0)}{dt}= -\left(\la_1+\la_2\right)p_0+\fr{\mu_1p_1+\mu_2p_2}{p_1+p_2}\left(p_1+p_2\right).
$$
Далее аналогично:
\begin{multline*}
\fr{d(p_1+p_2)}{dt}= 
\left(\la_1+\la_2\right)p_0-\left(\la_1+\la_2+\mu_1\right)p_1-
\left(\la_1+\la_2+\mu_2\right)p_2+{}\\
{}+\mu_1p_3+\mu_1p_4+\mu_2p_5+\mu_2p_6;
\end{multline*}

\vspace*{-12pt}

\noindent
\begin{multline*}
\fr{d(p_1+p_2)}{dt}= \left(\la_1+\la_2\right)p_0-
\fr{(\la_1+\la_2+\mu_1)p_1+(\la_1+\la_2+\mu_2)p_2}{p_1+p_2}(p_1+p_2)+{}\\
{}+
\fr{\mu_1p_3+\mu_1p_4+\mu_2p_5+\mu_2p_6}{p_3+\cdots+p_6}\left(p_3+\cdots+p_6\right).
\end{multline*}
%
И так далее складываем по~$2^s$ уравнений.

Обозначим
\begin{align*}
\tilde{\mu}_1&=\fr{\mu_1p_1+\mu_2p_2}{p_1+p_2}\,;
\\
\tilde{\mu}_2&=\fr{\mu_1p_3+\mu_1p_4+\mu_2p_5+\mu_2p_6}{p_3+\cdots+p_6}\,.
\end{align*}
%
Аналогично определяем остальные~$\tilde{\mu}_k$.
Обозначим $\tilde{\la}_k\hm=\la_1\hm+\la_2$ и~$$
x_0=p_0;\enskip  x_1=p_2+p_3;\enskip x_2=p_4+p_5+p_6+p_7;\ \  \ldots
$$
%
Получим систему %аналогичную (\ref{ur0101})
\begin{equation*}
\fr{d\vx}{dt}=\tilde{A}\vx(t),
\end{equation*}
где
    \begin{equation*}
\tilde{\la}_i=\la_1+\la_2\,; \quad 
\tilde{\mu}_i = \fr{\mu_1\sum\nolimits_{k=2^i-1}^{2^i+2^{i-1}-2}p_i +
\mu_2 \sum\nolimits_{k=2^i+2^{i-1}-1}^{2^{i+1}-2}p_i}{\sum\nolimits_{k=2^i-1}^{2^{i+1}-2}p_i}\,;
\end{equation*}
соответствующий процесс обозначим~$\tilde{X}(t)$.

Положим
\begin{equation*}
l\leq \tilde{\lambda}_k \leq L\,, \quad m\leq \tilde{\mu}_k \leq
M
\end{equation*}
для любых $k$, $t$ и~любого начального условия.

Получим теоремы~5 и~6, аналогичные которым доказаны в~\cite{multid}.
%\ref{ddddmuTh1} и~\ref{ddddmuTh2}.


{\bf 1.} Пусть  $\tilde{X}(t)$ имеет счетное число состояний
и
\begin{equation}
M < l\,. 
\label{ddddmu2m08}
\end{equation}

Пусть $\sigma =\sqrt{M/l}<1$,  $\delta_n\hm=\sigma ^n$, $n\hm\geq 0,$
$\tilde{x}_n\hm=\delta_n x_n$ и~$\tilde{\vx}\hm=\left(\tilde{x}_0,\tilde{x}_1,\dots\right)$. Пусть
$\Lambda \hm= \mathrm{diag}\left(\delta_0, \delta_1, \dots \right)$.

\smallskip

\noindent
\textbf{Теорема~5.}\
%\label{ddddmu2Th1}
 \textit{Пусть верно}~(\ref{ddddmu2m08}). \textit{Тогда
$\tilde{X}(t)$ нуль-эргодичен и~верны оценки}
\begin{align*}
\|\tilde{\vx}(t)\| &\le e^{ -\alpha^*  t} \|\tilde{\vx}(0)\|\,;
\\
\Pr \left( \tilde{X}(t)\leq n/\tilde{X}_j(0)=k\right) &\leq \sigma ^{k-n}
e^{-\alpha^*t}.
\end{align*}
\textit{Здесь}
\begin{equation*}
\Pr \left( \tilde{X}(t) > n/\tilde{X}(0)=k\right) >1 - \sigma ^{k-n}
e^{-\alpha^*t}  
\end{equation*}
\textit{и} $ \Pr \left( \tilde{X}(t)\hm >
n/\tilde{X}(0)=k\right) \to 1$  \textit{при $t \to \infty$  для  любых} $n$ \textit{и}~$k$.


\smallskip

{\bf 2.}  Пусть
\begin{equation}
L < m\,, \quad \alpha_*= l+m -2\sqrt{LM} > 0\,. 
\label{ddddmu2m04}
\end{equation}

\textbf{Теорема~6.}\
\textit{Пусть верно}~(\ref{ddddmu2m04}). \textit{Тогда
$\tilde{X}(t)$ слабо эргодичен и~верна оценка}
\begin{equation}
\|D{\bf w}(t)\| \le e^{- \alpha_* t}\|D{\bf w}(0)\|
\label{weakergbound2}
\end{equation}
\textit{для любых $ t  \hm\ge 0$ и~любого соответствующего начального условия}.

\section{Численный пример}
\label{chpr}

Пусть интенсивности имеют вид:
 $$
 \lambda_1(t)=1+\cos (2\pi t);\ \lambda_2(t)
=5+\sin (2\pi t);\ \mu_1(t)=11+\sin (2\pi t);\ \mu_2=9\,.
$$
%
Применить теорему~2 для получения оценок скорости сходимости затруднительно, 
так как нужно подбирать~$k$, очень близкое к~единице. Это связано с~тем, что $\la_1\hm+\la_2$ 
не сильно отличается от $\min(\mu_1,\mu_2)$, при этом по  формуле~(\ref{eqtmp2}) получается~$\alpha(t)$, 
почти равная нулю.

Применим теорему~6 для получения оценок скорости сходимости <<проекции>>.

Подбираем $l_1$, $L_1$, $m_1$ и~$M_1$, при которых верно   $l_1\hm\le\tilde{\la}
\hm\le L_1$ и~$m_1\hm\le \tilde{\mu}\hm\le M_1$.

Положив $\beta\hm= \sqrt{{M_1}/{L_1}} \hm= \sqrt{6}$, получаем 
$$
\alpha_* =l_1+m_1-2\sqrt{L_1M_1}\ge 10-4\sqrt 6\,.
$$

Получаем оценку
\begin{equation*}
\|D{\bf w}(t)\| \le e^{- \alpha_* t}\|D{\bf w}(0)\|
\end{equation*}
для любых $ t  \hm\ge 0$ и~любого соответствующего начального условия.
%
Здесь $D$~--- треугольная матрица c $d_{k+1}\hm=\beta^k$, $k\hm\ge 0 $.


На рис.~3 и~4 приведены 
графики для усеченной системы с~состояниями от~$0$ до $2^7-2$.
Графики строились для двух разных начальных условий. В~одном случае $p_0\hm=0{,}95$, 
остальные вероятности равны между собой. В~другом случае $p_0\hm=0{,}05$, 
остальные вероятности также равны между собой.  <<Проекция>> описывает число 
требований в~системе, и~получается ПРГ с~периодическими интенсивностями и~семью состояниями. 
В~частности, $\tilde{\mu}_1$, $\tilde{\mu}_2$ и~$\tilde{\mu}_3$ приведены  
соответственно  на рис.~4. 
Можно заметить, что изначально интенсивности сильно отличаются от периодических, 
но затем практически совпадают друг с~другом и~мало отличаются от периодических,
причем они заключены между~$\mu_1$ и~$\mu_2$.

\Abste{The author deals with a nonstationary queuing model $M_t/M_t/1$ 
with one server and two different types of requests. For this model, the author obtains 
a~one-dimensional birth and death process that describes the number of requirements
 in the original system. By applying the standard method of the logarithmic norm of the 
 operator of a~linear function, corresponding estimates for the rate of convergence and 
 ergodicity are obtained. A~numerical example with exact given values of intensities showing 
 the application of the studied approach is constructed and corresponding graphic 
 illustrations are provided. The author uses the general 
 algorithm to build graphs, it is associated with solving the Cauchy problem for 
 the forward Kolmogorov system on the corresponding interval which has already been 
 used by the authors in previous papers.}
