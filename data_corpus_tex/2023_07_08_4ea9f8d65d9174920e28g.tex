\[
\sum_{n=0}^{\infty} c_{n} x^{n}=\frac{1}{2-(1-x)^{-1}}
\]

следовательно $c_{n}=2^{n-1}, n>0$.

В случае $X=\stackrel{B}{B}$ число $c(x, y)=c_{n}$ есть число упорядоченных разбиений $n$-элементного множества, $|x \backslash y|=n$ и

\[
\sum_{n=0}^{\infty} \frac{c_{n}}{n !} x^{n}=\frac{1}{2-e^{x}}
\]

В случае $X=D$ число $c(x, y)=c_{n}$ есть число упорядоченных разложений на множители $n=y / x$. Следовательно,

\[
\sum_{n=1}^{\infty} \frac{c_{n}}{n^{s}}=\frac{1}{2-\zeta(1)}
\]

ПЕРИОД ф у н к ц и и $f(x)$ - число $T \neq 0$ такое, что при любом $x \in X \subset \mathbb{R}$ (или $X \subset \mathbb{C}$ ) числа $x-T$ и $x+T$ также принадлежат множеству $X$ и выполіняется равенство

\[
f(x+T)=f(x)
\]

Числа $\pm n T$, где $n-$ любое натуральное число, также являются П. функции $f(x)$. У функции $f=$ const на оси или на плоскости любое число $T \neq 0$ будет П.; для функции Дирихле

\[
D(x)=\left\{\begin{array}{l}
1, \text { если } x \text {-рациональное, } \\
0, \text { если } x \text {-иррациональное, }
\end{array}\right.
\]

любое рациональное число $T \neq 0$ будет П. Если функция $f(x)$ имеет период $T$, то функция $\psi(x)=f(a x+b)$, где $a$ и $b$ - постоянные и $a \neq 0$, имеет период $\frac{T}{a}$. Если действительная функция $f(x)$ с действительным аргументом непрерывна на $X$ (и не равна тождественно постоянной), то она имеет наименыший период $T_{0}>0$ и всякий другой действительный П. кратен $T_{0}$. Существуют функции с комплексным аргументом, у к-рых имеются два некратных с мнимым частным П.; таковы, напр., эллиптические бункции.
