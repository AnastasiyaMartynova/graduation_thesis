Для решения П. т. у. с переменными коэфффициентамі применяются однородные консервативные разностные схемы, выражающие на сетке законы сох ранения, присупие псходному дифференциальному уравнснию (см. [1], [5]). При шостроении разностных схем для П. т. У. с переменными коэффициентами шрименяются методы: баланса, вариационный, конечных әлементов. Напр., для уравнения

\[
\frac{\partial u}{\partial t}=\frac{\partial}{\partial x}\left(k(x, t) \frac{\partial u}{\partial x}\right)+f(x, t), 0<x<l, t>0,
\]

используются разностные схемы с весами

\[
y_{t, i}^{n}=\left(a\left(\sigma y^{n+1}+(1-\sigma) y^{n}\right)_{\bar{x}}\right)_{x, i}+\varphi_{i}^{n},
\]

где

\[
a=a_{i}^{n}=k\left(x_{i}-0,5 h, t_{n}+0,5 \tau\right) .
\]

Доказана сходимость и получены оценки погрешности однородных консервативных разностных схем для П. т. у. как в случае непрерывных, так и в случае разрывных коэффициентов (см. [1]).

Для решения систем уравнений параболич. типа, содержащих одну пространственную переменную, применяются те же разностные схемы, что и для одного уравнения. Вектор $y^{n+1}$ решения на новом слое находится матричной факторизации методом.

При решении квазиливейного П. т. у. используются неявныс абсолютно устойчивые разностные схемы. Решение $y^{n+1}$ разностного уравнения находится итерационным методом с использованием чрогонки. Наир., для уравнения

\[
\frac{\partial u}{\partial t}=\frac{\partial}{\partial x}\left(k(u) \frac{\partial u}{\partial x}\right), k(u)>0,
\]

применяют тисто неявную разностную схему

\[
\begin{gathered}
y_{t, i}^{n}=\left(a\left(y_{i}^{n+1}\right) y_{\bar{x}}^{n+1}\right)_{x, i}, \\
a\left(y_{i}^{n+1}\right)=0,5\left(k\left(y_{i}^{n+1}\right)-\vdash k\left(y_{i-1}^{n+1}\right)\right),
\end{gathered}
\]

к-рую решают с помощью итерационного метода ( $s-$ номер итерации):

$y_{i}^{(s+1)}=y_{i}^{n}+\tau\left(a\left(y_{i}^{(s)}\right) y_{\bar{\chi}}^{(s+1)}\right)_{x, i}, s=0,1, \ldots, m$,

\[
y_{i}^{(0)}=y_{i}^{n}, \quad y_{i}^{(m+1)}=y_{i}^{n+1} \text {. }
\]

Решение $y_{i}^{(s+1)}$ на каждой итерации находится методом прогонки. При решении нелинсйного П. т. у. нашли также применение схемы, основанные на идее Рунге Кутта метода. Так, для уравнения (3) используется двухәтапный метод

\[
\begin{gathered}
y_{i}^{n+1 / 2}=y_{i}^{n}+0,5 \tau\left(a\left(y_{i}^{n}\right) y_{\bar{x}}^{n+1 / 2}\right)_{x, i}, \\
y_{i}^{n+1}=y_{i}^{n}+0,5 \tau\left(a\left(y_{i}^{n+1 / 2}\right)\left(y^{n+1}+y^{n}\right)_{\bar{x}}\right)_{x, i} .
\end{gathered}
\]

Тестпрование іл проверка качества разностных схем для нелинейного П. т. У. проводится путем сравневия с точными автомодельными решениями, такими, напр., как решение тина температурной волны (см. [6]).

При решении многомерного П. т. у. используются переменных направлений методы, к-рые позволяют свести решение многомерной задачи к решению послөдовательности одномерных задач (см. [1], [7]-[10]). Предложено и исследовано значительное число абсолютно устойчивых алгоритмов переменных направлений. Эти алгоритмы являются экономичными в том смысле, что число арифметич. действий, необходимых для вычисления решения на новом временно́м слое $t_{n+1}$, имеет порядок числа узлов пространственной сетки. Ниже рассмотрен пример схемы переменных направлевий для уравнения

\[
\frac{\partial \|}{\partial t}=\frac{\partial^{2} u}{\partial x_{1}^{2}}+\frac{\partial^{2} u}{\partial x_{2}^{2}},\left(x_{1}, x_{2}\right) \in G, t>0
\]

в прямоугольнике $G\left\{0<x_{\alpha}<l_{\alpha}, \alpha=1,2\right\}$. Вводится сетка

$x_{i j}=\left(x_{1}^{(i)}, x_{2}^{(j)}\right), x_{1}^{(i)}=i h_{1}, i=0,1, \ldots, N_{1}, \quad h_{1} N_{1}=l_{1}$, $x_{2}^{(j)}=j h_{2}, j=0,1, \ldots, N_{2}, h_{2} N_{2}=l_{2}$

и обозначения

\[
\begin{gathered}
y_{i j}^{n}=y\left(x_{i j}, t_{n}\right), y_{i j}^{n+1 / 2}=y\left(x_{i j}, t_{n}+0,5 \tau\right), \\
\Lambda_{1} y_{i j}^{n}=\left(y_{i+1, j}^{n}-2 y_{i, j}^{n}+y_{i-1, j}^{n}\right) / h_{1}^{2}, \\
\Lambda_{2} y_{i j}^{n}=\left(y_{i, j+1}^{n}-2 y_{i j}^{n}+y_{i, j-1}^{n}\right) / h_{2}^{2} .
\end{gathered}
\]

Уравнение (4) решается с помощью следующеӥ разностной схемы

\[
\begin{aligned}
& \frac{y_{i j}^{n+1 / 2}-y_{i j}^{n}}{0,5 \tau}=\Lambda_{1} y_{i j}^{n+1 / 2}+\Lambda_{2} y_{i j}^{n}, \\
& \frac{y_{i j}^{n+1}-y_{i j}^{n+1 / 2}}{0,5 \tau}=\Lambda_{1} y_{i j}^{n+1 / 2}+\Lambda_{2} y_{i j}^{n+1} .
\end{aligned}
\]

Эти уравнения записываются при $i=1, \ldots, N_{1}-1$, $j=1, \ldots, N_{2}-1$ и доопределяются соответствующими граничными условиями. Из первого уравнения прогонкой по направлению $x_{1}$ для каждого $j=1,2, \ldots, N_{2}-1$ находится $y_{i j}^{n+1 / 2}$, а затем из второго уравнения прогонкой по направлению $x_{2}$ для каждого $i=1,2, \ldots$, $N_{1}-1$ находится $y_{i j}^{n+1}$. Таким образом, вычислительный алгоритм состоит в последовательном применениі одномерных прогонок.

Теоретич. основой построения и исследования экономичных разностных схем для многомерного П. т. у. является метод суммарной аппрокскмации (см. [1], [8], [9]). Обобщением методов переменных направлений явились аддитивные экономичные схемы с ураввениями на графах и векторные схемы (см. [11]).

В случае нерегулярных пространственных сеток разностные схөмы для П. т. у. строятся методом конечных әлементов и методом баланса (см. [12]).

Для решения сеточных уравнений, возникающих при аппроксимации многомерного П. т. У. неявными разностными схемами, применяются эффективные прямые и итерациоввые методы, разработанные для эллиптических разностных краевых задач: метод разделения переменных, использующий алгоритм быстрого дискретного преобразования Фурье, метод циклич. редукции, попеременно-треугольный итерациовный метод и др. (см. [13]).
