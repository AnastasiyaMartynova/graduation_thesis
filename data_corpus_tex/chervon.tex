\Section[n]{Введение}
Вопрос формирования и преобладания полей тёмного сектора вызывает особый интерес и~в~различных моделях трактуется с~различных теоретических позиций.
Как правило, поле тёмной энергии считается преобладающим последние 5~млрд лет, что приводит к~ускоренному расширению на современном этапе, замеченному в 1998~году.
Стандартная модель не может объяснить природу тёмного вещества, преобладающего во Вселенной.
Также актуальной проблемой наблюдательной космологии является ускоренное расширение Вселенной, для объяснения которого за последнее десятилетие построено большое количество теоретических моделей, среди которых присутствуют и~модели с~фантомными полями. 
Фантомные поля по отдельности или во взаимодействии с~другими полями тёмного сектора используются многими авторами для построения космологических моделей~\cite{chervon:cst}.

Рассмотренная в~настоящей работе модель с~тёмной энергией, представленной фантомными скалярными полями, приводит к~космологическим решениям на инфляционной стадии развития Вселенной (в~период её ускоренного расширения).

Фантомное поле является скалярным полем, имеет отрицательную кинетическую энергию и~описывается уравнением состояния $ w=p / \rho $. 
Для разных сред параметр уравнения состояния $w$ имеет разное значение. 
По известному $w$ мы можем идентифицировать какое"=либо из полей тёмного сектора.
Фантомное поле имеет уравнение состояния $ w \leq -1$, при котором плотность среды со временем увеличивается,
антигравитация возрастает, Вселенная будет ускоренно расширяться и~скорость расширения достигнет бесконечной величины за конечное время "--- произойдет Большой Разрыв (Big Rip).


Лагранжиан фантомного поля имеет вид~\cite{chervon:fks,chervon:wald}%
\begin{equation}\label{equ:cher:L_ph}
{\cal L}_{ph} = -\frac12 \phi_{\bigcom \mu} \phi^{\bigcom \mu} - V(\phi).%
\end{equation}
%
Действие для фантомного поля записывается следующим образом: %
\begin{equation} \label{equ:cher:S-ph} %
S_{ssf} = \int d^4x \sqrt{-g} \left( \,\frac{R}{2\kappa}+
{\cal L}_{ph}  \right).%
\end{equation}
%

Будем рассматривать фантомное поле $ \phi $ во Вселенной с
пространственно"=плоской метрикой Фридмана"--~Робертсона"--~Уокера с~линейным элементом 
$ds^2=dt^2-a^2(t)d\vec{r}{}^2$, где $ a(t) $ "--- масштабный фактор, 
$\vec{r}$ "--- радиус"=вектор в~пространстве координат. 
Масштабный фактор характеризует пространственный размер Вселенной на конкретном временном этапе.
Тензор энергии"=импульса (ТЭИ) имеет вид
$ T^{\mu}_{\nu} = {\rm diag} (\rho,-p,-p,-p) $, где плотность энергии
$ \rho $ положительна, а давление $ p $ отрицательно. 
Предполагая, что скаляное поле $ \phi $ зависит только от космологического времени $ t $, имеем
\begin{equation} \label{equ:cher:pro} %
\rho = -\frac12 \dot{\phi}^2 + V(\phi), \quad p = -\frac12 \dot{\phi}^2 - V(\phi),%
\end{equation}
т.\,е. мы рассматриваем динамическую эволюцию скалярного поля (здесь и~далее точка наверху означает производную по времени $t$).

Варьируя действие (\ref{equ:cher:S-ph}) по полю $ \phi $, получаем динамическое уравнение фантомного поля~\cite{chervon:fks}:
\begin{equation} \label{equ:cher:F}
\ddot {\phi}-3H(t)\dot {\phi} -\frac{\partial V(\phi)}{\partial \phi}=0,
\end{equation}
которое вместе с уравнениями Эйнштейна~\cite{chervon:wald} для фантомного поля
\begin{equation} \label{equ:cher:E}
H^2(t)=\frac{8\pi G}{3} \left(-\frac12 \dot{\phi}^2+V(\phi)\right) ,\quad
\dot{H}(t) = 4\pi G \dot{\phi}^2%
\end{equation}
образует самосогласованную систему динамических уравнений.
Здесь $G$ "--- гравитационная постоянная;
$ H(t) $ "--- параметр Хаббла, связывающий скорость удаления космологического объекта с~его расстоянием до наблюдателя. 
Параметр Хаббла связан с масштабным фактором $a(t)$ соотношением  $ H(t)  =  \dot{a}(t)/a(t) $. 
Уравнения записаны в~используемой в~космологии естественной системе единиц, в которой $ c = \hbar = 1$.

На сегодняшний день существует небольшое количество решений для фантомных полей, в~основном эти решения приближённые, так как получены численно. 
Поэтому задача поиска точных решений в~этой области является актуальной.

\Section{Метод суперпотенциала для фантомных полей}
Точные решения системы уравнений (\ref{equ:cher:F}) и~(\ref{equ:cher:E}) получить  достаточно сложно.
Эффективным при выполнении этой задачи является метод суперпотенциала в~космологии.
Суперпотенциал для фантомного поля строится по аналогии с методом построения для обычного скалярного поля~\cite{chervon:cs09ir}. 
Определяем суперпотенциал $\Upsilon $ как
\begin{equation*} %
\Upsilon (\phi)=V(\phi)-\frac12 U^2(\phi), \qquad U(\phi)=\dot\phi;%
\end{equation*}
тогда уравнение фантомного поля принимает вид
\begin{equation*}
 3H(t)U(\phi)+\frac{\partial \Upsilon(\phi)}{\partial \phi} =0.
\end{equation*}
Физический потенциал $V$ выражается через суперпотенциал $\Upsilon$ следующим образом:
\begin{equation} \label{equ:cher:3}
V(\phi) = \Upsilon (\phi)+\frac12 U^2(\phi).
\end{equation}
Математически такая подстановка означает замену переменных в~исходном полевом уравнении (\ref{equ:cher:F}).
Далее можно получить выражение для суперпотенциала в~квадратурах:
\begin{equation} \label{equ:cher:1}
\Upsilon (\phi)=\frac{3}{4M_P^2}\left(\int U(\phi)d\phi\right)^2,
\end{equation}
где $ M_P $ "--- масса Планка, в космологии $1/M_P^2 = 8 \pi G $.
Уравнения Эйнштейна (\ref{equ:cher:E}) можно привести к виду
\begin{eqnarray} \label{equ:cher:2}
H^2(t)=\frac{1}{3M_P^2}\Upsilon (\phi), \quad
H(t)=\frac{1}{2M_P^2}\int U(\phi)d\phi.
\end{eqnarray}

Теперь можно продолжить поиск решений с~заданным типом эволюции фантомного поля.
Рассмотрим несколько случаев, отличающихся видом зависимости скалярного поля $ \phi $ от времени:
будем задавать вид зависимости $ \phi(t) $ и путём подстановки его в~выражения (\ref{equ:cher:3})--(\ref{equ:cher:2}) получать соответствующее космологическое решение.

Для логарифмической эволюции фантомного поля $ \phi = A \ln (\lambda t) $
($A$, $\lambda$ "--- произвольные постоянные) из выражения (\ref{equ:cher:1}) находим 
\begin{equation*}
\Upsilon= \frac{3}{4M_p^2}\left(C_1-\frac{A^2}{t}\right)^2.
\end{equation*}
Далее находим параметр Хаббла и масштабный фактор, используя (\ref{equ:cher:2}):
\begin{equation*}
H=\frac{1}{2M_p^2}\left(C_1-\frac{A^2}{t}\right),\quad a(t)=C_2t^{-\frac{A^2}{2M_p^2}}e^{\frac{C_1}{2M_p^2}t}.
\end{equation*}
Здесь $C_1,$ $C_2$ "--- постоянные интегрирования. 
Знание масштабного фактора даёт возможность описать геометрию пространства"=времени.
Затем из соотношения (\ref{equ:cher:3}) находим физический потенциал:
\begin{equation*}
V(\phi)=\frac{3}{4M_p^2}\left(C_1-A^2\lambda
e^{-\phi/A}\right)^2+\frac{A^2\lambda^2}{2}e^{-2\phi/A}.
\end{equation*}
Далее можно исследовать динамику полученного решения, найти кинетическую энергию фантомного поля, рассмотреть его уравнение состояния, которое будет иметь такой вид:
\begin{equation} \label{equ:cher:eos}
w=\frac{K-V(\phi)}{K+V(\phi)}.
\end{equation}
Здесь $K$ "--- кинетическая энергия фантомного поля; она отрицательна, поскольку $ K = - \dot{\phi}^2 /2 <0 $.

Приведём несколько решений для разного вида зависимости $\phi(t)$, полученных аналогичным образом.
Решение для степенной эволюции фантомного поля $ \phi =A t^l $ ($l$ "--- постоянная, $ l\neq 0 $, $ l\neq 1/2 $):
\begin{gather*}
\Upsilon=\frac{3}{4M_p^2}\left(C_1 +\frac{A^2l^2}{2l-1}t^{2l-1}\right)^2,\\
H=\frac{1}{2M_p^2}\left(C_1 +\frac{A^2l^2}{2l-1}t^{2l-1}\right), \quad 
a(t)= \sqrt{\frac{A^2l}{2(2l-1)M_p^2}t^{2l}+\frac{C_1}{M_p^2}+C_2},\\
V(\phi)=\frac{3}{4M_p^2}\left(C_1 +\frac{A^2l^2}{2l-1} \left(\frac{\phi}{A}\right)^{\frac{2l-1}{l}}\right)^2+ \frac{1}{2}A^2l^2 \left(\frac{\phi}{A}\right)^{\frac{2l-2}{l}}.
\end{gather*}
%
В случае $l=1/2$ получим:%
\begin{gather*}
\Upsilon=\frac{3}{4M_p^2}\left(C_1+\frac{A^2}{4}\ln t\right)^2,\\
H=\frac{1}{2M_p^2}\left(C_1 +\frac{A^2}{4}\ln t\right), \quad 
a(t)=C_2 e^{B_1t}t^{\frac{A^2}{8M_p^2}t},\quad B_1=\frac{1}{2M_p^2}\left(C_1-\frac{A^2}{4}\right),\\
V(\phi)=\frac{3}{4M_p^2}\left(C_1 + \frac{A^2}{2}
\ln\left(\frac{\phi}{A}\right)\right)^2+\frac{A^4}{8\phi^2}.
\end{gather*}
Это решение очень интересное и, насколько известно авторам, оно никогда не рассматривалось в~литературе.


Решение для экспоненциальной эволюции фантомного поля $ \phi = A e^{-\lambda t} $:
\begin{gather}
\notag
% \label{equ:cher:exp1}%
\Upsilon=\frac{3}{4M_p^2}\left(C_1
-\frac{A^2\lambda}{2}e^{-2\lambda t}\right)^2,\\
\notag
% \label{equ:cher:exp2}%
 H=\frac{1}{2M_p^2}\left(C_1 -\frac{A^2\lambda}{2}e^{-2\lambda t}
\right),\quad  a(t)=C_2 e^{\frac{C_1}{2M_p^2}t}\exp \left(\frac{A^2}{8M_p^2}e^{-2\lambda t}\right),
\\
 \label{equ:cher:exp3}%
 V(\phi)=\frac{3}{4M_p^2}\left(C_1
-\frac{\lambda}{2}\phi^2\right)^2+\frac{\lambda^2}{2}\phi^2.
\end{gather}


Решение для эволюции фантомного поля типа $ \phi=A\ln \left(\th (\lambda t)\right) $:
%
\begin{gather*}
\Upsilon= \frac{3}{4M_p^2}\left(C_1-A^2\lambda\left(\th \lambda t+\frac{1}{\th \lambda t}\right)\right)^2,\\
H=\frac{1}{2M_p^2}\left(C_1-A^2\lambda\left(\th \lambda t+\frac{1}{\th \lambda t}\right)\right),\\
a(t)= \sqrt{2C_1t+C_2-\frac{A^2}{M_p^2} \ln\left( \frac{e^{2\lambda t}-e^{-2\lambda t}}{4} \right)},\\
V(\phi)=\frac{3}{4M_p^2}\left(C_1-2A^2\lambda \ch \frac{\phi}{A}\right)^2
-2A^2\lambda^2 \sh^2 \frac{\phi}{A}.
\end{gather*}


Решение для эволюции фантомного поля типа $ \phi=A\ln \left(\tg (\lambda t)\right) $:
\begin{gather*}
\Upsilon= \frac{3}{4M_p^2}\left(C_1+A^2\lambda\left(\tg \lambda t-\frac{1}{\tg \lambda t}\right)\right)^2,\\
H=\frac{1}{2M_p^2}\left(C_1+A^2\lambda\left(\tg \lambda t-\frac{1}{\tg \lambda t}\right)\right),\\
a(t)= \sqrt{2C_1t+C_2+\frac{A^2}{M_p^2}\ln\left(\tg \lambda t+\frac{1}{\tg \lambda t}\right)},\\
V(\phi)=\frac{3}{4M_p^2}\left(C_1+2A^2\lambda \sh \frac{\phi}{A}\right)^2
+2A^2\lambda^2 \ch^2 \frac{\phi}{A}.
\end{gather*}




Решение для эволюции фантомного поля типа $ \phi=A \sh^{-1} (\lambda t) $:
%
\begin{gather*}
%
\Upsilon= \frac{3}{4M_p^2}\left(C_1-\frac{A^2\lambda}{3}\bigl(\ch \lambda t(\ch^2 \lambda t +2)\bigr)\right)^2,\\
H=\frac{1}{2M_p^2}\left(C_1-\frac{A^2\lambda}{3}\bigl(\ch \lambda t(\ch^2 \lambda t +2)\bigr)\right),\\
a(t)= \sqrt{2C_1t+C_2+\frac{A^2}{3M_p^2}\left(\frac{2e^{2\lambda t}}{(e^{2\lambda t}-1)^2}
+\ln\left(\frac{2}{e^{2\lambda t}-1}\right)+\lambda t\right)},\\
V(\phi)=\frac{3}{4M_p^2}\left(C_1-\frac{\lambda}{3A}\phi^3\left(1+\frac{A^2}{\phi^2}\right)^{3/2}\right)
+\frac{\lambda^2}{2A^2}\phi^4\left(1+\frac{A^2}{\phi^2}\right).
%
\end{gather*}




Решение для эволюции фантомного поля типа $ \phi=A \sin^{-1} (\lambda t) $:
%
\begin{gather*}
%
\Upsilon= \frac{3}{4M_p^2}\left(C_1-\frac{A^2\lambda}{3}\ctg^3 \lambda t\right)^2,\\
H=\frac{1}{2M_p^2}\left(C_1-\frac{A^2\lambda}{3}\ctg^3 \lambda t\right),\\
a(t)= \sqrt{2C_1t+C_2+\frac{A^2}{6M_p^2}(\ctg^2
\lambda t+2\ln(\sin \lambda t))},\\
V(\phi)=\frac{3}{4M_p^2}\left(C_1-\frac{\lambda}{3A}\phi^3\left(1-\frac{A^2}{\phi^2}\right)^{3/2}\right)^2
+\frac{\lambda^2}{2A^2}\phi^4\left(1-\frac{A^2}{\phi^2}\right).
%
\end{gather*}

\Section{Графическое представление результатов}
В качестве примера проанализируем  свойства и~физические следствия одного из полученных решений.
Для экспоненциальной эволюции фантомного поля зависимость физического потенциала от фантомного поля задается формулой
(\ref{equ:cher:exp3}).
Положим значения всех произвольных постоянных, входящих в~(\ref{equ:cher:exp3}), равными единице, тогда потенциал поля будет иметь вид, представленный на рис.~\ref{equ:cher:V3-ph}.




Потенциал имеет два ненулевых минимума, которые соответствуют минимальному значению энергии поля, т.\,е. речь идёт о наиболее выгодном энергетическом состоянии поля "--- основном состоянии, которое получается вырожденным.

График зависимости параметра $ w $ из уравнения состояния (\ref{equ:cher:eos}) от времени (см. рис.~\ref{equ:cher:w3-ph})
подтверждает предположение о~том, что рассматриваемое скалярное поле тёмного сектора $ \phi $ является фантомным полем, поскольку $ w < -1 $ при неотрицательном значении космологического времени $t$.

\Section[n]{Заключение}
