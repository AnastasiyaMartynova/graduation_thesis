СУБДИФФЕРЕНЦИАЛ выпуклой функции $f: X \rightarrow \mathbb{R}$ в точке $x_{0}$, определенной на пространстве $X$, находящемся в двойственности с пространством $Y$ - множество в $Y$, определяемое соотношением:

\[
\begin{aligned}
& \partial f\left(x_{0}\right)=\left\{y \in Y: f(x)-f\left(x_{0}\right) \geqslant\right. \\
& \left.\geqslant\left\langle y, x-x_{0}\right\rangle \text { для всех } x \in X\right\} .
\end{aligned}
\]

Напр., С. нормы $f(x)=\|x\|$ в норми рованном пространстве $X$ с сопряженным $X^{*}$ имеет вид

$\partial f(x)=\left\{\begin{array}{l}\left\{x^{*} \in X^{*}:\left\langle x^{*}, x\right\rangle=\|x\|,\left\|x^{*}\right\|=1\right\}, \text { если } x \neq 0, \\ \left\{x^{*}:\left\|x^{*}\right\|=1\right\}, \text { если } x=0 .\end{array}\right.$

С. выпуклой функции $f$ в точке $x_{0}$ является выпуклым множеством. Если $f$ непрерывна в этой точке, то С. нешуст и компактен в топологии $\sigma(Y, X)$.

С. выпуклой функции играет роль, подобную роли производной в классич. анализе. Для него справедливы теоремы, аналогичные соответствующим теоремам для производной. Напр., если $f_{1}$ и $f_{2}-$ выпуклые функции и в нек-рой точке $x \in\left(\operatorname{dom} f_{1}\right) \wedge\left(\operatorname{dom} f_{2}\right)$, по крайней мере, одна из функций непрерывна, то

\[
\partial f_{1}(x)+\partial f_{2}(x)=\partial\left(f_{1}+f_{2}\right)(x)
\]

СУБПРОЕКТИВНОЕ ПРОСТРАНСТВО - одно Из обобщений пространств постоянной кривизны (проективного пространства). Определяется $k$-кратное проективное пространство афффинной связности, геодезические линии к-рого выражаются в нек-рой системе координат системой из $(n-1)$ уравнений, из к-рых ровно $k$ линейных. При $k=n-2$ геодезич. линии являются плоскими, располагаясь в двумерных евклидовых плоскостях, и пространство наз. субпроективным, если все эти двумерные евклидовы плоскости проходят через общую точку или параллельны одному направлению (общая точка - бесконечно удаленная).
