\section{Введение}

     Автоматический анализ тональности текстов на естественном языке,
подразумевающий автоматическое определение отношения автора
(положительное, отрицательное) к~теме текста, является одним из активно
развивающихся на\-прав\-ле\-ний в~сфере автоматической обработки текстов.

     Важной задачей в~рамках этого направления является задача
автоматизации создания и~улучшения качества словарей оценочных слов и~выражений. В~настоящее время для многих языков создаются такого рода
ресурсы оценочной лексики~[1, 2]. Для русского языка опубликован и~свободно
доступен лишь один автоматический порожденный словарь оценочных слов и~выражений ProductSentiRus~[3].

     Кроме того, анализ тональности текстов в~предметной области, например
отзывов пользователей некоторого продукта, требует адаптации систем анализа
тональности к~текстам этой предметной области~[4]. Так, некоторые слова
могут терять свою полярность в~конкретных областях. Например, такое слово,
как \textit{зло}, в~предметной области отзывов о фильмах обычно относится к~сюжету фильма и~ничего не говорит об отношении пользователя к~данному
фильму.

     Другие слова могут приобрести некоторую тональность в~конкретной
предметной области. Например, слово \textit{киношный} может иметь
негативную полярность, передавая значение <<далекий от реальной жизни>>.
Другой пример~--- слово \textit{атмосферный}, которое в~области отзывов о
фильмах не имеет отношения к~атмосфере планет, а~несет положительную
тональность создания хорошего настроения, чувства. Данное значение слова
атмосферный является относительно новым в~русском языке, не описано ни в~каких русских толковых словарях.

     Автоматическое извлечение оценочных слов может осуществляться на
основе текстовых корпусов или словарных ресурсов (толковых словарей,
тезаурусов и~т.\,п.). В~этой статье описывается комбинированный подход к~извлечению словаря оценочной лексики. На первом шаге словарь оценочной
лексики создается на основе извлечения признаков слов в~нескольких
текстовых корпусах и~последующего применения методов машинного обучения
для комбинирования этих признаков. Словарь представлен как список слов,
упорядоченный по мере снижения вероятности слова быть оценочным. На этом
этапе можно извлечь оценочные слова, которые отсутствуют в~словарях или
имеют тональность только в~текущей предметной области. Оценочные слова
извлекаются без их положительной или отрицательной оценки, поскольку этот
этап рассматривается как первый шаг в~порождении оценочного словаря
предметной области.

     На втором этапе производится улучшение качества полученного списка
оценочных слов на основе сопоставления его с~недавно опубликованным
тезаурусом русского языка РуТез. Модель извлечения оценочных слов на
основе корпусов и~тезауруса настраивается на области отзывов о фильмах.
Затем построенная модель используется для порождения оценочных словарей в~четырех других областях. Наконец, созданные словари оценочных слов из пяти
областей комбинируются, чтобы породить единый словарь оценочных слов в~широкой области товаров и~услуг (ProductSentiRus+).

     Данная статья имеет следующую структуру. Во втором разделе
рассматриваются методы порождения словарей оценочной лексики. В~третьем
разделе кратко представлена структура тезауруса русского языка РуТез,
предназначенного для автоматической обработки текстов. Четвертый раздел
представляет подход к~извлечению оценочной лексики в~заданной предметной
области. Пятый раздел рассматривает порождение обобщенного словаря
оценочной лексики в~области товаров и~услуг ProductSentiRus+. Полученный
словарь тестируется в~задаче классификации твитов на объективные и~субъективные.

\section{Близкие работы}

\vspace*{-1pt}

     Существуют два подхода к~созданию словарей оценочной лексики: один
основан на текстовых корпусах, а~другой~--- на словарных
ресурсах.


     Корпусные методы используют совместную встречаемость слов~[5--7]
или появление их в~заданных контекстах или
     лек\-си\-ко-син\-так\-си\-че\-ских шаблонах~[8]. Современные корпусные
методы обрабатывают большие объемы данных, например миллионы
     веб-стра\-ниц~\cite{6-luk} или сотни тысяч отзывов пользователей~[9].

     Словарные методы извлекают нужную информацию из существующих
словарей или тезаурусов и~обычно начинают свою работу с~некоторого
начального множества известных оценочных слов (\textit{плохой, хороший,
отличный, отвратительный} и~др.). В~[10] описывается ресурс SentiWordNet,
который был получен в~результате автоматической разметки тезауруса
английского языка WordNet~[11] и~в~котором каждому синсету WordNet
(набору синонимов) сопоставляется три числовых веса, отражающих долю
позитивности, негативности и~нейтральности слов синсета. Таким образом,
различные значения одного и~того же слова, входящие в~разные синсеты, могут
иметь различные соотношения весов полярности.

     В~[12] авторы исследуют различные подходы с~частичным обучением
для разметки полярности слов в~графе лексических отношений WordNet.
В~частности, применяются такие методы, как MinCut, Randomized MinCut,
Label Propagation~[13]; в~работе показано, что алгоритм Label Propagation
достигает лучших результатов. Эти и~подобные алгоритмы на графах
используются и~в~сочетании с~обработкой информации, извлекаемой из
текстовых корпусов.

     Во многих исследованиях словари оценочной лексики для заданной
предметной области создаются на основе корпусных подходов с~использованием различных типов распространения разметки, исходящей из
начального множества известных оценочных слов~[9]. Серьезной проблемой
таких подходов является определение подходящего размера и~состава
начального множества слов, что может зависеть от конкретной предметной
области.

     В данном исследовании создается оценочный словарь для заданной
предметной области на основе нескольких текстовых корпусов. Затем
полученный словарь улучшается на основе разметки понятий тезауруса с~использованием для всех предметных областей минимального изначально
заданного множества оценочных слов, состоящего из слов \textit{плохой}
и~\textit{хороший}.

\section{Лингвистическая онтология РуТез}

В данном исследовании используется тезаурус русского языка РуТез~[14].
РуТез~--- это так называемая лингвистическая онтология, т.\,е.\ онтология,
подавляющее большинство понятий которой основано на значениях реально
существующих языковых выражений (слов и~словосочетаний). РуТез
создавался вручную и~в течение долгого времени использовался в~различных
проектах автоматической обработки текстов и~информационного поиска.
Теперь РуТез доступен для использования в~исследовательских целях.
Опуб\-ли\-ко\-ванная версия РуТез содержит около~100~тысяч слов и~выражений
({\sf http://www. labinform.\linebreak ru/pub/ruthes/index.htm}).

Тезаурус РуТез отличается от тезаурусов типа WordNet тем, что его структура
представляет собой единую иерархическую сеть понятий, в~которой
представлены значения разных частей речи (существительных, прилагательных,
глаголов). Каждое понятие в~тезаурусе имеет уникальное однозначное имя.
Понятия соединяются между собой несколькими типами отношений. Каждому
понятию соответствует совокупность текстовых выражений, которыми данное
понятие может выражаться в~текстах (текстовые входы понятия). Текстовые
входы включают в~себя как отдельные слова, так и~большое количество
словосочетаний. Особенностью тезауруса РуТез является и~то, что он включает
термины так называемой общественно-политической области, широкой
предметной области жизни современного общества, включающей такие
подобласти, как политика, экономика, право, спорт и~др.

Многозначные слова описаны в~РуТез так же, как и~в тезаурусе WordNet, а~именно отнесены к~разным понятиям тезауруса. Например, в~текущей версии
тезауруса РуТез слово \textit{пресный} приписано трем понятиям:
\begin{itemize}
\item ПРЕСНАЯ ВОДА;
\item ПРЕСНЫЙ, БЕЗВКУСНЫЙ;
\item ПРЕСНЫЙ (НЕИНТЕРЕСНЫЙ).
\end{itemize}

  Первое понятие нейтрально и~не относится к~области отзывов о фильмах.
Второе понятие негативно, но также не относится к~этой области. Последнее
понятие негативно и~релевантно отзывам о фильмах.

\section{Извлечение оценочных словарей на~основе комбинированных
знаний}

     Алгоритм извлечения оценочных слов в~заданной предметной области
подразделяется на два этапа, которые будут рассмотрены ниже. Модель
извлечения слов строится в~предметной области отзывов о фильмах, а~затем
переносится в~другие предметные области.



\subsection{Этап~1. Извлечение оценочного словаря предметной области из
текстовой коллекции}

     На первом этапе для извлечения оценочных слов в~каждой предметной
области используются три текстовые коллекции.

\begin{table}\small

     Основной коллекцией является область отзывов пользователей в~заданной предметной области (\textit{целевая коллекция}~--- DOM),
большинству отзывов приписана числовая оценка, сообщающая отношение
пользователя к~фильму, обсуждаемому в~данном отзыве. Такая коллекция
содержит значительное количество как оценочных слов, так и~терминов
предметной области (\textit{актер, режиссер, кастинг} и~др.).

Для данного эксперимента использовались коллекции отзывов, собранные с~онлайновых сервисов {\sf imhonet.ru} и~{\sf market.yandex.ru} в~пяти
предметных областях: фильмы, книги, компьютерные игры, мобильные
телефоны и~цифровые камеры (табл.~1).

В качестве второй коллекции, относящейся к~предметной области, выбрана
область описаний объектов отзыва (\textit{коллекция описаний}~--- DESCR).
Для области фильмов и~книг это описания их сюжетов, для отзывов о
технических устройствах~--- описания этих технических устройств. В~этой
коллекции содержатся небольшая доля оценочных слов и~множество слов,
относящихся к~предметной области. Таким образом, такой корпус может
использоваться как контрастный корпус к~коллекции отзывов (см.\ табл.~1).

В качестве другого контрастного корпуса используется коллекция новостей
(\textit{новостная коллекция}~--- NEWS)~--- 1~млн документов. В~этом
корпусе содержится относительно низкая доля как оценочных, так
и~пред\-мет\-но-ори\-ен\-ти\-ро\-ван\-ных слов из отзывов.

На основе этих коллекций для каждого знаменательного слова~$w$
(существительного, прилагательного, глагола, наречия), встречающегося в~коллекции отзывов, вычисляется совокупность признаков, описывающих
<<поведение>> слова в~вышеперечисленных коллекциях.

	Первой группой признаков являются \textbf{частотные признаки},
вычисленные по каждой из текстовых коллекций. Такие признаки включают:
\begin{itemize}
\item  общие частоты встречаемости слов в~разных коллекциях (tf$_w$);
\item документные частоты (df$_w$)~--- число документов, в~которых
употреблялось слово~$w$;
\item частота употребления слов с~большой буквы (предполагается, что
оценочные слова обычно не являются именами собственными);
\item частота встречаемости слова со словами-операторами, усиливающими или
меняющими тональность слова на противоположную, например \textit{не
очень}.
\end{itemize}

	Признаки второй группы~--- \textbf{контрастные признаки}~---
считаются по разным корпусам. В~их состав входит признак
Cтранность~\cite{15-luk} и~известный в~информационном поиске признак
tf.idf. Оба типа признаков призваны зафиксировать более высокую долю
оценочных слов в~целевом корпусе DOM по сравнению с~контрастными
корпусами.

\textbf{Признак Странность} вычисляется на двух корпусах,
один из которых~--- корпус отзывов DOM, а~второй~--- контрастный: DESCR
или NEWS.
$$
\mathrm{Странность} = \fr{w_s/t_s}{w_g/t_g}\,,
  $$
где $w_s$~--- частота употребления слова в~корпусе~$s$; $t_s$~--- общее
количество слов в~корпусе~$s$; $w_g$~--- частота употребления слова в~контрастном корпусе~$g$; $t_g$~--- общее количество слов в~контрастном
корпусе~$g$. Вместо количества употреблений слова в~коллекции (tf$_w$) для
вычисления данного признака может быть использована и~документная частота
df$_w$.
	
Таким образом, данный типовой признак порождает три конкретных признака
$\mathrm{Странность}_{\mathrm{df}}$ на парах корпусов DOM--DESCR, DOM--NEWS
и~$\mathrm{Странность}_{\mathrm{tf}}$ на паре корпусов DOM--DESCR.

\textbf{Признак tf.idf} обычно используется для вычисления
веса слова в~документе при информационном поиске: tf~--- это обычно
частота упоминания слова в~отдельном документе, idf~--- это обратная
документная частота~df упоминания слов в~текстовой коллекции, в~которой
производится поиск.

В описываемых экспериментах используется tf$_w$~--- частота слова в~целевой
коллекции DOM, а~df$_w$ вычисляется по контрастным коллекциям.

В литературе встречаются различные формулы для вычисления tf.idf.
В~данной работе использовалась формула из~\cite{16-luk}:
\begin{equation*}
\mathrm{tf.idf} = \beta+ (1- \beta)\cdot \mathrm{tf}\cdot \mathrm{idf}\,,
\end{equation*}
где
\begin{equation*}
\mathrm{tf}\left(l\right)= \fr{\mathrm{freq}\left(l\right)}
{\mathrm{freq}\left(l\right)+0{,}5+1{,}5 \mathrm{dl}/\mathrm{avg}\_\mathrm{dl}}\,;\quad
\mathrm{idf}\left(l\right) =\fr{\log \left(\left(\vert c\vert +
0{,}5\right)/\mathrm{df}\left(l\right)\right)}{\log (\vert c\vert +1)}\,,
\end{equation*}
где $\mathrm{freq}\left(l\right)$~--- частота вхождения слова~$l$ в~целевую
коллекцию; dl~---
количество словоупотреблений в~целевой коллекции; avg\_dl~--- средняя
длина документа; $\mathrm{df}\left(l\right)$~--- количество документов в~контрастной коллекции,
в которых встречается слово~$l$; $\beta \hm= 0{,}4$; $\vert c\vert$~--- общее
число документов в~контрастной коллекции.	

	Поскольку оценочные словари создаются на основе отзывов
пользователей, которые обычно сопровождаются числовой оценкой в~баллах,
то также возможно использовать эти данные для создания отдельной группы
\textbf{признаков на основе оценок пользователей}.

В состав этих признаков входит \textbf{признак отклонения от средней
оценки}. Он вычисляется как разница между средней оценкой отзывов, в~которых упоминалось слово, и~средней оценкой отзыва:

\noindent
\begin{equation*}
\mathrm{dev}\left(l\right) =\left\vert \fr{\sum\nolimits_{i=1}^n m_ik_i}{k}-
\fr{\sum\nolimits_{i=1}^n
m_i}{n}\right\vert\,,\qquad
\sum\limits_{i=1}^n k_i =k\,,
\end{equation*}
где $l$~--- рассматриваемое слово; $n$~--- общее число отзывов в~коллекции;
$m_i$~--- оценка $i$-го отзыва; $k_i$~--- частота упоминания слова в~$i$-м
отзыве (может быть равной~0); $k$~--- частота слова в~коллекции.

Второй признак в~этой группе~--- это \textbf{дисперсия оценки слова}. Этот
признак показывает, насколько значительно различаются оценки отзывов, в~которых упоминается слово.
Предполагается, что если слово упоминается в~различных отзывах с~похожими оценками, то это, скорее всего, оценочное
слово:
\begin{gather*}
\mathrm{var}\left(l\right) =\fr{\sum\nolimits_{i=1}^n m_i^2 k_i}{k}-\left(
\fr{\sum\nolimits_{i=1}^n m_i
k_i}{k}\right)^2\,,\qquad
\sum\limits_{i=1}^n k_i =k\,.
\end{gather*}


     Отдельную группу признаков составляют \textbf{лингвистические
признаки}, включающие бинарные признаки части речи, многозначности части
речи для слова, признак наличия приставки из предопределенного списка
приставок, часто встречающихся в~составе оценочных слов (\textit{не},
\textit{без}, \textit{бес} и~др.).

Для обучения алгоритма были размечены все слова с~частотой встречаемости
более~3 в~коллекции отзывов о фильмах. Разметка была сделана двумя
разметчиками. Если возникало несогласие между разметчиками, то решение
принималось на основе совместного обсуждения. В~результате было размечено
4079~тональных слов. Лучшее качество в~задаче классификации на два класса
(оценочное слово vs.\ неоценочное слово) было достигнуто на основе набора
классификаторов Logistic Regression, LogitBoost и~Random Forest из
программного пакета WEKA. Для этого вероятности оценочности слов,
выдаваемые отдельными классификаторами, усреднялись.

Результатом применения описанного метода стал список слов, упорядоченный
по оцениваемой вероятности их оценочности~--- \textit{оценочным весам}. Этот
алгоритм располагает оценочные слова ближе к~началу списка и~присваивает
им высокие оценочные веса, а~нейтральные слова с~низкими оценочными
весами~--- ближе к~концу списка.

В итоге для отзывов о фильмах был получен список из более чем 18~тыс.\ слов.
На первых позициях списка оказались слова: \textit{ненапряжный},
\textit{несмешной}, \textit{неподражаемый}, \textit{невнятный},

\textit{отличнейший}, \textit{неспешный}, \textit{бездарный} и~др.

\subsection{Улучшение оценочного словаря предметной области на основе
тезауруса РуТез}

	Для улучшения качества порождаемого списка оценочных слов
применяется тезаурус русского языка РуТез. На вход алгоритма поступает
список слов, упорядоченных по мере вероятности их оценочности. Список
получен на основе применения метода машинного обучения, описанного в~предыдущем подразделе.

Слова, содержащиеся в~списке, имеют различный статус относительно
тезауруса РуТез. Часть слов не содержится в~тезаурусе, например три из
наиболее вероятных оценочных слов в~области фильмов не содержатся
в~тезаурусе. Вторая часть слов описана в~тезаурусе и~ровно в~тех значениях,
в~которых слова употребляются в~отзывах. Последняя часть слов (таких как
слово \textit{атмосферный}) представлена в~тезаурусе однако в~отзывах
о~фильмах и~книгах эти слова употребляются в~другом значении и~имеют другую
тональность. Таким образом, описания слов в~тезаурусе РуТез должны
использоваться так, чтобы не ухудшить исходный список.

	Основная идея алгоритма уточнения оценочного лексикона~--- это
автоматическое разделение понятий тезауруса на оценочные и~нейтральные и~дальнейшее использование полученной разметки для переранжирования списка
оценочных слов. Этот процесс, в~противоположность вышеупомянутому
алгоритму Label Propagation, регулируется посредством ранее полученных
весов оценочности слов.

  	Обозначим полученный на входе лексикон, в~котором слова упорядочены
по их оценочному весу (sw), как~$W_D$. Сначала алгоритм формирует два
множества тезаурусных понятий, используя слова, расположенные на обоих
концах списка: $L_s$~--- понятия, которые предполагаются оценочными,
и~$L_n$~--- нейтральные понятия. Для этого вычисляются средние оценочные
веса понятий csw по их текстовым входам из списка~$W_D$. Затем алгоритм
вносит в~$L_s$ понятия с~высоким средним весом (csw$_s\hm > \mathrm{csw}_{s0}$), также
в~это множество вносятся понятия, соответствующие словам \textit{плохой}
и~\textit{хороший}. Понятия с~низким средним весом (csw$_n \hm< \mathrm{csw}_{n0}$)
добавляются к~множеству нейтральных понятий~$L_n$, которое формируется
без всяких дополнительных предопределенных понятий. В~экспериментах
были получены следующие значения: csw$_{s0}\hm=0{,}85$ и~csw$_{n0}\hm=0{,}05$.

     Далее каждое множество ($L_s$ и~$L_n$) итеративно пополняется
понятиями на основе проверки двух условий: порогов для каждого множества
на оценочные веса понятий и~числа прямых отношений в~тезаурусе между
понятием и~множест\-вами.
{ %\looseness=1

}

     Формально $L_s$ и~$L_n$ итеративно набираются, как показано
     в~псевдокоде Алгоритм~1.

     Алгоритм использует следующую нотацию:
     \begin{itemize}
\item $Adj (L)$~--- это множество понятий, связанных непосредственными
отношениями с~понятиями из множества~$L$;
\item $nlink (C, L)$~--- это функция, возвращающая число прямых тезаурусных
отношений между понятием~$C$ и~множеством~$L$.
	\end{itemize}
	
  На последнем шаге веса $sw$ всех слов, соответствующих понятиям из
множества~$L_s$, модифицируются умножением их на множитель~$k_1$ ($k_1
\hm>1$), а~веса $sw$ всех слов, относящихся к~понятиям из~$L_n$, домножаются
на множитель~$k_2$ ($0 \hm< k_2 \hm< 1$). Оценочный список слов
переупорядочивается в~соответствии с~новыми весами.

улучшение качества оценочных словарей (см.\ табл.~2, колонки под названием
<<+РуТез>>).

\section{Улучшение словаря обобщенной области продуктов и~услуг}

Несмотря на существующие различия между словарями оценочной лексики в~конкретных предметных областях, можно предположить, что словари
оценочной лексики для широкой области продуктов и~услуг имеют и~достаточно много общего между собой. Так, объединением оценочных
словарей нескольких предметных областей в~единый словарь был создан
словарь ProductSentiRus\footnote{{\sf
http://www.cir.ru/SentiLexicon/ProductSentiRus.txt}.}.

     В данном исследовании обновленные оценочные словари конкретных
предметных областей также суммируются посредством формулы, которая
повышает рейтинг слов, встречающихся в~оценочных словарях разных
предметных областей и~имеющих высокий оценочный вес в~каждой из них.



	Объединенный вес оценочного слова считается по следующей формуле:
$$
R(w) =\max \left( \mathop{\mbox{prob}_d}\limits_{d\in D}(w)\right) \sum\limits_{d\in D}
\fr{1}{\vert D\vert } \left( 1- \fr{\mathrm{pos}_d(w)}{\vert d\vert }\right)\,,
$$
где $D$~--- набор предметных областей (в данном случае пять предметных
областей); $d$~--- это упорядоченный список оценочных слов в~конкретной
предметной области; $\vert d\vert$~--- это общее количество слов в~данном
списке. Функции $\mathrm{prob}_d(w)$ и~$\mathrm{pos}_d(w)$ отражают оценочный вес и~позицию слова в~списке~$d$.

	Точность на уровне 1000~P@1000 списка ProductSentiRus была оценена
как 90,5\%. Комбинация улучшенных списков оценочных слов в~словарь
ProductSentiRus+ дает 95,2\% в~терминах P@1000 (см.\ табл.~2).

него были извлечены первые 5000~оценочных слов (то же самое количество,
что и~из предыдущей версии).

\section{Заключение}

\vspace*{-4pt}

В статье описан комбинированный подход к~извлечению оценочных словарей в~разных предметных областях. На первом этапе для создания оценочного
словаря используется несколько текстовых коллекций, из которых извлекаются
признаки слов, и~создается модель извлечения слов на основе методов
машинного обучения. На втором этапе упорядоченный список оценочных слов
уточняется на основе информации о лексических отношениях между словами,
описанных в~тезаурусе русского языка РуТез.

	Комбинированная модель извлечения оценочных слов была применена к~нескольким предметным областям, получено улучшение качества оценочного
списка для этих предметных областей.

     Порожденные списки оценочных слов были сведены в~единый список
оценочных слов для продуктов и~услуг, в~результате был получен новый список
оценочных слов ProductSentiRus+, который представляет собой улучшенную
версию ранее опубликованного списка ProductSentiRus. Данный подход к~извлечению слов может быть применен для других языков и~использовать
другие тезаурусные ресурсы.
