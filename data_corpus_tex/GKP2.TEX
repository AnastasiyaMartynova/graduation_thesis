\section{Оптимальное управление в классе
дискретных управлений степени $p \geq 2$}

Рассмотрим второй крайний случай дискретных управлений конечной
степени. Будем считать, что период квантования
времени совпадает со всем промежутком управления, на котором
управления выбираются среди ограниченных полиномов
степени $p-1$ с ограниченными коэффициентами, т.\,е. выполняются
условия
\begin{gather}
\label{control_p}
u(t) = u_0 + u_1(t-t_*) + u_2(t-t_*)^2 + \dotsb + u_{p-1}(t-
t_*)^{p-1}, \quad |u(t)| \leq L, \ \ t \in T; \\
%
\label{control_p_ogr}
|u_j| \leq u_j^*, \ \ j=\overline{0,p-1}.
\end{gather}

В этом случае, после подстановки (\ref{control_p}) в систему
(\ref{problem}), задача ОУ сводится к оптимизации
системы управления по параметрам $u_j, \ j=\overline{0,p-1}$, с
учетом континуума ограничений
\begin{gather}
c'x(t^*) \to \max; \quad \Dot{x} = A(t)x + b_0(t)u_0 + b_1(t)u_1 +
\dotsb + b_{p-1}(t)u_{p-1}, \ \ x(t_*) = x_0;\notag \\
%
\label{zsko}
-L \leq u_0 + u_1(t-t_*) + \dotsb + u_{p-1}(t-t_*)^{p-1} \leq L, \ \
t \in T; \quad |u_j| \leq u_j^*, \ \ j=\overline{0,p-1},
\end{gather}
где $b_j(t) = b(t)(t-t_*)^j$, $j=\overline{0,p-1}$.

С помощью формулы Коши задача (\ref{zsko}) записывается в
эквивалентной функциональной форме
\begin{equation}\label{zsko_func_form}
\sum\limits_{j=0}^{p-1} q_j u_j \to \max; \quad -L \leq
\sum\limits_{j=0}^{p-1} d_j(t)u_j \leq L, \ \ t \in T; \quad
|u_j| \leq u_j^*, \ \ j=\overline{0,p-1},
\end{equation}
где
\begin{gather*}
q_j = \int_{t_*}^{t^*} \psi_c'(\tau) b(\tau) (\tau-t_*)^{j}
d\tau, \ \ j=\overline{0,p-1};\\
%
d_j(t) = (t-t_*)^{j}, \ \ t \in T_h, \ \ j=\overline{0,p-1}.
\end{gather*}

Задача (\ref{zsko_func_form}) представляет собой полубесконечную
задачу ЛП --- в ней конечное число переменных и
бесконечное (континуум) число основных ограничений. Численные
методы решения подобных задач описаны в \cite{KMO3}
(см. также \cite{Medv}). В данном пункте предлагается другой
(динамический) подход к решению задачи ОУ в классе
$U_1^p$.

Управление (\ref{control_p}) будем трактовать как выходной сигнал
\begin{equation}\label{vyh_sign}
u = d'(t)y \quad (d(t) \equiv (1, 0, \dotsc, 0) \in R^p)
\end{equation}
динамического регулятора
\begin{equation}\label{din_reg}
\Dot{y} = A_1(t) y \quad (y \in R^p, \ \ A_1(t) \equiv
\begin{pmatrix}
0 & 1 & 0 & \dotsc & 0 \\
0 & 0 & 1 & \dotsc & 0 \\
\hdotsfor[1.5]{5}\\
0 & 0 & 0 & \dotsc & 1 \\
0 & 0 & 0 & \dotsc & 0 \\
\end{pmatrix} \in R^{p \times p} )
\end{equation}
с начальным состоянием
\begin{equation}\label{nach_sost}
y_0 = (y_j(t_*), \ \ j=\overline{0,p-1}) = (j! u_j, \
j=\overline{0,p-1}) = Gz, \ \ z_* \leq z \leq z^* \ \ (G \in R^{p
\times q}).
\end{equation}

Таким образом, будем считать, что динамическая система
(\ref{problem}) управляется выходным сигналом
(\ref{vyh_sign}) динамического регулятора (\ref{din_reg}) путем
выбора его начального состояния (\ref{nach_sost}),
удовлетворяющего ограничениям (\ref{control_p_ogr}). При этом
выходные сигналы (\ref{vyh_sign}) динамического
регулятора (\ref{din_reg}) должны удовлетворять фазовым
ограничениям
\begin{equation}\label{faz_ogr}
|d'(t)y(t)| \leq L, \ \ t \in T.
\end{equation}

Хотя излагаемый далее метод решения можно построить для
поставленной задачи без всяких упрощений, ниже
ограничимся вполне разумным с практической точки зрения
предположением --- будем считать, что фазовое ограничение
(\ref{faz_ogr}) проверяется только в дискретные моменты времени $t
\in T_h$.

\begin{note}
Повышение точности выполнения фазового
ограничения можно добиться или с помощью процедуры
доводки \cite{KMO2}, или путем измельчения сетки в окрестности
моментов нарушения ограничений (\ref{faz_ogr}).
\end{note}

\begin{note}
Модель (\ref{control_p}), (\ref{control_p_ogr})
допускает различные обобщения. Можно считать,
что\linebreak $A_1 = A_1(t)$, $t \in T$, --- кусочно-непрерывная $p \times
p$-матричная функция. Если использовать
$\delta$-функцию Дирака, то соотношения (\ref{din_reg}),
(\ref{nach_sost}) можно записать в виде
$$
\Dot{y} = A_1(t)y + \delta(t-t_*)y_0, \ \ y(t_*) = 0.
$$
Дальнейшее обобщение
$$
\Dot{y} = A_1(t)y + B_1(t)v
$$
можно получить, если использовать непрерывную матричную функцию
$B_1(t)$, $t \in T$, и дискретно-импульсные
управления
$$
v(t) = \sum\limits_{k=0}^{N-1} \delta (t-t_k) v(t_k), \ \ t \in T,
$$
с полиэдральными ограничениями
$$
v(t_k) = (v_j(t_k), \ j=\overline{1,q}) \in V(t_k), \ \ t_k \in T_h,
$$
где $V(t_k) \subset R^q$, $t_k \in T_h$, --- заданные полиэдры.
\end{note}

Итак, в данном пункте, не переходя к возможным обобщениям,
рассмотрим подробно следующую задачу:
\begin{gather}
\label{zadacha_p}
c'x(t^*) \to \max; \\
%
\label{dyn_sys_p}
\Dot{x} = A(t)x + b(t)u, \ \ x(t_*) = x_0, \quad u = d'(t)y; \\
%
\label{dyn_sys_y}
\Dot{y} = A_1(t)y, \ \ y(t_*) = y_0 = Gz; \\
%
\label{ogr_p}
|u(t)| \leq L, \ \ t \in T_h, \quad z_* \leq z \leq z^*.
\end{gather}

Используя формулу Коши, сведем задачу
(\ref{zadacha_p})--(\ref{ogr_p}) к эквивалентной функциональной форме
\begin{equation}\label{zadacha_p_lp}
\varphi'z \to \max; \quad -L \leq \xi'(s) z \leq L, \ \ s \in T_h,
\quad z_* \leq z \leq z^*,
\end{equation}
параметры которой $\varphi' = \varphi_{c}'(t_*)G$, $\xi'(s) =
(\xi_j(s)$, $j \in J) = (\xi'(s,t_*)G_j$, $j \in J) =
\xi'(s,t_*)G$, $s \in T_h$ ($G_j$, $j \in J$, --- столбцы матрицы
$G$) можно генерировать динамически с
помощью решений $\varphi_c(t)$, $\psi_c(t)$, $t \in T$;
$\xi(s,t)$, $t_* \leq t \leq s$, $s \in T_h$,
сопряженных уравнений
\begin{gather}
\label{sopr_sys1}
\Dot{\varphi} = -A_1'(t)\varphi - d(t)b'(t)\psi, \\
%
\label{sopr_sys2}
\Dot{\psi} = -A'(t)\psi, \\
%
\Dot{\xi} = -A_1'(t)\xi \notag
\end{gather}
с начальными условиями
\begin{gather}
\label{nach_usl_sys1}
\varphi(t^*) = 0, \\
%
\label{nach_usl_sys2}
\psi(t^*)= c, \\
%
\xi(s,s) = d(s), \ \ s \in T_h,\notag
\end{gather}
соответственно.

Для решения задачи (\ref{zadacha_p_lp}) построим динамическую
реализацию двойственного адаптивного метода
\cite{KMO2}. Начнем с введения основного понятия метода --- опоры.
Из множеств $T_h$, $J = \{ 0, 1, 2, \dotsc,
q-1\}$ выделим два подмножества $T_{\op} \subset T_h$, $J_{\op}
\subset J$, $|T_{\op}| = |J_{\op}|$. Сформируем
$(|T_{\op}| \times |J_{\op}|)$-матрицу
$$
D_{\op} = \begin{pmatrix}
\xi_j(s), & j \in J_{\op} \\
s \in T_{\op} & \
\end{pmatrix}.
$$
Совокупность $K_{\op} = \{T_{\op}, J_{\op} \}$ с $T_{\op} \neq
\emptyset$, $J_{\op} \neq \emptyset$ назовем
опорой, если $\det D_{\op} \neq 0$.

Пара $K_{\op} = \{T_{\op}, J_{\op}\}$ из пустых множеств $T_{\op}
= \emptyset$, $J_{\op} = \emptyset$ является
(пустой) опорой $K_{\op}$ по определению.

Опору $K_{\op}$ сопровождают четыре объекта.

1. Функция потенциалов $\nu(t)$, $t \in T_h$. Неопорные значения
функции потенциалов положим равными нулю: $\nu(t)
= 0$, $t \in T_{\nop} = T_h \setminus T_{\op}$. Опорные значения
$\nu_{\op} = (\nu(t)$, $t \in T_{\op})$ найдем из
системы $|J_{\op}|$ уравнений
\begin{equation}\label{funct_pot}
\nu_{\op}' D_{\op} = \varphi_c'(t_*) G_{\op} = \varphi_{c \op}',
\quad G_{\op} = (G_j, \ j \in J_{\op}).
\end{equation}

2. Котраектория $(\psi(t)$, $\varphi(t))$, $t \in T$, --- решение
сопряженных уравнений (\ref{sopr_sys1}),
(\ref{sopr_sys2}) с начальными условиями (\ref{nach_usl_sys1}),
(\ref{nach_usl_sys2}) и скачками по компоненте
$\varphi(t)$, $t \in T$, в опорные моменты времени $t \in
T_{\op}$:
$$
\varphi(t-0) = \varphi(t+0) - \nu(t)d(t), \ \ t \in T_{\op}.
$$

3. Вектор оценок $\delta = (\delta_j, \ j \in J)$,
$\delta' = \varphi'(t_*)G$.
Отсюда видно, что $\delta'_{\op} = (\delta_j, \ j \in J_{\op})' =
\varphi'(t_*)G_{\op} = \varphi_c'(t^*)G_{\op} -
\nu_{\op}'D_{\op} = 0$.

Опору будем называть регулярной, если $\nu(t) \neq 0$, $t \in
T_{\op}$; $\delta_j \neq 0$, $j \in J_{\nop}$.

4. Вектор управляющих псевдопараметров $\zeta = (\zeta_j, \ j \in
J)$ и псевдоуправление $\omega(t)$, $t \in
T_h$. Их построение начнем с задания неопорных значений
\begin{equation}\label{vupp}
\zeta_j = z_{*j}, \ \text{если}\ \delta_j < 0; \quad \zeta_j =
z^*_j, \ \text{если}\ \delta_j > 0; \quad
\zeta_j \in [z_{*j}; z^*_j], \ \text{если} \ \delta_j = 0, \ \ j
\in J_{\nop},
\end{equation}
и опорных значений
\begin{equation}\label{pu}
\omega(t) = L \sign \nu(t), \ \text{если}\ \nu(t) \neq 0; \quad
\omega(t) \in [-L; L], \ \text{если} \ \nu(t)
= 0, \ \ t \in T_{\op}.
\end{equation}
Опорные компоненты $\zeta_j, \ j \in J_{\op}$, вектора управляющих
псевдопараметров найдем, решив систему
уравнений
\begin{equation}\label{vupp_op}
D_{\op} \zeta_{\op} = \omega_{\op} - \omega^0_{\op}.
\end{equation}
Здесь $\omega^0(t) = d'(t) \chi_0(t)$, $\chi_0(t)$, $t \in T$,
--- псевдотраектория регулятора --- решение
уравнения (\ref{dyn_sys_y}) с начальным условием $y(t_*) = G
\zeta^0$, где $\zeta^0 = (\zeta^0_{\op} = 0$,
$\zeta^0_{\nop} = \zeta_{\nop})$. Неопорные значения $\omega(t)$,
$t \in T_{\nop}$, псевдоуправления подсчитаем по
формуле
$$
\omega(t) = d'(t) \chi(t), \ \ t \in T_{\nop},
$$
где $\chi(t)$, $t \in T$, --- псевдотраектория регулятора ---
решение уравнения (\ref{dyn_sys_y}) с начальным
условием $y(t_*) = G \zeta$.

Из критериев оптимальности и субоптимальности адаптивного метода
\cite{KMO1} следуют два принципа.

{\bf Принцип максимума.} Для оптимальности вектора управляющих
параметров $z$ и соответствующей ему программы
$u(\cdot)$ необходимо и достаточно существования такой опоры\linebreak
$K_{\op} = \{ T_{\op}, J_{\op} \}$, что на
сопровождающих ее функции
потенциалов $\nu(t), \  t \in T_h$, и векторе оценок $\delta$
выполняются

1) условие максимума по управлению
$$
\nu(t)u(t) = \max_{-L \leq u \leq L} \nu(t)u, \ \ t \in T_{\op};
$$

2) условие максимума по управляющим параметрам
$$
\delta_j z_j = \max_{z_{*j} \leq z \leq z^*_j} \delta_j z, \ \ j \in
J_{\nop}.
$$

Опору $K_{\op}$, которая идентифицирует оптимальную программу,
будем называть оптимальной; ее сопровождают
оптимальные элементы.

{\bf Принцип $\varepsilon$-максимума.} При любом $\varepsilon \geq
0$ для $\varepsilon$-оптимальности вектора
управляющих параметров $z$ и соответствующей ему программы
$u(\cdot)$ необходимо и достаточно существования такой
опоры $K_{\op} = \{T_{\op}, J_{\op}\}$, что на сопровождающих ее
функции потенциалов
$\nu(t)$, $t \in T_h$, и векторе оценок $\delta$ выполняются

1) условие квазимаксимума по управлению
$$
\nu(t)u(t) = \max_{-L \leq u \leq L} \nu(t)u - \varepsilon_u(t), \ \
t \in T_{\op};
$$

2) условие квазимаксимума по управляющим параметрам
$$
\delta_j z_j = \max_{z_{*j} \leq z \leq z^*_j} \delta_j z -
\varepsilon_{zj}, \ \ j \in J_{\nop};
$$

3) условие $\varepsilon$-точности
$$
\sum\limits_{t \in T_{\op}} \varepsilon_u (t) + \sum\limits_{j \in
J_{\nop}} \varepsilon_{zj} \leq \varepsilon.
$$

Из условий оптимальности опоры двойственного адаптивного метода
следует

{\bf Критерий оптимальности опоры.} Для оптимальности опоры
$K_{\op}$ необходимо и достаточно, чтобы на некоторых
сопровождающих ее псевдоуправлении и векторе управляющих
псевдопараметров выполнялись неравенства
$$
|\omega(t)| \leq L, \ \ t \in T_{\nop}; \quad z_{*j} \leq \zeta_j
\leq z^*_j, \ \ j \in J_{\op}.
$$
Вектор управляющих псевдопараметров $\zeta$ и соответствующее ему
псевдоуправление $\omega(t)$, $t \in T$,
которые сопровождают оптимальную опору, являются оптимальными
начальными параметрами и управлением $u^0(t) =
\omega(t)$, $t \in T$; $z_j^0 = \zeta_j$, $j \in J$.

Опишем {\it двойственный метод} вычисления оптимальной программы
задачи (\ref{zadacha_p_lp}). Метод состоит из
последовательных преобразований опор, в результате которых
получается оптимальная опора. В качестве начальной
можно брать любую опору. Далее для упрощения выкладок
предполагается, что на итерациях двойственного метода
участвуют только регулярные опоры.

Обозначим
\begin{gather}
\label{rho}
\rho_{j_0} = \max\limits_{j \in J_{\op}} \rho_j, \quad \rho(t_0) =
\max\limits_{t \in T_{\nop}} \rho(t), \quad
\rho_0 = \max \{\rho_{j_0}, \rho(t_0)\};\\
%
\rho_j = \rho(\zeta_j,[z_{*j},z^*_j]), \ \ j \in J; \quad \rho(t) =
\rho( \omega(t),[-L,L]), \ \ t \in T_h,\notag
\end{gather}
где $\rho(c,[a,b])$ --- расстояние от числа $c$ до отрезка
$[a,b]$. Возможны две ситуации: 1)~$\rho_0 =
\rho(t_0)$; 2)~$\rho_0 = \rho_{j_0}$.

1) $(\rho_0 = \rho(t_0))$. Первыми построим приращения неопорных
значений $\Delta \nu(t)$, $t \in T_{\nop}$,
функции потенциалов
\begin{equation}\label{dm2_1}
\Delta \nu(t_0) =
\begin{cases}
\phantom{-}1, & \text{если}\ \omega(t_0) > L;\\
-1, & \text{если}\ \omega(t_0) < -L,
\end{cases}
\quad \Delta \nu(t) = 0, \ \ t \in T_{\nop} \setminus t_0.
\end{equation}
Приращения опорных значений $\Delta \nu_{\op} = (\Delta \nu(t)$,
$t \in T_{\op})$ функции потенциалов найдем из уравнения
\begin{equation}\label{dm2_2}
\Delta \nu_{\op}' D_{\op} = (\Delta \delta_j^{t_0}, \ \ j \in
J_{\op})',
\end{equation}
где $\Delta \delta_j^{t_0} = \Delta \varphi'(t_*)G_j$, $\Delta
\varphi(t)$, $t \in T$, --- компонента решения
сопряженных уравнений (\ref{sopr_sys1}), (\ref{sopr_sys2}) с
начальными условиями $\varphi(t^*) = 0$, $\psi(t^*)=
0$ и скачком в момент времени $t_0$:
$$
\varphi(t_0-0) = \varphi(t_0+0) - \Delta \nu(t_0)d(t_0).
$$
Положим
\begin{equation}\label{dm2_3}
\Delta \delta_j = 0, \ \ j \in J_{\op}.
\end{equation}
Наконец, неопорные значения приращения вектора оценок $\Delta
\delta_j$, $j \in J_{\nop}$, вычислим по формуле
\begin{equation}\label{dm2_4}
\Delta \delta_j = \Delta \varphi'(t_*) G_j, \ \ j \in J_{\nop},
\end{equation}
где $\Delta \varphi(t)$, $t \in T$, --- компонента решения
сопряженной системы (\ref{sopr_sys1}),
(\ref{sopr_sys2}) с начальными условиями $\varphi(t^*) = 0$,
$\psi(t^*)= 0$ и скачками в опорные моменты времени
$$
\varphi(t-0) = \varphi(t+0) - \Delta \nu(t)d(t), \ \ t \in T_{\op}.
$$

При движении (увеличении $\sigma \geq 0$)
\begin{equation}\label{dm2_5}
\nu(t\mid\sigma) = \nu(t) + \sigma \Delta \nu(t), \ \ t \in T_h; \quad
\delta_j(\sigma) = \delta_j + \sigma \Delta
\delta_j, \ \ j \in J, \quad \sigma \geq 0,
\end{equation}
из $(\nu(\cdot), \delta)$ вдоль направления
(\ref{dm2_1})--(\ref{dm2_4}) начальная скорость убывания
двойственной целевой функции задачи (\ref{zadacha_p_lp})
$\alpha^1 = L - \omega(t_0)$, если
$\omega(t_0) > L$; $\alpha^1 = \omega(t_0) + L$, если
$\omega(t_0) < -L$.

С увеличением $\sigma \geq 0$ будут появляться новые нули
\begin{align}\label{dm2_6}
\sigma_u(t) &=
\begin{cases}
-\nu(t) / \Delta \nu(t), & \text{если}\ \nu(t) \Delta\nu(t) < 0; \\
\infty, & \text{если}\ \nu(t) \Delta \nu(t) \geq 0, \ \ t \in T_{\op},
\end{cases}
\\
%
\label{dm2_6_1}
\sigma_{zj} &=
\begin{cases}
-\delta_j / \Delta \delta_j, & \text{если}\ \delta_j
\Delta \delta_j < 0; \\
\infty, & \text{если}\ \delta_j \Delta \delta_j \geq
0, \ \ j \in J_{\nop},
\end{cases}
\end{align}
функций (\ref{dm2_5}).

Упорядочим по возрастанию конечные числа из (\ref{dm2_6}),
(\ref{dm2_6_1}): $\sigma^1 < \sigma^2 < \dotsb <
\sigma^{n^*}$ (отсутствие таковых означает несовместность
ограничений задачи (\ref{zadacha_p_lp})). При движении
(\ref{dm2_5}) двойственная целевая функция между соседними нулями
коуправления $\sigma^k < \sigma^{k+1}$ из
(\ref{dm2_6}), (\ref{dm2_6_1}) изменяется линейно относительно
$\sigma$. Ее скорость $\alpha^k$ на этом участке в
точке $\sigma^{k+1}$ испытывает скачок
$$
\Delta \alpha^k =
\begin{cases}
2L\ |\Delta \nu(t^k)|, & \text{если}\ \sigma^k =\sigma_u(t^k); \\
(z^*_{jk} - z_{*jk}) \ |\Delta \delta_{jk}|, &
\text{если}\ \sigma^k = \sigma_{zj_k}.
\end{cases}
$$
Таким образом, $\alpha^{k+1} = \alpha^k + \Delta \alpha^k$.

Обозначим через $k_*$ такой индекс, что $\alpha^{k_*} < 0$,
$\alpha^{k_*+1} \geq 0$. Число $\sigma^* = \sigma^{k_*}$
называется коротким двойственным шагом, если $k_* = 1$, в
противном случае $\sigma^*$ --- длинный двойственный
шаг. С учетом 1а)~$\sigma^* = \sigma_u(t^{k_*})$;
1б)~$\sigma^* = \sigma_{zj_*} = \sigma_{zj_{k*}}$,
сформируем компоненты новой опоры $\ov{K}_{\op} = \{
\ov{T}_{\op}, \ov{J}_{\op} \}$: 1а)~$\ov{T}_{\op} =
(T_{\op} \setminus t_{k_*}) \cup t_0$, $\ov{J}_{\op} = J_{\op}$;
1б)~$\ov{T}_{\op} = T_{\op} \cup t_0$,
$\ov{J}_{\op} = J_{\op} \cup j_*$.

2) $(\rho_0 = \rho_{j_0})$. Сначала построим приращения опорных
компонент $\delta_j$, $i \in J_{\nop}$, вектора оценок
\begin{equation}\label{dm2_7}
\Delta \delta_{j_0} =
\begin{cases}
\phantom{-}1, & \text{если}\ \zeta_{j_0} > z^*_{j_0};\\
-1, & \text{если}\ \zeta_{j_0} < z_{*j_0},
\end{cases}
\quad \Delta \delta_j = 0, \ \ j \in J_{\op} \setminus j_0.
\end{equation}
Им соответствуют нулевые приращения неопорных значений функции
потенциалов
\begin{equation}\label{dm2_8}
\Delta \nu(t) = 0, \ \ t \in T_{\nop}.
\end{equation}
Опорные значения приращения функции потенциалов найдем из системы
уравнений
\begin{equation}\label{dm2_9}
\Delta \nu_{\op}' D_{\op} = - \Delta \delta_{\op}' = -(\Delta
\delta_j, \ j \in J_{\op})'.
\end{equation}
Вариации неопорных компонент вектора оценок вычислим по формуле
\begin{equation}\label{dm2_10}
\Delta \delta_j = \Delta \varphi'(t_*) G_j, \ \ j \in J_{\nop}.
\end{equation}

При движении (\ref{dm2_5}) вдоль направления (\ref{dm2_7})--(\ref{dm2_10}) 
начальная скорость 
убывания двойственной целевой функции задачи (\ref{zadacha_p_lp})
$\alpha^1 = z^*_{j_0} - \zeta_{j_0}$
при $\zeta_{j_0} > z^*_{j_0}$; $\alpha^1 = \zeta_{j_0} -
z_{*j_0}$ при $\zeta_{j_0} <z_{*j_0}$.

Далее поступаем аналогично случаю 1).

Новая опора имеет вид $\ov{K}_{\op} = \{\ov{T}_{\op},
\ov{J}_{\op}\}$, где 2а)~$\ov{T}_{\op} = T_{\op}
\setminus t_{k_*}$, $\ov{J}_{\op} = J_{\op} \setminus j_0$;
2б)~$\ov{T}_{\op} = T_{\op}$, $\ov{J}_{\op} =
(J_{\op} \setminus j_0) \cup j_*$.

В каждом случае для новой опоры $\ov{K}_{\op}$ подсчитаем
сопровождающие ее функцию потенциалов $\ov{\nu}(t)$,
$t \in T_h$, вектор оценок $\ov{\delta}_j$, $j \in J$, вектор
управляющих псевдопараметров $\ov{\zeta}_j$, $j
\in J$, и псевдоуправление $\ov{\omega}(t)$, $t \in T_h$.

Согласно \cite{KMO1} предложенный двойственный метод конечен,
если в процессе итераций встречаются только
регулярные опоры. Там же описана его модификация, которая конечна
для любой задачи (\ref{zadacha_p_lp}). Метод
завершает работу построением оптимальной опоры и сопровождающих ее
псевдоуправления и вектора управляющих
псевдопараметров, которые будут оптимальными управлением и его
начальными параметрами для задачи
(\ref{zadacha_p_lp}).

Как видно из описанного метода, основные затраты времени связаны с
вычислением двойственных шагов (\ref{dm2_6}),
(\ref{dm2_6_1}) и с пересчетом на итерациях элементов,
сопровождающих новую опору $\ov{K}_{\op}$. Для
осуществления итераций можно или заранее подсчитать все элементы
задачи ЛП (\ref{zadacha_p_lp}) и хранить их в
памяти ЭВМ, или вычислять эти элементы динамически, интегрируя
сопряженную систему полностью на всем промежутке
управления $T$. Первый способ требует больших затрат памяти,
второй сопряжен с существенными затратами времени.
Поэтому предлагается использовать специальный (быстрый) способ
подсчета необходимой на итерациях информации,
основанный на компромиcсе между двумя способами, упомянутыми выше.
Он заключается в том, чтобы за счет
использования небольшой дополнительной памяти экономить время на
интегрировании сопряженной системы, осуществляя
его лишь на небольших промежутках.

{\it Быстрый алгоритм замены опоры}. Перед началом процесса
вычислений двойственного метода подготовим
предварительную информацию. Если начальная опора $K_{\op}$ не
является пустой, то сформируем опорную матрицу
$D_{\op}$. При использовании $|T_{\op}|$ параллельно с
функционирующими процессорами работа, выполняемая одним
процессором для формирования $D_{\op}$, не превосходит одного
интегрирования сопряженной системы
(\ref{dyn_sys_y}) на промежутке $T$. Параллельно с формированием
$D_{\op}$ построим $F_{22}(t)$, $t \in T_h$:
$$
\Dot F_{22} = A_1(t)F_{22}, \quad F_{22}(t_*) = E,
$$
а также $F_{11}(t)$, $F_{12}(t)$, $t \in T_h$:
$$
\Dot{F}_{11} = A(t)F_{11}, \ \ F_{11}(t_*) = E; \quad \Dot{F}_{12} =
A(t) F_{12} + b(t)d'(t)F_{22}, \ \ F_{12}(t_*) =0.
$$
До начала процесса решения для начальной опоры $K_{\op}$ построим
также сопровождающую ее функцию потенциалов
$\nu(t)$, $t \in T_h$. Используя эту информацию, вектор оценок
можно вычислить по формуле
\begin{gather*}
\delta_j = \varphi'(t_*)G_j, \ \ j \in J_{\nop};\\
\varphi'(t_*)=
-c'F_{11}(t^*)F_{11}^{-1}(t_*)F_{12}(t_*)F_{22}^{-1}(t_*) +
c'F_{12}(t^*)F_{22}^{-1}(t_*) -
\sum\limits_{t \in T_{\op}} \nu(t)d'(t)F_{22}(t) F_{22}^{-1}(t_*).
\end{gather*}
Далее построим вектор управляющих псевдопараметров $\zeta_j$, $j
\in J$, и псевдоуправление $\omega(t)$, $t \in
T_h$, сопровождающие начальную опору $K_{\op}$.

Момент $t \in T_h \setminus \{ t_*, t^* \}$ будем называть точкой
минимума псевдоуправления $\omega(t)$, $t \in
T_h$, если $\omega(t) < \omega(t-h)$ и $\omega(t) < \omega(t+h)$;
точкой максимума, если $\omega(t) > \omega(t-h)$
и $\omega(t) > \omega(t+h)$. Обозначим множество точек минимума
псевдоуправления через $T_0^-$, точек максимума
--- через $T_0^+$; $T_0 = T_0^- \bigcup T_0^+$.

Множества $T_0^-$ и $T_0^+$ строятся до начала процесса решения
одновременно с построением псевдоуправления
$\omega(t)$, $t \in T_h$.

Пусть к началу произвольной итерации известна (хранится в памяти
ЭВМ) следующая информация: 1)~опора $K_{\op}$;
2)~матрица $D_{\op}$; 3)~опорные значения функции потенциалов
$\nu_{\op}$; 4)~вектор оценок $\delta$; 5)~вектор
управляющих псевдопараметров $\zeta$; 6)~множества $T_0^-$ и
$T_0^+$; 7)~значения компонент $F_{22}(t)$, $t \in
T_{\op} \bigcup T_0 \bigcup \{ t_*, t^* \}$; $F_{11}(t)$,
$F_{12}(t)$, $t \in \{ t_*, t^* \}$.

Используя информацию 6), 7), вычислим значения псевдоуправления в
точках экстремума $T_0$:
$$
\omega(t) = d'(t)F_{22}(t)F_{22}^{-1}(t_*)G\zeta, \ \ t \in T_0.
$$

Максимум функции $\rho(t)$, $t \in T_h$, (\ref{rho}), может
достигаться только в точках экстремума
псевдоуправления $\omega(t)$, $t \in T_h$. Поэтому для нахождения
момента $t_0$ достаточно знать множества
$T_0^-$, $T_0^+$ точек минимума и максимума псевдоуправления
$\omega(t)$, $t \in T_h$, и значения в них
фундаментальной матрицы $F_{22}(t)$. Тогда экстремальные значения
псевдоуправления будут равны $\omega(t) =
d'(t)F_{22}(t)F_{22}^{-1}(t_*)G\zeta$, $t \in T_0^- \bigcup
T_0^+$. Хранение и анализ множеств $T_0^-$, $T_0^+$
позволит избежать вычислительных затрат на обработку заведомо
бесперспективных точек.

Для быстрого вычисления на итерациях двойственных шагов
(\ref{dm2_6_1}) используем хранимую в памяти ЭВМ
информацию 1), 4), 7). Значения $\delta_j$, $j \in J_{\nop}$, уже
известны (хранятся в памяти), а значения
$\Delta \delta_j$, $j \in J_{\nop}$, подсчитаем по формуле
$$
\Delta \delta_j = \Delta \varphi'(t_*)G_j, \ \ j \in J_{\nop}; \quad
\Delta \varphi'(t_*) = -\sum\limits_{t \in
T_{\op}} \Delta\nu(t)d'(t)F_{22}(t) F_{22}^{-1}(t_*).
$$

После осуществления каждой итерации информацию 2)--5)
преобразуем следующим образом. В случае~1а) добавим в
матрицу $D_{\op}$ строку $d'(t_0)F_{22}(t_0) F_{22}^{-1}(t_*)G_j$,
$j \in J_{\op}$. Для ее подсчета
проинтегрируем уравнение $\Dot{F}_{22} = A_1(t)F_{22}$ на
промежутке $[t_{k_*},t_0]$ с начальным условием
$F_{22}(t_{k_*})$. Кроме того, удалим строку
$\xi'(t_{k_*},t_*)G_j$, $j \in J_{\op}$. В случае~1б) добавим
строку
$d'(t_0)F_{22}(t_0) F_{22}^{-1}(t_*)G_j$, $j \in J_{\op}$,
и добавим столбец
$d'(t)F_{22}(t)F_{22}^{-1}(t_*)G_{j_*}$, $t \in T_{\op}$.
В случае~2а) удалим строку $\xi'(t_{k_*},t_*)G_j$, $j
\in J_{\op}$, и удалим столбец $\xi'(t)F_{22}(t)F_{22}^{-
1}(t_*)G_{j_0}$, $t \in T_{\op}$, а в случае~2б) удалим
столбец $\xi'(t)F_{22}(t)F_{22}^{-1}(t_*)G_{j_0}$, $t \in
T_{\op}$, и добавим
$\xi'(t)F_{22}(t)F_{22}^{-1}(t_*)G_{j_*}$, $t \in T_{\op}$.

Опорные значения функции потенциалов $\ov{\nu}_{\op}$ найдем из
уравнения (\ref{funct_pot}). Вектор оценок
пересчитаем по формуле $\ov{\delta}_j = \delta_j + \sigma^*
\Delta \delta_j$, $j \in J$.

По правилам (\ref{vupp}), (\ref{pu}) построим неопорные компоненты
$\ov{\zeta}_j$, $j \in \ov{J}_{\nop}$,
вектора управляющих псевдопараметров и опорные значения
$\ov{\omega}(t)$, $t \in \ov{T}_{\op}$,
псевдоуправления. Решив систему (\ref{vupp_op}), найдем
$\ov{\zeta}_j$, $j \in \ov{J}_{\op}$.

Далее храним значение $F_{22}(t_0)$; $F_{22}(t_{k_*})$ удалим из
памяти.

Новые значения вектора управляющих псевдопараметров
$\ov{\zeta}_j$, $j \in J$, порождают новое псевдоуправление
$\ov{\omega}(t)$, $t \in T_h$, которое можно построить,
проинтегрировав на всем промежутке $T$ уравнение
(\ref{dyn_sys_y}) с начальным условием $y(t_*) = G \ov{\zeta}$.
Однако целью данной работы является построение
алгоритма, использующего минимальные интегрирования прямой и
сопряженной систем. Этой цели можно достичь, если на
каждой итерации использовать значения псевдоуправления не во все
моменты $t \in T_h$, а лишь в моменты $t \in T_0
\bigcup \{t_*, t^*\}$, в которые функция $\rho(t)$, $t \in T_h$,
достигает своих максимальных значений.

Значения псевдоуправления, соответствующего старой и новой опорам,
вычисляются по формулам
$$
\omega(t) = d'(t)F_{22}(t)F_{22}^{-1}(t_*)G\zeta; \quad
\ov{\omega}(t) =d'(t)F_{22}(t)F_{22}^{-1}(t_*)G\ov{\zeta}.
$$
Поэтому псевдоуправление изменяется в направлении $\Delta
\omega(t) = d'(t)F_{22}(t)F_{22}^{-1}(t_*)G(\ov{\zeta} - \zeta)$.

Наряду с хранящимися в памяти элементами 1)--7) будем
использовать дополнительную информацию
\begin{equation}\label{napr_i_shag}
\tau(t), \ \ \vartheta(t), \ \ t \in T_0 \bigcup \{ t_*, t^* \}.
\end{equation}
Числа (\ref{napr_i_shag}) подсчитаем по следующим правилам:
\begin{alignat*}{2}
\tau(t) &= -1, & \quad &\text{если}\ \ [t \in T_0^- \ \text{и}\
\Dot{\xi}'(t,t_*)G(\ov{\zeta}-\zeta) > 0] \
\text{или}\ [t \in T_0^+ \ \text{и}\
\Dot{\xi}'(t,t_*)G(\ov{\zeta}-\zeta) < 0]; \\
%
\tau(t) &= 1, &\quad &\text{если}\ \ [t \in T_0^+ \ \text{и}\
\Dot{\xi}'(t,t_*)G(\ov{\zeta}-\zeta) > 0] \
\text{или}\ [t \in T_0^- \ \text{и}\
\Dot{\xi}'(t,t_*)G(\ov{\zeta}-\zeta) < 0];
\end{alignat*}
\begin{gather}
\tau(t_*) = 1, \ \ \tau(t^*) = -1;\notag \\
%
\label{step}
\vartheta(t) = - \frac{\omega(t + \tau(t)h) - \omega(t)} {\Delta
\omega(t + \tau(t)h) - \Delta \omega(t)} = \\
= - \frac{(d'(t+\tau(t)h)F_{22}(t+\tau(t)h) - d'(t)F_{22}(t))
F_{22}^{-1}(t_*)G\zeta}
{(d'(t+\tau(t)h)F_{22}(t+\tau(t)h) - d'(t)F_{22}(t)) F_{22}^{-
1}(t_*)G(\ov{\zeta}-\zeta)}.\notag
\end{gather}
Числа $\tau(t)$, $t \in T_0$, указывают на возможное направление
движения точек максимума и минимума; $\vartheta(t)
\geq 0$ --- шаг, при котором вдоль направления $\Delta \omega(t)$,
$t \in T_h$, точка экстремума псевдоуправления
перейдет из точки $t$ в $t+\tau(t)h$. Шаги $\vartheta(t) < 0$ не
учитываются. Информацию о точках экстремума
псевдоуправления и о значениях в них матричной функции $F_{22}(t)$,
$t \in T$, преобразуем по этапам. Пусть вдоль
направления $\Delta \omega(t)$, $t \in T_h$, выполнен $(i-1)$-й этап,
и информация перед $i$-м этапом имеет вид
$T_0^{-i}$, $T_0^{+i}$, $\vartheta^i(t)$, $t \in T_0^i = T_0^{-i}
\bigcup T_0^{+i}$.

Предположим, что все числа $\vartheta^i(t)$, $t \in T_0^i$,
различны, кроме, возможно, чисел $\vartheta^i(t)$,
$\vartheta^i(t+h)$, $t, t+h \in T_0^i \bigcup \{t_*, t^*\}$,
причем $\tau(t) = 1$, $\tau(t+h) = -1$.

Подсчитаем шаг
\begin{equation}\label{step_i}
\vartheta^i = \vartheta^i(t^i) = \min\limits_{\vartheta^i(t) \geq
0} \vartheta^i(t), \ \ t \in T_0^i \bigcup \{t_*,t^*\}.
\end{equation}

В случае $\vartheta^i \leq 1$ хранимую в памяти информацию
преобразуем следующим образом.

1. Если $t^i \in T_0^i$ --- единственная точка, в которой
достигается минимум в (\ref{step_i}), то $T_0^{i+1} =
(T_0^i \setminus t^i) \cup \{ t^i + \tau(t^i)h \}$; вместо
значения фундаментальной матрицы $F_{22}(t^i)$
запоминаем значение $F_{22}(t^i+\tau(t^i)h)$; по формуле
(\ref{step}) вычисляем шаг $\vartheta(t^i+\tau(t^i)h)$.

2. Если $t^i = t_*$ или $t^i = t^*$, то $T_0^{i+1} = T_0^i \cup
\{t^i+\tau(t^i)h\}$. Вычисляем и запоминаем
значение фундаментальной матрицы $F_{22}(t^i+\tau(t^i)h)$;
полагаем $\tau(t^i+\tau(t^i)h) = \tau(t^i)$. Вычисляем
шаг\linebreak $\vartheta(t^i+\tau(t^i)h)$ согласно формуле (\ref{step}).
Момент $t^i+\tau(t^i)h$ является точкой минимума
псевдоуправления при $\omega(t^i) < \omega(t^i+\tau(t^i)h)$,
точкой максимума при $\omega(t^i) >
\omega(t^i+\tau(t^i)h)$.

3. При $\vartheta^i = \vartheta^i(t^i) = \vartheta^i(t^i+h)$,
$\tau(t^i) = 1$, $\tau(t^i+h) = -1$, $t^i, t^i+h
\in T_0^i \setminus \{t_*,t^*\}$, полагаем $T_0^{i+1} = T_0^i
\setminus \{t^i,t^i+h\}$; из памяти ЭВМ удалим
значения фундаментальной матрицы $F_{22}(t^i)$, $F_{22}(t^i+h)$.

4. В случае $\vartheta^i = \vartheta^i(t^i) = \vartheta^i(t^i+h)$,
$\tau(t^i) = 1$, $\tau(t^i+h) = -1$, $t^i =
t_*$ из множества $T_0^i$ удаляем точку $t^i+h$: $T_0^{i+1} =
T_0^i \setminus \{t^i+h\}$; из памяти ЭВМ удалим
значение фундаментальной матрицы $F_{22}(t^i+h)$.

5. При $\vartheta^i = \vartheta^i(t^i) = \vartheta^i(t^i+h)$,
$\tau(t^i) = 1$, $\tau(t^i+h) = -1$, $t^i+h = t^*$,
из множества $T_0^i$ удаляем точку $t^i$: $T_0^{i+1} = T_0^i
\setminus \{t^i\}$; из памяти ЭВМ удалим значение
фундаментальной матрицы $F_{22}(t^i)$.

Если $\vartheta^i > 1$, то хранимая в памяти ЭВМ информация
годится для использования на следующей итерации. На
этом текущая итерация завершается.

Представление об эффективности описанного двойственного метода
можно получить из \cite{Opt_nabl}, где аналогичный
метод используется для решения задачи оптимального наблюдения.

моменты получаются путем перемещения старых. На

\end{note}

\section{Приложение к задаче стабилизации динамических систем}


Рассмотрим динамическую систему управления (\ref{din_sys}),
которая не является собственно асимптотически
устойчивой. Будем считать, что система (\ref{din_sys}) управляема,
т.\,е. $\rank \{ b, Ab, ..., A^{n-1}b \} {=} n$.

Функция
\begin{equation}\label{stab_os}
u = u(x), \ \ u(0) = 0, \ \ |u(x)| \leq L, \ \ x \in G,
\end{equation}
называется ограниченной стабилизирующей обратной связью в области
$G$, если нулевое решение уравнения
\begin{equation}\label{zam_sys_stab}
\dot{x} = Ax + bu(x)
\end{equation}
асимптотически устойчиво в $G$.

Построение в явном (замкнутом) виде ограниченных стабилизирующих
обратных связей с достаточно большой областью
притяжения $G$ представляет трудную проблему. В этой ситуации
эффективным является метод стабилизации в режиме
реального времени, при котором функция (\ref{stab_os}) не строится
в явной форме, а вместо этого ее текущие
значения вычисляются в режиме реального времени по ходу каждого
конкретного процесса стабилизации.

В \cite{TK} для стабилизации динамических систем в режиме
реального времени предлагалось использовать метод
ОУ в режиме реального времени для специальных
вспомогательных (сопровождающих) задач ОУ. В
классе $U_N^p$ сопровождающая задача ОУ имеет вид
\begin{equation}\label{stab_problem}
\int_0^\theta |u(t)|dt \to \min; \quad \Dot{x} = Ax + bu, \ \
x(0) = z, \ \ x(\theta) = 0; \quad u(\cdot) \in U_N^p,
\end{equation}
где $\theta > 0$ --- параметр метода.

Пусть $u^0(t|z)$, $t \in [0, \theta]$, --- оптимальная программа
задачи (\ref{stab_problem}), $G_\theta$ ---
множество всех $z \in R^n$, для которых задача
(\ref{stab_problem}) имеет решение.

Оптимальная (стартовая) обратная связь
$$
u^0(z) = u(0\mid z), \ \ z \in G_\theta,
$$
является стабилизирующей, а область притяжения $G_\theta$ при
достаточно больших $\theta$ сколь угодно близка к
максимальной области притяжения состояния равновесия замкнутой
системы (\ref{zam_sys_stab}).

Стабилизация системы (\ref{din_sys}) в режиме реального времени
осуществляется следующим образом. До начала
процесса стабилизации вычисляется оптимальная программа
$u^0(t\mid x_0)$, $t \in [0, \theta]$. Время на ее вычисление
несущественно. На промежутке $[0, h[$ на вход системы
(\ref{din_sys}) подается управление $u^*(t) = u^0(t\mid x_0)$,
$t \in [0, h[$. Пусть $x^*(h)$ --- состояние, в котором система
(\ref{din_sys}) оказалась в момент $h$ под
действием этого управления. По измеренному $x^*(\tau)$ вычислим
оптимальную программу $u^0(t\mid x(h))$, $t \in [0,
\theta]$. Начальная часть $u^*(t) = u^0(t-h\mid x^*(h))$, $t \in [0,
h[$, этой программы подается на систему
(\ref{din_sys}) на промежутке $[h, 2h[$. Далее вычисления
повторяются.

Поскольку задачи (\ref{stab_problem}) для двух соседних моментов
$\tau$, $\tau+h$ и соответствующих им двух
состояний $x^*(\tau)$, $x^*(\tau+h)$ очень близки между собой, то
оптимальная опора $K_{\op}(\tau+h)$ для момента
$\tau+h$ быстро строится описанным в пп.\,4,~5 двойственным методом
по оптимальной опоре $K_{\op}(\tau)$ для
момента $\tau$, что позволяет осуществить стабилизацию в режиме
реального времени.

Приведем результаты численного эксперимента.

\begin{exam}
Рассмотрим задачу стабилизации двухмассовой
колебательной системы, исследованной в примере 1. В
качестве сопровождающей была рассмотрена следующая задача ОУ:
\begin{gather*}
\int_{0}^{10} |u(t)| dt \to \min; \ \ \Dot x_1 = x_3, \ \ \Dot
x_2 = x_4, \ \ \Dot x_3 = -x_1 + x_2 + u, \ \ \Dot
x_4 = 0.1 x_1 - 1.02 x_2, \\
%
x_1(0) = x_{10}, \ \ x_2(0) = x_{20}, \ \ x_3(0) = x_{30}, \ \ x_4(0) =
x_{40}; \ \ x_1(10) = x_2(10) = x_3(10) =x_4(10) = 0,
\end{gather*}
которая решалась в двух классах управлений:

1) в классе $U_{100}^1$
\begin{gather*}
0 \le v(t) \le 2, \ \ -100 \le w(t) \le 100, \ \ t \in [0, 10]; \\
%
u(t) = v(t) + (t-kh)w(t), \ \ t \in [kh, (k+1)h[, \ \ k = \overline{0,
99}, \ \ h = 0.1,
\end{gather*}

2) в классе $U_1^{5}$
\begin{gather*}
u(t) = u_0 + u_1(t-kh) + u_2(t-kh)^2 + u_3(t-kh)^3 + u_4(t-kh)^4; \\
%
t \in [kh, (k+1)h[, \ \ k = \overline{0, 99}, \ \ h = 0.1; \\
%
0 \leq u(t) \leq 2, \ \ t \in [0, 10], \ \ 0 \le u_0 \le 2, \ \
-10 \le u_j \le 10, \ \ j \in \{ 1,2,3,4 \}.
\end{gather*}

$x_1(t)$, $x_2(t)$, $x_3(t)$, $x_4(t)$. Сравнение приведенных
результатов показывает, что при невыполнении

ухудшается.
