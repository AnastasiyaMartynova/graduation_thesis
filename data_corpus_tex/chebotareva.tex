Пусть $E_p^{++}$ "--- четверть $x_p > 0$,  $x_{p - 1} > 0$
$p$-мерного евклидова пространства точек $x = \left( {x', x_p }
\right)$,  $x' = \left( {x'', x_{p - 1} } \right)$,  $x'' = \left(
{x_{1} , x_{2} , \,\dots x_{p - 2} } \right)$;  $\Omega$ "--- конечная
область в $E_p^{++}$,  ограниченная гиперповерхностью $\Gamma $ и
частями $\Gamma _0 $ и $\Gamma _1 $ гиперплоскостей $x_{p - 1} =
0$ и $x_p = 0$ соответственно;  $\Omega _e = E_p^{ + + } \backslash
\left( {\Omega \cup \Gamma } \right)$.

Рассмотрим в $E_p^{++} $ вырождающееся В"=эллиптическое уравнение
\begin{equation}
\label{chebotareva:eq1} E\left[ {u(x)} \right] = \Delta _{x''} u +
B_{x_{p - 1} } u + \frac{\partial }{\partial x_p }\left(
{x_p^\alpha \frac{\partial u}{\partial x_p }} \right) = 0, 
\end{equation}
где $\Delta _{x{'}'} = \sum\limits_{j = 1}^{p - 2} {\frac{\partial
^2}{\partial x_j^2 }} $,  $B_{x_{p - 1} } = \frac{\partial
^2}{\partial x_{p - 1}^2 } + \frac{k}{x_{p - 1} }\frac{\partial
}{\partial x_{p - 1} }$ "--- оператор Бесселя,  $0 < \alpha < 1$, 
$k > 0$ "--- постоянные,  $p \ge 3$.

\Section{Фундаментальное решение}
Будем искать решение уравнения~(\ref{chebotareva:eq1}) в виде

\begin{equation}
\label{chebotareva:eq2} u\left( x \right) = \left( {p_1^2 }
\right)^{ - \left( {\frac{\gamma - 2}{2} + \beta } \right)}w\left(
\sigma \right), 
\end{equation}
где
$\sigma = \frac{\rho ^2}{\rho _1^2 }$,  
$
\beta = \frac{\alpha }{2\left( {2 - \alpha } \right)}$, 
$\gamma = p + k, 
$
$\rho ^2 = \left| {x'}
\right|^2 + \frac{4}{\left( {\alpha - 2} \right)^2}\left(
{x_p^{\frac{2 - \alpha }{2}} - x_{p_0 }^{\frac{2 - \alpha }{2}} }
\right)^2$, 
 $\rho _1^2 = \left| {x'} \right|^2 +
\frac{4}{\left( {\alpha - 2} \right)^2}\left( {x_p^{\frac{2 -
\alpha }{2}} + x_{p_0 }^{\frac{2 - \alpha }{2}} } \right)^2$.


Подставляя функцию~(\ref{chebotareva:eq2}) в
уравнение~(\ref{chebotareva:eq1}),  имеем
\begin{equation}
\label{chebotareva:eq3} \sigma \left( {1 - \sigma } \right)w'' +
\left[ {\frac{\gamma }{2} - \left( {\frac{\gamma }{2} + 2\beta }
\right)\sigma } \right]w' - \beta \left( {\frac{\gamma - 2}{2} +
\beta } \right)w = 0.
\end{equation}

Известно~[\citen{chebotareva:c1}],  что в окрестности точки
$\sigma=1$ уравнение~(\ref{chebotareva:eq3}) имеет два линейно
независимых решения. Одно из них имеет вид
\begin{multline}
\label{chebotareva:eq4}
 w\left( \sigma \right) = \left( {1 - \sigma } \right)^{1 - 2\beta }F\left(
{1 - \beta , \frac{\gamma }{2} - \beta , 2 - 2\beta ; 1 - \sigma } \right) = \\
 = \sigma ^{ - \frac{\gamma - 2}{2}}\left( {1 - \sigma } \right)^{1 - 2\beta
}F\left( {1 - \beta , 2 - \frac{\gamma }{2} - \beta , 2 - 2\beta ; 1
- \sigma } \right).
 \end{multline}
Подставляя~(\ref{chebotareva:eq4}) в~(\ref{chebotareva:eq2}), 
получаем решение уравнения~(\ref{chebotareva:eq1}):
\begin{multline}
\label{chebotareva:eq5} q\left( {x; x_{p_0 } } \right) = A\left(
{\rho _1^2 } \right)^{ - \beta }\left( {\rho ^2} \right)^{ -
\frac{\gamma - 2}{2}}\left( {1 - \sigma } \right)^{1 - 2\beta
}\times\\\times
F\left( {1 - \beta,  2 - \frac{\gamma }{2} - \beta,  2 - 2\beta ;  1- \sigma } \right), 
\end{multline}
где $A$ "--- некоторая постоянная,  $F\left( {a, b, c; z} \right)$ "---
гипергеометрическая функция. Известно~[\citen{chebotareva:c2}], 
что решение~(\ref{chebotareva:eq5}) может быть представлено в виде
\begin{multline}
\label{chebotareva:eq6}
q\left( {x; x_{p_0 } } \right)= A\left( {\rho _1^2 } \right)^{ -
\beta }\left( {\rho ^2} \right)^{ - \frac{\gamma - 2}{2}}\left( {1
- \sigma } \right)^{1 - 2\beta }\times \\ \times \frac{\Gamma \left( {2 -
2\beta } \right)\Gamma \left( {\frac{\gamma - 2}{2}}
\right)}{\Gamma \left( {1 - \beta } \right)\Gamma \left(
{\frac{\gamma }{2} - \beta } \right)}F\left( {1 - \beta , 2 -
\frac{\gamma
}{2} - \beta,  2 - \frac{\gamma }{2}; \sigma } \right) + \\
 + A\left( {\rho ^2} \right)^{ - \left( {\frac{\gamma - 2}{2} + \beta }
\right)}\left( {1 - \sigma } \right)^{1 - 2\beta }\times \\ \times
\frac{\Gamma \left( {2 - 2\beta } \right)\Gamma \left( { -
\frac{\gamma - 2}{2}} \right)}{\Gamma \left( {1 - \beta }
\right)\Gamma \left( {2 - \frac{\gamma }{2} - \beta }
\right)}F\left( 1 - \beta,  \frac{\gamma }{2} - \beta,  \frac{\gamma }{2};  \sigma  \right).
\end{multline}
С помощью ряда Гаусса, а также разложения в~степенной ряд функций  \linebreak $(1 {-} \sigma )^{1 {-}
2\beta }$ и $\left( {1 {+} \frac{\left( {2 {-} \alpha } \right)^2\rho
^2}{16\left( {xx_0 } \right)^{\frac{2 {-} \alpha }{2}}}} \right)^{ -
\beta }$ при малых значениях $\rho $, 
решение~(\ref{chebotareva:eq6}) можно записать в~виде
\begin{multline}
\label{chebotareva:eq7} q\left( {x;  x_{p_0 } } \right) =
A\frac{\Gamma \left( {2 - 2\beta } \right)\Gamma \left(
{\frac{\gamma - 2}{2}} \right)}{\Gamma \left( {1 - \beta }
\right)\Gamma \left( {\frac{\gamma }{2} - \beta }
\right)}
\times\\ \times
\frac{\left( {2 - \alpha } \right)^{2\beta }\left( {x_p
x_{p_0 } } \right)^{ - \frac{\alpha }{4}}}{2^{4\beta }}\left(
{\rho ^2} \right)^{ - \frac{\gamma - 2}{2}} + q^\ast \left(
{x;  x_{p_0 } } \right), 
\end{multline}
где $q^\ast \left( {x; x_{p_0 } } \right)$ "--- регулярная в точке
$\left( {0', x_{p_0 }} \right)$ функция.
Функция~(\ref{chebotareva:eq7}) по переменным $x_1$,  $x_2$,  $\dots$,  $x_p$
является решением уравнения~(\ref{chebotareva:eq1}),  имеет
степенную особенность и,  следовательно,  является фундаментальным
решением уравнения~(\ref{chebotareva:eq1}) с особенностью в точке
$\left(0', x_{p_0}\right)$.

Для получения фундаментального решения
уравнения~(\ref{chebotareva:eq1}) с особенностью в произвольной
точке $x_0 \in E_p^{ + + } $применим к функции
(\ref{chebotareva:eq7}) оператор обобщенного сдвига
$T_{x'}^{{x}'_0 } $:

$$
\mathcal{E}\left( x; x_{p_0} \right) = A \frac{ \Gamma
\left(2-2\beta\right)\Gamma \left( \frac{\gamma-
2}{2}\right)}{\Gamma \left(1 - \beta\right)\Gamma
\left(\frac{\gamma}{2}-\beta\right)} \frac{\left(2 -
\alpha\right)^{2\beta}\left(x_p x_{p_0} \right)^{-
\frac{\alpha}{4}}}{2^{4\beta }} \times $$
\begin{multline}
\label{chebotareva:eq8} \times \int_0^\pi \biggl[
\left| {x''-x''_0 } \right|^2 +
x_{p - 1}^2 + x_{{p - 1}_0 }^2 -\biggr. 2x_{p - 1} x_{{p - 1}_0} \cos\varphi+\\
\biggl. +\frac{4}{\left(2 -
\alpha \right)^2}\left( x_p^{\frac{2 - \alpha }{2}} -
x_{p_0}^{\frac{2 - \alpha }{2}} \right)^2 \biggr] ^{ -
\frac{\gamma - 2}{2}}\sin ^{k - 1}\varphi d\varphi + \psi ^{\ast
\ast }\left( {x; x_0} \right), 
\end{multline}
где $C_k^{ - 1} = {\displaystyle \int_0^\pi} {\sin ^{k - 1}\varphi d\varphi
= \sqrt \pi \Gamma \left( {\frac{k}{2}} \right)\Gamma ^{ -
1}\left( {\frac{k + 1}{2}} \right)} $,  а $\psi ^{\ast \ast }\left(
{x; x_0 } \right)$ "--- регулярная в~точке $\left( {x; x_0 }
\right)$ функция.

Аналогично доказательству,  приведенному в~[\citen{chebotareva:c3}],
можно показать,  что при малых значениях $\rho _{xx_0 }$
выполняется
\begin{multline*}
\int_0^\pi \biggl[ \left| {x''-x''_0 } \right|^2 + x_{p -
1}^2 + x_{{p - 1}_0 }^2 -2x_{p - 1} x_{{p - 1}_0}
\cos\varphi+ \\ + \frac{4}{\left(2 - \alpha \right)^2}\left(
x_p^{\frac{2 - \alpha }{2}} - x_{p_0}^{\frac{2 - \alpha }{2}}
\right)^2 \biggr] ^{ - \frac{\gamma - 2}{2}}\sin ^{k - 1}\varphi
d\varphi = \\
=\left( {x_{p - 1} x_{p - 1_0 } } \right)^{-\frac{k}{2}}\rho
_{xx_o }^{2 - p} + R\left( {x; x_0 } \right), 
\end{multline*}
где $\rho _{xx_0 }^2 = \left| {{x}' - {x}'_0 } \right|^2 +
\frac{4}{\left( {2 - \alpha } \right)^2}\left( {x_p^{\frac{2 -
\alpha }{2}} - x_{p_0 }^{\frac{2 - \alpha }{2}} } \right)^2$.
Отсюда следует,  что фундаментальное
решение~(\ref{chebotareva:eq8}) может быть представлено в виде
\begin{multline}
\label{chebotareva:eq11}
 \mathcal{E}\left( {x; x_0 } \right) = A\frac{\Gamma ( {2 - 2\beta } )\Gamma
\bigl( \frac{\gamma - 2}{2} \bigr)}{\Gamma (1 - \beta )\Gamma \bigl( \frac{\gamma }{2} - \beta 
\bigr)}
\times \\ \times
\frac{\left( {2 - \alpha } \right)^{2\beta }}{2^{4\beta
}}\left( {x_p x_{p_0 } } \right)^{ - \frac{\alpha }{4}}\left(
{x_{p - 1} x_{p - 1_0 } } \right)^{\frac{ - k}{2}}\rho _{xx_o }^{2
- p} +  \mathcal{E}^\ast \left( {x; x_0 } \right), 
\end{multline}
где $\mathcal{E}^\ast \left(x; x_0 \right)$ "--- регулярная часть
фундаментального решения.

Фундаментальное решение обладает следующими свойствами:
\begin{equation}
\label{chebotareva:eq12} \mathcal{E}\left( {\xi;  x} \right) =
o\left( 1 \right)\text{ при } x_{p} \to 0, 
\end{equation}
\begin{equation}
\label{chebotareva:eq15} \mathcal{E}\left( {x; x_0 } \right) =
O\left( {\left( {\rho _{xx_0 }^2 } \right)^{ - \left(
{\frac{\gamma - 2}{2} + \frac{4 - 3\alpha }{2\left( {2 - \alpha }
\right)}} \right)}} \right)\text{ при } ~ r = \sqrt {x_1^2 + x_2^2
+ ... + x_p^2 } \to \infty .
\end{equation}

\Section{Формулы Грина}
Обозначим через $C_B^1 (\Omega \cup \Gamma _0 )$ множество четных
по $x_{p - 1}$ один раз непрерывно дифференцируемых в $\Omega \cup
\Gamma _0$ функций. Пусть \linebreak $u$,  $v \in C^2\left( \Omega \right) \cap
C^1\left( {\overline \Omega } \right) \cap C_B^1 \left( {\Omega
\cup \Gamma _0 } \right)$.

Непосредственными вычислениями можно проверить,  что
\begin{multline}
\label{chebotareva:eq17} vE\left[ u \right]x_{p - 1}^k + \Biggl(
{\sum\limits_{j = 1}^{p - 1} {\frac{\partial u}{\partial x_j
}\frac{\partial v}{\partial x_j } + x_p^\alpha \frac{\partial
u}{\partial x_p }\frac{\partial v}{\partial x_p }} } \Biggr)x_{p -
1}^k = \\ = \sum\limits_{j = 1}^{p - 1} {\frac{\partial }{\partial x_j
}\left( {x_{p - 1}^k v\frac{\partial u}{\partial x_j }} \right) +
\frac{\partial }{\partial x_p }\left( {x_{p - 1}^k x_p^\alpha
v\frac{\partial u}{\partial x_p }} \right)} .
\end{multline}

Интегрируя обе части тождества (\ref{chebotareva:eq17}) по области
$\Omega $ и пользуясь формулой Остроградского,  получим
\begin{multline}
\label{chebotareva:eq18} \int_\Omega vE\left[ u
\right]x_{p - 1}^k \,dx + \int_\Omega \Biggl(
{\sum\limits_{j = 1}^{p - 1} {\frac{\partial u}{\partial x_j
}\frac{\partial v}{\partial x_j } + x_p^\alpha \frac{\partial
u}{\partial x_p }\frac{\partial v}{\partial x_p }} } \Biggr)x_{p -
1}^k \,dx = \\
= \int_\Gamma {vA\left[ u \right]} x_{p - 1}^k\,
d\Gamma , 
\end{multline}
где $A\left[~\right] = \sum\limits_{j = 1}^{p - 1} {\cos \left(
{n, x_j } \right)\frac{\partial }{\partial x_j }} + x_p^\alpha \cos
\left( {n, x_p } \right)\frac{\partial }{\partial x_p }$ "---
конормальная производная,  $n$ "--- внешняя нормаль к границе
$\Gamma$. Меняя в формуле~(\ref{chebotareva:eq18}) $u$ и $v$
местами,  имеем
\begin{multline}
\label{chebotareva:eq19} \int_\Omega uE\left[ v
\right]x_{p - 1}^k\, dx + \int_\Omega \Biggl(
\sum\limits_{j = 1}^{p - 1} \frac{\partial v}{\partial x_j
}\frac{\partial u}{\partial x_j } + x_p^\alpha \frac{\partial
v}{\partial x_p }\frac{\partial u}{\partial x_p }  \Biggr)x_{p -
1}^k \,dx = \\= \int_\Gamma {uA\left[ v \right]} x_{p - 1}^k\,
d\Gamma.
\end{multline}
Вычитая~(\ref{chebotareva:eq19}) из~(\ref{chebotareva:eq18}), 
получим
\begin{equation}
\label{chebotareva:eq20} \int_\Omega \bigr[ vE\left[ u
\right] - uE\left[ v \right] \bigl]x_{p - 1}^k \, dx =
\int_\Gamma \bigl[ vA\left[ u \right] - uA\left[ v
\right] \bigr] x_{p - 1}^k \,d\Gamma .
\end{equation}

Формулы~(\ref{chebotareva:eq18}) и~(\ref{chebotareva:eq20})
называются соответственно первой и второй формулами Грина для
оператора $E$.

\Section{Интегральное представление и принцип максимума}
Пусть функция $u \in C^2\left( \Omega \right) \cap C^1\left(
{\overline \Omega } \right) \cap C_B^1 \left( {\Omega \cup \Gamma
_0 } \right)$ является решением уравнения~(\ref{chebotareva:eq1})
в~области $\Omega $ и точка $M_0 \left( {x_0 } \right) \in \Omega
$. Рассмотрим сферу $S_{x_o \varepsilon } $ с центром в точке $M_0
$ и~радиуса $\varepsilon $  такого,  что $S_{x_o \varepsilon }
\subset \Omega$. Обозначим через $\Omega _\varepsilon $ область, 
ограниченную координатными гиперплоскостями,  гиперповерхностью
$\Gamma $ и сферой $S_{x_0 \varepsilon } $ ($\Omega _\varepsilon =
\Omega \backslash \bar {S}_{x_0 \varepsilon } )$. Ясно,  что
фундаментальное решение $\mathcal{E}\left( {x; x_0 } \right)$
принадлежит классу $C^2\left( \Omega \right) \cap C^1\left(
{\overline \Omega } \right) \cap C_B^1 \left( {\Omega \cup \Gamma
_0 } \right)$. Применяя к функциям $\mathcal{E}\left( {x; x_0 }
\right)$ и $u(x)$ вторую формулу Грина для оператора $E$ в области
$\Omega _\varepsilon$,  получаем
\begin{multline}
\label{chebotareva:eq23}
 \int_\Gamma \bigl[ \mathcal{E}\left( {x; x_0 } \right)A\left[ {u\left( x
\right)} \right] - u\left( x \right)A\left[ \mathcal{E}\left(
{x; x_0 } \right)
\right] \bigr] x_{p - 1}^k\, d\Gamma = \\
 = \int_{S_{x_{_0 } \varepsilon } } \bigl[ \mathcal{E}\left( {x; x_0 }
\right)A\left[ u\left( x \right) \right] - u\left( x
\right)A\left[ \mathcal{E}\left( {x; x_0 } \right) \right]
\bigr] x_{p - 1}^k \,dS_{x_0 \varepsilon }, 
 \end{multline}
где $A$ "--- внешняя конормаль к сфере $S_{x_0 \varepsilon}$.

Переходя в формуле (\ref{chebotareva:eq19}) к пределу при
$\varepsilon \to 0$ и выбирая значение
\begin{equation}
\label{chebotareva:eq24} A=\frac{\Gamma (1 - \beta )\Gamma \left(
{\frac{\gamma }{2} - \beta } \right)}{4\pi ^{\frac{\gamma
}{2}}\Gamma \left( {2 - 2\beta } \right)}\left( {\frac{4}{2 -
\alpha }} \right)^{2\beta }, 
\end{equation}
будем иметь
\begin{multline*}
 u(x_0 ) = \int_\Gamma \bigl[ \mathcal{E}(x; x_0 )A[u\left(
x \right)] - u\left( x \right)A[\mathcal{E}(x; x_0 )] \bigr]x_{p -
1}^k \,d\Gamma  + \\+ \int_{\Gamma _1 } u(x; 0)\frac{\partial
\mathcal{E}(x', 0; x_0 )}{\partial x_p }x_{p - 1}^k\, dx'.
\end{multline*}
Отсюда и из (\ref{chebotareva:eq12}) следует,  что существует
решение $u(x)$ уравнения (\ref{chebotareva:eq1}),  удовлетворяющее
условию $u\left( x \right) = o\left( 1 \right)$ при $x_p \to 0$.
Для таких решений интегральное представление имеет вид
\begin{equation}
\label{chebotareva:eq25} u(x_0 ) = \int_\Gamma \bigl[
{\mathcal{E}(x; x_0 )A[u\left( x \right)] - u\left( x
\right)A[\mathcal{E}(x; x_0 )]} \bigr]x_{p - 1}^k \,d\Gamma  ,
\end{equation}
из которого вытекает
следующее свойство решения уравнения (\ref{chebotareva:eq1}).

\begin{newthm}{Теорема (Принцип максимума)}
Если $u(x) {\in} C^2\!\left( \Omega \right) \cap C^1\!\left( {\overline
\Omega } \right) \cap C_B^1 \!\left( {\Omega \cup \Gamma _0 }
\right)$ "--- решение уравнения \eqref{chebotareva:eq1}, 
удовлетворяющее условию $u\left( x \right) = o\left( 1 \right)$
при $x_p \to 0$,  то функция $u(x)$ достигает своего положительного
наибольшего и отрицательного наименьшего значений на границе
$\Gamma $,  если она не равна нулю.
\end{newthm}
\begin{proof}
Предположим,  что функция $u(x) {\in} C^2\!\left( \Omega \right) \hm\cap
C^1\!\left( {\overline \Omega } \right) \hm\cap C_B^1 \!\left( {\Omega
\cup \Gamma _0 } \right)$ удовлетворяет уравнению
(\ref{chebotareva:eq1}) и достигает своего положительного
наибольшего значения в некоторой внутренней точке $M_0 \left( {x_0
} \right)$ области $\Omega $. Тогда существует $\delta $-окрестность 
точки $x_0 $,  в~которой $u(x) < u(x_0 )$ при $x \ne
x_0 $ и~$u(x) > 0$. Пусть $S_{x_0 \delta } $ "--- сфера с центром
в~точке $x_0 $ и~радиусом $\delta $. Полагая в~интегральном
представлении решения $u(x)$,  что $\Gamma = S_{x_0 \delta } $, 
получим
\begin{multline}
\label{chebotareva:eq26} u(x_0 ) = \int_{S_{x_{_0 } \delta
} } E(x; x_0 )A\left[ u(x) \right]x_{p - 1}^k \, dS_{x_0 \delta} -\\-
 \int_{S_{x_0 \delta }}  u(x)A\left[ E(x; x_0 )
\right]x_{p - 1}^k \, dS_{x_0 \delta } = I_1 + I_2.
\end{multline}
Так как $u(x) > 0$ и $\mathcal{E}(x; x_0 ) > 0$,  а конормаль $A$
является внешней по отношению к сфере $S_{x_0 \delta } $,  то
$A\left[ {u(x)} \right] < 0$ и $A\left[ {\mathcal{E}(x; x_0 )}
\right] < 0$,  а значит, $I_1 $ и $I_2 $ имеют разные знаки. Если $I_1 <
0$,  а $I_2 > 0$,  то при $\delta \to 0 \quad I_1 $, возрастая,
стремится к~нулю,  а~$I_2 $, возрастая, стремится к~$u(x_0 )$. Таким
образом,  $I_1 < 0$ и $I_2 < u(x_0 )$. Учитывая это  и заменяя в
(\ref{chebotareva:eq26}) $u(x)$ на $u(x_0 )$,  получим
бессмысленное неравенство
\[u(x_0 ) < I_2 < u(x_0 ).\]
Следовательно,  функция $u(x)$ может достигнуть своего
положительного наибольшего значения лишь на границе $\Gamma$.
Аналогичным образом можно доказать,  что функция $u(x)$ достигает
своего отрицательного наименьшего значения также на границе
$\Gamma $.
\end{proof}
\begin{newthm}{Следствие}
Если функция $u(x) \in C^2\left( \Omega \right) \cap C^1\left(
{\overline \Omega } \right) \cap C_B^1 \left( {\Omega \cup \Gamma
_0 } \right)$ является решением уравнения \eqref{chebotareva:eq1}, 
то $\left| {u(x)} \right| \le \mathop {\max }\limits_{\xi \in
\Gamma } \left| {u(\xi )} \right|$. В частности,  если $u\big|
_\Gamma = 0$,  $u\big|_{x_p = 0}   = 0$,  то
$u(x) \equiv 0$ в $\overline \Omega$.
\end{newthm}

 \end{array} \right.

\Section{Сведение задач Дирихле и Неймана к интегральным

Решение задачи $D_i$ будем искать в виде потенциала типа двойного

\begin{equation}
\label{chebotareva:eq50} u(x) = W(x) = \int_\Gamma v(\xi

\begin{equation}

A\left[\mathcal{E}\left(\xi; x\right)\right]\xi_{p - 1}^{k}\,d\Gamma
= 2\varphi (x) , 
\end{equation}
\begin{equation}
\label{chebotareva:eq53} \mu(x) + 2\int_{\Gamma} \mu (\xi)
A_{x}\left[\mathcal{E}\left(\xi; x\right)\right]\xi_{p -
1}^{k}\,d\Gamma =-2\psi (x), 
\end{equation}
\begin{equation}
\label{chebotareva:eq54}  \mu(x) - 2\int_{\Gamma} \mu (\xi)
A_{x}\left[\mathcal{E}\left(\xi; x\right)\right]\xi_{p -
1}^{k}\,d\Gamma =-2\psi (x) .
\end{equation}

Отметим следующие свойства интегральных уравнений
(\ref{chebotareva:eq51})--(\ref{chebotareva:eq54}).

1. Из формулы (\ref{chebotareva:eq11}) следует,  что данные
уравнения являются уравнениями со слабой особенностью.

2. Ядра $A\left[ \mathcal{E}\left(\xi; x\right)\right]$ и $A_x
\left[ \mathcal{E}\left(\xi; x\right) \right]$ получаются друг из
друга перестановкой местами точек $\xi $ и $x. $Так как эти ядра
вещественные,  то они сопряженные,  а~значит, уравнения
(\ref{chebotareva:eq51}) и (\ref{chebotareva:eq54}), 
(\ref{chebotareva:eq52}) и (\ref{chebotareva:eq53}) "--- попарно
сопряженные интегральные уравнения. Следовательно,  для них
справедливы теоремы Фредгольма.

\Section{Исследование интегральных уравнений}
Рассмотрим однородное интегральное уравнение,  соответствующее
задаче $N_e $:
\begin{equation}
\label{chebotareva:eq55} \mu (x) -
2\int_{\Gamma}{\mu\left(\xi\right)A_x \left[
\mathcal{E}\left(\xi; x\right)\right]}\xi_{p - 1}^{k}\, d\Gamma = 0.
\end{equation}
Если $\overline {\mu}\left(\xi \right)$ "--- ненулевое решение
этого уравнения,  то функция $$\overline{u}(x) =
\int_{\Gamma}
\overline{\mu}\left(\xi\right)\mathcal{E}\left(\xi; x\right)
\xi_{p-1}^{k}\,d\Gamma$$ удовлетворяет условиям
(\ref{chebotareva:eq40})--(\ref{chebotareva:eq43}) внешней
задачи Неймана и граничному условию $A_x\left[\overline{u}\left( x
\right) \right]\left.\right|_{\Gamma} = 0$,  т.\,е.
\begin{equation}
\label{chebotareva:eq56} A_x \left[ \overline{u}\left( x \right)
\right]_{e}=-\frac{\overline{\mu}(x)}{2}+\int_{\Gamma}\overline{\mu}(\xi)A_{x}\left[\mathcal{E}\left(\xi; x\right)\right]\xi_{p
- 1}^{k}d\Gamma = 0.
\end{equation}

По теореме единственности для задачи $N_e$ $\overline{u}\left( x
\right) = 0$,  $x \in \Omega _e $. Так как потенциал простого слоя
есть непрерывная функция в $E_p^{ + + } $,  то $\overline{u}\left(
x \right)=0$,  $x \in \Gamma $.

В области $\Omega $ функция $\overline {u}\left( x \right) $
удовлетворяет уравнению (\ref{chebotareva:eq1}) и обращается в~нуль на границе $\Gamma $. По теореме о единственности для задачи
$D_i$ $\overline {u}\left( x \right)=0$,  $x \in \Omega $.
Следовательно, 
\begin{equation}
\label{chebotareva:eq57} A_x \left[\overline{u}\left( x \right)
\right]_{i}=\frac{\overline{\mu}(x)}{2}+\int_{\Gamma}\overline{\mu}(\xi)A_{x}\left[\mathcal{E}\left(\xi; x\right)\right]\xi_{p
- 1}^{k}\,d\Gamma = 0.
\end{equation}

Вычитая из равенства (\ref{chebotareva:eq57}) равенство
(\ref{chebotareva:eq56}),  получим $\overline {\mu} (\xi ) = 0$,  $x
\in \Omega $, т.\,е.~однородное интегральное уравнение
(\ref{chebotareva:eq55}) имеет только тривиальное решение. 
В силу альтернативы Фредгольма  интегральное уравнение
(\ref{chebotareva:eq54}) задачи $N_e $ однозначно разрешимо 
для любой непрерывной на $\Gamma $ функции 
\mbox{$\psi \left( x \right) \in \Gamma $.}

Таким образом,  значение $\lambda = 2$ "--- правильное для 
ядра $A_x \left[ \mathcal{E}\left(\xi; x\right)\right]$;  по
известной теореме Фредгольма  оно является правильным и~для
сопряженного ядра $A\left[ \mathcal{E}\left(\xi; x\right)\right]$.

Отсюда следует,  что интегральное уравнение
(\ref{chebotareva:eq51}) задачи $D_i $ однозначно разрешимо для
любой непрерывной функции $\varphi \left( x \right) \in C\left(
\Gamma \right)$.

Из разрешимости интегральных уравнений задач $D_i $ и $N_e $
следует,  что разрешимы и сами задачи. Это приводит к следующим
теоремам.

\begin{theorem}[8]Если $\Gamma$ "--- поверхность Ляпунова, которая
образует с гиперплоскостями $x_{p - 1} = 0$ и $x_p = 0$ прямые
углы,  то задача $D_i $ для этой поверхности разрешима при любых
непрерывных граничных данных и решение можно представить в виде
потенциала типа двойного слоя.
\end{theorem}
\begin{theorem}[9]Если $\Gamma $ "--- поверхность Ляпунова, которая образует 
с~гиперплоскостями $x_{p - 1} = 0$ и $x_p = 0$ прямые
углы,  то задача $N_e$ для этой поверхности разрешима при любых
непрерывных граничных данных и решение можно представить в виде
потенциала типа простого слоя.
\end{theorem}
Исследование второй пары интегральных уравнений
(\ref{chebotareva:eq52}) и (\ref{chebotareva:eq53}), 
соответствующих  задачам $D_e$ и $N_i$,  приводит к следующим
теоремам.
\begin{theorem}[10]Если $\Gamma $ "--- поверхность Ляпунова, образующая
с~гиперплоскостями $x_{p - 1} = 0$ и $x_p = 0$ прямые
углы,  и при этом выполняется условие
\[
\label{chebotareva:eq67} \int_\Gamma \psi \left( \xi
\right)\xi _{p - 1}^k \,d\xi  = 0,
\]
то задача $N_i $ для этой поверхности разрешима при любых
непрерывных граничных данных и решение можно представить в виде
потенциала типа простого слоя.
\end{theorem}
\begin{theorem}[11] Если $\Gamma $ "--- поверхность Ляпунова, которая
образует с гиперплоскостями $x_{p - 1} = 0$ и $x_p = 0$ прямые
углы,  то задача $D_e $ для этой поверхности однозначно разрешима
при любых граничных данных и решение можно представить в виде
\[
u\left( x \right) = \int_\Gamma {v\left( \xi \right)}
A\left[ \mathcal{E}\left(\xi; x\right)\right]\xi _{p - 1}^k d\Gamma
+ \frac{1}{\rho _{xx_0 }^{\gamma - 2 + 2\beta }
}\int_\Gamma {\nu \left( \xi \right)\xi _{p - 1}^k d\Gamma
}.
\]
\end{theorem}
