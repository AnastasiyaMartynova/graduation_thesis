В качестве расчётной схемы рассмотрим многослойную плоскую стенку,
представленную на рисунке и~состоящую из $n$ разнородных слоёв с~постоянными
в~пределах каждого слоя теплофизическими характеристиками.
Представим теплофизические характеристики многослойных стенок как единые целые
и~действующие в~них внутренние источники теплоты с~интенсивностью
$q_{v}(x, \tau )$  как функции координаты $x$ в~виде
\begin{gather}
\label{av:s:eq1}
\lambda (x)=\lambda _1 +\sum\limits_{i=1}^{n-1} (\lambda _{i+1}  -\lambda_i ) H  (x-x_i ),
\\
\label{av:s:eq2}
c_v (x)=c_{v1} +\sum\limits_{i=1}^{n-1} (c_{v\, i+1} -c_{vi}  ) H  (x-x_i ),
\\
\label{av:s:eq3}
q_v (x,\tau )=q_{v1} (\tau )+\sum\limits_{i=1}^{n-1} \bigl[ q_{v\,i+1} (\tau)-q_{vi} (\tau )  \bigr] H  (x-x_i ),
\end{gather}


\begin{figure}[t!] \centering
 \includegraphics{aver.eps}
\caption*{Расчётная схема}
\end{figure}


\noindent
где $\lambda _i $ и $c_{vi} $ "--- соответственно коэффициент теплопроводности
и~объёмная теплоёмкость $i$-того слоя стенок;
$x_{i}$ "--- координата сопряжения $i$-того и  ($i+1$)-го слоёв стенок;
$n$ "--- количество слоев; $q_{vi}(x,\tau )$ "---
интенсивность внутренних источников теплоты \mbox{в~$i$-том} слое;
$
H(x-x_i )= \left\{
\begin{array}{cc}
 0, &\text{если $x<x_i$,}\\
 1, &\text{если $x\geqslant x_i$}
\end{array} \right.$ "--- асимметричная единичная функция.



Математическая постановка краевой задачи нестационарной теплопроводности в~многослойных
стенках при несимметричных граничных условиях третьего рода
имеет вид [1]
\begin{gather}
\label{av:s:eq4}
c_v (x)\frac{\partial T(x, \tau )}{\partial \tau }=
\frac{1}{x^m}
\Bigl\{
\frac{\partial}{\partial x}\Bigl[
\lambda (x) x^m\frac{\partial T (x, \tau)}{\partial x}
\Bigr]
\Bigr\}+q_v (x, \tau )
\quad
(x_0 \leqslant x\leqslant x_n, \; \tau >0),
\\
\label{av:s:eq5}
T(x, 0)=f(x),
\end{gather}
\begin{equation}
\label{av:s:eq6}
\begin{array}{r}
 \Bigl[ \displaystyle
-\lambda (x) \frac{\partial T(x,\tau )} {\partial x}+\alpha _1 \beta _1 T(x, \tau )  \Bigr]_{x=0} =\alpha _1 \varphi_1 (\tau ), \vspace{1mm} \\
\displaystyle
 \Bigl[ \displaystyle
\lambda (x) \frac{\partial T(x, \tau)} {\partial x} +\alpha _2 \beta _2 T(x, \tau ) \Bigr]_{x=n} =\alpha _2 \varphi _2 (\tau ),
 \end{array}
\end{equation}
где $m \equiv 0, 1, 2$ соответственно для стенок плоской, цилиндрической и~сферической форм.



Искомое температурное поле представим в виде двух составляющих
\begin{equation}
\label{av:s:eq7}
T(x,\tau )=V(x,\tau )+U(x,\tau ),
\end{equation}
где квазистационарная составляющая $V(x,\tau )$ является решением уравнения
\begin{equation}
\label{av:s:eq8}
\frac{1}{x^m}\Bigl\{
\frac{\partial }{\partial x}\Bigl[ \lambda(x)x^m\frac{\partial V(x,\tau )}{\partial x}  \Bigr] \Bigr\}=0
\end{equation}
с неоднородными граничными условиями вида (\ref{av:s:eq6}).

Общий интеграл дифференциального уравнения (\ref{av:s:eq8}), например для многослойной
плоской стенки ($m= 0$), имеет вид
\begin{multline*}
\label{av:s:eq9}
V(x,\tau )=\frac{\alpha _1 a\varphi _1 (\tau )+\alpha _2 \varphi _2 (\tau
)-\alpha _1 \alpha _2 \left[ {\beta _2 \varphi _1 (\tau )-\beta _1 \varphi
_2 (\tau )} \right]}{\alpha _1 \beta _1 a+\alpha _2 \beta _2 }
\times \\
\times
\Bigl[
\frac{x-x_0 }{\lambda _1 }+\sum\limits_{i=1}^{n-1} \Bigl(
{\frac{1}{\lambda _{i+1} }-\frac{1}{\lambda _i }} \Bigr) ( x-x_i )H(x-x_i) \Bigr],
\end{multline*}
где $a=1+\alpha _2 \beta _2 \sum\limits_{i=1}^n ({x_i -x_{i-1}})/{\lambda _i } $.

Нестационарная составляющая $U(x, \tau )$ определяется из решения уравнения
вида (\ref{av:s:eq4}) с~однородными граничными условиями, т.\,е. при
$\alpha _1 \varphi _1 (\tau )=0$ и $\alpha _2 \varphi _2 ( \tau )=0$ в~соотношениях (6).

После определения функции $U(x, \tau )$ соотношение (\ref{av:s:eq7}) принимает вид
\begin{equation*}
\label{av:s:eq10}
T(x, \tau )=V(x, \tau )+\sum\limits_{n=1}^\infty U_n (\tau ) \Psi _n
(x)\exp(-k_n^2 \tau ).
\end{equation*}
где $\displaystyle a_n (\tau )=\frac{1}{N_n^2 }\int\limits_{x_0 }^x
\Bigl[ q_v (x,\tau)-C_v (x)\frac{\partial V}{\partial \tau }  \Bigr] \Psi _n (x)x^m dx$,
$\displaystyle N_n^2 =\int\limits_{x_0}^x C_v (x) \Psi _n^2 (x)x^m dx$ "--- квадрат
нормы собственных функций $\Psi _n (x)$,
$ \displaystyle
U_n (\tau )=A_n +\int\limits_0^\tau a_n (t)\exp(-k_n^2 t)dt.
$


Постоянные интегрирования $A_n $ находятся из начального условия (\ref{av:s:eq5}).
Формула для их определения будет
\[
A_n =\frac{1}{N_n^2}\int\limits_{x_0}^x \bigl[ f(x)-V(x, 0)\bigr]C_v(x)\Psi _n (x)x^mdx.
\]

Таким образом, на основе применения теории обобщенных функций путем сведения задачи теплопроводности для многослойной конструкции к~однослойной с~переменными (разрывными) физическими свойствами среды в~замкнутом виде получено точное аналитическое решение задачи нестационарной теплопроводности для многослойной конструкции с~переменными во времени внутренними источниками теплоты.
