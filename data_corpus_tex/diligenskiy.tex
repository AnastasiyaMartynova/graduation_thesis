Рассмотрим задачу оптимального по быстродействию управления процессом нагрева стержня ограниченной длины с~заданной точностью приближения к~требуемой температуре, оцениваемой в равномерной метрике.

Уравнение динамики распределённого объекта конечной длины в~канонической форме описывается одномерным параболическим уравнением теплопроводности
\begin{equation}
\frac{\partial T}{\partial \tau }=\frac{\partial ^2T}{\partial x^2},
\quad
0\le \tau <\infty ,\quad 0\le x \le 1, 
\label{dilig:eq1}
\end{equation}
с граничным управляющим воздействием
\begin{equation}
\frac{\partial T}{\partial x} \Bigr|_{x=1} =u(\tau ),
\label{dilig:eq2}
\end{equation}
условием адиабатичности
\begin{equation}
\label{dilig:eq3}
\frac{\partial T}{\partial x} \Bigr|_{x=0} =0
\end{equation}
и начальным условием
\begin{equation}
\label{dilig:eq4}
T \bigr|_{\tau =0} =0.
\end{equation}
Здесь 
$x$ "--- безразмерная (нормированная) пространственная координата по длине стержня; 
$\tau $ "--- безразмерное время (число Фурье); 
$T(x,\,\tau )$ "--- температурное поле в относительных единицах; 
$u(\tau )$ "--- управляющее воздействие, представляющее собой относительную величину теплового потока на границе \mbox{$x=1$}.

Ставится задача достижения в момент времени $\tau_{\text{к}} $ заданной температуры $T_{\text{з}} ={\rm const}$ с~требуемой точностью $\varepsilon$:
\begin{equation}
\label{dilig:eq5} 
\max \limits_{x\in [0,1]} | T(\tau_{\text{к}} , x)-T_{\text{з}} |\le \varepsilon
\end{equation}
при минимальном значении критерия оптимальности
\begin{equation}
\label{dilig:eq6}
J=\int_0^{\tau_{\text{к}} } dt =\tau_{\text{к}} =\min \limits_{u(\tau)}
\end{equation}
в условиях заданных ограничений на величину управляющего теплового потока
\begin{equation}
\label{dilig:eq7}
u_{\min } \le u (\tau )\le u_{\max }.
\end{equation}

Сформулированная задача \eqref{dilig:eq1}--\eqref{dilig:eq7} относится к~задачам недифференцируемой оптимизации. 
Она была всесторонне исследована в работах \cite{dilig:bib1, dilig:bib2}, в~которых был установлен ряд универсальных закономерностей алгоритмов управления и поведения оптимальных температурных распределений, приведённых ниже.

\begin{enumerate}
\item[1.] Установлено, что алгоритм оптимального управления $u^\ast (\tau )$ является кусочно"=постоянной (релейной) функцией времени, попеременно принимающей свои предельно допустимые согласно \eqref{dilig:eq7} значения $u_{\min}$ и $u_{\max}$ с~длительностями постоянства управления $\Delta _i$: $\sum_{i=1}^n {\Delta _i } =\tau_{\text{к}} $.

\item[\textcolor{white}{\eqref{dilig:eq2}}\!\!.] Число $n$ "--- число интервалов постоянства оптимального управления "--- однозначно определяется величиной допустимой требуемой точности $\varepsilon$  из \eqref{dilig:eq5}.
При ужесточении требований (при уменьшении $\varepsilon $) число $n$ возрастает. Другими словами, $n\to \infty $ при $\varepsilon \to 0$. 
При этом для каждого оптимального управления с фиксированным числом интервалов $n$ существует предельно достижимая точность нагрева $\varepsilon ^{(n)}$. \phantom{\eqref{dilig:eq2}}

\item[\textcolor{white}{\eqref{dilig:eq3}}\!\!.] Оптимальные конечные температурные распределения $T(\tau_{\text{к}}, x)$ при любом $\varepsilon $ обладают альтернансными свойствами: являются дифференцируемыми по $x$ функциями, принимающими предельно допустимые согласно \eqref{dilig:eq5} значения $T_{\text{з}} \pm \varepsilon $ в~чередующихся на отрезке $[0, 1]$ максимумах и~минимумах в~точках $x_i^\ast \in [0, 1]$.
Исходная задача недифференцируемой оптимизации эквивалентна задаче решения системы уравнений
\begin{equation}
\label{dilig:eq8} 
T(\tau_{\text{к}}, x) \bigr|_{x= x_i^\ast } =T_{\text{з}} \pm \varepsilon; 
\quad i=1, 2, \dots, R, \quad  R=
\begin{cases}
 n, & \varepsilon >\varepsilon ^{(n)}; \\
 n+1,&\varepsilon =\varepsilon ^{(n)},  \end{cases}
\end{equation}
дополненной условиями
\begin{equation}
\label{dilig:eq9}  \frac{\partial T(\tau_{\text{к}}, x)}{\partial x} \Bigl|_{x=x_{i _\nu }^\ast} =0;
\quad x_{i_\nu }^\ast \in \{x_i^\ast \},\quad \nu =1, 2, \dots, R_1, \quad  R_1 \le R
\end{equation}
для внутренних точек $x_i^\ast$ экстремума конечного распределения температуры.

\end{enumerate}

Система \eqref{dilig:eq8}, \eqref{dilig:eq9} является замкнутой относительно неизвестных, к которым
относятся длительности интервалов $\Delta_i$ и координаты локальных экстремумов $x_i^\ast \in [0,\,1]$.

Разработанный точный аналитический альтернансный метод решения задачи оптимального управления
(\ref{dilig:eq1})--(\ref{dilig:eq7}) инвариантен по отношению к~способу нахождения температурного состояния распределённого
объекта $T(\tau_{\text{к}}, x)$. 
В~работах \cite{dilig:bib1, dilig:bib2} использован точный метод расчёта температуры $T(\tau,\,x)$ в~форме классического разложения по собственным функциям в виде сходящегося бесконечного ряда. 
При этом в расчётах численные значения параметров оптимального алгоритма $\{ \Delta _i  \}$,
найденные на основе точных методов, в той или иной степени являются приближенными.

Рассмотрим возможность решения задачи (\ref{dilig:eq1})--(\ref{dilig:eq7}) с~использованием приближённого выражения для температурного поля в~конце нагревания.

Авторами \cite{dilig:bib3, dilig:bib4} для решения задач теплопроводности вида (\ref{dilig:eq1})--\eqref{dilig:eq4} предложен  метод построения аналитических квазиасимптотических решений, удовлетворительно описывающих температурные распределения краевых задач в области $0\leq \tau <\infty$, $ 0\leq x \leq 1$. 
Квазиасимптотические решения строятся путём сопряжения внутренних и внешних асимптотических представлений решения с~помощью специально конструируемых мультипликаторов.
Получаемые при таком подходе приближённые решения асимптотически совпадают с~точными решениями задачи при больших и~малых временах, а~в~промежуточной области имеют погрешность, которая может быть уменьшена путём увеличения числа учитываемых в~разложениях членов рядов.

Так, квазиасимптотическое решение для задачи (\ref{dilig:eq1})--(\ref{dilig:eq4}) при $u(\tau )=u_0 ={\rm const}$, построенное путём квазисопряжения первых двух членов внутреннего и~первых двух членов внешнего разложений, имеет следующий вид \cite{dilig:bib3}:
\begin{multline}
\label{dilig:eq10}
\tilde {T}(x,\tau )=u_0 \left\{ 
2\sqrt {\tau } \left[ i\, {\rm erfc}\Bigl( -\frac{1-x}{2\sqrt \tau } \Bigr)+
i\,{\rm erfc} \Bigl( -\frac{1+x}{2\sqrt \tau } \Bigr) \right]+ \right.
\\
\left. +4\tau i^2 {\rm erfc}\Bigl( \frac{1}{\sqrt \tau }\Bigr)+
\Bigl(\frac{x^2}{2}-\frac{1}{\textcolor{white}{\!\eqref{dilig:eq6}}\!}\Bigr) {\rm erfc}\Bigl( \frac{1}{\sqrt \tau }
\Bigr) \right\},
\end{multline}
где $i^n {\rm erfc}(z)$ "--- итерированные интегралы дополнительной функции ошибок.
