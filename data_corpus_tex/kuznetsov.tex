\Section[n]{Введение}
Пусть $G(x,  y)$ "--- \emph{функция Грина} первой краевой задачи для \emph{оператора Лапласа} в области ${V\subset \mathbb R^m}$ ${(m \geqslant 3)}$. Оператор
$\Green$ c ядром $G(x,  y)$,  действующий в $C(\bar V)$,  будем называть \emph{оператором Грина}.
Оценки степеней \emph{оператора Грина} могут использоваться для решения \emph{задачи Дирихле}
для уравнений \emph{Гельмгольца} и \emph{Лапласа},  а также при оценке значений собственных чисел
\emph{оператора Лапласа}.
Для вычисления $\Green^k f$ можно использовать стандартный процесс \emph{блуждания по сферам},  но это приводит
к~необходимости моделирования ветвящегося процесса и,  следовательно,  к~значительным затратам времени для расчётов.
В~работе рассмотрены методы,
позволяющие получить оценки $\Green^k f$ на траекториях марковских цепей,  связанных с~тем или иным интегральным
представлением решения \emph{уравнения Гельмгольца}.
Проведено сравнение с алгоритмами,  вычисляющими оценку решения \emph{уравнения Гельмгольца} без вычисления степеней
\emph{оператора Грина}. Рассмотрены возможности использования \emph{аналитического продолжения решения}.

\Section{Решение задачи Дирихле для уравнения Гельмгольца без вычисления степеней оператора Грина}
    Рассмотрим внутреннюю \emph{задачу Дирихле} для \emph{уравнения Гельмгольца}:
\begin{equation}
    \Delta u +\lambda u=-f,  \quad  u\bigr|_\Gamma=0.
    \label{kuznetsov:Helm1}
\end{equation}
   Для решения задачи (\ref{kuznetsov:Helm1}) обычно используются статистические оценки на траекториях марковского процесса \emph{блуждания по
сферам},  теория которых наиболее полно представлена в работе \cite{kuznetsov:Mikhailov}.
Укажем здесь только построенную там оценку.

   Определим случайный процесс \emph{блуждания по сферам} рекуррентными формулами: ${x_n=x_{n-1}+r_n\omega_n}$,  где $\omega_n$ "--- вектор изотропного
направления,  а $r_n$ "--- расстояние от точки $x_{n-1}$ до границы $\Gamma$.
Блуждание ведётся до момента $N$ выхода процесса в~$\varepsilon$-окрестность границы.
Оценка решения имеет следующий вид:
    $$
        \xi=\sum_{n=0}^{N}\left(\prod_{i=0}^{n-1}q(\lambda,  r_i)\right)f(\nu_n, \omega_n)\frac{r^2_n q(\lambda,  r_n)}{6q(\lambda,
r_n-\nu_n)}, \label{kuznetsov:walkOnSpheres2}
    $$
    где $\nu_n$ "--- случайная величина,  распределенная в интервале $(0; r)$ с плотностью $\frac{6x(1-x/r)}{r^2}$,  $q(\lambda,
r)=\frac{r\sqrt{\lambda}}{\sin(r\sqrt{\lambda})}$ (для $\mathbb{R}^3$),  $\lambda_1$ "--- первое собственное число оператора $\mathcal{L}=-\Delta$.

    В \cite{kuznetsov:Mikhailov} доказано,  что $\expect\abs{\xi^2}<+\infty$ при $\Re(\lambda)<\frac{\lambda_1}{2}$.

    В случае размерности пространства больше $3$ аналог этой оценки требует вычисления \emph{функции Бесселя}.
Оценку,  лишённую этого недостатка, можно
построить на траекториях \emph{блуждания по шарам}.

    Рассмотрим \emph{внутреннюю задачу Дирихле} для \emph{уравнения Лапласа} при размерности пространства $m=3$ (распространение на случай $m>3$ не
вызывает затруднений) в шаре $V=K_r(x)$ радиуса $r$ с центром в точке $x$ c~границей $S_r(x)$:
\begin{equation}\label{kuznetsov:Lapl}
        \Delta u=-f,\quad   u\bigr|_\Gamma=0;\qquad
        f\in C'(V)\cap C(\bar V).
    \end{equation}
    Пользуясь теоремой о среднем для задачи Дирихле и определением \emph{функции Грина} \cite{kuznetsov:Vladimirov},  решение задачи можно записать в
виде
$$
    u(x)=\frac{1}{4\pi r^2}\int\limits_{S_{r}(x)}u(y)d_yS+\int\limits_{K_r(x)}G_r(x,  y)f(y)dy,
$$
где ${G_r(x,  y)=\frac{1}{4\pi}\left(\frac{1}{\abs{x-y}}-\frac{1}{r}\right)}$ "--- \emph{шаровая функция Грина}.

Умножим обе части уравнения на $r^2$ и проинтегрируем от $0$ до $R$:
$$
        \int\limits_{0}^R r^2 u(x)dr=\frac{1}{4\pi}\int\limits_{0}^R\int\limits_{S_{r}(x)}u(y)d_yS dr+\int\limits_{0}^Rr^2\int\limits_{K_r(x)}G_r(x,
y)f(y)dy dr, $$
$$
        \frac{R^3}{3}u(x)=\frac{1}{4\pi}\int\limits_{K_{R}(x)}u(y)dy+\frac{1}{4\pi}\int\limits_\Omega\int\limits_{0}^R
r^2\int\limits_{0}^r\rho^2\left(\frac{1}{\rho}-\frac{1}{r}\right)f(x+\omega\rho)d\rho dr d\omega.
 $$
Изменив порядок интегрирования во втором интеграле правой части,  получим
\begin{equation}
    u(x)=\frac{1}{V_R}\int\limits_{K_{R}(x)}\left(u(y)+\frac{(R-\rho)^2(2R+\rho)}{6\rho}f(y)\right)d y,
    \label{kuznetsov:sol2}
\end{equation}
где $V_R=\frac{4}{3}\pi R^3$.

    Определим случайный процесс \emph{блуждания по шарам} рекуррентными формулами: $${x_n=x_{n-1}+R(x_{n-1})y_n},$$  где $y_n$ распределены равномерно в~шаре радиуса $1$ с~центром в нуле и независимы,  а $R(x)$ "--- расстояние от точки $x$ до границы $\Gamma$.
Последовательность $x_n$ образует ограниченный мартингал и,  следовательно,  сходится с вероятностью~$1$.
Осредняя по $y_n$,  получаем $$R(x_{n-1})=\frac{4}{3}\expect\abs{x_n-x_{n-1}},$$
откуда следует,  что $R(x_n)\to0$ с вероятностью $1$,  а $x_n$ сходится к точке на границе
области.

    Используя подстановку $f:=f+\lambda u$,  получим оценку решения задачи (\ref{kuznetsov:Helm1}):
    \begin{equation}
        \xi=\sum_{n=0}^{N-1}\left(\prod_{i=0}^{n-1}(1+\lambda s(x_i,  x_{i+1}))\right)s(x_n,  x_{n+1})f(x_{n+1}), \label{kuznetsov:walkOnBalls2}
    \end{equation}
    где $s(x,  y)=\frac{(R-\abs{x-y})^2(2R+\abs{x-y})}{6\abs{x-y}}$.

    Сравнение результатов работы на модельной задаче (п. 3) этих алгоритмов представлено в табл. \ref{kuznetsov:solEst1}
и~\ref{kuznetsov:solDispEst1}.

\Section{Оценки,  использующие степени оператора Грина}
    Задача (\ref{kuznetsov:Helm1}) эквивалентна интегральному уравнению $u=\lambda\Green u+\Green f$,  решение которого при малых $\lambda$
представляется рядом
\begin{equation}
    u=\sum_{n=0}^\infty\lambda^n\Green^{n+1}f.
    \label{kuznetsov:HelmSum}
\end{equation}
    При больших $\lambda$ можно использовать \emph{аналитическое продолжение решения} методом замены переменных \cite{kuznetsov:Kublanovskaya}.
Приведём краткое его описание.

    Пусть $D$ "--- односвязная подобласть области существования $u(x,  \lambda)$ относительно $\lambda$,
в которой функция $u$ не имеет никаких особых
точек по $\lambda$ кроме полюсов,  и $\lambda=0$ лежит в $D$.
На комплексной плоскости переменной $\eta$ выберем односвязную область $H$,
содержащую точку $\eta=0$,  и функцию $\lambda=\psi(\eta)$,  осуществляющую конформное отображение области $H$ на $D$,  причем так,  что $\psi(0)=0$.
Функция $\lambda=\psi(\eta)$ может быть разложена в ряд: $\lambda=\psi(\eta)=\sum_{n=1}^\infty a_n\eta^n$. Тогда функция $F(x,  \eta)=u(x,
\psi(\eta))=\sum_{n=0}^\infty\psi(\eta)^n\Green^{n+1}f$ регулярна в окрестности нуля и может быть разложена в степенной ряд:
\begin{equation}
            F(x,  \eta)=u(x,  \psi(\eta))=\Green f+ \sum_{n=1}^\infty\eta^n b_n, \label{kuznetsov:FSum}
\end{equation}
$$
        b_n=\sum_{k=1}^nd_{k}^{(n)}\Green^{k+1}f, \quad
        d_{k}^{(n)}=\frac{1}{n!}\left\{\frac{\partial^n}{\partial\eta^n}[\psi(\eta)]^k\right\}_{\eta=0}.
    $$

Пусть $C_\eta$ "--- круг $\abs{\eta}<R_\eta$,  в котором сходится ряд (\ref{kuznetsov:FSum}) на плоскости $\eta$,  $H'={H\cap C_\eta}$,  а $D'$ "---
образ
$H'$ при отображении $\lambda=\psi(x)$,  тогда:
\begin{itemize}
    \item если область $D'$ выходит за пределы круга сходимости ряда (\ref{kuznetsov:HelmSum}),  то $F(x, \psi^{-1}(\lambda))=\sum_{n=0}^\infty[\psi^{-1}(\lambda)]^n b_n$ является аналитическим продолжением функции $u(x,  \lambda)$ из круга
$C_\lambda$ в $D'$; если $D'\subset C_\lambda$,  то данная функция не является аналитическим продолжением,  но использование такого
представления может оказаться более удобным для вычислений;
    \item если $u(x,  \lambda)$ регулярна в $D$,  а $H$ "--- круг $\abs{\eta}<1$,  то $F(x,  \psi^{-1}(\lambda))$ даёт аналитическое продолжение функции
$u(x,  \lambda)$ из круга $C_\lambda$ во всю область~$D'$.
\end{itemize}

Если $D$ "--- односвязная область,  в которой $u(x,  \lambda)$ мероморфна по $\lambda$,  \mbox{$\lambda=0 \in$} $ D$,  точка $\lambda=\lambda_*$,  для которой ищется
значение функции,  лежит внутри~$D$,  а~$\lambda=\psi(\eta)$ осуществляет однозначное конформное отображение круга \linebreak ${H (\abs{\eta}<1)}$ на область $D$,
$\psi(0)=0$,  и для $\eta_*=\psi^{-1}(\lambda_*)$ выполняются неравенства $\max_{\eta_i\in H}\abs{\frac{\eta_*}{\eta_i}}<1$ и $\max_{\eta_i\in
H}\abs{\frac{\eta_*}{\eta_i}}<\max_{\lambda_i\in D}\abs{\frac{\lambda_*}{\lambda_i}}$,  где максимумы берутся по всем полюсам $\lambda_i$ в области $D$,
${\eta_i=\psi^{-1}(\lambda_i)}$. При этом:
\begin{itemize}
    \item остаточный член ряда (\ref{kuznetsov:HelmSum}) имеет оценку $\abs{R_n}=O\Bigl(\Bigl|\frac{\eta_*}{1-h}\Bigr|^{n+1}\Bigr)$,  где ${h>0}$
"--- сколь угодно маленькое число,  если в области $D$ функция $u(x,  \lambda)$ регулярна;
    \item $\abs{R_n}=O\Bigl(\Bigl|\frac{\eta_*}{\eta_1} \Bigr|^{n+1}n^{r-1}\Bigr)$,  где $\eta_1$ "--- ближайший полюс $F(x,  \eta)$ из $D$,  а $r$ "---
наибольшая кратность полюса.
\end{itemize}

   При $\Im(\lambda)\neq0$,  в качестве области $D$ рассмотрим плоскость с разрезом по вещественной оси $[\lambda_0,  \infty)$,  где
$0<\lambda_0\leqslant\lambda_1$. Отображающие функции в этом случае имеют вид \cite{kuznetsov:Kublanovskaya}:
   $$
   \lambda=\psi(\eta)=-\frac{4\lambda_0\eta}{(1-\eta)^2}, \quad
        \eta=\psi^{-1}(\lambda)=\frac{\sqrt{\lambda_0-\lambda}-\sqrt{\lambda_0}}{\sqrt{\lambda_0-\lambda}+\sqrt{\lambda_0}}.
    $$

   Найдём коэффициенты для ряда (\ref{kuznetsov:FSum}): разложение функции $\lambda^k=[\psi(\eta)]^k$ в~ряд Маклорена имеет вид
$(-4\lambda_0)^k\sum_{m=1}^\infty\frac{(2k+m-1)!}{(2m-1)!}\eta^{m+k}$,  подставляя его в~(\ref{kuznetsov:HelmSum}) и меняя порядок суммирования,
получаем
    $$
    F(x,  \eta)=\Green f+\sum_{n=1}^\infty\eta^n\sum_{k=1}^n(-4\lambda_0)^kC_{k+n-1}^{2k-1}\Green^{k+1}f.
    $$
   Проведя ограничение количества членов ряда и выполнив замену $l_k^{(m)}:={(-4\lambda_0)^k\sum_{n=k}^m\eta^nC_{k+n-1}^{2k-1}}$,  получим формулу для
разложения
    $$
        F(x,  \eta)=\Green f+\sum_{n=1}^m l_n^{(m)}\Green^{n+1}f.
    $$

    Мероморфная по $\lambda$ функция (\ref{kuznetsov:HelmSum}) имеет полюсы в точках спектра задачи~(\ref{kuznetsov:Helm1}) и,  следовательно,
аналитична на комплексной плоскости с разрезом по лучу $[\lambda_0; +\infty)$,  где $\lambda_0\leqslant \lambda_1$.

Рассмотрим последовательность $u_n=\Green^n f$. Очевидно,  что ${\Delta u_n=-u_{n-1}}$.
Применяя равенство (\ref{kuznetsov:sol2}) к этому уравнению,
получим:
$$
    u_n(x)=\frac{1}{V_R}\int\limits_{K_{R}(x)}\left(u_n(y)+\frac{(R-\rho)^2(2R+\rho)}{6\rho}u_{n-1}(y)\right)d y, $$
$$
    u_n(x)=\expect(u_n(x_1)+s(x,  x_1)u_{n-1}(x_1)).
$$
Используя эту оценку для $u_k(x_i)$ получим формулы:
\begin{equation}\label{kuznetsov:walkOnBalls}
\begin{array}{rcl}
    u_1(x_0)&\!\!\!\!\!\!=\!\!\!\!\!\!&\expect\sum\limits_{i=1}^{N}s(x_{i-1},  x_{i})f(x_i), \\
    u_2(x_0)&\!\!\!\!\!\!=\!\!\!\!\!\!&\expect\sum\limits_{i=1}^{N}s(x_{i-1},  x_{i})u_1(x_i)=\expect\sum\limits_{i=1}^{N}s(x_{i-1},  x_{i})\sum\limits_{j=i+1}^{N}s(x_{j-1},
x_{j})f(x_j), \hspace{-15mm} \\
    u_3(x_0)&\!\!\!\!\!\!=\!\!\!\!\!\!&\expect\sum\limits_{i=1}^{N}s(x_{i-1},  x_{i})u_2(x_i)=\expect\sum\limits_{i=1}^{N}s(x_{i-1},  x_{i})\sum\limits_{j=i+1}^{N}s(x_{j-1},
x_{j})u_1(x_j)= \hspace{-4mm}\\
    &\!\!\!\!\!\!=\!\!\!\!\!\!&\expect\sum\limits_{i=1}^{N}s(x_{i-1},  x_{i})\sum\limits_{j=i+1}^{N}s(x_{j-1},  x_{j})\sum\limits_{l=j+1}^{N}s(x_{l-1},  x_{l})f(x_l), \\
    &\!\!\!\!\!\!\ldots\!\!\!\!\!\!&\\
\end{array}
\end{equation}
которые очевидным образом позволяют оценивать конечное число степеней оператора Грина на одной траектории блуждания.

В трехмерном случае степени оператора Грина можно вычислять на траекториях процесса \emph{блуждания по шарам и сферам},  описанном в
\cite{kuznetsov:ENS},  который естественно обобщается на случай комплексного параметра.

   Пусть уравнение (\ref{kuznetsov:Helm1}) однозначно разрешимо и $0\leqslant\abs{\lambda}\leqslant c^2, $ $c=\mathrm{const}$,  тогда интегральное
представление для $u$ имеет вид:
   $$
       u(x)=\frac{q}{4\pi R^2(x)}\int\limits_{S_{R(x)}}u(y)d_yS+(1-q)\int\limits_{K_{R(x)}}p(x, y)\left(\frac{f(y)}{c^2}+\frac{c^2+\lambda}{c^2}u(y)\right)dy,
   $$
   где $q=\frac{Rc}{\sh(Rc)}$,  $p(x,  y)=\frac{c^2\sh((R-r)c)}{4\pi r(\sh(Rc)-Rc)}$ "--- плотность перехода из $x$ в $y$,  \linebreak $r=\abs{x-y}$. Траектория для
получения несмещенной оценки $u(x)$ строится следующим образом: пусть $x_0=x$. Точка $x_{n+1}$ с вероятностью $q(x_n)$ распределена равномерно на
сфере $S_{R(x_n)}$ и с вероятностью $1-q(x_n)$ -- в шаре $K_{R(x_n)}$ c плотностью $p(x,  y)$.\!\!$^2$\footnotetext{$^2$Метод моделирования плотности описан в~\cite{kuznetsov:Ermakov}.}

    Оценка $u(x)$ имеет следующий вид:
    $$
        \xi=\sum_{n=0}^{\infty} \frac{f(x_{i_n})}{c^2}\left(1+\frac{\lambda}{c^2}\right)^n\chi_{(n\leqslant N)},
    $$
    где $i_n$ "--- индекс $n+1$-го перехода в шар,  $N$ "--- число переходов в шар на траектории $\{x_i\}_{i=0}^\infty$.

    Произведя перегруппировку по $\lambda$,  получим, что
    $$
        \xi=\sum_{n=0}^{\infty}\lambda^n\sum_{m=n}^{\infty}\frac{f(x_{i_m})}{c^{2n+2}}C_m^n\chi_{(m\leqslant N)}.
        \label{kuznetsov:HelmSum2}
    $$
    Сравнивая с (\ref{kuznetsov:HelmSum}),  получаем несмещенную оценку для $(n+1)$-й степени оператора Грина:
    \begin{equation}
    \label{kuznetsov:walkOnBallsAndSpheres}
        \xi^{(n+1)}=\sum_{m=n}^{\infty}\frac{f(x_{i_m})}{c^{2n+2}}C_m^n\chi_{(m\leqslant N)}.
    \end{equation}
    В \cite{kuznetsov:ENS} доказано,  что описанный процесс с вероятностью $1$ сходится к границе области и $N<\infty$ с вероятностью $1$. Кроме того,
величина $N$ имеет моменты всех порядков. Пусть $M=\max(\abs{f(x)})$,  тогда
    $$
        \abs{\xi^{(n+1)}}\leqslant\frac{M}{c^{2n+2}}\sum_{m=n}^{N}C_m^n=\frac{M}{c^{2n+2}}C_{N+1}^{n+1}
        \leqslant \frac{M}{c^{2n+2}}\cdot\frac{N^{n+1}}{(n+1)!}.
    $$
    Значит,  оценка $\xi^{(n+1)}$ имеет все моменты.



    Решение задачи (\ref{kuznetsov:Lapl}) можно представить в виде суммы объемного потенциала и гармонической внутри области функции:
    \begin{equation}
        \label{kuznetsov:walkOnSpheres3}
        \left\{\begin{array}{rcl}
            u&\!\!\!\!=\!\!\!\!&v+w, \\
            \displaystyle v&\!\!\!\!=\!\!\!\!& \displaystyle \frac{1}{4\pi}\int\limits_D\frac{f(y)}{\abs{x-y}}dy, \\
            \Delta w&\!\!\!\!=\!\!\!\!&0, \\
            w\bigr|_\Gamma&\!\!\!\!=\!\!\!\!&-v.
        \end{array}\right.
    \end{equation}
    Значение функции $v$ оценивается \emph{по одному случайному узлу},  а $w$ находится методом \emph{блуждания по сферам} \cite{kuznetsov:Ermakov}.
Повторное применение этого алгоритма позволяет вычислить степени оператора Грина на траекториях ветвящегося процесса,  программная реализация которого
выполнена с помощью простой рекурсии. Конечность дисперсии оценок очевидна.

    Ещё один способ вычисления степеней \emph{оператора Грина} связан с вычислением самой \emph{функции Грина} краевой задачи:
    \begin{equation}\label{kuznetsov:greenFIter}
        \left\{\begin{array}{rcl}
            G(x,  y)&\!\!\!\!=\!\!\!\!&\displaystyle \frac{1}{4\pi\abs{x-y}}+g(x,  y), \\
            \Delta_y g(x,  y)&\!\!\!\!=\!\!\!\!&0, \\
            g(x,  y)\bigr|_\Gamma&\!\!\!\!=\!\!\!\!&\displaystyle -\frac{1}{4\pi\abs{x-y}}.
        \end{array}\right.
    \end{equation}
    В данном методе оценки степеней \emph{оператора Грина} строятся как оценки соответствующих кратных интегралов
    $$
        \Green^n f(x)=\idotsint\limits_D G(x, y_1)G(y_1,  y_2)\dots G(y_{n-1},  y_n)f(y_n)\,dy_1\dots dy_n.
    $$

\Section{Модельная задача}
Для проверки алгоритмов решалась внутренняя задача Дирихле для уравнения Гельмгольца в параллелепипеде размерами \linebreak $1\times2\times3$ с гранями
параллельными координатным осям.
Разрез для применения метода аналитического продолжения $[13{,}43; +\infty)$.
Известно,  что в~данном случае все собственные значения задачи вещественны,  положительны и $\lambda_1=\frac{49\pi^2}{36}\approx13{,}4336$.

В качестве точного решения выбиралась функция $u(x)=x_1(x_1-1)x_2\times(x_2-2)x_3(x_3-3)$,  которая соответствует правой части

        f(x,  \lambda)=-2(x_2(x_2-2)x_3(x_3-3)+x_1(x_1-1)x_3(x_3-3)+\\
        +x_1(x_1-1)x_2(x_2-2))-\lambda x_1(x_1-1)x_2(x_2-2)x_3(x_3-3).
    \end{multline*}

\noindent  Следует заметить,  что в методе блуждания по сферам и~шарам (алг.~(\ref{kuznetsov:walkOnBallsAndSpheres})) время расчётов сильно зависит от значения параметра $c$,  так при $c=100$ время расчёта для значения
$\lambda=9+9i$ выполняется за 113 мин 10 сек,  но при этом несколько повышается точность.

Полученные результаты показывают,  что оценки без аналитического продолжения не работают при $\Re\lambda>\lambda_1$. Методы \emph{блуждания по шарам}
(\ref{kuznetsov:walkOnBalls}) и \emph{блуждания по шарам и сферам} (\ref{kuznetsov:walkOnBallsAndSpheres}) с использованием \emph{аналитического
продолжения решения} дают неплохие результаты даже при $\Re\lambda>\lambda_1$ (например,  при $\lambda=15+15i$). C увеличением степени наблюдается
сильный рост отношения стандартного отклонения к оцениваемому значению,  поэтому увеличение количества членов ряда не приводит к улучшению оценок
решения. Следовательно,  для построения оценок при больших значениях параметра необходимо изменять алгоритмы для уменьшения дисперсии оценок или
использовать многократное аналитическое продолжение по малому количеству членов ряда.
