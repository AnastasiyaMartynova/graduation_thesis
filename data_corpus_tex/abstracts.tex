 \def\tit{DESIGNING OF~THE~DELAY-INDEPENDENT COMPUTING DEVICE}

 %1
 \def\aut{Yu.~Stepchenkov, Yu.~Diachenko, Yu.~Rozhdestvenski,
 N.~Morozov, and~D.~Stepchenkov }

 \titele{\tit}{\aut} %{\auf}{\leftkol}{\rightkol}

% \def\razd{Abstracts}

% \def\sect{\rm Abstracts}

 \thispagestyle{empty}

%\vspace*{-12pt}

 \noindent
The results of practical design of a delay-independent computing device
performing division and square root extraction in accordance with IEEE 754
Standard are presented. Advanced indicating subcircuit provides the total control of
transition termination of all elements in the computing device at each phase of
work. The validity of the delay-independent feature of the computing
device is provided by the hierarchical analysis.

%\vspace*{-6pt}

 \KWN{self-timed circuits; self-validation; computing device; hierarchical
analysis}

 The implementation results of the multicore

dataflow architecture specialized in parallel computations are presented. In

 \def\tit{COMPLETENESS OF~THE~SELF-TIMED ANALYSIS OF~ELECTRONIC CIRCUITS}

 %1
 \def\aut{L.~Plekhanov}


% \def\leftkol{\ } % ENGLISH ABSTRACTS}

 % \def\rightkol{\ } %ENGLISH ABSTRACTS}

 \noindent
 The comprehension of the self-timed analysis of circuits
associated with the initial states and changes of information inputs is discussed. It is shown that
an incomplete account of these changes leads to erroneous conclusions. Sufficient
conditions of changes in information inputs providing analysis completeness are
obtained. Some ways of full analysis implementation for event-oriented methods
and functional method are proposed.

 \def\tit{THE IMPACT OF~TRANSIENT FAILURES ON~MICROPROCESSOR SYSTEMS CACHE RELIABILITY}

 %1
 \def\aut{V.~Zakharov and B.~Shmeilin}


% \def\leftkol{\ } % ENGLISH ABSTRACTS}

 % \def\rightkol{\ } %ENGLISH ABSTRACTS}

 \titelee{\tit}{\aut} %{\auf}{\leftkol}{\rightkol}

%\vskip -14pt plus 6pt minus 3pt
% \vspace*{-12pt}

\noindent
The impacts of transient failures on cache reliability regarding the data, address tags, and status
bits are considered. The behavioral model of data elements, address tags, and status bits reflecting
their vulnerability to transient failures is proposed. For some applications, to increase fault
tolerance, it is recommended to use a cache with write-through instead of a cache with write-back. It
is shown that in multiprocessing systems the sensitivity of status bits to transient failures can be
lowered by using the write protocol with updating instead of write protocol with invalidation.

%\vspace*{-6pt}

\KWN{transient failures; vulnerability to transient failures; cache with write;
cache with write back; address tags; status bits; Hamming distance}

 \def\tit{RGB-CHARACTERIZATION OF COLOR PERCEPTION SPACE}

 %1
 \def\aut{O.~Arkhipov and Z.~Zykova }


% \def\leftkol{\ } % ENGLISH ABSTRACTS}

 % \def\rightkol{\ } %ENGLISH ABSTRACTS}

 \titelee{\tit}{\aut} %{\auf}{\leftkol}{\rightkol}

%\vspace*{-12pt}
%\vskip -14pt plus 6pt minus 3pt

\noindent
The problem of RGB-characterization of perceptual space of color pixels
presentations in printer outputs by an arbitrary personal computer user is
considered. An IT is proposed that allows to compute the functions of
RGB-characterization of space of color perception of pixels imprints by an
arbitrary user. This IT is based on testing the color perception of an arbitrary user,
the analysis of these tests, the account of color reproduction properties in the user
computer system. The IT computes the functions of the RGB-characterization of
the space of color perception of pixel printer outputs for an arbitrary user and is
similar to the functions of RGB-characterization of color space of watchers with
well-known anomalies of color vision.

%\vspace*{-6pt}

\KWN{color space; chromatic perception; color perception space; anomaly of
color vision; partial color blindness; RGB-\linebreak characterization}

EXPERIMENTHAL DATA}

A method of tracking of the changes of the shape of nature
objects based on processing of two-dimensional images using photogrammetry methods
