Задачи, связанные с нелинейным нагревом многослойных конструкций от действия
внутренних источников теплоты, имеют важный научный и практический интерес
[1--6].
При решении этих задач важнейшей проблемой является определение
предельной мощности источников, при которых количество получаемой от них
теплоты не может быть полностью отведено от конструкции при заданных
граничных условиях теплообмена.
Такие режимы нагрева приводят к~неограниченному возрастанию температуры в конструкции и~в~конечном итоге "---
к~её тепловому разрушению.
Для определения мощности таких источников теплоты необходимо иметь аналитическое решение соответствующей краевой задачи.

Эффективным методом решения задач теплопроводности для многослойных
конструкций является метод, основанный на применении обобщенных функций.
При этом многослойная система заменяется однослойной, но с переменными
(разрывными) физическими свойствами среды, которые описываются с помощью
единичных характеристических (асимметричных) функций.
Простота такого метода в том, что в данном случае нет необходимости специального выполнения условий
сопряжения.
Благодаря особым свойствам асимметричной функции, условиям
идеального термомеханического контакта между слоями удается удовлетворить
непосредственно в уравнении.

Рассмотрим многослойную плоскую стенку, у которой на поверхности \mbox{$x = x_0= 0$}
задана температура окружающей среды $t_1$, а~на поверхности \linebreak $x = x_{n} $ "---
температура $t_2 $.
Предположим, что в~пределах каждого слоя удельные
мощности тепловых источников аппроксимируются линейными функциями
температуры
\begin{equation}
\label{av:104:eq1}
 q_ {v _i} =a_i +b_i T,
\end{equation}
где $a_i =\omega _{0i} $, $b_i =\omega _{0i} \beta _i $; $\omega _{0i} $ "---
удельная мощность постоянно действующего внутреннего источника теплоты в~$i$-том слое стенки при $T= 0$\,\textcelsiusж $\beta _i $ "--- экспериментальная постоянная для $i$-того слоя стенки.

Представим коэффициент теплопроводности и удельную мощность внутреннего
источника теплоты для многослойной стенки как единые целые в~виде
\begin{gather}
\label{av:104:eq2}
\lambda (x)=\lambda _1 +\sum\limits_{i=1}^{n-1} (\lambda _{i+1} -\lambda _i) H(x-x_i );
\\
\label{av:104:eq3}
 q_ v (x, T)=a(x)+b(x)T,
\end{gather}
где $$a(x)=a_1 +\sum\limits_{i=1}^{n-1} {(a_{i+1} -a_i )} H(x-x_i ),$$
$$b(x)=b_1 +\sum\limits_{i=1}^{n-1} {(b_{i+1} -b_i )} H(x-x_i ),$$
$
H(x-x_i )=\left\{ \begin{array}{ll}
 0,&\text{если $x<x_i$,}\\
 1,&\text{если  $x\geqslant x_i$}
 \end{array} \right.
$ "--- асимметричная единичная функция.


Дифференциальное уравнение теплопроводности для определения стационарного
температурного поля в~многослойной конструкции с~нелинейными внутренними
источниками теплоты c учётом (1)--(3) в~этом случае будет иметь вид
\begin{equation}
\label{av:104:eq4}
\frac{d}{dx}\Bigl[\lambda (x)\frac{dT(x)}{dx}\Bigr]+b(x)T+a(x)=0.
\end{equation}

Перейдём в (\ref{av:104:eq4}) от переменной $x$ к~новой независимой переменной $z$ по формуле
\begin{equation}
\label{av:104:eq5}
z=\int\limits_0^x \sqrt {\frac{b(\xi )}{\lambda (\xi )}}  d\xi =\sqrt
{\frac{b_1 }{\lambda _1 }} x+\sum\limits_{i=1}^{n-1} \biggl( {\sqrt
{\frac{b_{i+1} }{\lambda _{i+1} }} -\sqrt {\frac{b_i }{\lambda _i }} }
\biggr) H(x-x_i ).
\end{equation}

Тогда уравнение (\ref{av:104:eq4}) в~новой переменной (\ref{av:104:eq5}) преобразуется к неоднородному
дифференциальному уравнению с постоянными и сингулярными коэффициентами вида
\begin{equation}
\label{av:104:eq6}
\frac{d^2T}{dz^2}+T(z)=-\sum\limits_{i=1}^{n-1} \biggl(
\sqrt{\frac{\lambda _{i+1} b_{i+1} }{\lambda _i b_i } } -1 \biggr)
\frac{dT}{dz}\Big|_{z=z_i } \delta (z-z_i )-\frac{a(z)}{b(z)},
\end{equation}
где $\delta (z-z_i ) $ "--- дельта-функция Дирака.


Общее решение уравнения (\ref{av:104:eq6}) с~помощью метода вариации произвольных
постоянных можно представить в виде
\begin{equation}
\label{av:104:eq7}
T(z)=C_1 \sin z+C_2 \cos z+D_1 (z)\sin z-D_2 (z)\cos z,
\end{equation}
где
$$
D_1 (z)=\int\limits_0^z f(z)\cos z\, dz, \quad
D_2 (z)=\int\limits_0^z f(z)\sin z\, dz ;$$
$$
f(z)=-\sum\limits_{i=1}^{n-1} \biggl( \sqrt {\frac{\lambda _{i+1} b_{i+1}
}{\lambda _i b_i }} -1\biggr)\frac{dT}{dz} \Big|_{z=z_i }
-\frac{a(z)}{b(z)}.
$$


После вычисления соответствующих интегралов общее решение (\ref{av:104:eq7}) запишется так:
\begin{multline}
\label{av:104:eq8}
 T(z)=C_1 \sin z+C_2 \cos z-\frac{a_1 }{b_1 }-
\sum\limits_{i=1}^{n-1}
\biggl\{ \Bigl( \frac{a_{i+1} }{b_{i+1} }-\frac{a_i }{b_1 } \Bigr)
 \left[ 1-\cos (z-z_i ) \right]+
\\
+\biggl( \sqrt {\frac{\lambda _{i+1} b_{i+1} }{\lambda _i b_i }} -1
\biggr)\frac{dT}{dz} \Big|_{z=z_i } \sin (z-z_i ) \biggr\} H(z-z_i ).
\end{multline}

Неизвестные производные $\frac{dT}{dz} \big|_{z=z_i } $ в (\ref{av:104:eq8})
представим в виде
\begin{equation}
\label{av:104:eq9}
\frac{dT}{dz} \Big|_{z=z_i } =D_1^i C_1 -D_2^i C_2 -D_3^i ,
\end{equation}
где $D_1^i $, $D_2^i $, $D_3^i $ определяются из следующих рекуррентных
соотношений:
\begin{gather}
\label{av:104:eq10}
D_1^j =\sqrt {\frac{\lambda _j b_j }{\lambda _{j+1} b_{j+1} }}
\biggl[ \cos z_j -\sum\limits_{i=1}^{j-1} \biggl( \sqrt {\frac{\lambda _{i+1} b_{i+1}
}{\lambda _i b_i }} -1\biggr)  D_1^i \cos (z_j -z_i ) \biggr];
\\
\label{av:104:eq11}
D_2^j =\sqrt {\frac{\lambda _j b_j }{\lambda _{j+1} b_{j+1} }}
\biggl[ \sin
z_j -\sum\limits_{i=1}^{j-1} \biggl( \sqrt {\frac{\lambda _{i+1} b_{i+1}
}{\lambda _i b_i }} -1 \biggr) D_2^i \cos (z_j -z_i ) \biggr];
\end{gather}
\begin{multline}
\label{av:104:eq12} \qquad\!\!\!
 D_3^j =\sqrt {\frac{\lambda _j b_j }{\lambda _{j+1} b_{j+1} }}
\biggl[
\sum\limits_{i=1}^{j-1}
\biggl( \sqrt {\frac{a_{i+1} }{b_{i+1} }}
-\frac{a_i }{b_i } \biggr)  \sin (z_j -z_i )- \\
 -\sum\limits_{i=1}^{j-1}
\biggl( \sqrt {\frac{\lambda _{i+1} b_{i+1}
}{\lambda _i b_i }} -1 \biggr) D_3^i \cos (z_j -z_i )
\biggr],
 \end{multline}
где $j\equiv 1, 2, \dots, n-1$.

После подстановки (\ref{av:104:eq9}) в (\ref{av:104:eq8}), получим
\begin{multline}
 T(z)=\biggl[ \sin z-
\sum\limits_{i=1}^{n-1}  \biggl(
\sqrt {\frac{\lambda _{i+1} b_{i+1} }{\lambda _i b_i }} -1\biggr)
D_1^i \sin (z-z_i )H(z-z_i ) \biggr] C_1 +
\\
 +\biggl[ \cos z+
\sum\limits_{i=1}^{n-1}
 \biggl( \sqrt
{\frac{\lambda _{i+1} b_{i+1} }{\lambda _i b_i }} -1 \biggr)
D_2^i \sin (z-z_i )H(z-z_i ) \biggr] C_2 -
\\
\label{av:104:eq13}
 -\frac{a_1 }{b_1 } -
\sum\limits_{i=1}^{n-1} \biggl( \sqrt {\frac{a_{i+1} }{b_{i+1} }} -\frac{a_i }{b_i } \biggr)
\left[ 1-\cos (z-z_i ) \right] H(z-z_i )+ \\
 +\sum\limits_{i=1}^{n-1}
\biggl( \sqrt {\frac{\lambda _{i+1} b_{i+1} }{\lambda _i b_i }} -1 \biggr) D_3^i \sin (z-z_i ) H(z-z_i ).
 \end{multline}

Постоянные интегрирования $C_{1}$ и $C_{2}$ находим из граничных условий
\begin{equation}
\label{av:104:eq14}
 T=t_1,~\text{ при $z= 0$; } \quad  T=t_2,~\text{ при $z=z_n$,}
 \end{equation}
где
$$
z_n =\sqrt {\frac{b_1 }{\lambda _1 }} h+\sum\limits_{i=1}^{n-1} \biggl(
\sqrt {\frac{b_{i+1} }{\lambda _{i+1} }} -\sqrt {\frac{b_i }{\lambda _i }}
 \biggr) (h-x_i );$$
$h$ "--- толщина $n$-слойной стенки.



Подставляя (\ref{av:104:eq13}) в (\ref{av:104:eq14}), получаем
\begin{equation}
\label{av:104:eq15}
C_1 =\frac{A}{R},
\quad
C_2 =t_1 +\frac{a_1 }{b_1 };
\end{equation}
где
\begin{multline}
\label{av:104:eq16}
A=t_2 +\frac{a_1 }{b_1 }+
\sum\limits_{i=1}^{n-1}
\left(
\frac{a_{i+1} }{b_{i+1} }-\frac{a_i }{b_i }
\right)
[1-\cos (z_n -z_i )]- \\
 -\sum\limits_{i=1}^{n-1}
\biggl( \sqrt {\frac{\lambda _{i+1} b_{i+1} }{\lambda _i b_i }} -1 \biggr)
D_3^i \sin (z_n -z_i )H(z-z_i )-\\-
\biggl[
\cos z_n
+\sum\limits_{i=1}^{n-1}
\biggl( \sqrt {\frac{\lambda _{i+1} b_{i+1}
}{\lambda _i b_i }} -1 \biggr)  D_2^i \sin (z_n -z_i )
\biggr] \left( t_1 +\frac{a_ 1}{ b_ 1 }
\right);
 \end{multline}
\begin{equation}
\label{av:104:eq17}
R=\sin z_n -\sum\limits_{i=1}^{n-1} {\left( {\sqrt {\frac{\lambda _{i+1}
b_{i+1} }{\lambda _i b_i }} -1} \right)} D_1^i \sin (z_n -z_i ).
\end{equation}

После подстановки (\ref{av:104:eq15}) в (\ref{av:104:eq13}) с~учётом (\ref{av:104:eq16}) и~(\ref{av:104:eq17}) получим
\begin{equation}
\label{av:104:eq18}
T(z)=\frac{A\varphi _1 (z)}{R}+\varphi _2 (z),
\end{equation}
где
\[
\varphi _1 (z)=\sin z-\sum\limits_{i=1}^{n-1}
\biggl( \sqrt {\frac{\lambda _{i+1} b_{i+1} }{\lambda _i b_i }} -1 \biggr) D_1^i \sin (z-z_i )H(z-z_i),
\]
\begin{multline*}
\varphi _2 (z)=\left( t_{C_1 } +\frac{a_1 }{b_1 } \right)
\biggl[ \cos z+
\sum\limits_{i=1}^{n-1} \biggl(
\sqrt {\frac{\lambda _{i+1} b_{i+1}}{\lambda _i b_i }} -1 \biggr) \biggr] D_2^i
\sin (z-z_i )H(z-z_i ) -
\\
 -\frac{a_1 }{b_1 }-
\sum\limits_{i=1}^{n-1} \left( \frac{a_{i+1} }{b_{i+1}
}-\frac{a_i }{b_i } \right) [ (1-\cos (z-z_i ) ] H(z-z_i )+
\\
 +\sum\limits_{i=1}^{n-1} \biggl( \sqrt {\frac{\lambda _{i+1} b_{i+1}
}{\lambda _i b_i } } -1 \biggr)   D_3^i \sin (z-z_i )H(z-z_i ).
 \end{multline*}

Рассмотрим знаменатель $R$ в формуле (\ref{av:104:eq18}). Например, для двухслойной стенки,
с~учётом обозначений, принятых в (\ref{av:104:eq1}), его можно представить следующим образом:
\begin{equation}
\label{av:104:eq19}
R=\sin z_2 -\biggl( \sqrt {\frac{\lambda _i b_i }{\lambda _2 b_2 }} -1 \biggr)\cos z_1 \sin (z_2 -z_1 )
\end{equation}
или в~таком виде:
\begin{equation}
\label{av:104:eq20}
R=\sin z_2 -\biggl( \sqrt {\frac{\lambda _i \omega _{0_1 } \beta _1
}{\lambda _2 \omega _{0_2 } \beta _2 }} -1 \biggr)\cos z_1 \sin (z_2 -z_1),
\end{equation}
где 
$z_1 =B_1 h_1 $,
$z_2 =B_1 h_1 +B_2 h_2 $,  
$B_1 =\sqrt {\frac{\omega
_{0_1 } \beta _1 }{\lambda _1 }} $,
$B_2 =\sqrt {\frac{\omega _{0_2 } \beta _2 }{\lambda _2 }} $; $h_1$, $h_2 $ "--- толщина первого и~второго слоев.

Запишем (\ref{av:104:eq20}) следующим образом:
\begin{equation}
\label{av:104:eq21}
R=\sin \left[ {\left( {z_2 -z_1 } \right)N_2 } \right]-(1-K_{\varepsilon _1
} )\cos \left[ {\left( {z_2 -z_1 } \right)N_1 } \right]\sin \left[ {\left(
{z_2 -z_1 } \right)N_3 } \right],
\end{equation}
где $$N_1 =\frac{z_1 }{z_2 -z_1 }, \quad N_2 =\frac{z_2 }{z_2 -z_1 }, \quad N_3 =\frac{z_2 -z_1 }{z_2 -z_1 };$$
$$K_{\varepsilon _1 } =\sqrt {\frac{\lambda _1
\omega _{0_1 } \beta _1 }{\lambda _2 \omega _{0_2 } \beta _2 }} ,\quad  z_2 -z_1
=B_2 h_2 .$$


Обозначим
\begin{equation}
\label{av:104:eq22}
B_2 h_2 =\mu_1 .
\end{equation}
Соотношение (\ref{av:104:eq21}) с~учётом (\ref{av:104:eq22}) примет вид
\begin{equation}
\label{av:104:eq23}
R=\sin \mu N_2 -(1-K_{\varepsilon _1 } )\cos \mu N_1 \sin \mu .
\end{equation}

Рассмотрим условия, при которых знаменатель формулы (\ref{av:104:eq18}) обращается в~ноль
и,~следовательно, температура принимает бесконечное значение:
\begin{equation}
\label{av:104:eq24}
\sin \mu N_2 -(1-K_{\varepsilon _1 } )\cos \mu N_1 \sin \mu =0.
\end{equation}
Выполнив преобразования в (\ref{av:104:eq24}) c учётом (22), получим
\begin{equation}
\label{av:104:eq25}
\sin \left[ {\mu _1 \left( {1+K_{\varepsilon _1 } \frac{\lambda _2 h_1
}{\lambda _1 h_2 }} \right)N_2 } \right]-(1-K_{\varepsilon _1 } )\cos \left[
{\mu _1 \left( {K_{\varepsilon _1 } \frac{\lambda _2 h_1 }{\lambda _1 h_2 }}
\right)N_2 } \right]\sin \mu _1 =0.
\end{equation}
Таким образом, задача о критических тепловых режимах, приводящих к тепловому
взрыву, в двухслойной стенке свелась к решению трансцендентного уравнения
(\ref{av:104:eq25}), т.\,е. к~отысканию первого корня $\mu _1 $ при различных значениях
безразмерных параметров $K_{\varepsilon _1 } $ и $\eta =\frac{\lambda _2 h_1
}{\lambda _1 h_2 }$.
% На рис.~1 представлены графики зависимости $\mu _1 =f(\eta ,K_{\varepsilon _1 } )$.
Из (22) найдём, что
$
\omega _{0_{2,\max } } =\frac{\mu _1^2 \lambda _2 }{\beta _2 h_2^2 }.
$

Если удельная мощность постоянно действующего внутреннего источника теплоты
во втором слое при известном внутреннем источнике теплоты в первом слое
превысит $\omega _{0_{2,\max} } $, то тепловой поток с~поверхностей
двухслойной стенки при заданных $t_1 $ и~$t_2 $ нельзя отвести, и~произойдёт
разрушение материалов конструкции.

На рис.~1 представлены графики зависимости $\mu _1 =f(\eta ,K_{\varepsilon _1 } )$,
отделяющие область, в которой стационарное
распределение температуры возможно, от области неограниченного возрастания
температуры. 
Проиллюстрируем их применение при следующих исходных данных:
\mbox{$\lambda _1 {=}0,065$\,Вт/м$\cdot$K,}
$\lambda _2 =0,32$~Вт/м$\cdot$K,
$\omega _{0_1 } =11,68$~кВт/м$^3$,
$\omega _{0_2 } =161,7$~кВт/м$^3$,
$\beta _1 =0,01$~К$^{-1}$,
$\beta _2 =0,1$~К$^{-1}$,
$h_1 =30\cdot 10^{-3}$~м,
$h_2 =7,5\cdot 10^{-3}$~м.

Определим параметры $\eta $ и $K_{\varepsilon _1 } $:
\[
\eta =\frac{\lambda _2 }{\lambda _1 }\frac{h_1 }{h_2
}=\frac{0,32}{0,065}\frac{30\cdot 10^{-3}}{7,5\cdot 10^{-3}}\approx
19,6923.
\]
Так как $\eta $ изменяется в пределах $0\leqslant \eta \leqslant \pi $, то
представим 19,6923 как $6\pi +0,268\pi $. Отбрасывая количество периодов
$6\pi $, окончательно получаем, что $\eta \approx 0,268\pi \approx 0,843$ и
\[
K_{\varepsilon _1 } =\sqrt {\frac{\omega _{0_1 } \beta _1 \lambda _1 }{\omega _{0_2 } \beta _2 \lambda _2 }} =
\sqrt {\frac{0,01\cdot 0,065}{0,1\cdot 0,32}} \sqrt {\frac{11,68 }{161,7}}
\approx 0,4.
\]

Используя найденные $\eta $ и $K_{\varepsilon _1 } $, из графика находим
$\mu _1 \approx2,1$. Тогда критическая мощность внутреннего источника теплоты,
действующего во втором слое, определяется выражением
\[
\omega _{0_{2,\max} } = \frac{\mu _1^2 \lambda _2 }{\beta _2 h_2^2}\approx \frac{4,41\cdot 0,32\cdot 10^6}{0,1\cdot 56,25}\approx 250\text{~кВт/м}^3.
\]
Критическую мощность внутреннего источника теплоты, действующего в первом
слое, найдём из соотношения
\[
\omega _{0_{1,\max } } =0,072 \omega _{0_{2,\max } } \approx 18\text{~кВт/м}^3.
\]


Приравняем к нулю выражение (\ref{av:104:eq19}):
\begin{equation}
\label{av:104:eq26}
\sin z_2 +\biggl(\sqrt {\frac{\lambda _1 b_1 }{\lambda _2 b_2 }} -1\biggr)\cos z_1 \sin (z_2 -z_1 )=0.
\end{equation}
Преобразуем его к виду
\begin{equation}
\label{av:104:eq27}
\tg z_2 =\frac{\sqrt {\frac{\lambda _1 b_1 }{\lambda _2 b_2 }} -1}{\sqrt
{\frac{\lambda _1 b_1 }{\lambda _2 b_2 }} +\tg^2z_1 }\tg z_1 ,
\end{equation}
откуда
\begin{equation}
\label{av:104:eq28}
z_2 =\arctg\left[ \frac{\sqrt {\frac{\lambda _1 b_1 }{\lambda _2 b_2
}} }{\sqrt {\frac{\lambda _1 b_1 }{\lambda _2 b_2 }} +\tg^2z_1 } \tg z_1 \right]+\pi
.
\end{equation}
Учитывая, что
\[
z_1 =h_1 \sqrt {\frac{\omega _{0_1 } \beta _1 }{\lambda _1 }} ,
\quad
z_2 =h_1 \sqrt {\frac{\omega _{0_1 } \beta _1 }{\lambda _1 }} +h_2 \sqrt
{\frac{\omega _{0_2 } \beta _2 }{\lambda _2 }} ,
\]
выражению (\ref{av:104:eq27}) можно придать такой вид:
\begin{equation}
\label{av:104:eq29}
\frac{\tg h_1 \sqrt {\frac{\omega _{0_1 } \beta _1 }{\lambda _1 }} }{\tg h_2
\sqrt {\frac{\omega _{0_2 } \beta _2 }{\lambda _2 }} }=-\sqrt {\frac{\lambda
_1 \omega _{0_1 } \beta _2 }{\lambda _2 \omega _{0_2 } \beta _2 }} .
\end{equation}
Откуда получаем расчётную формулу для определения критической толщины
первого слоя стенки, если известна толщина второго слоя:
\begin{equation}
\label{av:104:eq30}
h_{1\text{кр}} =\sqrt {\frac{\lambda _1 }{\omega _0 \beta _1 }} \left\{
{\arctg\left[ {-K_{\varepsilon _1 } \tg h_2 \sqrt {\frac{\omega _{0_2 } \beta
_2 }{\lambda _2 }} } \right]+\pi } \right\},
\end{equation}
и наоборот
\begin{equation}
\label{av:104::eq31}
h_{2\text{кр}} =\sqrt {\frac{\lambda _2 }{\omega _0 \beta _1 }}
\left\{ {\arctg\left[ {-K_{\varepsilon _1 } \tg h_1 \sqrt {\frac{\omega _{0_1 }
\beta _1 }{\lambda _1 }} } \right]+\pi } \right\} .
\end{equation}


Для трёхслойной стенки формула (\ref{av:104:eq17}) будет иметь вид
\begin{multline}
\label{av:104:eq31}
 R=\sin z_3 +\biggl( \sqrt {\frac{\omega
_{0_1 } \lambda _1 \beta _1 }{\omega _{0_2 } \lambda _2 \beta _2 }} -1
\biggr)\cos z_1 \sin (z_3 -z_1 )+ \\
 +\biggl( \sqrt {\frac{\omega _{0_2 } \lambda _2 \beta _2 }{\omega _{0_3 }
\lambda _3 \beta _3 }} -1 \biggr)\biggl[ \cos z_2 +\biggl(\sqrt
{\frac{\omega _{0_1 } \lambda _1 \beta _1 }{\omega _{0_2 } \lambda _2 \beta
_2 }} -1 \biggr)\times \\
\times \cos z_1 \cos (z_2 -z_1 ) \biggr]\sin (z_3 -z_2)=0,
\end{multline}
где $z_3 =B_1 h_1 +B_2 h_2 +B_3
h_3 $, $h_3 $ "--- толщина третьего слоя,
$B_3 =\sqrt {\frac{\omega _{0_3 } \beta _3 }{\lambda _3 }} $.



Рассмотрим частный случай, когда трёхслойная стенка представляет собой
симметричную конструкцию.
Разделив и умножив аргументы у тригонометрических функций в (\ref{av:104:eq31}) на $(z_2-z_1 )=B_2 h_2 $,
после несложных преобразований приходим к~следующему характеристическому уравнению:
\begin{multline*}
 \sin \left[
\mu _1 \left( 1+K_{\varepsilon _1 } \eta +
\frac{1}{K_{\varepsilon _2 } }\eta  \right) \right]-
(1-K_{\varepsilon _1 } )\cos (\mu _1 K_{\varepsilon _1 } \eta)\sin
\left[ \mu _1 \left( {1+\frac{1}{K_{\varepsilon _2 } }\eta }
\right) \right]- \\
 -(1-K_{\varepsilon _2 } )\Bigl\{ \cos [ \mu_1 (1+K_{\varepsilon _1 } \eta )]- \\
-(1-K_{\varepsilon _1 } )\cos ( \mu _1 K_{\varepsilon _1 } \eta )\cos \mu _1 )\Bigr\} \sin \left(\mu _1\frac{1}{K_{\varepsilon _2 } }\eta  \right)=0, ~~
 \end{multline*}
где $K_{\varepsilon _2 } =\sqrt {\frac{\omega _{0_2 } \lambda _2 \beta _2
}{\omega _{0_3 } \lambda _3 \beta _3 }} $.

Таким образом, задача о критических тепловых режимах в~трёхслойной стенке
свелась к~отысканию методом последовательных приближений корня $\mu _1 $ в~зависимости от безразмерных параметров $K_{\varepsilon _1 } $,
$K_{\varepsilon _2 } $ и $\eta $.

На рис.~2 предоставлены графики зависимости $\mu _1 =f(\eta , K_{\varepsilon_1 }, K_{\varepsilon _2 } )$.
Как и для двухслойной стенки, если удельная мощность
постоянного действующего внутреннего источника теплоты во втором слое
превысит $\omega _{\varepsilon _2 ,\,\max } $, то произойдет разрушение
материалов стенки.
