Если $\Re$ - класс полугрупп, замкнутый относительно изоморфизма и содержащий одноэлементную полугруппу, то функция, ставящая в соответствии каждой полугруппе $S$ пересечение всех ее конгруэнций $\theta$ таких, что $S / \theta \in \Re$, оказывается Р., напр. $\rho_{\mathfrak{R}}$. П р и м е р. Пусть $\Re$ - класс полугрупп, допускающих точное неприводимое представление. Тогда

\[
\rho_{\Re}(S)=\{(a, b) \mid a, b \in S,(a, b) \in \mu(a s) \cap \mu(b s)
\]

для всех $s \in S \bigcup \varnothing\}$, где

\[
\mu(a)=\left\{(x, y) \mid x, y \in S, a^{m} x=a^{n} y\right.
\]

для некоторых $m, n \geqslant 0\}$.

С каждым радикалом $\rho$ связан класс левых полигонов $\Sigma(\rho)$. Именно, если $A$ - левый $S$-полигон, то конгруэнция $\theta$ на полугруппе $S$ наз. $A$-аннулирующей, если $(\lambda, \mu) \in \theta$ влечет за собой $\lambda a=\mu a$ для всех $a \in A$. Точная верхняя грань всех $A$-аннулирующих конгруэнций оказывается $A$-аннулирующей конгруәнцией и обозначается Ann $A$. Класс $\Sigma(\rho)$, по определению, состоит из всех таких левых $S$-полигонов $A$, что $\rho(S / A n n A)=$ $=0$, причем $S$ пробегает класс всех полугрупп. Если $\theta-$ конгруэнция на $S$, то левый $(S / \theta)$-полигон лежит в $\Sigma(\rho)$ тогда и только тогда, когда он лежит в $\Sigma(\rho)$, будучи рассматриваемым как левый $S$-полигон. Наоборот, если дан класс $\Sigma$ левых полигонов, обладающий әтим свойством, и $\Sigma(S)$ - класс всех левых $S$-полигонов, лежащих в $\Sigma$, то функция

\[
\rho(S)=\left\{\begin{array}{c}
S \times S, \text { если } \Sigma(S) \text { пусто, } \\
\bigcap_{\Sigma(S)} \text { Ann } A \text { в противном случае }
\end{array}\right.
\]

оказывается $\mathrm{P}$.
