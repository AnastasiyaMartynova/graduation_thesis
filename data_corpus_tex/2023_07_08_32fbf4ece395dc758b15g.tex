В этом случае краевым условиям (11) в тождестве (10) должны удовлетворять и функции $\varphi \in W_{2}^{m}(\Omega)$. Для приближенного решения таких задач методом Галеркина необходимо, чтобы координатные функции удовлетворяли условиям (11). Введенные выше координатные функции $\varphi_{i}^{\mu}(x)$, в силу самого способа их построения, вообще говоря, не пригодны для представления приближенного решения, удовлетворяющего условиям (11).

Один из приемов построения Р. в. с. для задач с краевыми условиями вида (11) связан с использованием ме то д а ш т р ф а. Пусть, напр., требуется решить задачу Дирихле для уравнения Пуассона. Эта задача әквивалентна определению функции $u(x),\left.u\right|_{s}=$ $=0$, удовлетворяющей при произвольной функции $\varphi(x)$, $\left.\varphi\right|_{S}=0$, интегральному тождеству

\[
\int_{\Omega}\left(\frac{\partial u}{\partial x} \frac{\partial \varphi}{\partial x}+\frac{\partial u}{\partial y} \frac{\partial \varphi}{\partial y}\right) d \Omega=\int_{\Omega} f \varphi d \Omega .
\]

В методе штрафа вводится в рассмотрение функция $v$, удовлетворяющая при произвольных функциях $\varphi$ интегральному тождеству

\[
\begin{aligned}
\int_{\Omega}\left(\frac{\partial v}{\partial x} \frac{\partial \varphi}{\partial x}\right. & \left.+\frac{\partial v}{\partial y} \frac{\partial \varphi}{\partial y}\right) d \Omega+\frac{1}{\varepsilon} \int_{S} v \varphi d S= \\
& =\int_{\Omega} f \varphi d \Omega, \quad \varepsilon>0 .
\end{aligned}
\]

Функция $v$ является решением задачи с естествөнным краевым условием. Доказывается, что при малых значениях $\varepsilon$ решения $u$ и $v$ близки. Для приближенного решения последней задачи можно применить Р. в. с. с использованием регулярных координатных функций.

Пусть для произвольного положительного числа $h$ в $\Omega$ задано множество точек $z_{i}, i=1,2, \ldots, N$, наз. узлами сетки, такое, что каждая точка области отстоит от какого-либо узла не более чем на $h$. Пусть для каждого узла $z_{i}$ определен набор функций $\varphi_{1}^{i}, \varphi_{2}^{i}, \ldots$, $\varphi_{v(i)}^{i}$ из $W_{2}^{m}(\Omega)$, удовлетворяющих заданным граничным условиям (11), причем $v(i) \leqslant M$, где $M$ не зависил от $i$ и $h$. Пусть при каждом $i$ и всех $j$ интеграл

\[
\int_{\Omega} \varphi_{j}^{i} \varphi_{m}^{k} d \Omega
\]

отличен от нуля лишь для числа индексов $k$, ограниченного числом, не зависящцм от $i$ и $h$ (условие локальности координатных функций). Пусть $K-$ класс функций вида

\[
w=\sum_{i=1}^{N} \sum_{j=1}^{v(i)} \lambda_{j}^{i} \varphi_{j}^{i}
\]

где $\lambda_{j}^{i}$ - числовые параметры.

Если решение $u(x)$ краевой задачи может быть приближено функціями класса $K$ с точностью, характөризуемой неравенством

\[
\inf _{w \in K}\|u-w\|_{2, m} \leqslant C h^{l-m}\|u\|_{2, l}, \quad m<l,
\]

то для решения, полученного при помощи Р. в. с., справедлива оценка погрешности

\[
\|u-v\|_{2, m} \leqslant C h^{l-m}\|u\|_{2, l} .
\]

Нерегулярные сетки применяются иногда для более полного учета свойств задачи. Напр., для более точ- ного воспроизведения функции в окрестности угловой точки границы можно расположить узлы на радиальнокольцевой сетке.

Для численной реализации матрица Р. в. с. должна обладать не слишком плохой обусловленностью. Для задач вида (10) оптимальной считается обусловленность, выражаемая соотношением $\boldsymbol{P}=O\left(N^{2 m / n}\right)$, где $P-$ число обусловленности матрицы Р. в. с., $N$ - число узлов сетки, $n$ - размерность пространства, содержащего область $\Omega$. Для многих ковкретных задач такая обусловленность действительно имеет место.

Использование Р. в. с. сочетает достоинства метода сеток и проекционных методов. Структура Р. в. с. позволяет использовать экономпчные методы решения разностных схем. Легко устанавливается разрешимость Р. в. с.: матрица Р. в. с. положительно определена, если положительно определен дифференциальный оператор. Вопрос о сходимости сводится к вопросу об аппроксимации точного решения координатными функциями $\mathrm{P}$. в. с., и, следовательно, скорость сходимости определяется дифференциальными свойствами точного решения. Р. в. с. можно применять при весьма слабых ограничениях на данные задачи.

Исследования по Р. в. с. проводятся в слөдующих основных направлениях:

\begin{enumerate}
  \item создание координатных функций, удовлетворяющих краевым условиям, исследование их аппроксимационных свойств;

  \item получение оценок точности в различных нормах;

  \item построение Р. в. с. для задач, имеющих те или иные особенности (линии разрыва коэффициентов, угловые точки границы и т. Д.);

  \item разработка методов решения Р. в. с. и способы оштимизации методов решения;

  \item решение нелинейных уравнений;

  \item применение Р. в. с. для нестационарных уравнений.

\end{enumerate}
