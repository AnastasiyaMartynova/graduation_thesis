{\it Введение.}
Рассмотрим вещественную систему линейных алгебраических уравнений
$L_{\varepsilon}z=F$ с параметром $\varepsilon\geq 0$
следующего вида:
\begin{equation}
\label{sys}
L_{\varepsilon} z=\begin{pmatrix}
A & B \\ B^T & - \varepsilon C \end{pmatrix}
\binom{u}{p}=\binom{f}{g}=F,
\end{equation}
где $A=A^T>0$, $C=C^T>0$ --- квадратные матрицы размеров
$N_u\times N_u$ и $N_p\times N_p$, а $B$ --- прямоугольная, в общем случае,
матрица размера $N_u\times N_p$. Далее будем предполагать
невырожденность матрицы $L_{\varepsilon}$ при любом $\varepsilon\geq 0$.
Задачи такого типа возникают при численном решении систем линейных
уравнений в теории упругости и гидродинамике (задача Стокса), а также
при использовании смешанных аппроксимаций для эллиптических уравнений
второго порядка (см., напр., \cite{Diak1}, \cite{BrFor} и цитированную
там литературу).

С точки зрения приложений одним из наиболее важных частных случаев
задачи~(\ref{sys}) является алгебраическая система типа Стокса ---
$L_{0}z=F$ (случай $\varepsilon = 0$), а самым популярным
подходом к ее решению --- построение алгоритмов типа
Удзавы \cite{AGU}, \cite{L-Q1}, среди которых наиболее эффективны
методы, использующие переменные итерационные параметры. Краткое изложение
этой идеи состоит в следующем.
Сначала система $L_{0}z=F$ переписывается
в равносильном виде
\begin{equation}
\label{sys0}
\begin{array}{c}
A_0  p = G; \\
u = A^{-1} ( f - B\,p ),
\end{array}
\end{equation}
где $A_0=B^T A^{-1} B$, $G = B^T A^{-1} f - g$.
При этом условие $\det(L_{0})\neq 0 $
в силу очевидной факторизации ($I$ --- единичная матрица)
$$
L_{0} =
\begin{pmatrix}
A & 0 \\
B^T & I
\end{pmatrix}
\begin{pmatrix}
A^{-1} & 0 \\
0 & - B^T A^{-1} B
\end{pmatrix}
\begin{pmatrix}
A & B \\
0 & I
\end{pmatrix}
$$
гарантирует положительную определенность
матрицы $A_0$. Далее вводится спектрально-эк\-ви\-ва\-лент\-ный $A_0$
оператор $C$ (не обязательно совпадающий с одноименным из~(\ref{sys}))
такой, что
$$
C=C^T>0,\quad \sigma (C^{-1}A_0 ) \in[\gamma,\Gamma], \quad \gamma > 0.
$$
Теперь для решения первого уравнения~(\ref{sys0})
можно использовать трехслойные методы следующего вида:
\begin{equation}
\label{3varmeth}
\begin{array}{c}
C p^{k+1} = \wt \alpha_{k+1} ( C - \wt \tau_{k+1} A_0)p^k +
( 1 - \wt \alpha_{k+1} ) C p^{k-1} + \wt \alpha_{k+1} \wt \tau_{k+1} G, \\
C p^1 = ( C - \wt \tau_{1} A_0)p^0 +\wt \tau_{1} G,
\end{array}
\end{equation}
гарантирующие с произвольного начального приближения $p^0$
наилучшую для любого $k = 1, 2, \dotsc$
оценку погрешности~(\cite{SamNik}, c.\,318)
\begin{equation}
\label{estimp}
\|p^k-p\|_{D_p}\leq\epsilon_k \,\|p^0-p\|_{D_p},\quad
\epsilon_k = \frac{2 q_0^k}{1 + q_0^{2k}},
\end{equation}
с $q_0 = (1 - \sqrt{\xi})/(1 + \sqrt{\xi})$,
$\xi = \gamma / \Gamma$,
в метрике, порождаемой оператором $D_p = D_p^T > 0$ таким, что
$D_pC^{-1}A_0 = (D_pC^{-1}A_0)^T$.
Принципиально различными с точки зрения задания априорной информации
алгоритмами такого рода являются

полуитерационный метод Чебышева
\begin{equation}
\label{3cheb}
\wt \tau_k = \frac2{\gamma + \Gamma}, \quad
\wt \alpha_{k+1} = \frac4{4 - q_1^2 \wt \alpha_{k}}, \quad
k = 1, 2, \dotsc,
\end{equation}
где $\wt \alpha_{1} = 2$, $q_1 = (1 - \xi)/(1 + \xi)$,

и методы сопряженных направлений
\begin{equation}
\label{msg}
\begin{array}{c}
\wt\tau_{k+1}=\frac{(r^k,D_p w^k)}{(w^k,D_p w^k)},
\quad k = 0, 1, 2, \dotsc, \\
\wt \alpha_{k+1} = \bigg(1-\frac{\wt \tau_{k+1}}{\wt \tau_{k}}
\frac{(r^k,D_p w^k)}{(r^{k-1},D_p w^{k-1})}
\frac1{\wt \alpha_{k}} \bigg)^{-1},
\quad
k = 1, 2, \dotsc ,
\end{array}
\end{equation}
где $\wt \alpha_{1} = 1$, $w^k = C^{-1} x^k$,
$A_0 r^k = x^k$, $x^k = A_0 p^k - G$.
При этом в первом случае
выбор метрики достаточно произволен (напр., $D_p = C$ или $D_p = A_0$),
а во втором --- наиболее употребительным является оператор $D_p = A_0$
(метод сопряженных градиентов),
с деталями использования которого
можно ознакомиться в~(\cite{SamNik}, c.\,354; \cite{Heusser}).

Отметим также приводящий к оценке~(\ref{estimp}) метод Ричардсона
\begin{equation}
\label{2varmeth}
C p^{n+1} = ( C - \wt \tau_{n+1} A_0)p^n +
\wt \tau_{n+1} G, \quad n = 0, 1, \dotsc, k-1,
\end{equation}
с чебышевским набором параметров
\begin{gather}
\label{2cheb}
\wt \tau_{n}=\frac2{(\gamma+\Gamma)(1+q_1\mu_n)},\quad n=1,2,\dotsc,k, \\
\mu_n \in \aleph_k = \bigg\{ - \cos \frac{2i -1}{2k} \pi,\ \;
i = 1, 2, \dotsc, k \bigg\}.\notag
\end{gather}
Однако необходимость построения множества $\aleph_k$ для заранее определенного
количества итераций $k$, и кроме того, требование упорядоченности его
элементов для вычислительной устойчивости делают его менее привлекательным
с практической точки зрения по сравнению с приведенными выше
трехслойными методами.

Наконец, после того, как с помощью методов~(\ref{3varmeth})
или~(\ref{2varmeth})
достигнута требуемая точность $\epsilon_k$ в оценке~(\ref{estimp}),
определяется $ u^{k+1} $ из соотношения
$$
A\,u^{k+1} + B\,p^k = f,
$$
что приводит к оценке погрешности
\begin{equation}
\label{estimu}
\| u^{k+1} - u \|_{D_u} \leq \| R \| \;\| p^k - p \|_{D_p},
\end{equation}
где $R = D_u^{1/2} A^{-1} B\,D_p^{-1/2}$, $D_u = D_u^T > 0$.
При выборе $ D_u = A$, $D_p = A_0$ справедлива оценка $\|R\|\leq 1$,
а при $D_u = A$, $D_p = C$ --- соответственно
$\| R \| \leq \Gamma / \gamma$.

Таким образом, алгоритмы типа Удзавы осуществляют эффективное нахождение
решения вспомогательной подсистемы $A_0 p = G$ с последующим
определением недостающей компоненты решения~$u$.

В данной работе рассматривается
алгоритм Эрроу--Гурвица~\cite{AGU}
(искусственной сжимаемости) с переменными итерационными 
параметрами $\tau_{k+1}$, $\nu_{k+1}$
для решения алгебраической системы типа Стокса
$L_{0} z = F$
\begin{equation}
\label{meth}
\begin{array}{c}
A \, \frac{u^{k+1}-u^k}{\tau_{k+1}} +A u^k +B p^k = f, \\
-C\,\frac{ p^{k+1} - p^k}{\nu_{k+1} } + B^T u^{k+1} = g.
\end{array}
\end{equation}
Основным результатом является конструктивный выбор параметров,
при которых достигаются оценки~(\ref{estimp}),~(\ref{estimu}).
Этот факт не является тривиальным, поскольку оператор перехода
в методе~(\ref{meth}) в общем случае несимметризуем.
Отметим также, что ранее изучались вопросы сходимости и
оптимизации метода только при постоянных значениях
параметров~\cite{Tem1}--\cite{Chiz}.
\medskip

{\bf 1.} {\it Преобразование алгоритма.}
Обозначим погрешность метода на $k$-й итерации через
$$
(v^k, r^k) = ( u^k - u, p^k -p ),
$$
где $(u,p)$ --- точное решение задачи~(\ref{sys}) при $ \varepsilon = 0$,
тогда из соотношений~(\ref{meth}) имеем для $ k = 0, 1, \dotsc$
\begin{equation}
\label{errvr}
\begin{array}{c}
v^{k+1} = ( 1 - \tau_{k+1}) v^k - \tau_{k+1} A^{-1} B\, r^{k}, \\
r^{k+1} = ( I - \tau_{k+1} \nu_{k+1} C^{-1}A_0)r^k +
\nu_{k+1} ( 1 - \tau_{k+1} ) C^{-1} B^T v^{k}.
\end{array}
\end{equation}

После исключения компоненты погрешности $v$ из соотношений~(\ref{errvr})
имеем для $k = 1, 2, \dotsc$
\begin{equation}
\label{err2}
r^{k+1}=\mu_{k+1}(I-\rho_{k+1} C^{-1}A_0)r^k+(1- \mu_{k+1} ) r^{k-1},
\end{equation}
где
\begin{equation}
\label{parerr2}
\mu_{k+1} = 1 + \dfrac{\nu_{k+1}}{\nu_{k}} ( 1 - \tau_{k+1} ) , \quad
\rho_{k+1} = \mu_{k+1}^{-1} \tau_{k+1} \nu_{k+1}.
\end{equation}
Аналогично,
после исключения компоненты погрешности $r$ из соотношений~(\ref{errvr})
имеем для $k = 1, 2, \dotsc$
\begin{equation}
\label{err1}
v^{k+1}=\wt \mu_{k+1}(I-\wt \rho_{k+1} A^{-1}B_0)v^k+(1-\wt\mu_{k+1})v^{k-1},
\end{equation}
где $B_0 = BC^{-1}B^T$, а параметры имеют вид
\begin{equation}
\label{parerr1}
\wt \mu_{k+1}=1 + \frac{\tau_{k+1}}{\tau_{k}} ( 1 - \tau_{k} ) , \quad
\wt \rho_{k+1} = \wt \mu_{k+1}^{-1} \tau_{k+1} \nu_{k}.
\end{equation}
Таким образом, для погрешности метода~(\ref{meth})
совместная двухслойная формула~(\ref{errvr}) сводится
к двум независимым трехслойным формулам (\ref{err2}) и~(\ref{err1}),
что при соответствующем выборе параметров и начального приближения
может привести к получению искомых оценок.

Здесь же отметим исключительный случай $\tau_k=1$, $k=1, 2, \dotsc$,
упрощающий формулы~(\ref{err2}) и~(\ref{err1}) до двухслойных, т.к.
$\mu_{k} = \wt \mu_{k} = 1$. Здесь выбор $\nu_n = \wt \tau_n$,
$n = 1, 2,\dotsc, k$, из~(\ref{2cheb}) приводит к тождественному совпадению
метода~(\ref{meth}) с методом Ричардсона~(\ref{2varmeth}), что
в свою очередь гарантирует выполнение оценок~(\ref{estimp}),~(\ref{estimu}).
\medskip

{\bf 2.} {\it Вспомогательные результаты.}
В этом разделе отмечаются полезные свойства формул итерационных
параметров~(\ref{3cheb}),~(\ref{msg}),~(\ref{parerr2}).

\begin{lem} Итерационные параметры $\wt \tau_k$, $\wt \alpha_k$
в полуитерационном методе Чебышева~$(\ref{3varmeth})$, $(\ref{3cheb})$
удовлетворяют неравенствам для $k =1, 2, \dotsc$
$$
\wt \tau_k > 0, \quad 2 \geq \wt \alpha_k > 1,
$$
причем только $\wt \alpha_1 = 2$.
\end{lem}

\begin{pf} Первое неравенство вытекает из явного представления
$\wt \tau_k = 2/(\gamma + \Gamma)$, $k =1, 2, \dotsc$, и свойств спектра
$ \sigma (C^{-1}A_0 ) \in[\gamma,\Gamma]$, $\gamma > 0$,
а второе следует из представления (\cite{SamNik}, гл.\,7, \S\,3, с.\,322)
$$
\wt \alpha_{k+1} = \frac{2q_0(1+q_0^{2k})}{q_1(1+q_0^{2k+2})},
\quad k=1, 2, \dotsc,
\quad \text{и} \quad
\wt \alpha_{1} = 2.
$$
Действительно, т.к.
$$
q_0 = \frac{1-\sqrt{\xi}}{1+\sqrt{\xi}},\ \; \xi
= \frac{\gamma}{\Gamma} < 1,
\quad \text{и} \quad
q_1 = \frac{1 - \xi}{1 + \xi} = \frac{2q_0}{1+ q_0^2},
$$
то
$$
2 > \wt \alpha_{k+1} = 1 + \dfrac{q_0^2+q_0^{2k}}{1+q_0^{2k+2}} > 1.
$$
Напомним, что $\wt \alpha_1 = 2$.
\end{pf}

\begin{lem} Итерационные параметры $\wt \tau_k, \wt \alpha_k$
в методе сопряженных направлений~$(\ref{3varmeth})$, $(\ref{msg})$
удовлетворяют неравенствам для $ k =1, 2, \dotsc$
$$
\wt \tau_k > 0, \quad \wt \alpha_k \geq 1,
$$
причем только $\wt \alpha_1 = 1$.
\end{lem}

\begin{pf} Справедливость первого неравенства
следует из преобразования первой формулы~(\ref{msg}). Поскольку
$w^k = C^{-1} x^k = C^{-1}A_0 r^k$, имеем
$$
\wt \tau_{k+1} = \frac{(r^k,D_p w^k)}{(w^k,D_p w^k)}
= \frac{(r^k,D_p C^{-1}A_0 r^k)}{(w^k,D_p w^k)}.
$$
Далее, в силу
$D_p = D_p^T > 0$ и
$D_pC^{-1}A_0 = (D_pC^{-1}A_0)^T > 0$ получаем $\wt \tau_k > 0$
для всех $ k = 1, 2, \dotsc$

Для доказательства неравенства $\wt \alpha_{k+1} > 1$
при $k = 1, 2, \dotsc$ перепишем вторую формулу~(\ref{msg}) в виде
$$
\wt \alpha_{k+1} = 1 +
\frac{\wt \alpha_{k+1} \wt \tau_{k+1}}{\wt \alpha_{k} \wt \tau_{k}}
\frac{(r^k,D_p C^{-1}A_0 r^k)}{(r^{k-1},D_p C^{-1}A_0 r^{k-1})}.
$$
Теперь искомое неравенство легко доказывается по индукции, т.к. все
сомножители во втором слагаемом положительны. Напоминание о том,
что $\wt \alpha_1 = 1$, завершает доказательство леммы.
\end{pf}

\begin{lem} Пусть для итерационных параметров $\mu_k$, $\rho_k$,
определяемых формулами~$(\ref{parerr2})$
для соотношения~$(\ref{err2})$,
справедливы неравенства при $k =1, 2, \dotsc$
$$
\mu_{k+1} > 1, \quad \rho_{k+1} > 0.
$$
Тогда обратное преобразование к параметрам $\tau_{k}$, $\nu_{k}$
исходного алгоритма~$(\ref{meth})$
однозначно определяется формулами
\begin{equation}
\label{trsf}
\begin{array}{c}
\nu_{k+1} = \nu_k ( \mu_{k+1} -1 ) + \mu_{k+1}\rho_{k+1} > 0, \\
1 > \tau_{k+1} = \mu_{k+1}\rho_{k+1} / \nu_{k+1} > 0
\end{array}
\end{equation}
для $k =1, 2, \dotsc$, если $\nu_1 > 0$.
\end{lem}

\begin{pf}
Вторая формула в~(\ref{parerr2}) дает
$$
\tau_{k+1} \nu_{k+1} = \mu_{k+1}\rho_{k+1}.
$$
Теперь для некоторого $\nu_k > 0$ (напомним, что по предположению $\nu_1>0$)
из первой формулы в~(\ref{parerr2}) имеем
$$
\nu_{k+1} = \nu_k ( \mu_{k+1} -1 ) + \mu_{k+1}\rho_{k+1}.
$$
Отсюда в силу условия леммы получаем $\nu_{k+1} > 0$, и соответственно
$\tau_{k+1} = \mu_{k+1}\rho_{k+1} / \nu_{k+1} > 0$. Подстановка
в полученную формулу явного вида для $\nu_{k+1}$ приводит
к неравенству $\tau_{k+1} < 1$.
\end{pf}

{\bf 3.} {\it Выбор параметров для $p$.}
Для произвольного начального приближения $(u^0,p^0)$ выберем
итерационные параметры $\tau_k$, $\nu_k$ в методе~(\ref{meth})
следующим образом:
\begin{equation}
\label{parp}
\begin{array}{c}
\tau_1 = 1, \quad \nu_1 = \wt \tau_{1}, \quad
\nu_{k+1}=\nu_k (\wt \alpha_{k+1} -1 ) + \wt \alpha_{k+1} \wt \tau_{k+1}, \\
\quad \tau_{k+1} = \wt \alpha_{k+1} \wt \tau_{k+1} / \nu_{k+1},
\quad k = 1, 2, \dotsc,
\end{array}
\end{equation}
где $\wt \tau_{k}$, $\wt \alpha_{k}$ определяются
формулами~(\ref{3cheb}) или~(\ref{msg}).

\begin{thm} Для произвольного $k = 1, 2, \dotsc$ приближения
$p^k$, получаемые по формулам~$(\ref{meth})$ с параметрами~$(\ref{parp})$,
удовлетворяют оценке погрешности~$(\ref{estimp})$.
\end{thm}

\begin{pf}
В силу справедливости лемм 1, 2 параметры полуитерационного метода
Чебышева~(\ref{3varmeth}),~(\ref{3cheb})
и метода сопряженных направлений~(\ref{3varmeth}),~(\ref{msg})
удовлетворяют неравенствам
$$
\wt \tau_k > 0, \quad \wt \alpha_k > 1, \quad k = 2, 3, \dotsc,
$$
и, следовательно, допускают обратное преобразование~(\ref{trsf}).
Поэтому выбор параметров по формулам~(\ref{parp}) в методе~(\ref{meth})
в силу леммы 3
порождает для погрешности $r^k = p^k - p$ соотношение~(\ref{err2})
с $\mu_{k+1} = \wt \alpha_{k+1}$, $\rho_{k+1} = \wt \tau_{k+1}$
для $ k = 1, 2, \dotsc$
и $r^1 = ( I - \nu_1 C^{-1}A_0)r^0$, что и приводит к искомой оценке
погрешности~\cite{SamNik}.
\end{pf}

Следует отметить, что если дополнительно имеется ограничение
$\wt \alpha_{k+1} < 2$ (как в полуитерационном методе Чебышева),
то формулы~(\ref{parp}) устойчивы к ошибкам округлений.

Далее, при необходимости определить $u^{k+1}$, удовлетворяющее
оценке~(\ref{estimu}), достаточно взять $\tau_{k+1}=1$ и после этого
завершить вычисления. Таким образом, формулы~(\ref{meth}),~(\ref{parp})
иллюстрируют обобщение алгоритмов типа Удзавы в случае использования
переменных итерационных параметров.
\medskip

{\bf 4.} {\it Особенность выбора $\tau_1=1$.}
Проанализируем следствие первого шага
при $\tau_1=1$ с произвольного начального приближения $(u^0,p^0)$
для использования формулы~(\ref{err2}). Из~(\ref{errvr}) имеем
\begin{equation}
\label{v1v2}
v^1 = - A^{-1} B\,r^0, \quad v^2 = ( I - \tau_2 \nu_1 A^{-1}B_0)v^1.
\end{equation}
Отсюда следует, что начальное приближение $u^0$ фактически не участвует в
вычислениях и, следовательно, $v^0$ --- в оценках погрешности.
Другими словами, можно считать, что в методе~(\ref{meth})
величина $u^1$ выбирается специальным образом
\begin{equation}
\label{init}
A\,u^1 + B\,p^0 = f.
\end{equation}

Далее нам потребуется информация о спектре матрицы $A^{-1}B_0$
(напомним, что $B_{0} = B C^{-1} B^T$).

\begin{lem}
Ненулевые собственные значения
матрицы $A^{-1}B_0$ положительны и с учетом кратностей совпадают
с собственными значениями матрицы $C^{-1}A_0$. При этом имеется ровно
$ N_u - N_p \geq 0 $
нулевых собственных значений.
\end{lem}

\begin{pf}
Заметим, что
имеет место ограничение на размерности подсистем:
$N_u - N_p \geq 0 $ (в противном случае $\ker(B)$ не пусто,
т.е. матрица исходной системы $ L_{\varepsilon}$ вырождена).

Теперь, если ввести обозначения $ R = C^{-1}B^{T}$, $S=A^{-1}B$, то
матрицы $C^{-1}A_0$ и $A^{-1}B_0$
представимы в виде $RS$ и $SR$ соответственно.
В терминах характеристического многочлена
$\Phi_T(\lambda) = \det( \lambda \,I - T )$
квадратной матрицы $T$ это приводит к равенству
$$
\Phi_{A^{-1}B_0}(\lambda) = \lambda^{N_u - N_p} \Phi_{C^{-1}A_0}(\lambda)
$$
на основании
теоремы 1.3.20 из \cite{Horn}.
Поскольку
$\sigma (C^{-1}A_0 ) \in[\gamma,\Gamma]$, $\gamma > 0$, то
отсюда сразу следует искомое утверждение.
\end{pf}

Обозначим через $U$ и $P$ евклидовы пространства векторов размерностей
$N_u$ и $N_p$ соответственно.
Поскольку в общем случае $N_u \ge N_p$, то удобно обозначить
$\ker (A^{-1}B_0)$ (множество векторов
размерности $\dim(H) = N_u - N_p $) через $H$. Ясно, что
$$
H = \{u \in U : B^T u = 0 \}.
$$
Далее будем использовать разложение пространства
$U$ в прямую сумму $U = H \oplus G$, где
$G$ --- ортогональное дополнение к $H$.
Покажем, что метод~(\ref{meth}) при выборе начального
приближения вида~(\ref{init}) эквивалентен итерированию
ошибки $v^k$ в подпространстве $G$.

\begin{lem} Для любой итерации $k$ первая компонента $v^k$
погрешности итерационного метода~$(\ref{meth})$, стартующего с начального
приближения вида~$(\ref{init})$, является элементом
подпространства $G$ $($т.е. $(Av^k,h)=0$ $\forall h \in H)$.
\end{lem}

\begin{pf} Из соотношения~(\ref{init}) следует, что начальная погрешность
$(v^1,r^0)$ удовлетворяет равенству
$$
A\,v^1 + B\,r^0 = 0
$$
и, следовательно, $v^1$ является элементом $G$. Действительно, для
произвольного элемента $h \in H$ справедливо $ B^Th=0$, поэтому
$$
(Av^1,h)=-(Br^0,h)=-(r^0,B^Th)=0.
$$
Далее покажем, что если $v^k \in G$, то и $v^{k+1} \in G$.
Компонента $v^k$ удовлетворяет соотношению
$$
v^{k+1} = (1-\tau_{k+1})v^k - \tau_{k+1} A^{-1}Br^k,
$$
поэтому имеем
$$
(Av^{k+1},h)=\left( (1-\tau_{k+1})Av^k - \tau_{k+1} Br^k, h \right) =
(1-\tau_{k+1})(Av^k,h)\ \; \forall h \in H. 
$$
Таким образом, индуктивный переход и начальное условие гарантируют,
что для любой итерации $k$ вектор $v^k \in G$.
\end{pf}

Отсюда на основании лемм 4, 5 можно сделать вывод, что метод~(\ref{meth})
для решения задачи~(\ref{sys}),
стартующий с начального приближения~(\ref{init}), эквивалентен,
с точки зрения соотношений для погрешности, методу~(\ref{v1v2}),~(\ref{err1})
решения уравнения
$A^{-1}B_0\,u = A^{-1}B\,C^{-1} g$, $u \in G$.
При этом оператор $A^{-1}B_0$ симметризуем и
$\gamma (y,y) \leq (A^{-1}B_0y,y) \leq \Gamma (y,y)$
$\forall y \in G$, $\gamma >0$.
Если ввести оператор $D_u = D_u^T > 0$ такой, что
$D_uA^{-1}B_0 = (D_uA^{-1}B_0)^T$, то аналогично~(\ref{msg})
можно определить формулы методов сопряженных направлений
\begin{equation}
\label{msgu}
\begin{array}{c}
\displaystyle\wt \tau_{k+1} = \frac{(v^k,D_u w^k)}{(w^k,D_u w^k)},
\quad k = 0, 1, 2, \dotsc, \\
\wt \alpha_{k+1} = \bigg(1 - \frac{\wt \tau_{k+1}}{\wt \tau_{k}}
\displaystyle\frac{(v^k,D_u w^k)}{(v^{k-1},D_u w^{k-1})}
\displaystyle\frac1{\wt \alpha_{k}} \bigg)^{-1},
\quad
k = 1, 2, \dotsc,
\end{array}
\end{equation}
где $ \wt \alpha_{1} = 1$, $w^k = C^{-1} x^k$,
$B_0 v^k = x^k (v^k \in G)$, $x^k = B_0 u^k - BC^{-1}g$.

Далее определим последовательность итерационных параметров $\tau_k$,
$\alpha_k$,
приводящую к оценке погрешности для любого $k$
\begin{equation}
\label{estimu1}
\| u^{k+1} - u \|_{D_u} \leq \epsilon_k \,\| u^1 - u \|_{D_u},
\end{equation}
где $\epsilon_k$ определены в (\ref{estimp}).
\medskip

{\bf 5.} {\it Выбор параметров для $u$.} Используя свойства полушага с
$\tau_1 = 1$, для произвольного $p^0$ определим $u^1$. Это дает
возможность определить $\wt \tau_2$ по формулам~(\ref{3cheb})
или~(\ref{msgu}).
В соответствии с~(\ref{v1v2}) получаем $\nu_1 \tau_2 = \wt \tau_2$,
что порождает некоторый произвол в выборе $\nu_1$
(необходимо, чтобы $\tau_2 \neq 1$).
Зафиксировав каким-либо образом $\nu_1$, сразу же по формулам~(\ref{meth})
имеем возможность вычислить $p^1$ и $u^2$. Это в свою очередь
порождает значения
$\wt \alpha_{k+1}$, $\wt \tau_{k+1}$ при $k=2$
по формулам~(\ref{3cheb}) или~(\ref{msgu}).
Теперь, используя обратное преобразование формул~(\ref{parerr1}), получим
\begin{equation}
\label{paru}
\tau_{k+1} = \frac{(\wt \mu_{k+1} - 1) \tau_{k}}{ 1 - \tau_{k}}, \quad
\nu_{k} = \frac{\wt \mu_{k+1} \wt \rho_{k+1}}{ \tau_{k+1}},
\end{equation}
где $\wt \mu_{k+1} = \wt \alpha_{k+1}$,
$\wt \rho_{k+1} = \wt \tau_{k+1}$ из~(\ref{3cheb}) или~(\ref{msgu}).
Это приводит к получению $p^k$ и $u^{k+1}$ для $k=2$, и далее этот
процесс может быть продолжен сколь угодно долго.

Из формул~(\ref{paru}) следует, что их применимость определяется
условием $0 < \tau_k < 1$, $k = 2, 3, \dotsc$, что в свою очередь
зависит от выбора $\nu_1$.

\begin{lem} Для произвольного $k = 2, 3, \dotsc, k_0$
существует $0 < \tau_2 = \tau_2(k_0) < 1$ такое, что если
$1 < \wt \mu_{k+1} < 2$, то все $\tau_{k+1}$ из~$(\ref{paru})$
удовлетворяют неравенству $0 < \tau_{k+1} < 1$.
\end{lem}

\begin{pf}
Введем обозначения $y_k = \tau_k^{-1}$ и $\delta_{k+1} = ( \wt \mu^{k+1}
- 1 )^{-1}$. Обратим внимание, что все $\delta_{k+1} >1$, и перепишем первую
формулу~(\ref{paru}) в виде
$$
y_{k+1} = \delta_{k+1} ( y_k -1 ), \quad k = 2, 3, \dots, k_0.
$$
Это дает
$$
y_{k_0 + 1} = \bigg( \prod_{j=3}^{k_0+1} \delta_j \bigg) y_2 -
\sum_{j=3}^{k_0+1} \prod_{s=j}^{k_0+1} \delta_s =
\bigg( \prod_{j=3}^{k_0+1} \delta_j \bigg) \bigg( y_2 - 1 -
\sum_{j=3}^{k_0} \prod_{s=j}^{k_0} \delta_s^{-1} \bigg).
$$
Пусть
$$
 y_2 \geq 2 +
\sum_{j=3}^{k_0} \prod_{s=j}^{k_0} \delta_s^{-1},
$$
тогда для любого $k = 2, 3, \dotsc, k_0$ справедливо
$$
y_{k + 1} \geq \prod_{j=3}^{k+1} \delta_j > 1,
$$
или $0 < \tau_{k+1} < 1 $. Добиться же выполнения искомого
неравенства для $y_2$ несложно, взяв, например,
$\tau_2 = \tau_2(k_0) = y_2^{-1} = k_0^{-1}$.
\end{pf}

С помощью полученных результатов покажем, что справедлива

\begin{thm} Для произвольного $k = 1, 2, \dotsc$
существует набор итерационных параметров
$\tau_1 =1$, $\tau_2 \nu_1 = \wt \tau_2$, далее
по формулам~$(\ref{paru})$ с
$\wt \mu_{k+1} = \wt \alpha_{k+1}$ $(1 < \wt \mu_{k+1} < 2)$,
$\wt \rho_{k+1} = \wt \tau_{k+1}$ из~$(\ref{3cheb})$ или~$(\ref{msgu})$,
такой, что
метод~$(\ref{meth})$ генерирует
приближения $u^k$,
удовлетворяющие оценке погрешности~$(\ref{estimu1})$.
\end{thm}

\begin{pf}
Зафиксируем некоторое $k_0$ и положим $\nu_1 = \wt \tau_2 k_0$.
Тогда в силу леммы 6 формулы~(\ref{paru}) корректны и порождают
набор параметров $\tau_{k+1}$, $\nu_k$ при
$k = 2, 3, \dotsc, k_0 $ для~(\ref{meth}). В свою очередь это приводит
к соотношению~(\ref{err1}) для ошибки $v^k = u^k - u$
с параметрами~(\ref{parerr1}), гарантирующему для
любого $k = 1, 2, \dots, k_0$ оценку (\ref{estimu1}).
\end{pf}

Прокомментируем полученные результаты. Ранее для решения задачи
$L_0 z = F $ были известны алгоритмы
(типа Удзавы), приводящие для погрешности $r^k = p^k - p$
к наилучшей при заданной информации оценке~(\ref{estimp}).
Выше было показано (см. теорему 1), что все они могут быть
представлены в форме алгоритма Эрроу--Гурвица~(\ref{meth})
при соответствующем выборе итерационных параметров.
Кроме того, если известны границы спектра $0 < \gamma, \Gamma$ матрицы
$C^{-1} A_0$, то можно также,
пользуясь только формулами~(\ref{meth}),
добиться аналогичной
оценки~(\ref{estimu1}) для погрешности $v^k = u^k - u $ за счет
специального выбора параметров~(\ref{paru}).
В дальнейшем представляется интересным проанализировать вычислительную
корректность этого подхода, если параметры вычисляются из
вариационных принципов.
