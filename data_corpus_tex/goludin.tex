{\bf 1.} В работах [1--3] построены детерминированные феноменологические модели
изотермической ползучести поливинилхлоридного пластиката, а в [4] предложены
стохастические определяющие соотношения для этих же температурных условий.

Целью настоящей работы является экспериментальное исследование ползучести
поливинилхлоридного пластиката, статистический анализ данных, построение
феноменологической теории ползучести и проверка ее адекватности
экспериментальным данным в вероятностной постановке в условиях
неизотермического температурного нагружения.

Эксперименты проводились с трубчатыми образцами длинной $1\,000$~мм и~сечением
$1,2$~мм$^{2}$ в состоянии поставки. Контроль полной относительной
деформации осуществлялся с точностью до $2,5\cdot 10^{-4}$.
Величина относительной деформации во всех экспериментах не превосходила
$0,1$, контроль температуры "--- $\pm 0,5\,^\circ$C.

Экспериментальные исследования поливинилхлоридного пластиката были выполнены
при пяти значениях растягивающего усилия
$Q=\{ 5,59; 7,55;$  $10,5;$ $ 12,46; 14,42 \}$~Н (что соответствует номинальным
напряжениям $\sigma =\{ 4,66;$  $6,29; 8,75; 10,38; 12,02 \}$~МПа)
в~течение $8$ часов, затем производилась разгрузка в течение $20$ часов.
При этом испытания протекали при температурах $T=\{ 0; 8; 9; 16; 20; 24; 25; 28\}\,^\circ$C
($ \pm 0,5\,^\circ$C):
\begin{itemize}
 \item  при
температуре $T=8\,^\circ $C было выполнено $2$ испытания при $\sigma =\{10,38;$ $12,02\}$~МПа;
\item
при температурах \mbox{$T=\{ 0;$} $16;$ $25;$ $28\}\,^\circ$C "--- по $3$ испытания при
$\sigma =\{4,66;$ $6,29;$ $8,75\}$~МПа;
\item  при \mbox{$T=9\,^\circ $C} "--- $5$
испытаний при $\sigma =\{ 4,66;$ $6,29;$ $8,75;$ $10,38;$ $12,02\}$~МПа;
\item  при $T=20\,^\circ $C "--- $28$~испытаний при $\sigma {=}\{ 4,66;$ $6,29;$ $8,75;$ $10,38;$ $12,02\}$\,МПа;
\item при $T=24\,^\circ$C "---
$17$~испытаний при $\sigma {=}\{ 4,66;$ $6,29;$ $8,75;$ $10,38;$ $12,02\}$\,МПа.
\end{itemize}

В качестве примера на рис. $1$ и $2$ представлены кривые ползучести всех
образцов соответственно при $T=\{ 20;$ $24\}\,^\circ $C
(упругая деформация вычиталась из общей деформации).
Кроме этого были выполнены испытания при переменных (ступенчатых) режимах температуры со
сложной (ступенчатой) программой изменения напряжения ($7$~образцов).
Эти экспериментальные данные в дальнейшем использовались для проверки
адекватности расчёта по  стохастической модели неизотермической ползучести экспериментальным данным.

Испытания при различных значениях растягивающего усилия $Q$ (напряжения
$\sigma )$ и температуры $T$ показали, что вся накапливаемая в процессе
ползучести деформация является обратимой, т.\,е. после снятия нагрузки по
истечении некоторого времени образцы практически полностью
восстанавливают первоначальные размеры.

\textbf{2.} Выполним первичный статистический анализ деформаций ползучести при
постоянных напряжениях и температурах.

Будем рассматривать деформацию ползучести образца как случайную функцию
времени $p(t)$ при фиксированных постоянном напряжении и~постоянной температуре:
в~качестве иллюстрации её значения в~дискретные
моменты времени для некоторых фиксированных значений температур и~напряжений
представлены на рис.~$1$, $2$ точками.
При $t=\rm const$ деформация ползучести
при $\sigma =\rm const$ и~при $T= \rm const$ есть некоторая случайная величина "---
сечение случайной функции $p(t)$.
Набор таких сечений образует случайную последовательность
(решетчатую случайную функцию), которая несёт
всю наиболее существенную информацию относительно $p(t)$.

Рассмотрим оценки для моментных функций случайной величины $p(t)$
при различных постоянных напряжениях и температурах:
\begin{gather}
%\label{gol:eq1}
m(t_i )=\frac 1n \sum\limits_{l=1}^n p_l (t_i ) ;
\notag \\
%\label{gol:eq2}
K(t_i, t_j )=\frac 1{n-1}\sum\limits_{l=1}^n
\bigl[ p_l ( t_i )-m(t_i ) \bigr] \bigl[ p_l (t_j)-m(t_j ) \bigr] ;
\notag \\
%\label{gol:eq3}
S(t_j )=\sqrt {K(t_j , t_j )} ;
\notag \\
\label{gol:eq4}
r(t_i, t_j )=\frac{K(t_i, t_j )}{S(t_i)S(t_j )},
\end{gather}
где $p_l(t_i)$ "--- вектор значений случайной величины деформации ползучести при $t_i = \rm const$.

Большую информацию дают значения нормированной корреляционной функции (\ref{gol:eq4})
и~при обработке реализаций при каждом фиксированном значении температуры,
и~при использовании всех $64$ реализаций для всех $5$ напряжений и~всех
температур $T=\{ 0; 8; 9; 16; 20; 24; 25; 28 \}\, ^\circ$C.
Вычисление $r(t_i, t_j )$ производилось для различных пар,
образованных следующими моментами времени (час): $0,25$; $0,5$; $1$; $2$; $4$; $6$; $8$.
В~таблице в качестве примера приведены результаты вычислений значений
нормированной корреляционной матрицы для $64$ реализации для всего ряда
температур ($n=64)$. Из данных таблиц видно, что все временные сечения
находятся в жёсткой корреляционной зависимости, поскольку значения $r(t_i, t_j )$
отличаются от единицы лишь в~третьем знаке.

Таким образом, поскольку значения корреляционной матрицы для деформации
ползучести близки к единице, то это свидетельствует о подобии кривых
ползучести отдельных реализаций не только для одного температурного режима,
но и для реализаций, полученных для различных значений температур и
напряжений. Следует отметить, что аналогичный результат для полимеров был
отмечен в [5].

\textbf{3.} В работе [4] построена стохастическая модель изотермической ползучести
поливинилхлоридного пластиката.
Переходя к формулировке стохастических уравнений для нестационарных температурных
режимов, можно взять за основу методологию, использованную в [4], при этом в частном
случае при $T= \rm const$ должны получиться соответствующие стохастические уравнения
изотермической ползучести.
Поэтому в качестве базовой модели для обобщения используем
стохастический вариант изотермической наследственной теории ползучести в
дифференциальной форме [4]:
\begin{gather}
\label{gol:eq5}
p(t)=\sum\limits_{k=1}^s \eta _k (t) ,
\\
\label{gol:eq6}
\dot \eta _k (t)=\lambda _k
\Bigl[ A a_k \Bigl( \frac{\sigma }{\sigma _\ast } \Bigr)^n-\eta _k (t)
\Bigr],
\end{gather}
где $A$ "--- случайная величина, а $s$, $\lambda _k$, $a_k$, $n$, $\sigma _\ast $ "---
детерминированные постоянные материала, методика идентификации которых на
основе метода последовательного выделения экспоненциальных слагаемых
изложена в~[6,~7].

При постоянном напряжении $\sigma = \rm const$ решение (\ref{gol:eq5}), (\ref{gol:eq6}) имеет вид
\begin{equation}
\label{gol:eq7}
p(t)=A\sum\limits_{k=1}^s
a_k \bigl( 1-\exp (-\lambda _k t )  \bigr) \Bigl( \frac{\sigma }{\sigma _\ast }  \Bigr)^n  ,
\end{equation}
а варьированием случайного параметра $A$ можно описать любую кривую
ползучести при стационарном напряжении.
Так, для рассматриваемого материала в~[4] спектр всех кривых ползучести при $\sigma = \rm const$
и~$T=24\,^\circ$C описывается следующей конкретизацией соотношения~(\ref{gol:eq7}):
\begin{equation}
\label{gol:eq8}
p(t)=A K(t) \Bigl(\frac{\sigma }{\sigma _\ast } \Bigr)^{1,53},
\end{equation}
где
\begin{multline}
\label{gol:eq9}
K(t)=
25,92\cdot 10^{-3}\bigl( 1-\exp(-30,68t) \bigr)+ \\
+
10,28\cdot 10^{-3}\bigl( 1-\exp (-1,95t) \bigr)+
23,51\cdot 10^{-3}\bigl( 1-\exp (-0,23t) \bigr),
\end{multline}
$\sigma _\ast =8,75$~МПа.

Исходя из гипотезы подобия кривых ползучести поливинилхлоридного пластиката
(см. таблицу), соотношения (\ref{gol:eq8}), (\ref{gol:eq9}) можно обобщить для описания спектра
кривых ползучести для $\sigma = \rm const$ и $T= \rm const$, введя вместо случайного
параметра $A$ случайную функцию температуры:
\begin{equation}
\label{gol:eq10}
p(t)=B \exp(\alpha T) K(t) \Bigl( \frac{\sigma }{\sigma _\ast } \Bigr)^{1,53},
\end{equation}
где $B$ "--- случайная, а $\alpha $ "--- детерминированная величины.

На первом этапе идентификации параметров $B$ и $\alpha $ необходимо
построить детерминированную модель, соответствующую (\ref{gol:eq10}),
заменив в ней случайную величину $B$ на её математическое ожидание $b$.
Тогда параметры $b$ и $\alpha $ могут быть определены, например, по методу наименьших
квадратов на основании осреднённых экспериментальных кривых ползучести,
соответствующих всевозможным парам $(\sigma, T)$.
Результаты расчётов позволили получить следующие значения параметров:
$b=0,281$ и $\alpha =0,056$.

Для идентификации случайной величины $B$ (фактически "--- построения её
выборки), для каждой из 64 реализаций при фиксированных парах значений
$(\sigma _i , T_j )$ находится в~дискретные моменты
времени $t_k $ величина
\begin{equation}
\label{gol:eq11}
B_{kij} =\frac{p^\ast (t_k )}{
\exp ( 0,056 T_j ) K(t_k )\bigl( \frac{\sigma _i }{\sigma_\ast } \bigr)^{1,53} },
\end{equation}
и далее она осредняется по всем дискретным значениям времени $t=t_k $
($p^\ast (t_k )$ "--- экспериментальные значения).
На рис.~$3$ представлена гистограмма распределения случайной величины $B$
с~математическим ожиданием $m_B =0,284$ и среднеквадратичным отклонением $S_B =0,028$
($f$ "--- частота попадания величины $B$ в заданный интервал).
Из рис.~$3$ следует, что для случайной величины $B$ можно использовать нормальный закон распределения.

В силу полной обратимости деформации ползучести поливинилхлоридного
пластиката и подобия кривых ползучести при стационарных температурно"=силовых
условиях можно обобщить уравнения состояния (\ref{gol:eq5}), (\ref{gol:eq6}) на случай
неизотермической ползучести следующим образом:
\begin{gather}
\label{gol:eq12}
p( t)=\sum\limits_{k=1}^s \eta _k ( t ) ,
\\
\label{gol:eq13}
\dot \eta _k (t)=\lambda _k
\Bigl[ B a_k \exp (\alpha T )\Bigl( \frac{\sigma }{\sigma _\ast } \Bigr)^n-\eta _k
(t)  \Bigr],
\end{gather}
где $B$ "--- случайная, $s$, $\lambda _k$, $a_k$, $n$, $\sigma _\ast$, $\alpha $ "---
детерминированные величины (численные характеристики всех детерминированных
величин определены выше).

\textbf{4.} Экспериментальная проверка стохастической модели (\ref{gol:eq12}), (\ref{gol:eq13}) выполнялась
как для стационарных, так и нестационарных температурно"=силовых режимов
нагружения.

При постоянных напряжениях и температурах решение (\ref{gol:eq12}), (\ref{gol:eq13}) имеет вид (\ref{gol:eq9}),
(\ref{gol:eq10}), и поскольку величина $B$ распределена по нормальному закону,
а~соотношение (\ref{gol:eq10}) стохастически линейное, то случайная функция $p(t)$
также будет распределена по нормальному закону.
На рис. $1$, $2$ штриховыми линиями (выборочно) показаны расчётные доверительные интервалы
для деформации ползучести (значение вероятности "--- 0,9973) при стационарных
температурно"=силовых условиях нагружения, а на рис.~4,~5 представлена
аналогичная информация для нестационарных (изменяющихся ступенчато)
температурно"=силовых режимов нагружения.
Анализ этой информации позволяет сделать вывод, что наблюдается соответствие экспериментальных
данных и~расчётных значений в~вероятностной постановке, поскольку опытные данные
попадают в соответствующие доверительные интервалы для прогнозируемой
деформации ползучести.
