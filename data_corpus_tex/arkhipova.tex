\Section[n]{Введение} Рассмотрим нагруженное уравнение смешанного типа
\begin{equation}
\label{arkhip:eq1} Lu =   u_{xx} + \left( \mathop{\rm sgn } t \right) u_{tt} +
a(t) u(x, 0) + b(t) u (x, d)= 0
\end{equation}
в прямоугольной области
$D=\left\{ { \left( {x,t} \right):\, 0 < x < 1, -\alpha < t <\beta }
\right\}$, где $\alpha,\beta$ "--- заданные положительные действительные
числа, $a(t)=a_{1}(t)$ при $t\geq{0}$,
$a(t)=a_{2}(t)$ при $t\leq{0}$, $b(t)=b_{1}(t)$ при $t\geq{0}$,
$b(t)=b_{2}(t)$ при $t\leq{0}$, $d=d_{1},$ при $t>{0}$, $d_{1} \in \left(0, \beta\right)$,
$d= - d_{2}$ при $t<{0}$, $d_{2} \in \left(0,\alpha\right)$, $d_{1}$ и $d_{2}$ "--- заданные положительные числа из указанных промежутков,
$a_{i}(t)$, $b_{i}(t)$, $i = 1, 2$, "--- заданные непрерывные
функции. Числа $a_{1}\left(0\right)$ и $a_{2}\left(0\right)$ и соответственно $b_{1}\left(0\right)$ и $b_{2}\left(0\right)$ здесь не связаны никакими условиями.

\smallskip
\begin{newthm}{Задача Дирихле} Найти в области $D$ функцию $u(x, t),$ удовлетворяющую следующим условиям\/{\rm :}
\begin{gather}
\label{arkhip:eq2} u\left( {x,\,t} \right) \in C^{1}\left(\, \overline
{D}\, \right)\cap C^{2}\left(D_{+} \cup D_{-}\right);
\\
\label{arkhip:eq3} Lu(x, t) \equiv 0,\quad ( x,\,t) \in D_{+} \cup D_{-} ;
\\
\label{arkhip:eq4} u\left( {0,\,t} \right) = u(1, t) = 0,
\quad {-\alpha \leq{t} \leq{\beta}};
\\
\label{arkhip:eq5} u\left( {x,\, \beta} \right) = \varphi (x), u(x,\,-\alpha) = \psi(x),
\quad {0\leq{x}\leq{1}},
\end{gather}
где $\varphi (x),$ $\psi \left( {x}
\right)$ "--- заданные достаточно гладкие функции{\rm ,} при этом $\varphi
\left( {0} \right) = \varphi\left( {1}\right) = \psi \left( {0}
\right) = \psi\left( {1}\right)=0$, $D_{+} = D \cap \left\{{y>0}\right\},$ $D_{-} = D \cap \left\{ {y<0}\right\}.$
\end{newthm}

\smallskip

Отметим, что в работе \cite{arh:1} для нагруженного
параболо"=гиперболического уравнения в прямоугольной области изучена
начально"=граничная задача, в которой методом спектральных разложений
\cite{arh:2} установлен критерий единственности решения этой
задачи и само решение построено в виде суммы ряда по собственным
функциям соответствующей одномерной задачи на собственные значения.

Ранее в работах [\citen{arh:3}--\citen{arh:10}] изучены краевые
задачи (локальные и нелокальные) для нагруженных дифференциальных
уравнений в частных производных отдельных и смешанных типов в
классических областях, у которых гиперболическая часть представляет собой характеристический треугольник. В работе \cite{arh:11} изучена задача \eqref{arkhip:eq2}--\eqref{arkhip:eq5} для уравнения  \eqref{arkhip:eq1} при $b(t)\equiv 0$ в прямоугольной области $D$.

В данной работе в соответствии с \cite{arh:1, arh:2, arh:11} установлен критерий единственности решения задачи
Дирихле для уравнения смешанного типа с~нагруженными слагаемыми \eqref{arkhip:eq1} при $b(t)\ne 0$ в~прямоугольной области $D$.

\Section{Единственность} Пусть $u(x, t)$ "--- решение задачи \eqref{arkhip:eq2}--\eqref{arkhip:eq5}. Рассмотрим функцию
\begin{equation}
\label{arkhip:eq6} u_{k}(t)= \sqrt{2}\int_0^1 u (x, t)\sin {\lambda_{k}x}dx,
\end{equation}
где $\lambda_{k} = \pi k$, $k\in \mathbb N$. На основании \eqref{arkhip:eq6} введём функцию
\begin{equation} 
\label{arkhip:eq7} u_{k,\varepsilon}(t)= \sqrt{2}\int_\varepsilon^{1-\varepsilon} u (x, t)\sin {\lambda_{k}x}dx,
\end{equation}
где $\varepsilon$ "--- достаточно малое положительное число. 
Дифференцируя  равенство \eqref{arkhip:eq7} по $t$ два раза при $t\in (-\alpha,\,0)\cup(0,\,\beta)$ и учитывая уравнение \eqref{arkhip:eq1}, получим
\begin{multline}
u_{k,\varepsilon} ^{\prime \prime}(t)=
\sqrt{2}\int_\varepsilon^{1-\varepsilon} u_{tt}\left( {x,\,t}
\right)\sin {\lambda_{k}x}dx =
\\
= \sqrt{2}\int_\varepsilon^{1-\varepsilon} \left[ {- u_{xx} -
a_{1} (t)u\left( {x,\,0} \right)- b_{1} \left( {t}
\right)u\left( {x,\,d_{1}} \right)}\right] \sin {\lambda_{k}x}dx =
\\
= - \sqrt{2}\int_\varepsilon^{1-\varepsilon} u_{xx}\sin
{\lambda_{k}x}dx - \sqrt{2} a_{1}\left( {t}
\right)\int_\varepsilon^{1-\varepsilon}u\left( {x,\,0}
\right)\sin {\lambda_{k}x}dx -
\\
- \sqrt{2} b_{1}\left( {t}
\right)\int_\varepsilon^{1-\varepsilon}u\left( {x, \,
d_{1}} \right)\sin {\lambda_{k}x}dx, \quad t > 0;
\label{arkhip:eq8}
\end{multline}
\begin{multline}
u_{k,\varepsilon} ^{\prime \prime}(t)=
\sqrt{2}\int_\varepsilon^{1-\varepsilon} u_{tt}\left( {x,\,t}
\right)\sin {\lambda_{k}x}dx =
\\
= \sqrt{2}\int_\varepsilon^{1-\varepsilon} \left[ {u_{xx} +
a_{2} (t)u\left( {x,\,0} \right) + b_{2} (t)u\left( {x,\,- d_{2}} \right)}\right] \sin
{\lambda_{k}x}dx =
\\
= \sqrt{2}\int_\varepsilon^{1-\varepsilon} u_{xx}\sin
{\lambda_{k}x}dx + \sqrt{2} a_{2}\left( {t}
\right)\int_\varepsilon^{1-\varepsilon}u\left( {x,\,0}
\right)\sin {\lambda_{k}x}dx +
\\
+ \sqrt{2} b_{2}\left( {t}
\right)\int_\varepsilon^{1-\varepsilon}u\left( {x, \,
- d_{2}} \right)\sin {\lambda_{k}x}dx, \quad t < 0.
\label{arkhip:eq9}
\end{multline}

Интегрируя по частям два раза в интегралах, содержащих $u_{xx}$, и переходя к пределу при $\varepsilon \to 0$, с учётом однородных граничных условий \eqref{arkhip:eq4} получим
\begin{equation} \label{arkhip:eq10}
u_{k} ^{\prime \prime}(t) - \lambda_{k} ^{2}
u_{k}(t) = - a_{1}(t)u_{k} \left( {0}
\right) - b_{1}(t)u_{k} \left( {d_{1}}
\right),\quad t > 0,
\end{equation}
\begin{equation} \label{arkhip:eq11}
u_{k} ^{\prime \prime}(t) + \lambda_{k} ^{2}
u_{k}(t) = a_{2}(t)u_{k}
\left({0}\right) + b_{2}(t)u_{k}
\left({-d_{2}}\right),\quad t < 0.
\end{equation}

\end{equation}

\end{equation}

\end{equation}

- \Bigl(\ch{\lambda_{k} \beta} - \frac{a_{1k} (\beta)}{\lambda_{k}} - \widetilde M_{1 k}b_{1 k}(\beta)\Bigr)N_{2 k}b_{2 k}(t) +
\\
+ \Bigl( \frac{a_{2k} (t)}{\lambda_{k}} + N_{1 k}b_{2 k}(t)\Bigr)\bigl(\sh{\lambda_{k} \beta - \widetilde M_{2 k}b_{1 k}(\beta)}\bigr),\quad t < 0.
\end{multline*}
%\end{center}

Таким образом, функции $u_{k}(t)$ однозначно
определены, что позволяет доказать теорему единственности решения
задачи \eqref{arkhip:eq2}--\eqref{arkhip:eq5}.

Пусть $u\left({x,\,t}\right)$ "--- решение однородной задачи
\eqref{arkhip:eq2}--\eqref{arkhip:eq5} (при $\varphi( x ) =
\psi( x ) \equiv{0}$) и выполнены условия \eqref{arkhip:eq21}
при всех $k\in{\mathbb  N}$. Тогда $\varphi_{k} = \psi_{k} \equiv{0}$ и из
формул \eqref{arkhip:eq22} и \eqref{arkhip:eq6} следует, что при любом $t \in
{\left[{-\alpha,\,\beta}\right]}$
\begin{equation} \label{arkhip:eq23'}
\int_0^1 u\left( {x,\,t}\right)\sin {\lambda_{k}x}dx = 0
,\quad k = 1, 2,\dots 
\end{equation}
Из равенств \eqref{arkhip:eq23'}  в силу полноты системы синусов
$\left\{\sqrt{2} \sin{\lambda_{k}x}\right\}$ в пространстве
$L_{2}\left[{0, 1}\right]$ следует, что $u\left({x,t}\right) = 0$
почти всюду на $\left[{0, 1}\right]$ при любом
$y\in\left[{-\alpha,\beta}\right]$. Поскольку в силу \eqref{arkhip:eq2}
функция $u\left({x,\,t}\right)$ непрерывна в $\overline {D}$, то
$u\left({x,\,t}\right) \equiv {0}$ в $\overline {D}$.

Пусть при некоторых $\alpha$, $\beta$, $a(t)$,
$b(t)$ и $k = p \in N$ нарушено условие \eqref{arkhip:eq21}:
\begin{multline}
\Delta( p ) = -\sin{\lambda_{p}\alpha}\Bigl(\ch{\lambda_{p}\beta} - \frac{a_{1 p} (\beta)}{\lambda_{p}} - \widetilde M_{1 p}b_{1 p}(\beta)\Bigr) -
\\
- \cos{\lambda_{p}\alpha}\bigl(\sh\lambda_{p}\beta - \widetilde M_{2 p}b_{1 p}(\beta)\bigr)-
\\
- \Bigl(\ch{\lambda_{p} \beta} - \frac{a_{1 p} (\beta)}{\lambda_{p}} - \widetilde M_{1 p}b_{1 p}(\beta)\Bigr)N_{2 p}b_{2 p}(-\alpha) +
\\
+\left( \frac{a_{2 p} \left({-\alpha}\right)}{\lambda_{p}} + N_{1 p}b_{2 p}(-\alpha)\right)\left(\sh{\lambda_{p} \beta }- \widetilde M_{2 p}b_{1 p}(\beta)\right) = 0.
\label{arkhip:eq23}
\end{multline}
Тогда однородная задача \eqref{arkhip:eq2}--\eqref{arkhip:eq5} (при
$\varphi( x )\equiv{0}$, $\psi( x )\equiv{0}$)
имеет нетривиальное решение
\begin{equation}\label{arkhip:eq24}
u_{p}\left({x,\,t}\right) = u_{p}(t)\sin{\lambda_{p}x},
\end{equation}
где функция $u_{p}(t)$ определяется по формуле:
\begin{equation}\label{arkhip:eq25}
u_{p} (t) = \left\{ \begin{array} {l}
\displaystyle
\frac{A_{p}\widetilde M_{2 p}}{A\left(b_{1}, d_{1}\right)}\left[a_{1p} (t)b_{1 p}(\beta) - b_{1 p}(t)a_{1 p} (\beta)\right] + \\[2mm]
\displaystyle \hspace{1cm}
 + \frac{\lambda_{p}A_{p}\widetilde M_{2 p}}{A\left(b_{1}, d_{1}\right)}\left[\ch{\lambda_{p} \beta}b_{1 p}(t) -\ch{\lambda_{p} t}b_{1 p}(\beta)\right] + \\[2mm]
\displaystyle \hspace{1cm}
 + \frac{\lambda_{p}A_{p}\widetilde M_{1 p}}{A\left(b_{1}, d_{1}\right)}\left[\sh {\lambda_{p}t}b_{1 p}(\beta) - \sh {\lambda_{p}\beta}b_{1 p}(t)\right]  + \\[2mm]
 \displaystyle \hspace{1cm}
+ \frac{A_{p}}{A\left(b_{1}, d_{1}\right)}\left[\sh {\lambda_{p}t}a_{1 p}(\beta) - \sh {\lambda_{p}\beta}a_{1 p}(t)\right] + \\[2mm]
 \displaystyle \hspace{3cm} + \frac{\lambda_{p}A_{p}}{A\left(b_{1}, d_{1}\right)}\sh{\left[\lambda_{p}\left(\beta - t\right)\right]},\quad t \ge 0,\\[3mm]
  \displaystyle 
\frac{\lambda_{p}  A_{p}}{A\left(b_{1}, d_{1}\right)}\left(\sin{\lambda_{p} t}\Bigl(\ch{\lambda_{p}\beta} - \frac{a_{1p} (\beta)}{\lambda_{p}} - \widetilde M_{1 p}b_{1 p}(\beta)\Bigr)\right)  - \\[2mm]
\displaystyle \hspace{1cm}
 -\cos{\lambda_{p}t}\Bigl(\sh\lambda_{p}\beta - \widetilde M_{2 p}b_{1 p}(\beta)\Bigr) - \\[2mm]
 \displaystyle \hspace{1cm}
 - \Bigl(\ch{\lambda_{p} \beta} - \frac{a_{1 p} (\beta)}{\lambda_{p}} - \widetilde M_{1 p}b_{1 p}(\beta)\Bigr)N_{2 p}b_{2 p}(t) + \\[2mm]
  \displaystyle \hspace{3cm}
 +\Bigl( \frac{a_{2p} (t)}{\lambda_{p}} + N_{1 p}b_{2 k}(t)\Bigr)\widetilde M_{2 p}b_{1 p}(\beta) ,\quad t \le 0.\\
\end {array} \right.
\end{equation}
Здесь $A_{p}\neq{0}$, $B_{p}\neq{0}$ "--- произвольные  постоянные,
$A\left(b_{1}, d_{1}\right)=\lambda_{p}\sh {\lambda_{p} \beta} - \widetilde M_{2 p} b_{1
p}(\beta)$.


Действительно, функция \eqref{arkhip:eq25} по построению удовлетворяет
условиям \eqref{arkhip:eq2}--\eqref{arkhip:eq4}, а в силу условия \eqref{arkhip:eq23}
 для нее выполняются
равенства $$u_{p}\left({x,\beta}\right) = u_{p}\left({x,-\alpha}\right) =
0$$ при всех $x\in[0, 1]$, так как
$$u_{p}(\beta) = 0, \quad  u_{p}\left({-\alpha}\right) = \displaystyle\frac{A_{p}\Delta \left(p\right)}{A\left(b_{1}, d_{1}\right)} = 0.$$

Естественно, возникает вопрос о существовании нулей выражения $\Delta (k)$. Для этого  $\Delta (k)$ представим в следующем виде:
\begin{equation}\label{arkhip:eq27}
 - \Delta (k) = P_{k}\sin{\lambda_{k} \alpha} + Q_{k}\cos{\lambda_{k} \alpha} + L_{k},
\end{equation}
где
$$P_{k} = \ch {\lambda_{k} \beta} - \frac{1}{\lambda_{k}}a_{1 k}(\beta) - \widetilde M_{1 k}b_{1 k}(\beta), \quad 
Q_{k} = \sh{\lambda_{k} \beta} - \widetilde M_{2 k}b_{1 k}(\beta),$$
$$L_{k} = P_{k}N_{2 k}b_{2 k}(-\alpha) + \Bigl(\frac{1}{\lambda_{k}}a_{2 k}(-\alpha) + N_{1 k}b_{2 k}(-\alpha)\Bigr)Q_{k}.$$
Из соотношения \eqref{arkhip:eq27} имеем
\begin{equation}\label{arkhip:eq28}
\sin{\left(\lambda_{k}\alpha + \varphi_{k}\right)} = -\frac{L_{k}}{\sqrt{P_{k}^2 + Q_{k}^2}},\quad  \varphi_{k} = \arcsin\displaystyle\frac{Q_{k}}{\sqrt{P_{k}^2 + Q_{k}^2}}.
\end{equation}
Отсюда при условии
\begin{equation}\label{arkhip:eq29}
\normalsize
\frac{|L_{k}|}{\sqrt{P_{k}^2 + Q_{k}^2}}\le 1
\end{equation}
уравнение \eqref{arkhip:eq28} равносильно следующему уравнению:
\begin{equation}\label{arkhip:eq28'}
\normalsize
\alpha = \frac{\left({-1}\right)^{n+1}}{\lambda_{k}}\arcsin{\frac{L_{k}}{\sqrt{P_{k}^2 + Q_{k}^2}}} + \displaystyle \frac{n}{k}-\displaystyle\frac{\varphi_{k}}{\lambda_{k}}=f(\alpha), \quad  n\in \mathbb N.
\end{equation}

Если  $b_{2 k}(-\alpha) = 0$, то $$L_{k}= \frac{1}{\lambda_{k}}a_{2 k}(-\alpha)Q_{k},$$ 
и тогда
$$\displaystyle \frac{|L_{k}|}{\sqrt{P_{k}^2 + Q_{k}^2}} \le \frac{|a_{2 k}(-\alpha)|}{\lambda_{k}}\le \frac{\alpha \| a_{2}\| }{\lambda_{k}}, \quad  \| a_{2}\|  = \max_{-\alpha\le s\le 0}|a_{2}\left(s\right)|.$$
Отсюда видно, что существует $k_{0}\in \mathbb N$ такое, что при всех $k>k_{0}$
$$ \displaystyle\frac{\alpha \| a_{2}\| }{\lambda_{k}}\le 1.$$

Следовательно, при $b_{2 k}(-\alpha)=0$ неравенство \eqref{arkhip:eq29}  при больших $k$ всегда выполнено.

Если $b_{2 k}(-\alpha) = 0$ и $a_{2 k}(-\alpha) = 0$, то $L_{k}=0,$ и из уравнения \eqref{arkhip:eq28'} получим
$$\alpha = \displaystyle\frac{n}{k}-\frac{\varphi_{k}}{\lambda_{k}}, \quad  n\in \mathbb N .$$


Если $b_{2}(t) = b_{2} = {\rm const}\ne 0, a_{2}(t) = a_{2} = {\rm const}\ne 0$, то $b_{2 k}(-\alpha) = b_{2}\left(1 - \cos{\lambda_{k} \alpha}\right)/{\lambda_{k}}$  и $a_{2 k}(-\alpha) = a_{2}\left(1 - \cos{\lambda_{k} \alpha}\right)/{\lambda_{k}}$, и тогда выражение \eqref{arkhip:eq27} примет вид
\begin{equation}
\label{arkhip:eq31}
 - \Delta (k) = P_{k}\sin{\lambda_{k} \alpha} + \widetilde Q_{k}\cos{\lambda_{k} \alpha} + \widetilde L_{k},
\end{equation}
где
$$\widetilde Q_{k} = Q_{k}-\displaystyle\frac{b_{2}}{\lambda_{k}}\left(P_{k}N_{2 k} + Q_{k}N_{1 k}\right) - \displaystyle\frac{a_{2}}{\lambda_{k}^2}Q_{k}, \quad 
\widetilde L_{k} = \displaystyle\frac{b_{2}}{\lambda_{k}}\left(P_{k}N_{2 k} + Q_{k}N_{1 k}\right) + \displaystyle\frac{a_{2}Q_{k}}{{\lambda_{k}}^2}.$$
Далее из соотношения \eqref{arkhip:eq31} найдём
$$\sin{\left(\lambda_{k}\alpha + \theta_{k}\right)} = -\displaystyle\frac{\widetilde L_{k}}{\sqrt{P_{k}^2 + \widetilde Q_{k}^2}}, \quad  \theta_{k} = \arcsin{\displaystyle\frac{\widetilde Q_{k}}{\sqrt{P_{k}^2 +  Q_{k}^2}}}.$$
Отсюда при условии
\begin{equation}\label{arkhip:eq32}
\frac{|\widetilde L_{k}|}{\sqrt{P_{k}^2 + \widetilde Q_{k}^2}} \le 1
\end{equation}
получим
$$\alpha = \displaystyle\frac{\left({-1}\right)^{m+1}}{\lambda_{k}}\arcsin\frac{\widetilde L_{k}}{\sqrt{P_{k}^2 + \widetilde Q_{k}^2}} + \displaystyle \frac{m}{k}-\frac{\theta_{k}}{\lambda_{k}}, \quad  m\in \mathbb N .$$

Поскольку $\widetilde L_{k}$ является бесконечно малой величиной при $k \to \infty$, при больших $k$ неравенство \eqref{arkhip:eq32} всегда имеет место.

В общем случае при выполнении неравенства \eqref{arkhip:eq29}  для разрешимости  нелинейного уравнения \eqref{arkhip:eq28'}  относительно $\alpha$ достаточно потребовать, чтобы производная $|f'(\alpha)|\le d<1$.
Последнее условие выполнено, когда $\| b_{2}\| $  и $\| a_{2}\| $ достаточно малы.

Таким образом, нами установлен следующий критерий единственности.

\smallskip

\begin{theorem}
Если существует решение задачи \eqref{arkhip:eq2}--\eqref{arkhip:eq5} и выполнены
условия \eqref{arkhip:eq13}{\rm ,} то оно единственно только тогда{\rm ,} когда
условия  \eqref{arkhip:eq21} справедливы при всех $k\in \mathbb  N.$
\end{theorem}
