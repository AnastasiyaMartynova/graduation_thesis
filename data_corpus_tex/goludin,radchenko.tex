\title{Феноменологическая стохастическая модель изотермической ползучести 
поливинилхлоридного пластиката} 
      {Феноменологическая стохастическая модель изотермической ползучести \dots } 

\engtitle{A stochastic phenomenological model of polyvinyl chloride plastic isothermal creep} 

\author{В.\,П.~Радченко, Е.\,П.~Голудин}{Р\,а\,д\,ч\,е\,н\,к\,о~В.\,П., Г\,о\,л\,у\,д\,и\,н~Е.\,П.}
\engauthor{V.\,P.~Radchenko, E.\,P. Goludin}


\workabstract{Выполнен статистический анализ экспериментальных данных по ползучести поливинилхлоридного пластиката при 
$T = 24\,^\circ\rm C$. Предложена стохастическая модель одноосной ползучести и~проведено обоснование ряда гипотез, используемых при построении модели, на основании экспериментальных данных. Выполнена проверка адекватности стохастических уравнений экспериментальным данным. Наблюдается соответствие данных расчёта и~опытных данных.}

\engabstract{Statistical analysis of polyvinyl chloride plastic creep experimental data at the temperature of $24\,^\circ\rm C$ is carried out. A uniaxial stochastic creep model is introduced. Some hypotheses used in the process of model development are justified on the basis of experimental data. The stochastic equation sufficiency to fit experimental data is verified. The theoretical results are considered to be conformed to experimental ones.}

\textbf{1.} Существенное влияние случайных возмущений механических характеристик 
материала на поля деформаций и напряжений и необходимость развития 
вероятностных методов для расчёта на прочность элементов конструкций 
отмечалась во многих работах (см., например, [1--5]). Одним из этапов решения этой проблемы является 
разработка соответствующих феноменологических моделей неупругого 
деформирования статистически неоднородных сред, поскольку они являются 
основной составной частью решения стохастических краевых задач [6--10]. 
Особую актуальность эта задача приобретает для деформации ползучести, 
разброс экспериментальных значений которой, например, для металлов может 
составлять до 50--70\,\% , и~такие результаты приходится рассматривать как 
приемлемые [3, 11, 12].

Основы построения стохастических феноменологических уравнений в условиях 
ползучести были заложены Ю.\,П.~Самариным [13, 14] и~получили развитие, 
например, в~работах [15, 16]. В~[13]~отмечен достаточно широкий спектр 
факторов, влияющих на разброс деформации ползучести. Поэтому раздельный 
микроскопический анализ всех этих факторов является крайне сложной задачей 
и~в~настоящее время вряд ли возможен. Поэтому предпочтительным является 
феноменологический подход анализа стохастических закономерностей ползучести, 
т.\,е. явление исследуется на уровне наблюдателя без детального выяснения 
причин, порождающих случайность. При построении феноменологических 
стохастических теорий полагается, что условия лабораторных испытаний 
идеальны (все внешние факторы строго калиброваны) и~весь разброс деформации 
ползучести связывается с~действием внутренних причин (помех). Если 
необходимо учесть внешние помехи (факторы), например допуски на напряжения, 
нагрузки, температуры и~т.\,д., то соответствующий анализ можно выполнить 
обычными методами теории случайных функций.

Таким образом, в дальнейшем предполагается, что деформация ползучести образца является 
случайной функцией времени $p(t)$. 

Целью настоящей работы является экспериментальное исследование ползучести 
поливинилхлоридного пластиката, статистический анализ опытных данных, построение 
феноменологической теории ползучести и~проверка её адекватности 
экспериментальным данным в~вероятностной постановке. Здесь следует отметить, 
что частные исследования этого материала для построения детерминированных 
теорий выполнялись в~работах [13,~15,~17].

\textbf{2.} Экспериментальные исследования поливинилхлоридного пластиката были 
выполнены при температуре $T = 24\pm0{,}5\,^\circ\rm C$. 
Эксперименты проводились с~трубчатыми образцами длинной $1000$~мм и~сечением $1{,}2$ мм$^{2}$ 
в~состоянии поставки. Контроль полной 
относительной деформации осуществлялся с~точностью до $2,5 \cdot 10^{ - 4}$. 
Величина относительной деформации во всех экспериментах не превосходила~$0{,}1$.

Испытания были выполнены при пяти значениях растягивающего усилия $Q = 
\{ 5,59;$ $7,55;$ $10,5;$ $12,46;$ $14,42 \}$~Н (что соответствует 
номинальным напряжениям $\sigma = \{ 4,66;$ $6,29;$ $8,75;$ $10,38;$ $12,02 \}$~МПа) в~течение $8$ часов, затем производилась разгрузка в~течение 
$20$ часов. При первых трёх нагрузках было выполнено по $3$ испытания, при 
последних двух "--- по $4$~испытания. Кривые прямой ползучести всех образцов 
приведены на~рис.~1 и~2 (упругая деформация вычиталась из общей 
деформации) и~являлись базовыми при построении модели ползучести. Кроме 
этого были выполнены испытания при переменных (ступенчатых) режимах 
нагружения со сложной программой изменения напряжения (2 образца). Эти 
экспериментальные данные, представленные на рис.~3, в дальнейшем 
использовались для проверки адекватности стохастической модели ползучести.

\textbf{3.} Выполним первичный статистический анализ деформаций ползучести при 
постоянных напряжениях.

Будем рассматривать деформацию ползучести образца как случайную функцию 
времени $p(t)$ при фиксированном постоянном напряжении: её 
значения в~дискретные моменты времени представлены на рис.~1 и~2 
точками. При $t = \rm const$ деформация ползучести при $\sigma = \rm const$ есть 
некоторая случайная величина "--- сечение случайной функции~$p( t )$. 
Набор таких сечений образует случайную последовательность 
(решетчатую случайную функцию), которая несёт всю наиболее существенную 
информацию относительно~$p(t)$.

Рассмотрим оценки для моментальных функций случайной величины $p( t )$ при различных постоянных напряжениях 
($l$ "--- номер реализации):
\begin{equation}
\label{radch:eq1}
m\left( {t_i } \right) = \frac{1}{n}\sum\limits_{l = 1}^n {p _l 
\left( {t_i } \right)} ;
\end{equation}
\begin{gather}
\label{radch:eq2}
K\left( {t_i ,t_j } \right) = \frac{1}{n - 1}\sum\limits_{l = 1}^n {\left[ 
{p_l \left( {t_i } \right) - m\left( {t_i } \right)} \right]
\left[ {p_l \left( {t_j } \right) - m\left( {t_j } \right)} \right]} ;
\\
%\end{equation}
%\begin{gather}
\label{radch:eq3}
S\left( {t_j } \right) = \sqrt {K\left( {t_j ,t_j } \right)} ;\\
\label{radch:eq4}

{t_i } \right)S\left( {t_j } \right)},
\end{gather}
где $m$, $K$, $S$, $r$ "--- математическое ожидание, корреляционный момент,

\textbf{4.} Переходя к~формулировке стохастических уравнений, следует указать на 
неединственность решения этой проблемы, причём пути обобщений здесь во 
многом определяются видом детерминированных уравнений ползучести, которые 
должны получаться из стохастических после операции осреднения. Поскольку 
деформация ползучести поливинилхлоридного пластиката после разгрузки 
полностью обратима, то естественно в~качестве базовой детерминированной 
модели можно использовать вариант наследственной теории ползучести с~экспоненциальным 
ядром ползучести в~дифференциальной форме [19]:
\begin{gather}
\label{radch:eq5}
p\left( t \right) = \sum\limits_{k = 1}^s {\eta _k \left( t \right)} ,\\
\label{radch:eq6}
\dot {\eta }_k \left( t \right) = \lambda _k \left[ {a_k \left( 
{\frac{\sigma }{\sigma _ * }} \right)^n - \eta _k \left( t \right)} 
\right],
\end{gather}
где $s$, $\lambda _k$, $a_k$, $n$, $\sigma _ * $ "--- постоянные материала, методика 
идентификации которых на основе метода последовательного выделения 
экспоненциальных слагаемых изложена в~[20].

При постоянном напряжении $\sigma = \rm const$ решение (\ref{radch:eq5}), (\ref{radch:eq6}) имеет вид:
\begin{equation}
\label{radch:eq7}
p\left( t \right) = \sum\limits_{k = 1}^s {a_k \left( {1 - e^{ - \lambda _k 
t}} \right)\left( {\frac{\sigma }{\sigma _ * }} \right)^n} .
\end{equation}

Для того чтобы описать весь спектр реализации при постоянном напряжении в~качестве 
стохастического аналога экспоненциального представления деформации 
ползучести, рассмотрим выражение
\begin{equation}
\label{radch:eq8}
p\left( t \right) = \sum\limits_{k = 1}^s {A_k \left( t \right)\left( {1 - 
e^{ - \lambda _k t}} \right)\left( {\frac{\sigma }{\sigma _ * }} \right)^n} ,
\end{equation}
где коэффициенты разложения $A_k \left( t \right)$ являются случайными 
функциями времени, а $\lambda _k$, $n$, $\sigma _ * $ "--- по"=прежнему считаются 
постоянными. Таким образом, вид конкретной реализации случайной функции (\ref{radch:eq8}) 
определяется выбором совокупности реализаций случайных функций $A_k \left( t 
\right)$.

Применяя к (\ref{radch:eq8}) операцию осреднения, получаем:
\begin{equation}
\label{radch:eq9}
 \langle p\left( t \right) \rangle = \sum\limits_{k = 1}^s { \langle  A_k \left( t \right) \rangle  
\left( {1 - e^{ - \lambda _k t}} \right)\left( {\frac{\sigma }{\sigma _ * }} 
\right)^n} .
\end{equation}

Поскольку равенство (\ref{radch:eq9}) должно описывать осреднённую кривую ползучести, 
величины $ \langle  A_k \left( t \right) \rangle  $ приходится считать постоянными:
\begin{equation}
\label{radch:eq10}
 \langle  A_k \left( t \right) \rangle  = a_k .
\end{equation}
Условие (\ref{radch:eq10}) позволяет представить случайные функции в~виде суммы одной 
случайной величины и~одной центрированной случайной функции:
\begin{equation}
\label{radch:eq11}
A_k \left( t \right) = A_k + B_k \left( t \right);
\quad
 \langle  A_k \rangle  = a_k ,
\quad
 \langle  B_k \left( t \right) \rangle  = 0.
\end{equation}


Таким образом, равенство (\ref{radch:eq8}) можно записать так:
\begin{equation}
\label{radch:eq12}
p\left( t \right) = \sum\limits_{k = 1}^s {\Big[ {A_k + B_k \left( t 
\right)} \Big]\left( {1 - e^{ - \lambda _k t}} \right)\left( {\frac{\sigma 
}{\sigma _ * }} \right)^n} .
\end{equation}


Теперь каждая реализация для (\ref{radch:eq12}) определяется выбором значений случайных 
величин $A_k $ и~реализаций случайных функций $B_k \left( t \right)$.

Представим деформацию ползучести $p\left( t \right)$ в виде следующей 
аддитивной суммы:
\begin{equation}
\label{radch:eq13}
p\left( t \right) = p_1 \left( t \right) + p_2 \left( t \right),
\end{equation}
где
\begin{gather}
\label{radch:eq14}
p_1 \left( t \right) = \sum\limits_{k = 1}^s {A_k \left( {1 - e^{ - \lambda 
_k t}} \right)\left( {\frac{\sigma }{\sigma _ * }} \right)^n} ,\\
\label{radch:eq15}
p_2 \left( t \right) = \sum\limits_{k = 1}^s {B_k \left( t \right)\left( {1 
- e^{ - \lambda _k t}} \right)\left( {\frac{\sigma }{\sigma _ * }} 
\right)^n} .
\end{gather}

Учитывая (\ref{radch:eq9})--(\ref{radch:eq11}), имеем:
\begin{equation}
\label{radch:eq16}
 \langle p\left( t \right) \rangle = \langle p_1 \left( t \right) \rangle ,
\quad
 \langle p_2 \left( t \right) \rangle = 0.
\end{equation}


Из равенства (\ref{radch:eq16}) следует, что случайная функция (\ref{radch:eq15}) может рассматриваться 
как некоторый <<шум>>, наложенный на случайную функцию (\ref{radch:eq14}). Отсюда следует, 
что можно так подобрать случайные величины $A_k $ в~(\ref{radch:eq14}), что деформация 
$p_1 \left( t \right)$ будет играть главную роль в~сумме (\ref{radch:eq13}). Таким 
образом, роль случайной функции (\ref{radch:eq15}) сводится лишь к~созданию некоторых 
случайных отклонений во времени каждой из кривых~(\ref{radch:eq14}). С~математической 
точки зрения это сводится к~принятию гипотезы, согласно которой случайные 
величины $A_k $ в~(\ref{radch:eq11}) могут быть подобраны таким образом, чтобы случайные 
функции~$B_k \left( t \right)\left( {1 - e^{ - \lambda _k t}} \right)\left( 
{\frac{\sigma }{\sigma _ * }} \right)^n$ были эргодическими по отношению 
к~математическому ожиданию:
\[
\lim \limits_{t \to \infty } \frac{1}{t}\int\limits_0^t {B\left( 
\tau \right)} \left( {1 - e^{ - \lambda _k \tau }} \right)\left( 
{\frac{\sigma }{\sigma _ * }} \right)^nd\tau = 0.
\]

Такое представление крайне важно для моделирования процесса ползучести, при 
этом каждая реализация деформации строится следующим образом: производится 
выбор значений случайных величин $A_k $ и~получается кривая (\ref{radch:eq14}); затем 
добавляется какая"=либо реализация случайной функции (\ref{radch:eq15}) с~нулевым средним 
во времени значением. <<Шумовая>> добавка (\ref{radch:eq15}) относительно невелика 
и~в~ряде задач может вообще не учитываться. Более того, происхождение <<шума>> 
обусловлено, возможно, не только физическими причинами (например, дискретным 
характером развития деформации во времени), но и~ошибками самого 
эксперимента (случайные колебания (допуски) температуры и~напряжения в~процессе испытаний), 
а~также и~погрешностями применения тех или иных теорий ползучести (см.~рис.~1 и~2). Всё это 
не оставляет сомнений в~том, что главная часть разнообразия деформационных свойств образцов 
находит свое отражение в~выражении~(\ref{radch:eq14}).

\textbf{5.} В дальнейшем ограничимся построением стохастической модели только для 
главного слагаемого $p_1 \left( t \right)$, которое при $\sigma = \rm const$ 
имеет вид~(\ref{radch:eq14}).

Учитывая (\ref{radch:eq8})--(\ref{radch:eq10}), детерминированные определяющие соотношения (\ref{radch:eq5}), (\ref{radch:eq6}) 
могут быть обобщены на случай стохастических уравнений для главной части 
деформации ползучести $p_1 \left( t \right)$ в~виде:
\begin{gather}
\label{radch:eq17}
p_1 \left( t \right) = \sum\limits_{k = 1}^s {\eta _k \left( t \right)} ,\\
\label{radch:eq18}
\dot {\eta }_k \left( t \right) = \lambda _k \left[ {A_k \left( 
{\frac{\sigma }{\sigma _ * }} \right)^n - \eta _k \left( t \right)} 
\right],
\end{gather}
где $A_k $ "--- случайные величины; $s$, $\lambda _k$, $n$ "--- детерминированные 
величины. Другими словами, для построения стохастической модели~(\ref{radch:eq17}),~(\ref{radch:eq18}), 
достаточно построить детерминированную модель~(\ref{radch:eq5}),~(\ref{radch:eq6}) и~в~ней заменить 
детерминированные величины $a_k $ на случайные $A_k $.

Для идентификации параметров $S$, $\lambda _k$, $a_k$, $n$ используются осреднённые 
кривые ползучести при постоянных напряжениях. Для данного материала они 
приведены на рис.~5 (точки) и построены на основании информации, 
представленной на рис. 1 и 2. Согласно методике [21, 22] сначала строится 
экспоненциальная аппроксимация любой из осреднённых кривых (в 
рассматриваемом случае это кривая при $\sigma = 8,75$ МПа), а далее, исходя 
из подобия осреднённых кривых, строится, например, по методу наименьших 
квадратов, степенная зависимость от напряжения.

и $\lambda _k $ представлены в табл. 3.


Если обозначить

+ \\+ 10,28 \cdot 10^{ - 3}\left( {1 - e^{ - 1,95t}} \right) + 23,51 \cdot 10^{

то для поливинилхлоридного пластиката получена следующая двумерная

const$:

p\left( t \right) = K\left( t \right)\left( {\frac{\sigma }{8,75}}

Для построения стохастической модели вновь обратимся к~данным табл.~2, из 
которой видно, что значения нормированной корреляционной матрицы близки 
к~единице. Отсюда следует, что все кривые ползучести при постоянных (но 
разных) напряжениях можно считать подобными. Поэтому соотношение (\ref{radch:eq14}) можно 
обобщить для стохастического варианта в~виде
\begin{equation}
\label{radch:eq21}
p_1 \left( t \right) = A \cdot K\left( t \right)\left( {\frac{\sigma 
}{8,75}} \right)^{1,53},
\end{equation}
где $A$ "--- случайная величина с~математическим ожиданием $ \langle A \rangle = 1$. 
В~этом случае будет выполняться условие $ \langle p_1 \left( t \right) \rangle = p\left( t \right)$ 
(см. формулы (\ref{radch:eq19})--(\ref{radch:eq21})). Используя выражение (\ref{radch:eq18}) и~минимизируя 
относительно неизвестного параметра $A$ разность $\left| {p^\ast \left( t 
\right) - p_1 \left( t \right)} \right|$ для каждой из~17 реализаций, 
представленных на рис.~1 и~2, определяем выборку случайной величины~$A$, 
по которой можно найти все её статистические  оценки ($p^\ast \left( t 
\right)$ "--- экспериментальные данные). Обработка полученной выборки 
позволила выбрать для её описания нормальный закон распределения 
с~математическим ожиданием $m_A = 1{,}03$ и~среднеквадратическим отклонением 
$S_A = 0{,}071$.

Таким образом, стохастическая модель поливинилхлоридного пластиката имеет 
вид (\ref{radch:eq13}) и (\ref{radch:eq14}), где случайные величины $A_k $ определяются равенством
\begin{equation}
\label{radch:eq22}
A_k = A \cdot a_k 
\quad
\left( k = 1,\,2,\,3 \right),
\end{equation}
где $A$ "--- случайная нормально распределённая величина, а $a_k $ "--- 
детерминированные параметры, значения которых приведены в~табл.~3.

\textbf{6.} Экспериментальная проверка стохастической модели была выполнена как при 
постоянных, так и~при переменных режимах нагружения.

При постоянных напряжениях имеем стохастическое равенство (\ref{radch:eq21}), и~поскольку 
случайная величина $A$ распределена по нормальному закону, то и~случайная 
функция для главной части деформации ползучести $p_1 \left( t \right)$ также 
будет распределена по нормальному закону. На рис.~1 и~2 штриховыми линиями 
показаны доверительные трёхсигмовые интервалы (вероятность $0{,}9973)$ для 
деформации ползучести для всех пяти напряжений, рассчитанные по 
стохастической модели (\ref{radch:eq19}), (\ref{radch:eq21}).

Хорошо известно, что наиболее контрастно недостатки любой теории проявляются 
при ступенчатом режиме нагружения~[3]. Поэтому и~в~данной работе были 
осуществлены испытания двух образцов при сложной программе нагружения, 
результаты которых приведены на рис.~3. Как следует из этого рисунка, 
ступенчатое изменение напряжения происходило в~моменты $t = \left\{ {t_j } 
\right\} = \{ 0$; $1$; $2$; $3$; $4$; $5$; $6$; $7\}$ (час), $j=1,\, 2,\, \dots,\, 8$. Для такого режима нагружения решение стохастической 
системы дифференциальных уравнений (\ref{radch:eq17}), (\ref{radch:eq18}), (\ref{radch:eq22}) имеет вид
\begin{equation}
\label{radch:eq23}
p_1 \left( t \right) = \sum\limits_{j = 1}^N {A \cdot K\left( {t - t_j } 
\right)\left[ {f\left( {\sigma \left( {t_j + 0} \right)} \right) - f\left( 
{\sigma \left( {t_j - 0} \right)} \right)} \right]} ,
\end{equation}
где $t \in \left( {t_j,\, t_{j + 1} } \right)$, $j=1,\, 2,\, \dots,\, 7$; 
$f\left( \sigma \right) = \left( {\frac{\sigma }{\sigma _ * }} \right)^{1,53}$; 
$K\left( {t - t_j } \right)$ "--- задаётся (\ref{radch:eq19}); 
$N \leqslant 8$; $t_j$ --- значения времени, в~которых напряжения претерпевают разрыв 
первого рода.

На рис.~3 штриховыми линиями показаны трёхсигмовые доверительные интервалы 
для данного режима нагружения, рассчитанные по соотношению~(\ref{radch:eq23}).

Таким образом, и~для постоянных (рис.~1 и~2), и~для переменных (рис.~3) 
режимов нагружения наблюдается хорошее соответствие расчётных и~экспериментальных данных, поскольку опытные данные попадают в~соответствующие доверительные интервалы для прогнозируемой деформации 
ползучести.
