В работе [1] было получено следующее усиление теоремы У.\,Янга о
равномерной ограниченности последовательности частных сумм рядов Фурье
функций ограниченной вариации.
\medskip

{\bf Теорема A.} {\it
Пусть $n_1 = 1 < n_2 < n_3 < \dotsb$ --- возрастающая последовательность
натуральных чисел такая, что для некоторого числа $A$ выполнено условие
\begin{equation}
\sum_{j = m}^{\infty} \frac{1}{n_j} \le \frac{A}{n_m},   \quad m = 1, 2,
\dotsc
\end{equation}
Тогда для произвольной функции $f$ ограниченной вариации с рядом Фурье
$$
\frac{a_0}{2} + \sum_{k = 1}^{\infty} (a_k \cos kx + b_k \sin kx)
$$
справедлива оценка
\begin{equation}
\sum_{j = 1}^{\infty} \bigg | \, \sum_{k = n_j}^{n_{j + 1} - 1}
( a_k \cos kx + b_k \sin kx ) \bigg | \le CA V(f),
\end{equation}
где $C$ --- абсолютная постоянная, а $V(f)$ ---
вариация функции $f$ на периоде.
}
\medskip

В [1] приведены некоторые следствия из оценки (2), а также аналогичные ей
результаты.
Известно ([2], c.\,24), что условие (1) равносильно возможности
представить последовательность $\{ n_j \}$ в виде объединения конечного
числа лакунарных последовательностей.
В данной статье выясняется, в какой мере условие (1) является
существенным для справедливости теоремы A. Будет показано, что это
условие не является необходимым и в то же время оно не может быть значительно
ослаблено. Эти утверждения составляют содержание теорем 1 и 2
соответственно.

\begin{thm}
Пусть последовательность $\{ n_j \}$ состоит из всех натуральных
чисел $k$, удовлетворяющих условиям $3^p \le k \le 3^p + 2^p$, $p=0, 1, 2,
\dotsc$ Для этой последовательности не выполняется условие вида $(1)$,
но вместе с тем для любой функции $f$ ограниченной вариации справедлива
оценка
\begin{equation}
\sum_{j = 1}^{\infty} \bigg | \, \sum_{k = n_j}^{n_{j + 1} - 1}
( a_k \cos kx + b_k \sin kx ) \bigg | \le C V(f)
\end{equation}
с абсолютной постоянной $C$.
\end{thm}

\begin{pf}
Для рассматриваемой последовательности условие (1) не выполняется, т.\,к.
$$
\sum_{n_j \ge 3^p}^{\infty} \frac{1}{n_j} > \sum_{k = 3^p}^{3^p + 2^p}
\frac{1}{k} > \frac{2^p}{3^p + 2^p} > \frac{2^p}{2 \cdot 3^p}.
$$
Докажем оценку (3).
Обозначив $A_k (x) :=  a_k \cos kx + b_k \sin kx$,
получим
$$
\sum_{j = 1}^{\infty} \bigg | \, \sum_{k = n_j}^{n_{j + 1} - 1}
A_k (x) \bigg |
= \sum_{p = 0}^{\infty} \bigg ( \sum_{k = 3^p}^{3^p + 2^p - 1}
| A_k (x) | + \bigg | \sum_{k = 3^p + 2^p}^{3^{p + 1} - 1} A_k (x)
\bigg | \bigg ).
$$
Используя известную оценку ([2], c.\,81)
$| A_k (x) | \le \frac{1}{k} V(f)$,
находим
\begin{equation}
\sum_{p = 0}^{\infty} \sum_{k = 3^p}^{3^p + 2^p - 1} | A_k (x) | \le
\sum_{p = 0}^{\infty} \sum_{k = 3^p}^{3^p + 2^p - 1} \frac{1}{k} V(f) \le
\sum_{p = 0}^{\infty} \frac{2^p}{3^p} V(f) = 3 V(f).
\end{equation}
Так как последовательность, составленная из чисел $3^p$, $3^p + 2^p$,
$p = 0, 1, \dotsc$, удовлетворяет условию (1), то согласно теореме A
\begin{equation}
\sum_{p = 0}^{\infty} \bigg | \sum_{k = 3^p + 2^p}^{3^{p + 1} - 1} A_k (x)
\bigg | \le C V(f)
\end{equation}
с некоторой постоянной $C$. Из (4) и (5) вытекает оценка (3).
\end{pf}

Покажем, что если последовательность $ \{n_j \}$ удовлетворяет условию
\begin{equation}
\lim_{j \to \infty} \frac{n_{j + 1}}{n_j} = 1,
\end{equation}
то для нее оценка вида (2) может не иметь места.

Будем рассматривать функцию ограниченной вариации
$$
\frac{\pi - x}{2} = \sum_{k = 1}^{\infty} \frac{\sin kx}{k}, \quad
0 < x < 2 \pi.
$$
Введем обозначение
$\Delta_{\nu} := \max_{j \ge \nu} \big( \frac{n_{j + 1}}{n_j} - 1 \big)$.
В силу (6) $\lim\limits_{\nu \to \infty} \Delta_{\nu} = 0$.

\begin{thm}
Пусть для последовательности $ \{n_j \}$ выполняется условие $(6)$. Тогда
для
\begin{equation}
x \in \bigg ( \frac{\pi}{n_{\nu + 1}}, \frac{\pi}{n_{\nu}} \bigg ]
\end{equation}
справедлива равномерная относительно всех параметров оценка
\begin{equation}
F(x) := \sum_{j = 1}^{\infty} \bigg | \, \sum_{k = n_j}^{n_{j + 1} - 1}
\frac{\sin kx}{k} \bigg | \ge \frac{1}{12} \log \frac{1}{\Delta_{\nu}}
+ O(1).
\end{equation}
\end{thm}

{\bf Доказательство.}
Зафиксируем значение $x$, удовлетворяющее условию (7), и положим $N_{\nu}
:= [1 / (6 \Delta_{\nu})]$. Оценку (8) достаточно доказать при условиях
$N_{\nu} > 1$ и
\begin{equation}
x \in (0, \pi / 6].
\end{equation}
В дальнейшем будем считать эти условия выполненными.

Если натуральное число $m < N_{\nu}$, то существуют $j$ такие, что
\begin{equation}
\bigg ( m + \frac{1}{6} \bigg ) \pi \le n_j x \le
\bigg ( m + \frac{1}{3} \bigg ) \pi,
\end{equation}
и такие, что
\begin{equation}
\bigg ( m + \frac{2}{3} \bigg ) \pi \le n_j x \le
\bigg ( m + \frac{5}{6} \bigg ) \pi.
\end{equation}
Действительно, если бы оценки (10) не выполнялись ни для одного числа $j$,
то существовало бы $j$ такое, что
$$
n_j x < \bigg ( m + \frac{1}{6} \bigg ) \pi, \quad
n_{j + 1} x > \bigg ( m + \frac{1}{3} \bigg ) \pi,
$$
откуда
\begin{equation}
(n_{j + 1} - n_j ) x > \frac{\pi}{6}.
\end{equation}
Но из цепочки неравенств
$$
\bigg ( m + \frac{1}{3} \bigg ) \pi < n_{j + 1} x \le
\frac{n_{j + 1}}{n_{\nu}} \pi
$$
следует, что $j \ge \nu$. Кроме того, по предположению
$n_j x < \big ( m + \frac{1}{6} \big ) \pi < N_{\nu} \pi$.
Поэтому
$(n_{j + 1} - n_j ) x = n_j x \big ( \frac{n_{j + 1}}{n_j} - 1 \big )
< N_{\nu} \pi \Delta_{\nu} \le \frac{\pi}{6}$,
что противоречит оценке (12).
Точно так же обосновывается существование $j$, для которых справедливы
неравенства (11).

Для каждого $m = 1, 2, \dots, N_{\nu} - 1$ обозначим через $E_m$
множество тех $j$, для которых
\begin{equation}
\bigg ( m + \frac{1}{6} \bigg ) \pi \le n_j x < n_{j + 1} x \le
\bigg ( m + \frac{5}{6} \bigg ) \pi.
\end{equation}
Тогда
$$
F(x) \ge \sum_{m = 1}^{N_{\nu} - 1} \sum_{j \in E_m} \bigg | \,
\sum_{k = n_j}^{n_{j + 1} - 1} \frac{\sin kx}{k} \bigg |.
$$
В силу (13) для всех $k$ таких, что $n_j \le k \le n_{j + 1} -1$,
знаки $\sin kx$ одинаковы и
$| \sin kx | \ge 1/2$.
Поэтому
\begin{equation}
F(x) \ge \sum_{m = 1}^{N_{\nu} - 1} \sum_{j \in E_m}
\sum_{k = n_j}^{n_{j + 1} - 1} \frac{1}{2k} \ge \frac{1}{2}
\sum_{m = 1}^{N_{\nu} - 1} \sum_k \frac{1}{k},
\end{equation}
где для каждого $m$ суммирование ведется по всем таким $k$, что
$$
\bigg ( m + \frac{1}{3} \bigg ) \frac{\pi}{x} \le k \le
\bigg ( m + \frac{2}{3} \bigg ) \frac{\pi}{x}.
$$
Так как для любых положительных $a$ и $b$
$$
\sum_{a \le k \le b} \frac{1}{k} \ge \int_{a + 1}^b \frac{du}{u} =
\log \frac{b}{a + 1},
$$
то из (14) с учетом (9) следует оценка
\begin{multline*}
F(x) \ge \frac{1}{2} \sum_{m = 1}^{N_{\nu} - 1} \log
\frac{ \big ( m + \frac{2}{3} \big ) \frac{\pi}{x}}
{ \big ( m + \frac{1}{3} \big ) \frac{\pi}{x} + 1} \ge
\frac{1}{2} \sum_{m = 1}^{N_{\nu} - 1} \log
\frac{ \big ( m + \frac{2}{3} \big ) \pi}
{ \big ( m + \frac{1}{3} \big ) \pi + \frac{\pi}{6}} =\\
%
= \frac{1}{2} \sum_{m = 1}^{N_{\nu} - 1} \log
\frac{m + \frac{2}{3}}
{m + \frac{1}{2}} = \frac{1}{12} \log N_{\nu} + O(1) =
\frac{1}{12} \log \frac{1}{\Delta_{\nu}} + O(1).\quad\square
\end{multline*}

Проиллюстрируем оценку (8) на примере последовательности
\begin{equation}
n_j := 2^{j^{\alpha}}, \quad j = 1, 2, \dotsc, \quad 0 < \alpha < 1.
\end{equation}
Для этой последовательности числа $n_j$ не являются целыми. Нетрудно
видеть, что это несущественно, если условиться понимать в (8) символ
$\sum\limits_{j = a}^b$
с произвольными положительными $a$ и $b$ как сумму по всем натуральным $j$
таким, что $a \le j \le b$.
Для последовательности (15)
$\frac{n_{j + 1}}{n_j} - 1 = 2^{(j + 1)^{\alpha} - j^{\alpha}} - 1$.
Так как с ростом $j$ разность $(j + 1)^{\alpha} - j^{\alpha}$ убывает,
то
$\Delta_{\nu} = 2^{(\nu + 1)^{\alpha} - \nu^{\alpha}} - 1$.
Пользуясь дважды формулой конечных приращений Лагранжа, находим
$\Delta_{\nu} = 2^{\alpha / (\nu + \theta)^{1 - \alpha}} - 1 <
2^{1 / \nu^{1 - \alpha}} - 1 < \frac{2}{\nu^{1 - \alpha}}$.
Значит,
\begin{equation}
\log \frac{1}{\Delta_{\nu}} > (1 - \alpha) \log \nu - \log 2.
\end{equation}
Если $x$ удовлетворяет условию (7), то
$\pi/x < 2^{(\nu + 1)^{\alpha}} \le 2^{(2 \nu)^{\alpha}}$,
откуда
\begin{equation}
\nu \ge \frac{1}{2} \bigg ( \log \frac{\pi}{x} \bigg )^{1 / \alpha}.
\end{equation}
Объединив оценки (16) и (17), получим
$\log \frac{1}{\Delta_{\nu}} >
\frac{1 - \alpha}{\alpha} \log \log \frac{\pi}{x} - 2 \log 2$.

Таким образом, для последовательности (15) имеем
$$
F(x) \ge \frac{1 - \alpha}{12 \alpha} \log \log \frac{\pi}{x} + O(1)
$$
равномерно относительно $\alpha \in (0, 1)$ и $x \in (0, \pi / 6]$.
%\newpage

%{\it Добавление при корректуре.}
В теореме 2 функция, для которой не выполнялась оценка (2), имела точку
разрыва.

Заметим, что для любой последовательности $\{ n_j \}$, удовлетворяющей условию
(6), существует непрерывная функция ограниченной вариации, для которой оценка
(2) не имеет места.

Действительно, для каждой сходящейся к нулю последовательности существует
мажорирующая ее выпуклая сходящаяся к нулю последовательность ([2],
c.\,653).

Пусть числа $N_{\nu}$ и $\Delta_{\nu}$ те же, что и в доказательстве теоремы
2, и $\{ \varepsilon_k \}$ --- выпуклая сходящаяся к нулю последовательность
такая, что для $p = N_{\nu} n_{\nu + 1}$
$$
\varepsilon_p \ge \Bigg ( \log \frac{1}{\Delta_{\nu}} \Bigg )^{- 1 / 2}.
$$
Положим $b_k := \varepsilon_k / k$  и
$g(x) := \sum\limits_{k = 1}^{\infty} b_k \sin
kx$. Тогда функция $g(x)$ непрерывна и имеет ограниченную вариацию, т.\,к.
ее производная суммируема (в силу выпуклости последовательности
$\{ \varepsilon_k \}$).

Проведя для функции
$$
G(x) := \sum_{j = 1}^{\infty} \bigg | \, \sum_{k = n_j}^{n_{j + 1} - 1}
b_k \sin kx \bigg |
$$
те же рассуждения, что и для функции $F(x)$ при доказательстве теоремы 2,
получим для $x$, удовлетворяющих условию (7), аналог оценки (14)
\begin{equation}
G(x) \ge \frac{1}{2} \sum_{m = 1}^{N_{\nu} - 1} \sum_k b_k,
\end{equation}
где сумма по $k$ имеет тот же смысл, что и в (14).

Так как для всех $k$, участвующих в оценке (18), $k \le p =
N_{\nu} n_{\nu + 1}$, то из (18) вытекает оценка
$$
G(x) \ge \frac{1}{2} \varepsilon_p \sum_{m = 1}^{N_{\nu} - 1} \sum_k
\frac{1}{k} \ge \frac{1}{12} \varepsilon_p \log \frac{1}{\Delta_{\nu}} + O(1)
\ge \frac{1}{12} \Bigg ( \log \frac{1}{\Delta_{\nu}} \Bigg )^{1 / 2} + O(1),
$$
доказывающая наше утверждение.
