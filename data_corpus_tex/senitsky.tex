Частоты и формы колебаний являются важными динамическими характеристиками, 
определяющими возможность наступления резонансных состояний, а~также вклад 
соответствующих гармоник при анализе напряжений и~перемещений цилиндров 
в~случае нестационарных воздействий [1--3]. Однако получение замкнутого 
решения, определяющего свободные колебания короткого цилиндра при 
произвольных краевых условиях на криволинейных и торцевых поверхностях, даже 
в~осесимметричном случае, представляет сложную проблему. Настоящая работа как 
раз и~посвящена построению нового точного решения этой не простой краевой 
задачи о~свободных осесимметричных колебаниях ортотропного цилиндра при 
произвольных граничных условиях на его криволинейных поверхностях и~торцах, 
задаваемых в~смешанной форме. Существенным представляется то, что 
независимыми при этом являются шесть упругих констант анизотропного 
материала. Кроме того, в~математической модели учитываются силы вязкого 
сопротивления, которые вводятся в~процессе решения задачи в~соответствии 
с~частотно"=независимой гипотезой Фойгта~[4]. Применяется обобщённая процедура 
метода конечных интегральных преобразований (КИП) с~определением в~процессе 
решения компонентов ядровой вектор"=функции~[3].

\textbf{1.} В цилиндрической системе координат ($r$, $\theta$, $z$) 
рассматривается ортотропный полый круговой цилиндр 
$\Omega:\;\left\{ a \leqslant r \leqslant b,\;0 \leqslant z \leqslant h,\;0 \leqslant \theta 
\leqslant 2\pi  \right\}$. Дифференциальные уравнения движения 
в~напряжениях при осесимметричной деформации цилиндра записываются следующим 
образом~[5]:
\begin{equation}
\label{senic:eq1}
 \begin{array}{r}
\displaystyle
\frac{\partial \sigma _{rr} }{\partial r} + \frac{\partial \tau _{rz} 
}{\partial z} + \frac{\sigma _{rr} - \sigma _{\theta \theta } }{r} - \rho 
\frac{\partial ^2u}{\partial t^2} = 0,\\
\displaystyle
{\phantom{\int\limits^1}}\frac{\partial \tau _{rz} }{\partial r} + \frac{\partial \sigma _{zz} 
}{\partial z} + \frac{\tau _{rz} }{r} - \rho \frac{\partial ^2w}{\partial 
t^2} = 0.
 \end{array}
\end{equation}

Физические и геометрические уравнения для ортотропного упругого тела 
в~цилиндрических координатах могут быть представлены в~виде~[5]:
\begin{equation}
\label{senic:eq2}
 \begin{array}{l}
\displaystyle
\sigma _{rr} = a_{11} \varepsilon _{rr} + a_{12} \varepsilon _{\theta \theta 
} + a_{13} \varepsilon _{zz},
\quad 
\sigma _{\theta \theta } = a_{21} \varepsilon _{rr} + a_{22} \varepsilon _{\theta \theta } + a_{23}\varepsilon _{zz},
\\ \displaystyle
\sigma _{zz} = a_{31} \varepsilon _{rr} + a_{32} \varepsilon _{\theta \theta 
} + a_{33} \varepsilon _{zz},\quad \tau _{rz} = a_{55} \gamma _{rz} ,\quad \tau_{r\theta } = \tau _{\theta z} = 0,^{\phantom{\frac12}}
\end{array}
\end{equation}
\begin{equation}
\label{senic:eq3}
\varepsilon _{rr} = \frac{\partial u}{\partial r},\quad 
\varepsilon _{\theta \theta } = \frac{u}{r},\quad 
\varepsilon _{zz} = \frac{\partial w}{\partial z},\quad
\gamma _{rz} = \frac{\partial u}{\partial z} + \frac{\partial w}{\partial r},\quad 
\gamma _{r\theta } = \gamma _{\theta z} = 0.
\end{equation}
Здесь $\sigma _{rr}$, $\sigma _{\theta \theta }$, $\sigma _{zz}$, $\tau _{rz}$, 
$\tau _{r\theta }$, $\tau _{\theta z}$ "--- компоненты тензора напряжений; 
а~$\varepsilon _{rr}$, $\varepsilon _{\theta \theta }$, $\varepsilon _{zz}$, 
$\gamma_{rz}$, $\gamma _{r\theta }$, $\gamma _{\theta z}$ "--- с~точностью до постоянной 
соответствующие компоненты тензора деформаций; $u$, $w$, $v$ "--- компоненты 
вектора перемещений ($v=0$); $t $ "--- время; $a_{ij}$, $\rho $ "--- упругие постоянные и~плотность ортотропного материала цилиндра.

Если воспользоваться формулами (\ref{senic:eq2}), (\ref{senic:eq3}), то дифференциальные уравнения~(\ref{senic:eq1}) 
преобразуются следующим образом:

\begin{multline*}
a_{11} \frac{1}{r}\frac{\partial }{\partial r}\left[ {r\frac{\partial 
u\left( {r,z,t} \right)}{\partial r}} \right] - a_{22} \frac{1}{r^2}u\left( 
{r,z,t} \right) + a_{55} \frac{\partial ^2u\left( {r,z,t} \right)}{\partial 
z^2} + 
\\
 + \left( {a_{13} + a_{55} } \right)\frac{\partial ^2w\left( {r,z,t} 
\right)}{\partial r\partial z} + \left( {a_{13} - a_{23} } 
\right)\frac{1}{r}\frac{\partial w\left( {r,z,t} \right)}{\partial z} - \rho 
\frac{\partial ^2u\left( {r,z,t} \right)}{\partial t^2} = 0;
\end{multline*}
\begin{multline}
 \label{senic:eq4}
a_{55} \frac{1}{r}\frac{\partial }{\partial r}\left[ {r\frac{\partial 
w\left( {r,z,t} \right)}{\partial r}} \right] + a_{33} \frac{\partial 
^2w\left( {r,z,t} \right)}{\partial z^2} + \left( {a_{55} + a_{31} } 
\right)\frac{\partial ^2u\left( {r,z,t} \right)}{\partial r\partial z} + 
\\
+ \left( {a_{32} + a_{55} } \right)\frac{1}{r}\frac{\partial u\left( 
{r,z,t} \right)}{\partial z} - \rho \frac{\partial ^2w\left( {r,z,t} 
\right)}{\partial t^2} = 0.
\end{multline}
Соответственно, 
\begin{equation}
\label{senic:eq5}
 \begin{array}{l}
\displaystyle
\sigma _{rr} = a_{11} \frac{\partial u}{\partial r} + a_{12} \frac{1}{r}u + 
a_{13} \frac{\partial w}{\partial z},
\quad
\sigma _{\theta \theta } = a_{21} 
\frac{\partial u}{\partial r} + a_{22} \frac{1}{r}u + a_{23} \frac{\partial 
w}{\partial z},
\\\displaystyle
\sigma _{zz} = a_{31} \frac{\partial u}{\partial r} + a_{32} \frac{1}{r}u + 
a_{33} \frac{\partial w}{\partial z},
\quad 
\tau _{zz} = a_{55} \left( 
{\frac{\partial u}{\partial z} + \frac{\partial w}{\partial r}} \right).{\phantom{\int\limits^1}}
\end{array}
\end{equation}


На криволинейных поверхностях ($r = a$ и  $r = b$) могут быть сформулированы произвольные 
граничные условия, а~на торцах цилиндра ($z = 0$ и $z = h$) должны быть заданы одно 
напряжение и~одно перемещение. Поскольку рассматриваются лишь свободные 
колебания, то без ущерба общности рассуждений все граничные условия можно 
считать однородными (нулевыми). Для определённости в~дальнейшем будем 
полагать, что на одной криволинейной поверхности заданы напряжения, а~на 
другой перемещения.
Таким образом, имеем:
\begin{equation}
 \begin{array}{l}
\displaystyle
\text{при } r = a:\quad  \sigma _{rr} = a_{11} \frac{\partial u}{\partial r} + a_{12} 
\frac{1}{r}u + a_{13} \frac{\partial w}{\partial z} = 0; \quad 
\tau _{rz} = a_{55} \left( {\frac{\partial u}{\partial z} + \frac{\partial w}{\partial r}} 
\right) = 0;
\\\displaystyle
\text{при } r = b:\quad  u = 0;\quad w = 0.
\end{array}
\end{equation}
На торцах "--- два варианта граничных условий:
\begin{gather}
\text{а) при } z = 0\; \text{и}\; z=h:\quad  
\sigma _{zz} = a_{13} \frac{\partial u}{\partial r} + a_{23} \frac{1}{r}u + a_{33} \frac{\partial w}{\partial z} = 0;
\quad u = 0;\;\;
\\ 
\text{б) при } z = 0\; \text{и}\; z=h:\quad  
\tau _{rz} = a_{55} \left( {\frac{\partial u}{\partial z} + \frac{\partial w}{\partial r}} \right) = 0;\quad w = 0 .\qquad
\qquad
\end{gather}

В начальный момент времени ($t = 0$) считаются известными перемещения $u_0\left( {r,z} \right)$, 
$w_0 \left( {r,z} \right)$ и~скорости перемещений ${\dot u_0 }\left( {r,z} \right)$, ${\dot w_0 }\left( {r,z} \right),$ то есть при $t = 0$:
\begin{equation}
u = u_0 \left( {r,z} \right),\quad \frac{\partial u}{\partial t} = 
{\dot u_0 }\left( {r,z} \right); \qquad w = w_0 \left( {r,z} \right),\quad 
\frac{\partial w}{\partial t} = 
{\dot w_0 \left( {r,z} \right)}.
\end{equation}

\begin{remark}[1]В случае, когда задаются неоднородные граничные условия {\rm (6)--(8)} 
{\rm (}нестационарная ди\-на\-ми\-чес\-кая задача{\rm )}, то рассматриваемую начально-краевую 
задачу необходимо привести к~стандартной форме~{\rm [6]}. Для анизотропного 
цилиндра такая процедура описана в~{\rm [2, 3]}.
\end{remark}

Представляют интерес собственные колебания сплошного анизотропного 
(ортотропного) короткого цилиндра. В~этом случае вместо первых двух условий~(6), следует принять условия регулярности решения:
\begin{equation}
 \begin{array}{l}
\displaystyle
\text{при } r = 0:\quad  u < \infty,\quad w < \infty ;
\\\displaystyle
\text{при } r = b:\quad  u = 0;\quad w = 0.
\end{array}
\end{equation}


Соотношения (\ref{senic:eq4}), (6)--(9) и~представляют собой математическую формулировку 
рассматриваемой краевой задачи.

\textbf{2.} Решение осуществляется методом КИП. Сначала применяется конечное преобразование Фурье по 
переменной $z$, а~затем обобщённое КИП по радиальной координате $r$ с~определением 
ядровой функции в~процессе решения~[3]. Для этой цели вводим конечные интегральные косинус и~синус 
преобразования Фурье по переменной $z$:

\begin{gather}
 \label{senic:eq6}
\Big[ {U_{c,s} \left( {r,n,t} \right),\; W_{c,s} \left( {r,n,t} \right)} 
\Big] = \int\limits_0 ^h {\Big[ {u\left( {r,n,t} \right),\; w\left( 
{r,n,t} \right)} \Big]} \left[ {\cos \frac{n\pi z}{h},\; \sin \frac{n\pi 
z}{h}} \right]dz,
\\
\Big[ {u\left( {r,n,t} \right),\; w\left( {r,n,t} \right)} \Big] = 
\sum\limits_{n = 0}^\infty {\Omega _n^{ - 1} } \Big[ {U_{c,s} \left( 
{r,n,t} \right),\; W_{c,s} \left( {r,n,t} \right)} \Big]\left[ {\cos 
\frac{n\pi z}{h},\; \sin \frac{n\pi z}{h}} \right],
\end{gather}
где $\Omega _n = \left\{ {\begin{array}{cl}
 h, & \text{при }  n=0,\\
 \frac12 h, & \text{при }  n\ne0.
 \end{array}} \right.$ 

Величины $U_c$, $W_c $ и $U_s$, $W_s $ представляют соответственно косинус и~синус трансформанты (изображения) Фурье компонентов $u$ и~$w$ вектора перемещений, то есть 
индекс <<$c$>> относится к косинус преобразованию, а <<$s$>> "--- к~синус 
преобразованию Фурье в формулах (\ref{senic:eq6}).

Применим теперь в~случае (7) к~первому дифференциальному уравнению (\ref{senic:eq4}) 
синус, а~ко второму "--- косинус преобразования Фурье (\ref{senic:eq6}), а~в~случае~(8) 
наоборот. Затем этим же преобразованиям подвергаем граничные~(6) и~начальные~(9) условия. 
В~результате получим:
\begin{multline*}
a_{11} \frac{\partial ^2U_{s,c} }{\partial r^2} + a_{11} 
\frac{1}{r}\frac{\partial U_{s,c} }{\partial r} - \left( {a_{22} 
\frac{1}{r^2} + a_{55} \frac{n^2\pi ^2}{h^2}} \right)U_{s,c} \mp \left( 
{a_{13} + a_{55} } \right)\frac{n\pi }{h}\frac{\partial w_{c,s} }{\partial 
r} \mp \\
 \mp \left( {a_{13} - a_{23} } \right)\frac{1}{r}\frac{n\pi }{h}W_{c,s} \rho 
\frac{\partial ^2U_{c,s} }{\partial t^2} = 0; 
\end{multline*}
\begin{multline}
 \label{senic:eq7}
a_{55} \frac{\partial ^2W_{c,s} }{\partial r^2} + a_{55} 
\frac{1}{r}\frac{\partial W_{c,s} }{\partial r} - a_{33} \frac{n^2\pi 
^2}{h^2}W_{c,s} \pm \left( {a_{13} + a_{55} } \right)\frac{n\pi 
}{h}\frac{\partial U_{s,c} }{\partial r}\pm 
\\
\pm \left( {a_{23} + a_{55} } \right)\frac{n\pi }{h}U_{s,c} - \rho 
\frac{\partial ^2w_{c,s} }{\partial t^2} = 0;
\end{multline}
при $r = a$ имеем
\begin{equation}
\label{senic:eq8}
a_{11} \frac{\partial U_{s,c} }{\partial r} + a_{12} \frac{1}{r}U_{s,c} \mp a_{13} \frac{n\pi }{h}W_{c,s} = 0,
\quad 
\frac{\partial W_{c,s} }{\partial r}\pm \frac{n\pi }{h}U_{s,c} = 0,\quad 
\frac{\partial W_{c,s} }{\partial r}\pm \frac{n\pi }{h}U_{s,c} = 0;
\end{equation}
при $r = b$: $U_{s,c} = W_{c,s} = 0;$

при $t = 0$:
\begin{equation}
\label{senic:eq9}
U_{s,c} = U_{0s,c} \left( {r,n} \right),\quad 
 \frac{\partial U_{s,c} }{\partial t} = \dot U_{0s,c} \left( {r,n} \right);\quad
W_{c,s} = W_{0c,s} \left( {r,n} \right),\quad 
\frac{\partial W_{c,s} }{\partial t} = \dot W_{0c,s} \left( {r,n} \right).
\end{equation}
Здесь $U_{0s,c}$, $W_{0c,s}$, $\dot U_{0s,c}$, $\dot W_{0c,s} $ "---  трансформанты  Фурье известных 
функций начальных перемещений и~скоростей перемещений:
\begin{equation}
\label{senic:eq10}
\begin{array}{c}
\displaystyle
\Big[ {U_{0s,c},\; W_{0s,c} } \Big] = 
\int\limits_0^h {\Big[ {u_0 \left( {r, z} \right),\; w_0 \left( {r, z} \right)} \Big]} \left[ {\cos \frac{n\pi 
z}{h},\; \sin \frac{n\pi z}{h}} \right]dz,\\ \displaystyle
\Big[ \dot U_{0s,c},\; \dot W_{0s,c}  
\Big] = \int\limits_0^h \Big[ \dot u_0 \left( {r,z}\right),\;
\dot W_0 \left( {r,z} \right) \Big] \left[ {\cos \frac{n\pi z}{h},\;\sin \frac{n\pi z}{h}} \right]dz.
\end{array}
\end{equation}
Верхние знаки в равенствах (\ref{senic:eq7}), (\ref{senic:eq8}) соответствуют граничным условиям на 
торцах цилиндра~(7), а~нижние "--- (8).

\begin{remark}[2]В случае, когда рассматривается сплошной круговой цилиндр, помещённый в~жёсткую обойму, то преобразованные по Фурье граничные условия~(6) принимают 
вид

\begin{equation}
 \begin{array}{l}
\displaystyle
\text{при } r = 0:\quad  U_{s,c} < \infty,\quad W_{c,s} < \infty;
\\\displaystyle
\text{при } r = b:\quad  U_{s,c} = W_{c,s} = 0.
\end{array}
\end{equation} 
\end{remark}

Соотношения (\ref{senic:eq7})--(\ref{senic:eq9}) и представляют преобразованную в~пространстве 
изображений Фурье \mbox{($r$, $n$, $t$)} рассматриваемую краевую задачу.

Введём обобщённое КИП с~неизвестными пока компонентами $G_1$, $G_2$ 
ядровой вектор"=функции и~весом $r$~[3]:
\begin{gather}
\label{senic:eq11}
\varphi \left( {\lambda _{in} ,n,t} \right) = \int\limits_a^b r \left[ 
{U_{s,c} \left( {r,n,t} \right)G_1 \left( {\lambda _{in} ,r} \right) + 
W_{c,s} \left( {r,n,t} \right)G_2 \left( {\lambda _{in} ,r} \right)} 
\right]dr,\\
U_{s,c} \left( {r,n,t} \right) = \sum\limits_{i = 1}^\infty {\varphi \left( 
{\lambda _{in} ,t} \right)} G_1 \left( {\lambda _{in} ,r} \right)\left\| 
{G_{in} } \right\|^{ - 2},\quad
W_{c,s} \left( {r,n,t} \right) = \sum\limits_{i = 1}^\infty \varphi \left( {\lambda _{in} ,t} \right)G{ 
}_2\left( {\lambda _{in} ,r} \right)\left\| {G_{in} } \right\|^{ - 2}.
\end{gather}
Здесь $\varphi \left( {\lambda _{in} ,t} \right)  $ "--- трансформанта, (19) "--- формулы обращения КИП, $\left\| {G_{in} } \right\| $ "--- норма ядровой вектор"=функции:
\begin{equation}
\label{senic:eq12}
\left\| {G_{in} } \right\|^2 = \int\limits_a^b {r\left[ {G_1^2 \left( 
{\lambda _{in} ,r} \right) + G_2^2 \left( {\lambda _{in} ,r} \right)} 
\right]} dr,
\end{equation}
$\lambda _{in} > 0$ ($ i \in \mathbb N$; $n \in \{0\}\cup \mathbb N$) "--- 
положительные параметры, образующие счётное множество.

Индексы <<$i$>> и <<$n$>> во всех выражениях соответствуют числу полуволн в~направлении радиальной и~осевой координат цилиндра. 

Если подвергнуть теперь соотношения (\ref{senic:eq7}), (\ref{senic:eq9}) КИП (\ref{senic:eq11}), проинтегрировать по 
частям члены, содержащие производные по $r$, сложить уравнения и~соответствующие начальные условия, а~затем воспользоваться двумя известными условиями структурного алгоритма метода КИП [3]:
\begin{multline}
\Bigg[ {a_{11} } r\left( {G_1 \frac{\partial U_{s,c} }{\partial r} - 
{G}'_1 U_{s,c} } \right) + a_{55} r\left( {G_2 \frac{\partial W_{c,s} 
}{\partial r} - {G}'_2 W_{c,s} } \right)\pm \\
\pm \left( {a_{13} \pm a_{55} } \right)\frac{n\pi }{h}r {\left( {G_2 
U_{s,c} - G_1 W_{c,s} } \right)} \Bigg]\Bigg|_a^b   = 0,
\end{multline}
\begin{multline}
\label{senic:eq13}
\int\limits_a^b r\Bigg\{ {U_{s,c} }  \Bigg[ {a_{11} } 
\left( {{{G}'}'_1 + \frac{1}{r}{G}'_1 } \right) - \left( {a_{22} 
\frac{1}{r^2} + a_{55} \frac{n\pi }{h}} \right)G_1 \mp \left( {a_{13} +

\begin{equation}
\label{senic:eq36}
\left\{ {\begin{array}{l}
 \delta _{11}^\ast C_{1n} + \delta _{12}^\ast C_{3n} = 0, \\ 
 \delta _{21}^\ast C_{1n} + \delta _{22}^\ast C_{3n} = 0. 
 \end{array}} \right.
\end{equation}
Здесь 
\begin{equation}
 \begin{array}{c}
 \delta _{12}^\ast \ne \delta _{21}^\ast ,\quad  
\delta _{11}^\ast = b{J}'_1 \left( {A_{in} b} \right) + f_1 J_1 \left( 
{A_{in} b} \right),\quad \delta _{12}^\ast = b{I}'_1 \left( {D_{in} b} \right) + 
f_1 I_1 \left( {D_{in} b} \right),\\
\delta _{21}^\ast = f_{2n} r^{ - 1}{J}''_1 \left( {A_{in} b} \right) + 
\left( {f_{3n} + f_{4n} r^{ - 2}} \right){J}'_1 \left( {A_{in} b} \right) - 
r\left( {1 + f_{5n} r^{ - 2} - f_{6n} r^{ - 4}} \right)J_1 \left( {A_{in} b} 
\right),\\
\delta _{22}^\ast = f_{2n} r^{ - 1}{I}''_1 \left( {D_{in} b} \right) + 
\left( {f_{3n} + f_{4n} r^{ - 2}} \right){I}'_1 \left( {D_{in} b} \right) - 
r\left( {1 + f_{5n} r^{ - 2} - f_{6n} r^{ - 4}} \right)I_1 \left( {D_{in} b} 
\right),
 \end{array}
\label{senic:eq37}
\end{equation}
а $f_1$, $f_{2n}$, \dots, $f_{6n}$ определяются равенствами (38).

Если теперь приравнять главный детерминант системы (\ref{senic:eq36}) к нулю, то получаем 
трансцендентное уравнение для определения собственных значений $\lambda _{in}$:
\begin{equation}
\label{senic:eq38}
\delta _{11}^\ast \delta _{22}^\ast - \delta _{12}^\ast \delta _{21}^\ast = 0
\end{equation}
и соответствующие выражения для компонент $G_1$, $G_2 $ ядра КИП (\ref{senic:eq30}), в~которых
\begin{equation}
\label{senic:eq39}
C_{2n} = C_{4n} = 0,\quad C_{1n} = \delta _{12}^\ast, \quad C_{3n} = - \delta _{11}^\ast .
\end{equation}

В случае, когда начальные условия (9) не нулевые, то применяя к~соотношению 
(\ref{senic:eq18}) последовательно формулы обращения (19) и~(\ref{senic:eq6}), окончательно получаем 
в~случае (7) искомые компоненты $u$, $w$ вектора перемещений: 
\begin{equation}
 \begin{array}{l}
\displaystyle
 u\left( {r,z,t} \right) = \sum\limits_{n = 0}^\infty {\sum\limits_{i = 
1}^\infty {\Omega _n^{ - 1} } } \varphi \left( {\lambda _{in} ,n,t} 
\right)\cos \frac{n\pi z}{h}G_1 \left( {\lambda _{in} ,r} \right)\left\| 
{G_{in} } \right\|^{ - 2},\\
\displaystyle
w\left( {r,z,t} \right) = \sum\limits_{n = 0}^\infty {\sum\limits_{i = 
1}^\infty {\Omega _n^{ - 1} \varphi \left( {\lambda _{in} ,n,t} \right)\sin 
\frac{n\pi z}{h}G_2 } } \left( {\lambda _{in} ,r} \right)\left\| {G_{in} } 
\right\|^{ - 2}.
\end{array}\label{senic:eq40}
\end{equation}

Для граничных условий на торцах цилиндра (8) в равенствах (\ref{senic:eq40}) косинус 
и~синус следует поменять местами.

\textbf{4.} В~качестве примера проанализируем спектры частот $\omega _{in} $ 
и~$\omega _{in}^\ast $ свободных осесимметричных колебаний помещённого в~жёсткую 
обойму сплошного цилиндра, у~которого $h = 0{,}3$~м. 
Цилиндр выполнен из стеклопластика плотность которого $\rho =1{,}9\cdot 10^{3}$~кг/м$^{3}$. 
Рассматривались два варианта армирования~[7]. 

Первый соответствует более сильному армированию в~плоскостях, 
перпендикулярных оси цилиндра по отношению к~армированию вдоль образующей, 
при таких значениях упругих постоянных: 
$a_{11}=a_{22}=3{,}143\cdot10^{10}$~Н/м$^{2}$, 
$a_{33}=0{,}861\cdot 10^{10}$~H/м$^{2}$, 
$a_{12}=0{,}431\cdot 10^{10}$~H/м$^{2}$, 
$a_{13}=a_{23}=0{,}275\times 10^{10 }$~H/м$^{2}$.

Второй вариант соответствует противоположному случаю, 
когда 
$a_{11}=a_{22}=0{,}861\cdot 10^{10}$~H/м$^{2}$, 
$a_{33}=3{,}143\cdot 10^{10}$~H/м$^{2}$, 
$a_{12}=0{,}431\cdot 10^{10}$~H/м$^{2}$, 
$a_{13}=a_{23}=0{,}275\cdot 10^{10 }$~H/м$^{2}$.

Коэффициент потерь $\gamma _i = \gamma = 0{,}001$~[4]. При анализе 
варьировалось отношение $\frac{l}{2b}$, характеризующее относительную длину 
цилиндра.



В таб. 1 и 2 для первого и второго вариантов армирования приведены  частоты 
$\omega _{in} $ первых трёх тонов ($i = 1,\,2,\,3$) осесимметричных колебаний 
ортотропных цилиндров при одной, двух и~трёх полуволнах ($n = 1,\,2,\,3$) вдоль их 
образующих. Расчёты выполнялись для значений параметра 
$\frac{l}{2b}=\{0{,}857;\; 6{,}00\}$ по уравнению (\ref{senic:eq38}) 
и~формулам (\ref{senic:eq17}), (\ref{senic:eq19}). 
Для постоянного коэффициента потерь на каждой моде колебаний в данном 
примере: $\omega _{in}^\ast =  0{,}9987 \cdot \omega _{in},$ то есть $\omega 
_{in}^\ast $ отличаются от соответствующих частот, определённых без учёта 
сил внутреннего трения $\omega _{in} $, на 0,13\,{\%} (практически совпадают). 
Из таб.~1 и~2 следует, что характер анизотропии (армирования) существенно 
влияет на величины $\omega _{in} $ осесимметричных колебаний цилиндров. 
В~коротких цилиндрах частоты колебаний существенно зависят от числа полуволн 
$n$ вдоль образующих. К~интересным качественным результатам полученным для~коротких цилиндров 
($\frac{l}{2b}=0{,}857$) следует отнести перестройку тонов 
колебаний, то есть при фиксированном $i$ с~ростом $n$ наблюдается появление более низких частот 
$\omega _{in} $.
