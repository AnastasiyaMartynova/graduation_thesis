\section{Введение}

Естественным обобщением классической задачи об оптимальном назначении
является ее многоиндексная версия: найти минимум линейной функции
\begin{equation}
\label{a1}
\sum_{i_1 = 1}^{n} \sum_{ i_2 = 1}^{n} \dotsb \sum_{ i_m = 1}^{n}
c_{i_1 i_2 \dotsb i_m} x_{i_1 i_2 \dotsb i_m}
\end{equation}
при выполнении условий на переменные
\begin{gather}
\label{a2}
x_{i_1 i_2 \dotsb i_m}\in \{0, 1\}; \\
%
\label{a3}
\sum_{i_1 = 1}^{n} \dotsb
\sum_{i_{k-1} = 1}^{n} \sum_{ i_{k+1} = 1}^{n} \dotsb \sum_{ i_m = 1}^{n}
x_{i_1 i_2 \dotsb i_m} =1
\end{gather}
для всяких $ 1\le i_k \le n$, $1\le k\le m$.
Здесь через $ c_{i_1 i_2 \dotsc i_m} $ обозначены элементы
прямоугольной $\overbrace{n \times \dotsb \times n}^{m}$-матрицы
--- заданные вещественные числа,
$1 \le i_k \le n$, $k=1, \dotsc, m$.

По виду ограничений (\ref{a3}) такую задачу называют аксиальной \cite{EKK}.
Решение задачи может быть представлено выбором в
$\overbrace{n \times \dotsb \times n}^{m}$-матрице
$(c_{i_1 i_2 \dotsc i_m})$ ровно $n$ элементов (как и в
классической двухиндексной задаче), сумма весов которых и составляет
целевую функцию. Именно только этим выбранным элементам соответствуют
единичные значения переменных задачи.
Многоиндексность позволяет более полно отразить специфику прикладных задач
по сравнению с двухиндексным случаем.

Так же, как и в классической (двухиндексной) задаче о назначении,
для многоиндексной задачи (\ref{a1})--(\ref{a3}) удобно использовать
более компактную форму ее записи с помощью подстановок из
симметрической группы $S_n$ порядка $n$:
минимизировать линейную форму
\begin{equation}
\label{a4}
\sum_{i=1}^{n} c_{i, \pi_1(i), \sigma_{31}(i), \dotsc, \sigma_{m1}(i)}
\end{equation}
на множестве подстановок $\{\pi_k\mid 1\le k < m \}$ таких, что
\begin{equation}
\label{a5}
\sigma_{k k'} \in S_n \text{\; при \;} 1\le k'< k \le m,
\end{equation}
где через
$\sigma_{k k'}$ обозначена подстановка
$\pi_{k-1}\pi_{k-2} \dotsb \pi_{k'+1}\pi_{k'}$, $\ 1\le k'< k \le m$.

Существенным отличием рассматриваемой в данной работе многоиндексной
аксиальной задачи
о назначениях от задачи (\ref{a4}), (\ref{a5}) является замена условия
(\ref{a5}) на условие
\begin{equation}
\label{a6}
\sigma_{k k'} \in P_n \text{\; при \;} 1\le k'< k \le m,
\end{equation}
где $P_n$ --- множество всех одноциклических подстановок из
симметрической группы $S_n$ порядка~$n$.

Классическая многоиндексная задача о назначениях
(на подстановках из симметрической группы $ S_n$ порядка $ n$)
$NP$-трудна, начиная с числа индексов, равного трем \cite{BS89}, \cite{BS91}.
В двухиндексном варианте эта задача полиномиально разрешима, чего нельзя
сказать о двухиндексной задаче о назначениях на одноциклических подстановках,
поскольку, очевидно, последняя совпадает с классической задачей коммивояжера.
Отсюда следует, что рассматриваемая в статье задача
MAX SNP-трудна \cite{PY91}, \cite{SG76}.

Более того, в отличие от двухиндексной задачи (коммивояжера) и
многоиндексной задачи о назначениях (на подстановках из
$S_n$) многоиндексная аксиальная задача о
назначениях на одноциклических подстановках не при всяких входах может иметь
решение. В \cite{GS} для трехиндексной задачи о назначениях на
одноциклических подстановках был обоснован критерий разрешимости задачи:
задача разрешима тогда и только тогда, когда $n$ нечетно.
Там же предложен приближенный алгоритм решения
трехиндексной задачи, имеющий линейную (относительно длины входа)
трудоемкость, и получены условия асимптотической точности этого алгоритма
при случайно задаваемых входных данных.

В данной работе представлен критерий разрешимости $m$-индексной
аксиальной задачи
о назначениях на одноциклических подстановках при $3 \le m \le 7$:
начиная с некоторого номера $n_m$, задача разрешима
при $n\ge n_m$ тогда и только тогда, когда $n$ нечетно.
В качестве одного из нерешенных вопросов сформулирована гипотеза о
справедливости критерия для любого $m>2$.

\section{Предварительные замечания и необходимый признак разрешимости
задачи}

Условия (\ref{a6}) для шестииндексной задачи
проиллюстрированы на рис.\,1 в следующей наглядной форме:

\put(120,130){\special{em:graph gim1.pcx}}

В частности, здесь
$\sigma_{31}=\pi_{2}\pi_{1}$,
$\sigma_{52}=\pi_{4} \pi_{3} \pi_{2}$,
$\sigma_{62}=\pi_{5} \pi_{4} \pi_{3} \pi_{2}$,
$\sigma_{61}=\pi_{5} \pi_{4} \pi_{3} \pi_{2} \pi_{1}$.

Далее будем ссылаться на следующие два очевидных утверждения,
касающихся свойств подстановок из $S_n$.

\begin{note}
\label{n1}
При умножении произвольной подстановки из $S_n$ на транспозицию $(i,j)$
(как справа, так и слева) четность числа циклов в подстановке меняется.
При этом число циклов уменьшается на единицу, если индексы $i$ и $j$
принадлежат разным циклам, и увеличивается на единицу, если $i$, $j$
находятся в одном цикле.
\end{note}

\begin{note}
\label{n2}
Для любых двух подстановок $\pi$ и $\alpha$ из $S_n$ имеет место свойство:
подстановки $\pi$ и $\alpha \pi \alpha^{-1}$ имеют одинаковое число
циклов.
\end{note}

Задачу будем называть {\em разрешимой}, если для нее существует такая
система подстановок $\{\pi_k\mid1\le k < m \}$, для которой выполняются
условия (\ref{a6}). В противном случае задачу называем {\em неразрешимой}.
В \cite{GS} обоснован необходимый признак --- нечетность $n$ --- разрешимости
трехиндексной задачи. Этот признак легко распространяется на случай
произвольного числа индексов $m>2$.

\begin{thm}
\label{th1}
При $n \ge m > 2$ для разрешимости $m$-индексной задачи о назначении на
одноциклических подстановках из $S_n$ необходимо, чтобы $n$
было нечетным.
\end{thm}

\begin{pf}
Допустим противное: для некоторого четного $n$ нашлись подстановки
$\{\pi_k\mid 1\le k < m \}$, удовлетворяющие условию
(\ref{a6}). Тогда первые две подстановки $\pi_1$, $\pi_2$ и их произведение
$\pi_2\pi_1$ являются одноциклическими. Подстановка $\pi_1$ представима в виде
произведения $(n-1)$ транспозиций, число которых нечетно в силу четности $n$.
Согласно замечанию~\ref{n1} после умножения одноциклической
подстановки $\pi_2$ на нечетное число транспозиций (справа) получим
подстановку $\pi_2 \pi_1$ с четным числом циклов, т.\,е.
$\pi_2 \pi_1 \notin P_n$. Пришли к противоречию.
\end{pf}

\section{Критерий разрешимости $7$-индексной задачи}

Рассмотрим разбиение множества нечетных натуральных чисел на подмножества
\begin{align*}
N_1&=\{n\in N\mid n\ne 0\ (\Mod 2),\ n\ne 0\ (\Mod 3),\ n\ne 0\ (\Mod 5)\},\\
%
N_2&=\{n\in N\mid n\neq 0\ (\Mod 2),\ n\neq 0\ (\Mod 3),\ n=0\ (\Mod 5)\}, \\
%
N_3&=\{n\in N\mid n\neq 0\ (\Mod 2),\ n=0\ (\Mod 3),\ n\neq 0\ (\Mod 5)\},\\
%
N_4&=\{n\in N\mid n\neq 0\ (\Mod 2),\ n=0\ (\Mod 3),\ n=0\ (\Mod 5)\}.
\end{align*}

Легко видеть, что $7$-индексная задача не имеет смысла
при $n<7$.

Далее для определенности положим $\pi=(1, 2, \dotsc,n)$.

\begin{lem}
\label{lm1}
Если $n\in N_1$ и $n\ge 7$, то $7$-индексная задача о назначениях
на одноциклических подстановках разрешима.
\end{lem}

\begin{pf}
Покажем, что если $n\in N_1$ и $n\ge 7$, то подстановки
$\pi_1 = \pi_2 = \pi_3 =\pi_4 = \pi_5 = \pi_6 = \pi$
являются допустимым решением задачи.
Действительно, в этом случае подстановки, входящие в (\ref{a6}), имеют
вид $\pi$, $\pi^2$, $\pi^3$, $\pi^4$, $\pi^5$, $\pi^6$
и являются одноциклическими.
\end{pf}

\begin{lem}
\label{lm2}
$7$-индексная задача о назначениях на одноциклических подстановках
разрешима, если $ n\in N_2$, $n\ge 25$.
\end{lem}

\begin{pf}
Покажем, что если $n\in N_2$, $n\ge 25$, то допустимое решение задачи
дают подстановки
$\pi_1 = \pi_2 = \pi_3 =\pi_4 = \pi$,
$\pi_5 = \alpha \pi,\ \pi_6 = \alpha \pi \alpha^{-1}$,
где $\alpha=(8,12)(8,5)(8,14)(1,8)$.

В этом случае минимальное значение $n$ равно
$\min \{n\in N_2\mid n\ge 14\}=25$, а
подстановки, входящие в (\ref{a6}), имеют
следующий вид (условно разобьем их на три подвида):
\begin{itemize}
\item[I.] $\pi$, $\pi^2$, $\pi^3$, $\pi^4$;
\item[II.] $\alpha \pi \alpha^{-1}$;
\item[III.] $\alpha \pi$, $\alpha \pi^2$, $\alpha \pi^3$,
$\alpha \pi^4$, $\alpha \pi^5$, $\alpha \pi^6$.
\end{itemize}

Подстановки первого подвида являются одноциклическими.
С учетом замечания \ref{n2} подстановка второго подвида также
является одноциклической.

Покажем одноцикличность подстановок третьего подвида.
Поскольку $n\in N_2$, то $ \pi^5 $ можно представить в виде произведения
пяти независимых циклов
$(1,6,\dotsc,n-4)(2,7,\dotsc,n-3)
(3,8,\dotsc,n-2)(4,9,\dotsc,n-1)(5,9,\dotsc,n)$.
Согласно замечанию \ref{n1} для того чтобы подстановку
$\pi^5$ преобразовать в
одноциклическую, потребуется, как минимум, домножение ее на четыре
транспозиции. При умножении $\pi^5$ на транспозицию $(1,8)$
слева получаем подстановку $(1,8)\pi^5$ в виде следующего
произведения четырех независимых циклов:
$$
(1,8,13,\dotsc,n-2,3,6,11,\dotsc, n-4)(2,7,\dotsc,n-3)
(4,9,\dotsc,n-1)(5,10,\dotsc,n),
$$
представленных на рис.\,2.
\begin{center}
\begin{picture}(470,170)(0,-15)
\put(120,150){\special{em:graph gim2.pcx}}
\end{picture}
\end{center}

\noindent{}При умножении текущей подстановки на новую транспозицию каждый раз
возникает одинаковая ситуация: элементы
транспозиции принадлежат разным циклам подстановки, и число циклов уменьшается
на единицу. Поэтому с учетом замечания \ref{n1} подстановка
$\alpha \pi^5$ одноциклическая.

Подстановки $\pi$, $\pi^2$, $\pi^3$, $\pi^4$, $\pi^6$ одноциклические.
Следовательно, подстановки
$(1,8)\pi$, $ (1,8)\pi^2$, $(1,8)\pi^3$, $(1,8)\pi^4$, $(1,8)\pi^6 $ состоят
из двух циклов.
При этом, как нетрудно проверить,
элементы $\{8\}$, $\{14\}$ принадлежат разным циклам.

Поэтому с учетом замечания \ref{n1} подстановки
$(8,14)(1,8)\pi$, $(8,14)(1,8)\pi^2$, $(8,14)(1,8)\pi^3$,\linebreak
$(8,14)(1,8)\pi^6$ являются одноциклическими.

Аналогично показывается, что при умножении каждой из последних
подстановок на транспозицию (5,8), а затем на (8,12)
также получаются одноциклические подстановки.

Рассмотрим далее подстановку $(1,8)\pi^4$. Она состоит из двух циклов и
содержит элементы $\{8\}$, $\{14\}$ в одном из этих циклов. С учетом замечания
\ref{n1} подстановка $(8,14)(1,8)\pi^4$ состоит из трех циклов.
При этом элементы $\{5\}$, $\{8\}$ и $\{12\}$ принадлежат разным циклам
(см. рис.\,3).
\begin{center}
\begin{picture}(470,140)(0,-15)
\put(110,120){\special{em:graph gim3.pcx}}
\end{picture}
\end{center}

\noindent{}Отсюда следует, что произведение
$(8,12)(5,8)$ на $(8,14)(1,8)\pi^4$ --- одноциклическая подстановка.

Итак, все подстановки, фигурирующие в условии (\ref{a6}),
являются одноциклическими при $n\in N_2$, $n\ge 25$.
\end{pf}

\begin{lem}
\label{lm3}
$7$-индексная задача о назначениях на одноциклических подстановках
разрешима, если $ n\in N_3$, $n\ge 27$.
\end{lem}

\begin{pf}
Покажем, что если $n\in N_3$, $n\ge 27$, то в качестве решения задачи
можно взять подстановки
$\pi_1 = \pi_2 = \pi$, $\pi_3 = \alpha \pi$,
$\pi_4 = \pi_5 = \alpha \pi \alpha^{-1}$,
$\pi_6 = \beta \alpha \pi \alpha^{-1}$,
где $\alpha=(6,14)(1,6)$, $\beta=(23,3)(14,3)$.
Минимальное значение $n$ в этом случае равно
$\min \{n\in N_3\mid n\ge 23\}=27$.
При этом подстановки, входящие в условие (\ref{a6}), имеют
следующий вид (условно разобьем их на пять подвидов):
\begin{itemize}
\item[I.] $\pi$, $\pi^2$;
\item[II.] $\alpha \pi \alpha^{-1}$, $\alpha \pi^2 \alpha^{-1}$;
\item[III.] $\alpha \pi$, $\alpha \pi^2$,
$\alpha \pi^3$, $\alpha \pi^4$, $\alpha \pi^5$;
\item[IV.] $\beta \alpha \pi^4$, $\beta \alpha \pi^5$,
$\beta \alpha \pi^6$;
\item[V.] $\beta \alpha \pi \alpha^{-1}$, $\beta \alpha \pi^2 \alpha^{-1}$,
$\beta \alpha \pi^3 \alpha^{-1}$.
\end{itemize}

Подстановки первого подвида, а с учетом замечания \ref{n2},
и подстановки второго подвида являются одноциклическими.

Покажем одноцикличность подстановок третьего подвида.
Так как $n\in N_3$, то $ \pi^3$ можно представить в виде
произведения трех независимых циклов.
Элементы $\{1\}$, $\{6\} $ и $\{14\}$ лежат в разных циклах.
Поэтому произведение $(6,14)(1,6)$ на $ \pi^3$ --- одноциклическая
подстановка.

Подстановки $\pi$, $\pi^2$, $\pi^4$, $\pi^5$ одноциклические.
Следовательно, каждая из подстановок
$(1,6)\pi$, $(1,6)\pi^2$, $(1,6)\pi^4$, $(1,6)\pi^5 $ состоит
из двух циклов. Легко проверить, что в каждой из этих подстановок
элементы $\{6\}$ и\ $\{14\}$ принадлежат разным циклам.
Поэтому подстановки
$\alpha \pi$, $\alpha \pi^2$, $\alpha \pi^4$, $\alpha \pi^5$
одноциклические по замечанию \ref{n1}.

Покажем одноцикличность подстановок четвертого подвида.
Так как $\alpha \pi^4$ и $\alpha \pi^5$
одноциклические, то подстановки $(3,14) \alpha \pi^4$ и
$(3,14) \alpha \pi^5$ состоят из двух циклов.
Легко проверить, что в каждой из этих подстановок
элементы $\{3\}$, $\{23\}$ принадлежат разным циклам.
Поэтому подстановки
$\beta \alpha \pi^4$, $\beta \alpha \pi^5$
одноциклические согласно замечанию \ref{n1}.

Поскольку $n\in N_3$, то подстановка $\pi^6$ может быть представлена
в виде следующего произведения трех независимых циклов:
$$
(1,7,\dotsc\,n-2,4,10,\dotsc,n-6)(2,8,\dotsc,n-1,5,11,\dotsc,n-5)
(3,9,\dotsc,n,6,12,\dotsc,n-4),
$$
причем элементы $\{1\}$, $\{6\}$, $\{14\}$
принадлежат разным циклам.
Поэтому умножение подстановки $\alpha = (6,14)(1,6)$
на $\pi^6$ дает  одноциклическую подстановку $\alpha \pi^6$.
При умножении подстановки $\beta=(3,23)(3,14)$
на одноциклическую подстановку $\alpha \pi^6$ сначала получаем
подстановку $(3,14) \alpha \pi^6$, состоящую из двух циклов.
Элементы $\{3\},\ \{23\}$ принадлежат разным циклам. Следовательно,
подстановка $(3,23)(3,14) \alpha \pi^6$ $=\beta \alpha \pi^6$
одноциклическая.

Аналогичным образом показывается одноцикличность трех подстановок пятого типа.
\end{pf}

\begin{lem}
\label{lm4}
$7$-индексная задача о назначениях на одноциклических подстановках
разрешима, если $n\in N_4$, $n\ge 45$.
\end{lem}

\begin{pf}
Если
$N_4=\{n\in N\mid n\neq 0\ (\Mod 2),\ n=0(\Mod 3),\ n=0\ (\Mod 5)\}$,
то допустимым решением задачи являются подстановки
$\pi_1 = \pi_2 = \pi$, $\pi_3 = \alpha \pi$,
$\pi_4 = \pi_5 = \alpha \pi \alpha^{-1}$,
$\pi_6 = \beta \alpha \pi \alpha^{-1}$,
где $\alpha=(11,14)(11,5)(2,18)(1,2)$, $\beta=(32,15)(31,32)$.

В этом случае подстановки, входящие в условие (\ref{a6}),
имеют вид
\begin{itemize}
\item[I.] $\pi$, $\pi^2$;
\item[II.] $\alpha \pi$, $\alpha \pi^2$, $\alpha \pi^3$,
$\alpha \pi^4$, $\alpha \pi^5$;
\item[III.] $\alpha \pi \alpha^{-1}$, $\alpha \pi^2 \alpha^{-1}$;
\item[IV.] $\beta \alpha \pi^4$, $\beta \alpha \pi^5$, $\beta \alpha \pi^6$;
\item[V.] $\beta\alpha\pi\alpha^{-1}$, $\beta\alpha\pi^2 \alpha^{-1}$,
$\beta \alpha \pi^3 \alpha^{-1}$.
\end{itemize}

Как и в предыдущем случае, разбили их на пять подвидов.

Проведя аналогичные рассуждения, можно показать, что приведенные выше
подстановки удовлетворяют условию (\ref{a6}).
\end{pf}

Теперь сформулируем критерий разрешимости $7$-индексной задачи.

\begin{thm}
\label{th2}
Найдется такой номер $n_7$, что $7$-индексная задача о
назначениях на одноциклических подстановках из $S_n $ разрешима
при $n\ge n_7 $ тогда и только тогда, когда $n$ нечетно.
\end{thm}

\begin{pf}
Необходимость следует из теоремы \ref{th1}.
Достаточность получим из лемм \ref{lm1}--\ref{lm4}, согласно которым
значение $n_7=45$ удовлетворяет условиям теоремы.
\end{pf}

\section{Заключительные замечания о разрешимости многоиндексной задачи}

Непосредственно из критерия разрешимости $7$-индексной задачи вытекает
справедливость критерия для задач с числом индексов $m$ от 3 до 6.

\begin{thm}
\label{th3}
Для всякого $2<m\le 7$ найдется такой номер $n_m$, что
$m$-индексная аксиальная задача о назначениях на одноциклических подстановках
из $S_n$ разрешима при $n\ge n_m$ тогда
и только тогда, когда $n$ нечетно.
\end{thm}

Отметим некоторые нерешенные вопросы, 
представляющие интерес для дальнейших исследований.
\medskip

1. Опровергнуть или доказать, что верна следующая
\medskip

Гипотеза. Для любого $m>2$ найдется такой номер $n_m$, что
$m$-индексная аксиальная задача о
назначениях на одноциклических подстановках из $S_n$
разрешима при $ n\ge n_m$
тогда и только тогда, когда $n$ нечетно.
\medskip

2. Для заданного числа индексов $m>2$ было бы любопытным указать
минимальный номер $n_m$, начиная с которого
нечетность $n$ является необходимым и достаточным условием разрешимости
$m$-индексной задачи о назначениях на одноциклических
подстановках.
\medskip

3. Как было сказано в начале статьи, эффективный приближенный
алгоритм решения удалось построить только для $3$-индексной задачи.
Представляется интересным реализация оптимизационного аспекта задачи
при большем числе индексов.
