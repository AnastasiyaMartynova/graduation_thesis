В теории вероятностей существуют несколько различных понятий сходимости, из к-рых для теории статистич. оценивания наиболее важными являются сходимость по вероятности и сходимость с вероятностью 1. Если последовательность статистич. оценок сходится по вероятности к оцениваемой величине, то про эту последовательность говорят, что она является «слабо состоятельной», или просто «состоятельной», употребляя термин «сильная состоятельность» по отношению к последовательности оценок, сходящейся с вероятностью 1 к оцениваемой величине.

СОСТОЯТЕЛЬНЫЙ КРИТЕРИЙ - статистический критерий, достоверно отличающий проверяемую гипотезу от альтернативы при нсограниченном увеличении числа наблюдений.

Значимости уровень) задана заранее и равна $\alpha(0<\alpha<0,5)$. Далее, пусть по первым $n$ наблюдениям $X_{1}, X_{2}, \ldots, X_{n}$ построен статистич. критериіі уровня $\alpha$ для проверки $H_{0}$ против $H_{1}$ и пусть $\beta_{n}(\theta), 0 \in \Theta$, - его мощности критерия функция, показывающая при каждом $\theta$, с какой вероятностью этот критерий отклоняет $H_{0}$, если случайная величина $X_{i}$ подчиняется закону $P_{\theta}$, при этом $\beta_{n}(\theta) \leqslant \alpha$ при всех $\theta \in \Theta_{0}$. Неограниченно увеличивая число наблюдений, можно построить последовательность статистич. критериев заданного уровня $\alpha$, предназначенных для проверки гипотезы $H_{0}$ против альтернативы $H_{1}$, при этом соответствующая им последовательность функций мощности $\left\{\beta_{n}(\theta)\right\}$ будет удовлетворять условию

\[
\beta_{n}(\theta) \leqslant \alpha \text { для любого } n \text { при всех } \theta \in \Theta_{0} \text {. }
\]

Если в этих условиях последовательность функций мощности $\left\{\beta_{n}(\theta)\right\}$ такова, что для любого фиксированноro $\theta \in \Theta_{1}=\Theta \backslash \Theta_{0}$

\[
\lim _{n \rightarrow \infty} \beta_{n}(\theta)=1,
\]

то говорят, что построена состоятельная последовательность статистич. критериев уровня $\alpha$ для проверки гипотезы $H_{0}$ против альтернативы $H_{1}$. Часто, допуская при этом определенную вольность, говорят, что построен С. к. Так как функция $\beta_{n}(\theta), \theta \in \Theta_{1}$, являющаяся сужением функции мощности $\beta_{n}(\theta), \theta \in \Theta=\Theta_{0} \cup \Theta_{1}$, на множество $\Theta_{1}$, есть мощность статистич. критерия, построенного по наблюдениям $X_{1}, X_{2}, \ldots, X_{n}$, то в терминах мощности свойство состоятельности последовательности статистич. критериев выражается в том, что соответствугоие им мощности $\beta_{n}(\theta), \theta \in \Theta_{1}$, сходятся ва $\Theta_{1}$ к функции, тождественно равной 1 на $\Theta_{1}$.

Пусть $X_{1}, X_{2}, \ldots, X_{n}$ - независимые одинаково распределенные случайные величины, функция распределения к-рых принадлежит семейству $H=$ $=\{F(x)\}$ всех непрерывных функций распределения на $\mathbb{R}^{1}$, и пусть $p=\left(p_{1}, p_{2}, \ldots, p_{k}\right)-$ вектор положительных вероятностей такой, что $p_{1}+p_{2}+\ldots+p_{k}=1$. Далее, пусть $F_{0}(x)$ - произвольная функция распределения из семейства $H$. Функция распределения $F_{0}(x)$ и вектор $p$ однозначно определяют разбиение числовой оси на $k$ полуивтервалов $\left(x_{0} ; x_{1}\right],\left(x_{1} ; x_{2}\right], \ldots$, $\ldots,\left(x_{k-1} ; x_{k}\right]$, где

\[
\begin{gathered}
x_{0}=-\infty, \quad x_{k}=+\infty, \\
x_{i}=F_{0}^{-1}\left(p_{1}+\ldots+p_{i}\right)=\inf \left\{x: F_{0}(x) \geqslant p_{1}+\ldots+p_{i}\right\}, \\
i=1,2, \ldots, k-1 .
\end{gathered}
\]

Иначе говоря, гравицы полуинтервалов суть квантили функции распределения $F_{0}(x)$. С помощью полуинтервалов $\left(x_{0} ; x_{1}\right],\left(x_{1} ; x_{2}\right], \ldots,\left(x_{k-1} ; x_{k}\right)$ семейство $H$ можно разбить на два непересекающихся множества $H_{0}$ и $H_{1}$ по следующему правилу: функция распределения $F$ из $H$ принадлежит $H_{0}$ тогда и только тогда, если

\[
F\left(x_{i}\right)-F\left(x_{i-1}\right)=p_{i}, \quad i=1,2, \ldots, k,
\]

в противном случае $F \in H_{1}$. Пусть, далее, $v_{n}=\left(v_{n 1}\right.$, $\left.v_{n 2}, \ldots, v_{n k}\right)$ - вектор частот, получающийся в результате группировки первых $n$ случайных величин $X_{1}$, $X_{2}, \ldots, X_{n}(n>k)$ по полуинтервалам $\left(x_{0} ; x_{1}\right], \ldots$ $\ldots,\left(x_{k-1}, x_{k}\right)$. В этих условиях для проверки гипотезы $H_{0}$, согласно к-рой функция распределения случайных величин $X_{1}, X_{2}, \ldots, X_{n}$ принадлежит множеству $H_{0}$, против альтернативы $I_{1}$, по к-рой функция распределения случайных величин $X_{1}, X_{2}, \ldots, X_{n}$ принадлежит множеству $H_{1}$, можно воспользоваться критерием «хиквадрат», основанным на статистике

\[
X_{n}^{2}=\sum_{i=1}^{k} \frac{\left(v_{n i}-n p_{i}\right)^{2}}{n p_{i}} .
\]

Согласно критерию «хи-квадрат» с уровнем значимости $\alpha(0<\alpha<0,5)$, гипотезу $H_{0}$ следует отвергнуть, коль скоро $X_{n}^{2}>\chi_{k-1}^{2}(\alpha)$, где $\chi_{k-1}^{2}(\alpha)$ - верхняя $\alpha$-квантиль «хи-квадрат» расиределения с $k-1$ степенями свободы.
