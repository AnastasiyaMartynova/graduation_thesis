\rukeywords{метод Римана, задача Коши--Гурса, Задача Дарбу, дифференциальные уравнения в частных производных, система уравнений Эйлера--Пуассона--Дарбу}

\ruabstract{Рассмотрена система $n$ дифференциальных уравнений в частных производных  в матричной записи (система уравнений Эйлера"--~Пуассона"--~Дарбу). Поставлены задачи Коши"--~Гурса и Дарбу для случая, когда характеристические числа матрицы-коэффициента принадлежат интервалу  $(0; 1/2)$. Матрица"=коэффициент приведена к жордановой форме, что позволило разделить систему на $r$ независимых систем уравнений, по одной для каждой жордановой клетки. В полученных системах матричный коэффициент имеет одно собственное значение из рассматриваемого интервала. Для систем уравнений с одним матричным коэффициентом, представляющим собой жорданову клетку, которая является диагональной или треугольной матрицей, решение может быть получено с~использованием известных свойств функций от матрицы. С~использованием построенной ранее матрицы Римана рассматриваемой системы уравнений для всех $r$  систем уравнений построена матрица Римана"--~Адамара. С помощью матрицы Римана"--~Адамара для каждой системы матричных уравнений в частных производных построено решение задач Коши"--~Гурса и Дарбу. Решение исходных задач записано в виде прямой суммы решений систем для жордановых клеток. Сформулирована теорема корректности полученных решений.}

\entitle{Boundary value problems for matrix Euler--Poisson--Darboux equation with~data~on~a~characteristic}
%
\enauthor{A.~A.~Andreev, E.~A.~Maksimova}{A\,n\,d\,r\,e\,e\,v~A.~A., M\,a\,k\,s\,i\,m\,o\,v\,a~E.~A.}

\enabstract{We consider the system of $n$ partial differential equations in matrix notation (the system of 
Euler--Poisson--Darboux equations). For the system we formulate the Cauchy--Goursat and Darboux problems for the case when the eigenvalues of the coefficient matrix lie in $(0; 1/2)$. The coefficient matrix is reduced to the Jordan form, which allows to separate the system to the $r$ independent systems, one for each Jordan cell. The coefficient matrix in the obtained systems has the only one eigenvalue in the considered interval. For a system of equations having the only coefficient matrix in form of Jordan cell, which is the diagonal or triangular matrix, we can construct the solution using the properties of matrix functions. We form the Riemann--Hadamard matrices for each of $r$ systems using the Riemann matrix for the considered system, constructed before. That allow to find out  the solutions of the Cauchy--Goursat and Darboux problems for each system of matrix partial differential equations. The solutions of the original problems are represented in form of the direct sum of the solutions of systems for Jordan cells. The correctness theorem for the obtained solutions is formulated.
}

В настоящее время имеется ряд монографий и статей, посвященных краевым задачам и их корректности для уравнения 
Эйлера"--~Пуассона"--~Дарбу и~его обобщений. Так, в монографии Р.~С.~Хайруллина~\cite{Hairullin} получены общие решения для всех возможных вещественных значений параметров и построены решения задачи Коши. 
Ранее в~работах [\citen{dis}--\citen{Elianu}] получены решения различных краевых задач для систем двух уравнений 
Эйлера"--~Пуассона"--~Дарбу методом Римана\cite{Riemann}, обобщенным на системы дифференциальных уравнений в~частных производных.

Известно, что метод решения задач Коши"--~Гурса и Дарбу для уравнения Эйлера"--~Пуассона"--~Дарбу  
$$U_{xy}-\frac{b}{x-y}U_x+\frac{a}{x-y}U_y+\frac{c}{(x-y)^2}U=0$$ 
в случае $a=b=1/6$, $c=0$  С.~Геллерстедт \cite{Gel} впервые применил метод, носящий название метода Римана"--~Адамара. 
Позже этот метод был обобщен \cite{Andreev,spicin} на один класс систем гиперболического типа второго порядка с двумя неизвестными переменными и кратными характеристиками "--- систему Эйлера"--~Пуассона"--~Дарбу.

\smallskip
 Рассмотрим следующую систему $n$ дифференциальных уравнений в~частных производных:
\begin{equation}
  \label{eq1}
  \frac{\partial^{2}U}{\partial \xi \partial \eta}+\frac{G}{\eta - \xi}\frac{\partial U}{\partial \xi}-\frac{G}{\eta - \xi}\frac{\partial U}{\partial \eta}=0,
\end{equation}
где 
  $U=( u_1, \dots, u_n)^\top$, $G$ "--- действительная $n \times n $-матрица.

В работе \cite{Andreev} построена матрица Римана и с её помощью получено решение задач Коши"--~Гурса и Дарбу для системы \eqref{eq1} при $n=2$ и различных собственных значениях квадратной матрицы $G$ из интервала $(0; 1/2)$. 
В \cite{my,my1} получены решения задачи Коши для случаев, когда собственные значения матрицы $G \in \mathbb R^{n\times n}$ "--- комлексно"=сопряжённые с действительной частью из интервала $(-1/2; 1/2)$.


Необходимо найти решение задач Коши"--~Гурса и Дарбу для системы~\eqref{eq1} в~случае, когда спектр квадратной матрицы $G$ принадлежит интервалу $(0; 1/2)$.

\smallskip

{\small \sc Задача Коши"--~Гурса.} 
\it
Найти вектор-функцию $U(\xi,\eta),$ удовлетворяющую следующим условиям\/{\rm:}
\begin{enumerate}
\item[\rm 1)] $U(\xi,\eta)\in C(\bar{D})\cap C^2(D),$ где $D=\{(\xi, \eta): 0< \xi<\eta <1 \};$
\item[\rm 2)] $U(\xi,\eta)$ удовлетворяет системе \rm  \eqref{eq1}; \it
\item[\rm 3)] выполняются  условия
\begin{gather}
  \label{kr1}
  U(0, \eta)=\psi(\eta), \quad  \eta \in \left[0; 1\right],
\\
  \label{kr2}
  \lim\limits_{ \eta - \xi \to -0} K \Bigl(\frac{\eta-\xi}{2}\Bigr)\Bigl(\frac{\partial U}{\partial{\xi}}-\frac{\partial U}{\partial{\eta}}\Bigr)=\nu(\xi),\quad \xi \in (0; 1), 
\end{gather}
\end{enumerate}
где \rm $\psi(\eta)=(\psi_1(\eta),\dots ,\psi_n(\eta))^\top,$ $ \nu(\xi)=(\nu_1(\xi),\dots,\nu_n(\xi))^\top,$ $ K(t)=t^{2G}$.


\smallskip

{\small \sc Задача Дарбу.} \it  Найти вектор-функцию $U(\xi, \eta),$ удовлетворяющую следующим условиям\/{\rm:}
\begin{enumerate}
\item[\rm 1)] $U(\xi,\eta)\in C(\bar{D})\cap C^2(D),$ где $D=\{(\xi, \eta): 0< \xi<\eta <1 \};$
\item[\rm 2)] $U(\xi,\eta)$ удовлетворяет системе  \rm \eqref{eq1}; \it
\item[\rm 3)] выполняются условия \eqref{kr1} и 
\begin{gather}
  \label{krD1}
  U(\xi,\xi)=\tau(\xi), \quad  \xi \in \left[0, 1\right],
\end{gather}
\end{enumerate}
где \rm $\tau(\eta)=(\tau_1(\eta),\dots ,\tau_n(\eta))^\top,$ $ \tau(0)=\psi(0)$.
\smallskip

Известно \cite{gant}, что для любой матрицы $G$ существует матрица перехода $Q$ к жорданову базису такая, что 
\begin{equation*}
 Q^{-1} G Q=\Lambda, 
\end{equation*}
где $\Lambda$ "--- блочно-диагональная матрица, которая является жордановой формой матрицы $G$. 
Матрица $\Lambda$ состоит из $r$ жордановых клеток
\begin{equation*}
\Lambda= 
    \left(
	    \begin{array}{cccccc}
              \Lambda_1 & 0 & 0&  \dots  &0\\
	      0& \Lambda_2 & 0 &  \dots  &0\\
	       \dots  &  \dots  &  \dots &  \dots  & \dots \\
	      0& 0 & 0 &  \dots  &\Lambda_r\\
            \end{array}
    \right), \quad r\leq n,
\end{equation*}
\begin{equation*}
\Lambda_k=
  \underbrace{
  \mkern-10mu
    \left(
	    \begin{array}{cccccc}
              \lambda_k & 1 & 0&  \dots  &0 &0\\
	      0& \lambda_k & 1 &  \dots  &0 &0\\
	       \dots  &  \dots  &  \dots &  \dots  & \dots  & \dots \\
	      0& 0& 0 &  \dots  &\lambda_k&1 \\
	      0& 0& 0 &  \dots  &0&\lambda_k \\
            \end{array}
    \right)
    \mkern-10mu
   }_{l_k}
\end{equation*}
 "---  жорданова клетка порядка $l_k$, $\sum_{k=1}^{r} l_k =n$, соответствующая собственному значению $\lambda_k$. 
Также известно \cite{gant}, что одному собственному значению  может соответствовать более одной жордановой клетки. 
Количество $s$ жордановых клеток размера $l_k$, соответствующих собственному значению $\lambda_k$, вычисляется по формуле из \cite{tir}:
\begin{equation*}
\label{count_j}
 s=\mathop{\rm rank}((G-\lambda_k E)^{l_k-1})-2 \mathop{\rm rank}((G-\lambda_k E)^{l_k}) + \mathop{\rm rank}((G-\lambda_k E)^{l_k+1}).
\end{equation*}

После преобразования  $Q^{-1} G Q=\Lambda$ система \eqref{eq1} примет вид
\begin{equation}
  \label{eq_tmp}
  \frac{\partial^{2}\tilde{U}}{\partial \xi \partial \eta}+\frac{\Lambda}{\eta - \xi}\frac{\partial \tilde{U}}{\partial \xi}-\frac{\Lambda}{\eta - \xi}\frac{\partial \tilde{U}}{\partial \eta}=0,
\end{equation}
где 
\begin{equation}
\label{QU}
\tilde{U}=Q^{-1} U .
\end{equation}

Очевидно, система уравнений \eqref{eq_tmp} распадается на $r$ независимых систем уравнений вида
\begin{equation}
  \label{eq2}
  L\tilde{U}_{(k)}=\frac{\partial^{2} \tilde{U}_{(k)}}{\partial \xi \partial \eta}+\frac{\Lambda_k}{\eta - \xi}\frac{\partial \tilde{U}_{(k)}}{\partial \xi}-\frac{\Lambda_k}{\eta - \xi}\frac{\partial \tilde{U}_{(k)}}{\partial \eta}=0;
\end{equation}
условия Коши"--~Гурса \eqref{kr1}, \eqref{kr2} для уравнения \eqref{eq2} будут иметь вид
\begin{gather}
  \label{kr21}
  \tilde{U}_{(k)}(0,\eta)=\tilde{\psi}_{(k)}(\eta), \quad  \eta \in \left[0; 1\right], \quad \tilde{\psi}=Q^{-1} \psi
\\
  \label{kr22}
  \lim\limits_{ \eta - \xi \to -0} \tilde{K}_{(k)} \Bigl(\frac{\eta-\xi}{2}\Bigr)
  \Bigl(\frac{\partial \tilde{U}_{(k)}}{\partial{\xi}}-\frac{\partial \tilde{U}_{(k)}}{\partial{\eta}}\Bigr)=\tilde{\nu}_{(k)}(\xi),\\
  \xi \in (0; 1),\quad  \tilde{\nu}=Q^{-1} \nu, \quad  \tilde{K}_{(k)}(t)=t^{\Lambda_k},
\end{gather}
где $\tilde{U}_{(k)}$, $\tilde{\psi}_{(k)}$,  $\tilde{\nu}_{(k)}$ "--- группы координат вектор-функций, соответствующих жордановой клетке $\Lambda_k$.
Условия Дарбу \eqref{kr1}, \eqref{krD1} примут вид \eqref{kr21} и 
\begin{gather}
  \label{krD21}
  \tilde{U}_{(k)}(\xi,\xi)=\tilde{\tau}_{(k)}(\xi),\quad  \xi \in \left[0; 1\right], \quad \tilde{\tau}=Q^{-1}\tau.
\end{gather}
Существенную роль при решении задач \eqref{eq2}, \eqref{kr21}, \eqref{kr22} и \eqref{eq2}, \eqref{kr21}, \eqref{krD21} играет так называемая матрица Римана"--~Адамара.

\begin{gather*}
 W_i(\xi,\eta,\xi_0,\eta_0)= 
\begin{cases}
  R(\xi,\eta;\xi_0,\eta_0), & \eta>\xi_0,\\[1mm]

+ \int _{\eta_0}^{\xi_0+\varepsilon}
\Bigl[
W_i \frac{\partial \tilde{U}_{(k)}}{\partial \eta} - \frac{\partial W_i}{\partial \eta} \tilde{U}_{(k)} - 2 W_i \frac{\Lambda_k}{\eta-\xi} \tilde{U}_{(k)}
\Bigr]
_{\scriptsize{
\begin{array}{l}
\xi=0
 \end{array} }}
  d \eta - \\
- \int _{0}^{\xi_0- 2\varepsilon}
\Bigl[
W_i \frac{\partial \tilde{U}_{(k)}}{\partial \xi} - \frac{\partial W_i}{\partial \xi} \tilde{U}_{(k)} - 2 W_i \frac{\Lambda_k}{\eta-\xi} \tilde{U}_{(k)}
\Bigr]
_{\scriptsize{
\begin{array}{l}
\eta=\xi_0+\varepsilon
 \end{array} }}
 d \xi
\biggr).
\end{multline}

Очевидно, $\tilde{U}_{(k)}(\xi_0,\eta_0)$ можно записать в виде 
\begin{gather}
\label{sum}
 \tilde{U}_{(k)}(\xi_0,\eta_0)=\sum\limits_{j=1}^{l_k} I(\lambda_k,u_{(k)j}) e_j,
\end{gather}
где $e_j=(e_{j1}, e_{j2},\dots ,e_{jl_{k}})^\top$; 
$e_{ji}=0$, 
$i\neq j$; $e_{jj}=1$;
$u_{(k)j}$ "--- компоненты вектора~$\tilde{U}_{(k)}$; 
$l_k$ "--- размер жордановой клетки $\Lambda_k$;
\begin{multline}
\label{I_lambda}
 I(\Lambda_k,u_{(k)j}) = \biggr( 
 \lim\limits_{\varepsilon \to 0}  \int _0^{\xi_0-2 \varepsilon}
 \Bigl[W_i \Bigl(
\frac{\partial u_{(k)j}}{\partial \eta}-\frac{\partial u_{(k)j}}{\partial \xi}\Bigr) - \\
-
\Bigl(\frac{\partial f_i(\Lambda_k)}{\partial \eta}-\frac{\partial f_i(\Lambda_k)}{\partial \xi} - 4 f_i(\Lambda_k) \frac{\Lambda_k}{\eta-\xi}\Bigr)u_{(k)j}
\Bigr]
_{\scriptsize{
\begin{array}{l}
\eta=\xi+\varepsilon
 \end{array} }}
 d \xi -
\\
-
 \int _{\xi_0-2 \varepsilon}^{0}
 \Bigl[
f_i(\Lambda_k) \frac{\partial u_{(k)j}}{\partial \xi} - \frac{\partial f_i(\Lambda_k)}{\partial \xi} u_{(k)j} - 2 f_i(\Lambda_k) \frac{\Lambda_k}{\eta-\xi} u_{(k)j}
\Bigr]
_{\scriptsize{
\begin{array}{l}
\eta=\xi_0-\varepsilon
 \end{array} }}
  d \xi -
\\-
 \int _{\xi_0- \varepsilon}^{\varepsilon}
 \Bigl[
f_i(\Lambda_k) \frac{\partial u_{(k)j}}{\partial \eta} - \frac{\partial f_i(\Lambda_k)}{\partial \eta} u_{(k)j} - 2 f_i(\Lambda_k) \frac{\Lambda_k}{\eta-\xi} u_{(k)j}
\Bigr]
_{\scriptsize{
\begin{array}{l}
\xi=0
 \end{array} }}
  d \eta +\\
+ \int _{\xi_0+ \varepsilon}^{\eta_0}
\Bigl[
f_i(\Lambda_k) \frac{\partial u_{(k)j}}{\partial \eta} - \frac{\partial f_i(\Lambda_k)}{\partial \eta} u_{(k)j} - 2 f_i(\Lambda_k) \frac{\Lambda_k}{\eta-\xi} u_{(k)j}
\Bigr]
_{\scriptsize{
\begin{array}{l}
\xi=\xi_0-2 \varepsilon
 \end{array} }}
  d \eta -\\
- \int _{\xi_0- 2\varepsilon}^{0}
\Bigl[
f_i(\Lambda_k) \frac{\partial u_{(k)j}}{\partial \xi} - \frac{\partial f_i(\Lambda_k)}{\partial \xi} u_{(k)j} - 2 f_i(\Lambda_k) \frac{\Lambda_k}{\eta-\xi} u_{(k)j}
\Bigr]
_{\scriptsize{
\begin{array}{l}
\eta=\eta_0
 \end{array} }}
  d \xi +
  \\
+ \int _{\eta_0}^{\xi_0+\varepsilon}
\Bigl[
f_i(\Lambda_k) \frac{\partial u_{(k)j}}{\partial \eta} - \frac{\partial f_i(\Lambda_k)}{\partial \eta} u_{(k)j} - 2 f_i(\Lambda_k) \frac{\Lambda_k}{\eta-\xi} u_{(k)j}
\Bigr]
_{\scriptsize{
\begin{array}{l}
\xi=0
 \end{array} }}
  d \eta - \\
- \int _{0}^{\xi_0- 2\varepsilon}
\Bigl[
f_i(\Lambda_k) \frac{\partial u_{(k)j}}{\partial \xi} - \frac{\partial f_i(\Lambda_k)}{\partial \xi} u_{(k)j} - 2 f_i(\Lambda_k) \frac{\Lambda_k}{\eta-\xi} u_{(k)j}
\Bigr]
_{\scriptsize{
\begin{array}{l}
\eta=\xi_0+\varepsilon
 \end{array} }}
 d \xi
\biggr).
\end{multline}

Известно \cite{Lankaster}, что если $\Lambda_k$ "--- жорданова клетка, то функция от матрицы $ I(\Lambda_k,u_{(k)j})$ может быть записана в виде
\begin{equation}
 \label{I_f_matr}
 I(\Lambda_k,u_{(k)j})=
  \left(
    \begin{array}{ccccccccc}
      I(\lambda_k,u_{(k)j})& \frac{I_{\lambda_k}'(\lambda_k,u_{(k)j})}{1!} 	& \vdots & \frac{I_{\lambda_k}^{(l_j-1)}(\lambda_k,u_{(k)j})}{(l_j-1)!}\\
      0	& I(\lambda_k,u_{(k)j}) 		& \vdots & \frac{I_{\lambda_k}^{(l_j-2)}(\lambda_k,u_{(k)j})}{(l_j-2)!}\\
      \ldots		& \ldots 				& \ddots & \ldots\\
      0			& 0				& \ldots & I(\lambda_k,u_{(k)j})\\
    \end{array}
  \right).
\end{equation}

Подставляя \eqref{I_f_matr} в \eqref{sum}, после некоторых преобразований получаем
\begin{gather*}
\tilde{U}_{(k)}(\xi_0,\eta_0)= EI(\lambda,\tilde{U}_{(k)})+
\sum\limits_{j=1}^{l_k-1}\frac{H_{l_k}^j}{j!} I^{(j)}_{\lambda_k}(\lambda_k,\tilde{U}_{(k)}),
\end{gather*}
где $H_{l_k}$ "--- $l_k \times l_k$-матрица вида
\begin{equation*}
\label{H}
 H_{l_k}=
\left(
\begin{array}{cccccc}
  0 & 1 & 0 & 0 & \dots & 0\\
  0 & 0 & 1 & 0 & \dots & 0\\
  \dots & \dots & \dots & \dots & \dots & \dots \\
  0 & 0 & 0 & 0 & \dots & 1\\
  0 & 0 & 0 & 0 & \dots & 0\\
\end{array}
\right).
\end{equation*}

Подстановкой в тождество \eqref{I_lambda} собственного значения $\lambda_k$ матрицы $W_1$ Римана"--~Адамара задачи 
Коши"--~Гурса с существенным использованием \linebreak свойств этой матрицы и применением соответствующих краевых условий \eqref{kr21}, \eqref{kr22} предельным переходом при $\varepsilon \to 0$ получим 
\begin{multline*}
 I(\lambda_k,\tilde{U}_{(k)}) =2^{2\lambda_k-1}K_1(\lambda_k)  \int _0^{\xi}\nu(t) 
 \bigl[(\eta-t)(t-\xi)\bigr]^{-\lambda_k}dt + \\
+K_1(\lambda_k) \xi^{-\lambda_k}  \int _{0}^{\xi}
\Bigl( \psi'(t)+\frac{\lambda_k}{t} \psi(t)\Bigr) \Bigl( \frac{t^2}{\eta-t} \Bigr) ^{\lambda_k}
{}_2 F_1 \left(
\begin{array}{c}
 \lambda_k, \lambda_k\\
2 \lambda_k
\end{array};
\frac{t(\eta-\xi)}{\xi(\eta-t)}
\right)
dt+\\
+(\eta-\xi)^{-\lambda_k}  \int _{\xi}^{\eta}
\Bigl( \psi'(t)+\frac{\lambda_k}{t} \psi(t)\Bigr)  t^{\lambda_k}
{}_2 F_1 \left(
\begin{array}{c}
 \lambda_k, 1-\lambda_k\\
2 \lambda_k
\end{array};
\frac{\xi(\eta-t)}{t(\eta-\xi)}
\right)dt.
\end{multline*}

Для задачи Дарбу функция $I(\lambda_k,\tilde{U}_{(k)})$ будет иметь вид
\begin{multline*}
 I(\lambda_k,\tilde{U}_{(k)}) =
 2(1-2\lambda_k) K_2(\lambda_k) (\eta-\xi)^{1-2\lambda} \int _0^{\xi}\tau(t) \bigl[(\eta-t)(\xi-t)\bigr]^{\lambda_k-1}dt + \\
+K_2(\lambda_k) \frac{(\eta-\xi)^{1-2\lambda_k}}{\xi^{1-\lambda_k}}  \int _{0}^{\xi}
\Bigl( \psi'(t)+\frac{\lambda_k}{t} \psi(t) \Bigr) 
\times  \hspace{3cm}
\\
\hspace{3cm}
\times \frac{t}{(\eta-t)^{1-\lambda_k}}
{}_2 F_1 \left(
\begin{array}{c}
 1-\lambda_k, 1-\lambda_k\\
2-2\lambda_k
\end{array};
\frac{t(\eta-\xi)}{\xi(\eta-t)}
\right)
dt+\\
+(\eta-\xi)^{-\lambda_k}  \int _{\xi}^{\eta}
\Bigl( \psi'(t)+\frac{\lambda_k}{t} \psi(t)\Bigr)  t^{\lambda_k}
{}_2 F_1 \left(
\begin{array}{c}
 \lambda_k, 1-\lambda_k\\
2 \lambda_k
\end{array};
\frac{\xi(\eta-t)}{t(\eta-\xi)}
\right)dt,
\end{multline*}
где 
$$
K_1(\lambda_k)=\frac{\Gamma(1-2 \lambda_k)}{\Gamma(1-\lambda_k) \Gamma(1-\lambda_k)},
\quad 
K_2(\lambda_k)=\frac{\Gamma(2 \lambda_k)}{\Gamma(\lambda_k) \Gamma(\lambda_k)}.
$$

Решение задачи Коши"--~Гурса и Дарбу уравнения \eqref{eq_tmp} можно записать в~виде прямой суммы \cite{Markus} решений вспомогательных систем \eqref{eq2}:
\begin{equation*}
 \tilde{U}(\xi,\eta)=\oplus\sum\limits_{k=1}^{r} \tilde{U}_{(k)}(\xi,\eta).
\end{equation*}

Выполняя в полученных выражениях замену \eqref{QU}, получим решения исходных задач. 
Полученный результат согласуется с результатами А.~А.~Андреева~\cite{Andreev} для системы двух уравнений Эйлера"--~Пуассона"--~Дарбу.

Непосредственной проверкой нетрудно убедиться в том, что полученные решения удовлетворяют уравнению и начальным данным. Из самого способа получения решений и их вида следует единственность решения поставленных задач. Таким образом, справедлива 
\smallskip
\begin{theorem}
Если $\tau(x) \in C^3 \left[0; 1\right]$ и $\nu(x) \in C^2 (0; 1),$ то полученные решения есть классические решения задач Коши"--~Гурса  и Дарбу для уравнения \eqref{eq1} и они корректны по Адамару\rm.
\end{theorem}
