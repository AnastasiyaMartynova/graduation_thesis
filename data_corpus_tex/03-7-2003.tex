\section{Введение}

Рассматривается линейная неоднородная система
функционально-разностных уравнений
\begin{equation}
x (t)=\int_{-r}^{0}d_{\vartheta}\eta (t,\vartheta)
x (t+\vartheta) +h (t),\label{f1}
\end{equation}
где $x:\Bbb{R}\to\Bbb{R}^{n}$; $h\in\Bbb{C} (
\Bbb{R},\Bbb{R}^{n})$; матричная функция $\eta (
t,\cdot)$ при каждом фиксированном $t\in\Bbb{R}$ имеет ограниченную
вариацию на отрезке $[-r,0]$, $\eta (t,0)=0$.

Для указанной системы изучается начальная задача Коши в пространстве 
непрерывных функций. Пусть $t_{0}\in\Bbb{R}$ --- начальный момент и 
$\varphi\in\Bbb{C} ([t_{0}-r,t_{0}],\Bbb{R}
^{n})$ --- начальная функция. Функция $x\in\Bbb{C} ([t_{0}-r,+\infty)
,\Bbb{R}^{n})$ является решением начальной задачи Коши, если
$x (t)=\varphi (t) $ при $t\in [t_{0}
-r,t_{0}]$, и для нее равенство (\ref{f1}) выполняется
тождественно на полуоси $ (t_{0},+\infty) $. Для
существования непрерывного решения начальной задачи Коши
необходимо, чтобы выполнялось условие согласования
\begin{equation}
\varphi (t_{0})=\int_{-r}^{0}d_{\vartheta}\eta (
t_{0},\vartheta) \varphi (t_{0}+\vartheta) +h (
t_{0}) .\label{sogl_obch}
\end{equation}

Понятие функционально-разностного 
уравнения (ФРУ) обобщает понятие разностного уравнения с непрерывным 
временем так же, как понятие 
функционально-дифференциального уравнения обобщает 
понятие дифференциально-разностного уравнения. В работе для линейных 
нестационарных систем ФРУ установлены условия существования 
и единственности решений начальной задачи Коши в пространстве 
непрерывных функций. Получена формула, дающая аналитическое 
представление общего решения изучаемой системы ФРУ. Рассмотрены методы
нахождения указанного представления. 
Полученные результаты иллюстрируются примерами. 
Указанный круг вопросов исследовался для линейных систем 
функционально-дифференциальных уравнений [1]--[4]. Для линейных систем
разностных уравнений с непрерывным временем рассматриваемые
проблемы изучались в [5]--[7].
Специальные решения линейных разностных уравнений с непрерывным временем 
построены в [8]. Для линейных систем разностных уравнений с 
дискретным временем решения указанных проблем изложены в [9]. Для
линейных стационарных систем ФРУ рассматриваемый круг вопросов
исследовался в [10].


\section{Существование и единственность решения начальной задачи Коши}

Пусть функция $x\in\Bbb{C} ([t_{0}-r,+\infty)
,\Bbb{R}^{n}) $ является решением начальной задачи Коши для 
начального момента $t_{0}\in\Bbb{R}$ и начальной функции $\varphi\in
\Bbb{C} ([t_{0}-r,t_{0}],\Bbb{R}^{n}) $ системы 
ФРУ (\ref{f1}) с функцией $h\in
\Bbb{C} ([t_{0},+\infty),\Bbb{R}^{n})$. Введем 
следующие обозначения: $\widetilde{x} (t)
=x (t) -\varphi (t_{0}) $, $t\geq t_{0}$,
$\widetilde{\varphi } (s)=\varphi (s)
-\varphi (t_{0}) $, $s\in [t_{0}-r,t_{0}]$,
$\widetilde{h} (t)=h (t) -h (
t_{0}) $, $t\geq t_{0}$. Тогда
$\widetilde{x}\in\Bbb{C}_{t_{0}} ([
t_{0},+\infty),\Bbb{R}^{n})=\{
\widetilde{x}: \widetilde{x}\in \Bbb{C} ([
t_{0},+\infty),\Bbb{R}^{n})$, $\widetilde{x} (t_{0})=0 \}$,
$\widetilde{\varphi
}\in\Bbb{C}_{t_{0}} ([t_{0}-r,t_{0}],\Bbb{R}
^{n})=\{ \widetilde{\varphi}: \widetilde{\varphi}\in
\Bbb{C} ([t_{0}-r,t_{0}],\Bbb{R}^{n})$,
$\widetilde{\varphi} (t_{0})=0 \} $, $\widetilde
{h}\in\Bbb{C}_{t_{0}} ([t_{0},+\infty),\Bbb{R}
^{n})=\{ \widetilde{h}: \widetilde{h}\in\Bbb{C} (
[t_{0},+\infty),\Bbb{R}^{n})$, $\widetilde
{h} (t_{0})=0 \} $.

\begin{assrts}
Для заданного начального момента $t_{0}
\in\Bbb{R}$, начальной функции $\varphi\in\Bbb{C} (
[t_{0}-r,t_{0}],\Bbb{R}^{n}) $ и функции
$h\in\Bbb{C} ([t_{0},+\infty),\Bbb{R}^{n})$
функция $x\in\Bbb{C} ([t_{0}-r,+\infty)
,\Bbb{R}^{n})$ является решением начальной задачи Коши системы
ФРУ $(\ref{f1})$ тогда и только тогда, когда
функция $\widetilde{x}\in\Bbb{C}_{t_{0}} ([t_{0},+\infty),
\Bbb{R}^{n})$ является решением уравнения 
\begin{equation}
\widetilde{x} (t)=(D\widetilde{x}) (
t) + (H\widetilde{\varphi}) (t) + (
H_{0}\varphi (t_{0})) (t) +\widetilde
{h} (t),\quad t\geq t_{0}.\label{ur_oper_1}
\end{equation}
Здесь оператор $D$ определяется формулами
\begin{equation}
(D\widetilde{x}) (t)=
\begin{cases}
\int\limits_{t_{0}}^{t}d_{s}\eta (t,s-t) \widetilde{x} (s)
, & t_{0}\leq t\leq t_{0}+r;\\
\int\limits_{t-r}^{t}d_{s}\eta (t,s-t) \widetilde{x} (s)
, & t>t_{0}+r,
\end{cases}
\label{oper_D}
\end{equation}
оператор $H$ определяется формулами
\begin{equation}
(H\widetilde{\varphi}) (t)=
\begin{cases}
\int\limits_{t-r}^{t_{0}}d_{s}\eta (t,s-t) \widetilde{\varphi} (
s) -\int\limits_{t_{0}-r}^{t_{0}}d_{s}\eta (t_{0},s-t_{0})
\widetilde{\varphi} (s), & t_{0}\leq t\leq t_{0}+r;\\
-\int\limits_{t_{0}-r}^{t_{0}}d_{s}\eta (t_{0},s-t_{0}) \widetilde
{\varphi} (s), & t>t_{0}+r,
\end{cases}
\label{oper_H}
\end{equation}
оператор $H_{0}$ определяется формулой
\begin{equation}
(H_{0}\varphi (t_{0})) (t)=(
\eta (t_{0},-r) -\eta (t,-r)) \varphi (
t_{0}),\quad t\geq t_{0}.\label{oper_H_0}
\end{equation}
\end{assrts}

\begin{pf}
После преобразования системы уравнений
(\ref{f1}) и условия согласования (\ref{sogl_obch}) при $t_{0}\leq
t\leq t_{0}+r $ находим
$\widetilde{x} (t)=\widetilde{h} (t) -\int\limits_{t_{0}
-r}^{t_{0}}d_{s}\eta (t_{0},s-t_{0})
\widetilde{\varphi} (s) + (\eta (
t_{0},-r) -\eta (t,-r)) \varphi (
t_{0}) +\int\limits_{t_{0}}^{t}d_{s}\eta (t,s-t)
\widetilde{x} (s) +\int\limits_{t-r}^{t_{0}}d_{s}\eta (
t,s-t) \widetilde{\varphi} (s)$,
при $t>t_{0}+r$ \ $\widetilde{x} (t)
=\int\limits_{t-r}^{t}d_{\vartheta}\eta (
t,s-t) \widetilde{x} (s) -\int\limits_{t_{0}-r}^{t_{0}}d_{s}
\eta (t_{0},s-t_{0}) \widetilde{\varphi} (
s) + (\eta (t_{0},-r) -\eta (
t,-r)) \varphi (t_{0})+\widetilde{h} (t)$.
Следовательно, системе (\ref{f1}) можно поставить в соответствие уравнение
(\ref{ur_oper_1}), где оператор $D$ определяется формулами (\ref{oper_D}),
оператор $H$ определяется формулами (\ref{oper_H}), а оператор $H_{0}$
--- формулой (\ref{oper_H_0}).
\end{pf}

Для любого $\Delta>0$ рассмотрим сужение уравнения (\ref{ur_oper_1}) на 
отрезок $ [t_{0},t_{0}+\Delta] $. Имеем
\begin{equation}
\widetilde{x} (t)=(D_{\Delta}\widetilde{x})
(t) + (H_{\Delta}\widetilde{\varphi}) (
t) + (H_{0\Delta}\varphi (t_{0})) (
t) +\widetilde{h} (t),\quad t\in [t_{0}
,t_{0}+\Delta] .\label{G_ur_x_DH}
\end{equation}
Для сужения функций $\widetilde{x}$ и $\widetilde{h} $ на отрезок
$[t_{0},t_{0}+\Delta] $ оставляем те же обозначения,
полагая $\widetilde{h}\in\Bbb{C}_{t_{0}} ([
t_{0},t_{0}+\Delta],\Bbb{R}^{n}) $,
$\widetilde{x}\in\Bbb{C}_{t_{0}} ([
t_{0},t_{0}+\Delta],\Bbb{R}^{n})$.

Продолжим функцию $\eta$ по второму аргументу на всю числовую ось, полагая
$\eta (t,s)=0$ при $s\geq0$ и $\eta (t,s)
=\eta (t,-r) $ при $s\leq-r$, $t\in\Bbb{R}$. Тогда значения 
операторов $D_{\Delta}$, $H_{\Delta}$ и $H_{0\Delta}$ при любом $\Delta>0$ 
можно определить формулами
\begin{gather}
(D_{\Delta}\widetilde{x}) (t)=\int_{t_{0}}
^{t}d_{s}\eta (t,s-t) \widetilde{x} (s)
,\quad t_{0}\leq t\leq t_{0}+\Delta, \label{oper_delta1} \\
%
(H_{\Delta}\widetilde{\varphi}) (t)
=\int _{t-r}^{t_{0}}d_{s}\eta (t,s-t)
\widetilde{\varphi} (s)
-\int_{t_{0}-r}^{t_{0}}d_{s}\eta (t_{0},s-t_{0})
\widetilde{\varphi} (s),\quad t_{0}\leq t\leq
t_{0}+\Delta, \notag \\
%
(H_{0\Delta}\varphi (t_{0})) (
t)=(\eta (t_{0},-r) -\eta (
t,-r)) \varphi (t_{0}),\quad t_{0}\leq
t\leq t_{0}+\Delta.\notag
\end{gather}

\begin{lems}
Пусть выполнены условия
\begin{itemize}
\item[1)] функция $\Var\limits_{z\in [-r,0]}
\eta (t,z) $ ограничена на любом отрезке числовой оси$;$
\item[2)] для любого $\tau\in\Bbb{R}$ отображение 
$t \to\int\limits_{t-r}^{\tau}\eta (t,s-t) ds$ непрерывно 
на любом отрезке числовой оси.
\end{itemize}
Тогда $D_{\Delta}:\Bbb C_{t_{0}} ([t_{0},t_{0}+\Delta]
,\Bbb{R}^{n}) \to C_{t_{0}} ([t_{0}
,t_{0}+\Delta],\Bbb{R}^{n}) $.
\end{lems}

\begin{pf}
Обозначим $\Bbb{AC}_{t_{0}} ([
t_{0},t_{0}+\Delta],\Bbb{R}^{n})=\{
\widetilde{x}: \widetilde{x}\in \Bbb{AC} ([
t_{0},t_{0}+\Delta],\Bbb{R}^{n})$,
$\widetilde{x} (t_{0})=0 \}$.
Преобразуем формулы,
определяющие значения оператора $D_{\Delta}$,
$$
(D_{\Delta}\widetilde{x}) (t)=\int_{t_{0}}
^{t}d_{s}\eta (t,s-t) \widetilde{x} (s)
=-\int_{t_{0}}^{t_{0}+\Delta}\eta (t,s-t)
\widetilde{x}' (s) ds,\quad t_{0}\leq t\leq
t_{0}+\Delta.
$$
Определим значения оператора $\widetilde{D}_{\Delta}$ следующими формулами:
$$
(\widetilde{D}_{\Delta}y) (t)=-\int_{t_{0}
}^{t_{0}+r}\eta (t,s-t) y (s) ds,\quad t\in [
t_{0},t_{0}+\Delta],\quad y\in\Bbb{L}_{1} ([
t_{0},t_{0}+\Delta],\Bbb{R}^{n}) .
$$
Для произвольной функции $\widetilde{x}\in\Bbb{AC}_{t_{0}} ([
t_{0},t_{0}+\Delta],\Bbb{R}^{n})$ функция $D_{\Delta
}\widetilde{x}\in\Bbb{C}_{t_{0}} ([t_{0},t_{0}+\Delta]
,\Bbb{R}^{n})$ тогда и только тогда, когда функция $\widetilde
{D}_{\Delta}y\in\Bbb{C}_{t_{0}} ([t_{0},t_{0}+\Delta]
,\Bbb{R}^{n})$ для функции $y\in\Bbb{L}_{1} ([
t_{0},t_{0}+\Delta],\Bbb{R}^{n})$, $y (s)
=\widetilde{x}' (s) $, $s\in [t_{0},t_{0}
+\Delta] $. Докажем, что оператор
$\widetilde{D}_{\Delta}$ имеет тип $\Bbb{L}_{1} ([
t_{0},t_{0}+\Delta],\Bbb{R}^{n}) \to\Bbb{C}
([t_{0},t_{0}+\Delta],\Bbb{R}^{n}) $ и является непрерывным.

Для оператора $\widetilde{D}_{\Delta}$ выполнены условия

A) $\vraisup\limits_{s,t\in [t_{0},t_{0}+\Delta]}
| \eta (t,s-t) | <\infty$;

B) функция $t \to\int\limits_{t_{0}}^{\tau}\eta (t,s-t) ds$ 
непрерывна при любом $\tau\in [t_{0},t_{0}+\Delta] $ на отрезке
$ [t_{0},t_{0}+\Delta] $.

Действительно, по определению вариации $\Var\limits_{z\in [-r,0]}
\eta (t,z) \geq | \eta (t,-r) -\eta (t,z) | + | \eta (
t,z) -\eta (t,0) | \geq2 | \eta (
t,z) | - | \eta (t,-r) | $. Тогда
$| \eta (t,z) | \leq\frac{1}{2}\Var\limits_{z\in [
-r,0] }\eta (t,z) +\frac{1}{2} |
\eta (t,-r) |$. Функции $\Var\limits_{z\in [
-r,0] }\eta (t,z) $ и $\eta (
t,-r)$ ограничены по условию 1) леммы 2.1 на $ [t_{0}
,t_{0}+\Delta] $. Тогда $\sup\limits_{t\in [t_{0},t_{0}
+\Delta],z\in [-r,0] } | \eta (
t,z) | <\infty$. Имеем $\vraisup\limits_{t,s\in [t_{0}
,t_{0}+\Delta] }| \eta (t,s-t) |
\leq\vraisup\limits_{t\in [t_{0},t_{0}+\Delta],z\in [t_{0}
-t,t_{0}-t+r] }| \eta (t,z)|\leq\vraisup\limits_{t\in [t_{0},t_{0}+\Delta]
,z\in [-r,0] }| \eta (t,z) | <\infty$. Справедливость 
условия A) доказана. Для любого $\tau\in\Bbb{R}$ имеем
$\int\limits_{t_{0}}^{\tau}\eta (t,s-t) ds=\int\limits_{t-r}^{\tau}\eta (
t,s-t) ds-\int\limits_{t-r}^{t_{0}}\eta (t,s-t) ds$ при
$t\in [t_{0},t_{0}+\Delta] $. Следовательно, в силу условия 2) 
леммы 2.1 условие B) для оператора $\widetilde{D}_{\Delta}$ выполняется.

Условия A) и B) гарантируют, что оператор $\widetilde{D}_{\Delta}$
имеет тип $\Bbb{L}_{1} ([t_{0},t_{0}+\Delta],\Bbb{R}
^{n}) \to\Bbb{C} ([
t_{0},t_{0}+\Delta],\Bbb{R}^{n}) $ и является
непрерывным ([11], с.100).

Докажем теперь, что оператор $D_{\Delta}$ имеет тип $\Bbb C_{t_{0}} ([t_{0}
,t_{0}+\Delta],\Bbb{R}^{n}) \to \Bbb C_{t_{0}} (
 [t_{0},t_{0}+\Delta],\Bbb{R}^{n}) $. Для произвольного
 $t\in [t_{0,}t_{0}+\Delta] $ введем оператор $D_{\Delta
t}:\Bbb{C}_{t_{0}} ([t_{0},t_{0}+\Delta],\Bbb{R}
^{n}) \to\Bbb{R}^{n}$ с помощью формулы
$D_{\Delta t}\widetilde{x}=(D_{\Delta}\widetilde{x})
(t)$. Однопараметрическое семейство операторов
$D_{\Delta t}$, $t\in [t_{0,}t_{0}+\Delta] $,
удовлетворяет условиям

C) для любого элемента $\widetilde{x}\in\Bbb{AC}_{t_{0}} (
[t_{0,}t_{0}+\Delta],\Bbb{R}^{n}) $
функция $D_{\Delta
t}\widetilde{x}$ аргумента $t$ непрерывна на $ [t_{0,}t_{0}
+\Delta] $;

D) для любого элемента
$\widetilde{x}\in\Bbb{C}_{t_{0}} ([
t_{0,}t_{0}+\Delta],\Bbb{R}^{n}) $ функция $D_{\Delta
t}\widetilde{x}$ аргумента $t$ ограничена на $ [t_{0,}t_{0}+\Delta] $.

Действительно, имеет место равенство $D_{\Delta t}\widetilde{x}=(
\widetilde{D}_{\Delta}y) (t) $ при $t\in [
t_{0,}t_{0}+\Delta] $, $y (t)=\widetilde{x}' (
t)$, $\widetilde{x}\in\Bbb{AC}_{t_{0}} ([t_{0,}
t_{0}+\Delta],\Bbb{R}^{n}) $. Справедливость условия C) следует 
из непрерывности функции $ (\widetilde{D}_{\Delta}y) (
t)$ на отрезке $ [t_{0,}t_{0}+\Delta] $. Справедливость
условия D) следует из неравенств $\sup\limits_{t\in [t_{0},t_{0}
+\Delta] }| D_{\Delta t}\widetilde{x} | \leq
\sup\limits_{t\in [t_{0},t_{0}+\Delta] }\Var\limits_{z\in [
-r,0] }\eta (t,z) \max\limits_
{s\in [t_{0},t_{0}+\Delta] } | \widetilde{x} (s) |$.

Условия C) и D) гарантируют, что оператор $D_{\Delta}$ имеет тип
$\Bbb C_{t_{0}} ([t_{0},t_{0}+\Delta],\Bbb{R}^{n}) \to  \Bbb C_{t_{0}
} ([t_{0},t_{0}+\Delta],\Bbb{R}^{n})$
согласно теореме 6 из ([12], с.\,73).
\end{pf}

Пусть выполнены условия

\begin{pf}
Справедливость утверждения леммы для
оператора $H_{0\Delta}$ следует из условия 2). Для доказательства
утверждения леммы об операторе $H_{\Delta}$ достаточно показать,
что оператор
$(\widetilde{H}_{\Delta}\widetilde{\varphi}) (t)
=\int\limits_{t-r}^{t_{0}}d_{s}\eta (t,s-t)
\widetilde{\varphi} (s)

\begin{equation}
T (t,s,t_{0})=\frac{d}{ds}\int_{t_{0}}^{s+r}dS (
t,\xi) \int_{-r}^{s-\xi} [\eta (
\xi,\vartheta) -\eta (\xi,-r)]
d\vartheta,\quad t>t_{0},
\ \ s\in [t_{0}-r,t_{0}] .\label{G_ur_T_S}
\end{equation}
\end{thms}

\begin{pf}
Рассмотрим решение $x_{\widetilde{\varphi}}$ с 
начальной функцией $\widetilde{\varphi}\in\Bbb{C}^{2} ([
t_{0}-r,t_{0}],\Bbb{R}^{n}) $. Это решение при $t>t_{0}$ 
совпадает с решением $x_{\widetilde{h}}$, где $\widetilde{h}$ определяется 
формулами
\begin{equation}
\widetilde{h} (t)=
\begin{cases}
\int\limits_{-r}^{t_{0}-t}d_{\vartheta}\eta (t,\vartheta) \widetilde
{\varphi} (t+\vartheta) -\int\limits_{-r}^{0}d_{\vartheta}\eta (
t_{0},\vartheta) \widetilde{\varphi} (t_{0}+\vartheta)
, & t\in [t_{0},t_{0}+r];\\
-\int\limits_{-r}^{0}d_{\vartheta}\eta (t_{0},\vartheta) \widetilde
{\varphi} (t_{0}+\vartheta), & t>t_{0}+r.
\end{cases}
\label{h_voln}
\end{equation}
После преобразования (\ref{h_voln}) находим $\widetilde{h} (
t)=\int\limits_{-r}^{t_{0}-t} [\eta (t,-r)
-\eta (t,\vartheta)] \widetilde{\varphi
}^{\prime} (t_{0}) d\vartheta+\int\limits_{t-r}^{t_{0}}\int\limits_{-r}
^{s-t} [\eta (t,-r) -\eta (t,\vartheta)]
d\vartheta\widetilde{\varphi}^{\prime\prime} (s) ds
-\int\limits_{-r}^{0}d_{\vartheta}\eta (t_{0},\vartheta)
\widetilde {\varphi} (t_{0}+\vartheta)$,
$t\in [t_{0},t_{0}+r] $, $ \widetilde{h} (
t)=-\int\limits_{-r}^{0}d_{\vartheta}\eta (
t_{0},\vartheta) \widetilde{\varphi} (
t_{0}+\vartheta)$, $ t>t_{0}+r$. Преобразуем выражение для
решения $x_{\widetilde{h}}$
\begin{multline*}
x_{\widetilde{h}} (t)=\int_{t_{0}}^{t_{0}+r}dS (
t,\xi) \widetilde{h} (\xi)=\int_{t_{0}}^{t_{0}
+r}dS (t,\xi) \int_{-r}^{t_{0}-\xi} [\eta (
\xi,-r) -\eta (\xi,\vartheta)] d\vartheta
\widetilde{\varphi}^{\prime} (t_{0}) -\\
-\int_{t_{0}-r}^{t_{0}}\int_{t_{0}}^{s+r}dS (t,\xi) \int
_{-r}^{s-\xi} [\eta (\xi,-r) -\eta (\xi
,\vartheta)] d\vartheta\widetilde{\varphi}^{\prime\prime
} (s) ds.
\end{multline*}
Теперь преобразуем выражение для решения $x_{\widetilde{\varphi}}$
$$
x_{\widetilde{\varphi}} (t)=-\int_{t_{0}-r}^{t_{0}}T (
t,\tau,t_{0}) d\tau\widetilde{\varphi}^{\prime} (t_{0})
+\int_{t_{0}-r}^{t_{0}}\int_{t_{0}-r}^{s}T (t,\tau,t_{0})
d\tau\widetilde{\varphi}^{\prime\prime} (s) ds.
$$

Запишем условия совпадения решений $x_{\widetilde{h}}$ и $x_{\widetilde
{\varphi}} $ для произвольных функций $\widetilde{\varphi}\in\Bbb{C}
^{2} ([t_{0}-r,t_{0}],\Bbb{R}^{n})$,
$ t>t_{0}$, $s\in [t_{0}-r,t_{0}]$,
\begin{align*}
\int_{t_{0}}^{t_{0}+r}dS (t,\xi)
\int_{-r}^{t_{0}-\xi} [\eta (\xi,-r) -\eta (
\xi,\vartheta)]
d\vartheta&=-\int_{t_{0}-r}^{t_{0}}T (t,\tau,t_{0})
d\tau,\\
-\int_{t_{0}}^{s+r}dS (t,\xi)
\int_{-r}^{s-\xi} [\eta (\xi,-r) -\eta (
\xi,\vartheta)] d\vartheta&=\int_{t_{0}-r}^{s}T (
t,\tau,t_{0}) d\tau.
\end{align*}
При выполнении второго условия первое выполняется. Дифференцируемость
по $s$ левой части второго условия следует из дифференцируемости правой части
этого условия. Дифференцируя второе равенство по $s$ и производя замену 
переменной, получаем искомую формулу (\ref{G_ur_T_S}).
\end{pf}

\begin{exams}
Дано однородное скалярное уравнение
(\ref{f1}) с функцией $\eta (t,\vartheta)
=t\vartheta$, $r=1$.
\end{exams}

Формула (\ref{G_ur_T_S}) имеет вид $T (t,s,t_{0})
=\frac{d}{ds}\int\limits_{t_{0}}^{s+1}dS (t,\xi)
\frac{\xi}{2} (s-\xi+1) ^{2}$, $t>t_{0}$, $s\in [
t_{0}-1,t_{0}] $. Пусть
$t\in (t_{0},t_{0}+1] $. Если $t_{0}-1\leq s\leq t-1$, то из 
примера 4.1 следует $S (t,\xi)=-1-t\int\limits_{\xi}^{t}e^{\frac
{1}{2} (t^{2}-y^{2}) }dy$ при $\xi\in [t_{0},s+1] $.
Следовательно, $T (t,s,t_{0})=t\int\limits_{t_{0}}^{s+1}e^{\frac{1}
{2} (t^{2}-\xi^{2}) }\xi (s-\xi+1) d\xi$,
$t\in (t_{0},t_{0}+1] $, $s\in [t_{0}-1,t-1] $. Если
$t-1<s\leq t_{0}$, то из примера 4.1 следует $S (t,\xi)
=-1-t\int\limits_{\xi}^{t}e^{\frac{1}{2} (t^{2}-y^{2}) }dy$ при $\xi
\in [t_{0},t]$ и $S (t,\xi)=0$ при $\xi\in [
t,s+1] $. Следовательно, $T (t,s,t_{0})=t\int\limits_{t_{0}}
^{t}e^{\frac{1}{2} (t^{2}-\xi^{2}) }\xi (
s-\xi+1) d\xi+t (s-t+1) $, $t\in (
t_{0},t_{0}+1] $, $s\in [t_{0}-1,t-1] $.
