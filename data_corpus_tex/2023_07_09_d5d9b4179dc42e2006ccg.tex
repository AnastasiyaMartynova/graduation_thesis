Пусть $\Omega=\mathbb{R} n ;$ задача отыскания решения в полосе $D=\mathbb{R} n \times(0, T)$ параболич. системы уравнений (1), удовлетворяющих на характеристике $\Omega_{0}=\{x \in \mathbb{R} n, t=0\}$ начальному условию (2), наз. Коши задачей для уравнения (1). Классич. решением задачи Коши (1), (2) наз. вектор-функция $u(x, t)$, принадлежащая $C^{2} p,{ }^{1}(D) \cap C\left(D \cup \Omega_{0}\right)$ и удовлетворяющая в $D$ системе (1), а на $\Omega_{0}$ - начальному условию (2). Если правая часть $f(x, t)$ принадлежит пространству Гёльдера $C^{\alpha}(\bar{D})$ при нек-ром $\alpha>0$, а коэфффициенты - достаточно гладкие в $\bar{D}$, ограниченные вместе со своими производными функции, то для любой непрерывной и ограниченной в $\mathbb{R} n$ начальной вектор-функции $\varphi(x)$ существует ограниченное в $D$ решение задачи Коши и ограниченное решение задачи Коши единственно.

Условие ограниченности может быть заменено условием «не слишком быстрого роста». Нашр., для уравнения 2-го порядка справедливо следующее утверждение. Пусть коэфффициенты уравнения (1')

\[
a_{i, j}(x, t), b_{i}(x, t), c(x, t) \text { и } \frac{\partial a_{i, j}(x, t)}{\partial x_{i}}
\]

принадлежат пространству Гёльдера $C^{\alpha}(\bar{D})$ при нек-ром $\alpha>0$, а непрерывная в $\mathbb{R}^{n}$ функция $\varphi(x)$ и непрерывная в $\bar{D}$ I локально непрерывная по Гёльдеру по переменным $x$ равномерно по $t \in[0, T]$ (с нек-рым показателем $\alpha>0)$ функция $f(x, t)$ удовлетворяют неравенствам

\[
\begin{gathered}
|\varphi(x)| \leqslant C e^{h|x|^{2}}, x \in \mathbb{R}^{n}, \\
|f(x, t)| \leqslant C e^{h|x|^{2}},(x, t) \in D .
\end{gathered}
\]

Тогда в полосе $D=\mathbb{R} n \times(0, T)$ при достаточно малом (зависящем от $h$ ) $T$ существует решение задачи Коши $\left(1^{\prime}\right),\left(2^{\prime}\right) ;$ оно представляется в виде

\[
\begin{aligned}
& u(x, t)=\int_{\mathbb{R}^{n}} \Gamma(x, t ; \xi, 0) \varphi(\xi) d \xi+ \\
& +\int_{0}^{t} \int_{\mathbb{R}^{n}} \Gamma(x, t ; \xi, \tau) f(\xi, \tau) d \xi d \tau,
\end{aligned}
\]

где $\Gamma(x, t ; \xi, \tau)$ - фундаментальное решение уравнения ( $\left.1^{\prime}\right)$, и удовлетворяет оценке

\[
|u(x, t)| \leqslant C_{1} e^{k|x|^{2}}
\]

с нек-рыми положительными и постоянными $C_{1}$ и $k$. Условие (8) гарантирует единственность решения задачи Коши.

В случае уравнения с постоянными коәффициентами можно указать условие типа (8) на рост решения, необходимое и достаточное для единственности решения задачи Коши. Напр., для того чтобы в классе функций, удовлетворяющих неравенству

\[
|u(x, t)| \leqslant C e^{|x| h(|x|)},
\]

где $h(|x|)$ - положительная непрерывная на $[0, \propto)$ функция, решение задачи Коши для уравнения теплошроводности было единственно, необходимо и достаточно, чтобы расходился интеграл $\int_{0}^{\infty} \frac{d r}{h(r)}$.

Для параболич. уравнений можно рассматривать и задачи без начальных условий (задача Фурье). Напр., для однородного уравнения теплопроводности - задачу отыскания решения этого уравнения в цилиндре $D=\{x \in \Omega,-\infty<t<+\infty\}$, где $\Omega$ - ограниченная область с достаточно гладкой границей $\partial \Omega$, удовлетворяющего краевому условию

\[
\left.u(x, t)\right|_{x \in \partial \Omega}=\psi(x, t)
\]

Если функция $\psi$ непрерывна и ограничена, то существует ограниченное решение задачи Фурье; ограниченное решение задачи Фурье единственно.
