  \section{Введение}

  Область применения результатов настоящей статьи~--- проектирование систем управления 
жесткого реального времени (СУРВ) для объектов, функ\-цио\-ни\-ру\-ющих в~автоматическом 
режиме. Напомним требования к~дискретизации времени и~восстановлению сигнала по 
выборкам, возникающие из особенностей функционирования СУРВ.
  \begin{enumerate}[1.]
  \item Необходимо определить постоянный интервал равномерной дискретизации сигнала 
по времени и~задаться типом аппроксимации сигнала по выборкам. При этом адаптирующая 
аппроксимация с~переменным шагом дискретизации не применяется.
  \item В современных СУРВ используют аппроксимацию ступеньками или отрезками 
прямых линий по выборкам и~существенно реже используют функцию 
$\mathrm{sinc}(x)$~[1, 2].
  \item Необходимо обработку информации и~выдачу сигнала управления на 
исполнительные органы СУРВ проводить за один или два интервала дискретизации времени.
  \item Необходимо обеспечить сохранение значений сигнала без искажений в~точках 
осуществления выборок из сигнала при аппроксимации сигнала. 
  \end{enumerate}
  
  Аппроксимация сигнала по выборкам из него происходит с~погрешностью 
аппроксимации~$\Delta$, равной наибольшему значению разности между первичным 
аналоговым значением сигнала на выходе датчика и~его вторичным значением, 
восстановленным путем аппроксимации величин выборок. Постоянный интервал 
дискретизации времени~$T_s$ зависит от закона аппроксимации и~максимально допустимой 
погрешности аппроксимации~$\Delta$ от максимальных параметров аппроксимируемого 
сигнала~$p(t)$: граничной частоты~$f$ в~спектре частот, наибольшей скорости изменения 
$\max p^{(1)}(t)\hm=V$, наибольшего ускорения изменения $\max p^{(2)}(t)\hm=a$, 
наибольшей резкости изменения $\max p^{(3)}(t)\hm=R$ и~т.\,д. 
  
  Таким образом, можно записать функциональную зависимость от множества параметров:
  \begin{equation}
  T_s\leq F\max \left\{ f, \Delta, V, a, R, \ldots , p^{(n)}(t)\right\}\,,
  \label{e1-m}
  \end{equation}
где $(n)$~--- наибольший порядок максимального значения производной $\max p^{(n)}(t)$ от 
сигнала $p(t)$ по времени, который учитывается при определении~$T_s$. 
  
  Известны три основных метода определения частоты дискретизации $f_s\hm=1/T_s$ или 
постоянного по величине интервала дискретизации времени~$T_s$ в~СУРВ.
  
  Первый метод определен теоремой НКШ (Найквиста, Котельникова, Шеннона)~[3--7].
  
  Теорема НКШ (теорема отсчетов)~\cite{3-m, 4-m} доказана К.~Шенноном на основе 
теоремы В.\,А.~Котельникова~\cite{6-m} и~работы Найквиста~\cite{5-m} и~используется 
в~теории и~технике связи. 
  
  \smallskip
  
  \noindent
  \textbf{Теорема НКШ.} \textit{Если функция не содержит частот выше~$f$~Гц, она 
полностью определяется своими мгновенными значениями в~моменты, отстоящие друг от 
друга на $1/2f$~секунд.}
  
  \smallskip
  
  Интервал времени $1/2 f$ назван Шенноном~\cite{4-m} интервалом Найквиста~\cite{5-m}.
  
  Недостатки теоремы НКШ при решении задач в~управляющих системах СУРВ следуют из 
процедур ее практического использования~\cite{4-m}:
  \begin{enumerate}[(1)]
  \item  восстановление функции происходит в~течение большого времени существования 
$T_c$ этой функции (звукового сигнала) с~последовательным суммированием всех 
мгновенных значений (выборок), которые были сделаны из этой функции. При этом заранее 
известно, что справедливо неравенство $T_c\hm\gg T_s$. В~СУРВ большие задержки при 
обработке сигналов во времени недопустимы;
  \item в устройстве восстановления функции по ее отсчетам в~каждой точке отсчета на 
интервале времени~$T_c$ помещают импульс с~амплитудой, равной величине каждого 
отсчета, на место этого отсчета, осуществляют последовательное преобразование этого 
импульса по передаточной характеристике фильтра нижних частот, результаты 
преобразований накапливают в~течение интервала времени~$T_c$ и~получают исходную 
функцию.
  
  Математически процесс преобразования и~восстановления сигнала~$p(t)$ (звукового 
сигнала) описывается рядом В.\,А.~Котельникова~\cite{5-m, 6-m}:
  \begin{equation}
  p(t)= \sum\limits_{k=1}^{2T_cf} p_k \fr{\sin \pi(2ft-k)}{\pi(2ft-k)}\,,
  \label{e2-m}
  \end{equation}
где $k$~--- номер отсчета (выборки) на интервале времени~$T_c$; $2T_c f$~--- число 
отсчетов на интервале времени~$T_c$; $p_k$~--- амплитуда отсчета с~номером~$k$.

  Выражение~(2) подобно гармоническому ряду Фурье и~является сложным с~точки зрения 
объема необходимых вычислительных операций для его реализации. Выражения для 
ступенчатой и~линейной аппроксимации (для восстановления сигнала по выборкам из него) 
существенно проще в~математическом описании и~реализации;
  \item  применяемые в~практике разработки и~реализации СУРВ методы ступенчатой 
и~линейной аппроксимации вообще не используются и~не упоминаются при доказательстве 
теоремы НКШ~\cite{4-m, 6-m};
  \item в теореме НКШ для определения~$T_s$ используется только граничная частота~$f$ 
в~спектре частот сигнала, а остальные параметры, входящие в~(1), не используются; 
  \item на практике~\cite{8-m} и~в теории~\cite{9-m, 10-m} при использовании теоремы 
НКШ и~ступенчатой или линейной аппроксимации сигнала по выборкам обычно используют 
эмпирическое соотношение $T_s\hm\leq (1/2f)/(8\div 10)$, которое является 
приблизительным и~не имеет строгого теоретического обоснования. Это обусловлено 
большой популярностью и~известностью теоремы НКШ и~делает погрешность расчетов 
неопределенной величиной.
  \end{enumerate}
  
  В связи с~этими и~прочими~\cite{11-m} недостатками нерационально определять интервал 
дискретизации сигнала~$T_s$ по теореме НКШ при осуществлении точных инженерных 
расчетов при использовании ступенчатой и~линейной аппроксимации для восстановления 
сигнала $p(t)$. В~\cite{11-m} сделан справедливый вывод о необходимости использования 
теоремы НКШ только в~теории связи (радиотехнике) для восстановления речевого сигнала, 
но не в~системах управления реального времени. 
  
  Второй подход сводится к~определению критерия наибольшего отклонения (КНО) или 
величины интервала дискретизации времени~$T_s$. Критерий наибольшего
отклонения предложил 
В.\,Н.~Хлистунов~\cite{12-m, 13-m}, который применил для этой цели наибольшее значение 
остаточного члена формулы Лагранжа. Достоинства критерия наибольшего отклонения 
заключаются в~следующем.
  \begin{enumerate}[1.]
  \item 
   Получены и~обоснованы выражения параболического КНО или интервалов 
дискретизации времени $T_{p1}\hm=\Delta / V$ и~$T_{p2}\hm=\sqrt{8\Delta/a}$, которые 
используют параметры~$\Delta$, $V$ и~$a$, входящие в~выражение~(1). Индекс~<<$p$>> 
означает параболическую (parabola) зависимость.
  \item 
  Для восстановления сигнала $p(t)$ по выборкам из него через интервал времени 
$T_{p1}\hm=\Delta /V$ используется ступенчатая аппроксимация. Для интервала 
дискретизации $T_{p2}\hm= \sqrt{8\Delta/a}$  используется линейная аппроксимация.
  \end{enumerate}
  
  Недостатки критерия наибольшего отклонения, которые не определены 
 в~\cite{12-m, 13-m}, следующие.
   \begin{description}
 \item[Недостаток 1.] Отсутствует связь величины граничной частоты~$f$ в~спектре 
сигнала $p(t)$ с~максимальными значениями параметров~$V$ и~$a$ этого сигнала~(1).
  
  \item[Недостаток 2.] Совместное рассмотрение выражений КНО $T_{p1}$ и~$T_{p2}$ 
показывает, что $T_{p1}$ зависит только от максимальной скорости~$V$ 
и~погрешности~$\Delta$ \textit{ступенчатой} аппроксимации сигнала по выборкам, 
а~$T_{p2}$ зависит только от максимального ускорения~$a$ и~погрешности~$\Delta$ 
\textit{линейной} аппроксимации сигнала по выборкам. Зависимость~$T_{p2}$ 
одновременно от скорости и~ускорения сигнала В.\,Н.~Хлистуновым не получена. Это 
обусловлено тем, что его подход к~получению КНО заключается в~использовании 
остаточного члена формулы Лагранжа и~не позволяет (принципиально) получить 
необходимый результат.
  
    \item[Недостаток 3.] Отсутствует возможность определения величины $T_{pn}$ (если 
$n\hm\geq 3$) при условии восстановления сигнала при помощи ступенчатой или линейной 
аппроксимации, так как остаточный член формулы Лагранжа при $n \hm= 3$ содержит 
максимальную величину третьей $\max p^{(3)}(t)\hm=R$ производной от сигнала. При этом 
аппроксимация осуществляется квадратичными параболами по трем точкам, а не отрезками 
прямых линий или ступеньками. Подобный недостаток препятствует определению величины 
шага~$T_{pn}$ дискретизации сигнала $p(t)$ по времени, если $n\hm\geq 3$.
\end{description}
  
  Недостаток~2 КНО устранен автором в~статье~\cite{14-m}, где получено выражение 
в~виде обобщенного критерия наибольшего отклонения для линейной аппроксимации 
сигнала $p(t)$ отрезком прямой линии по двум точкам 
  \begin{equation}
  T_{p2c}=\fr{2\Delta}{V_{21}}+\fr{V_{21}}{a}=\sqrt{\fr{8\Delta}{a}}\,\left( 
\fr{m_V}{2}+\fr{1}{2m_V}\right) =T_{p2}\tau_{2c}\,.
  \label{e3-m}
  \end{equation}
Здесь $m_V\hm = V/V_{21}\hm\geq 1$~--- коэффициент рассогласования скорости сигнала~$p(t)$.

  При $V_{21}=\sqrt{2\Delta a}=V$ (или $m_V\hm=1$) выражение~(3) преобразуется 
в~(2). Выражение $V_{21}\hm=\sqrt{2\Delta a}\hm=V$ названо условием согласования 
максимальных значений параметров $\max\{\Delta, V, a\}$ сигнала~$p(t)$.
  
  Добавка определения <<обобщенный>> к~названию КНО вызвана полученным 
результатом в~виде выражения~(3), которое содержит в~одной формуле все три параметра 
восстановленного сигнала $\max\{\Delta, V_{21}, a\}$, а не по два параметра, как 
в~выражениях КНО В.\,Н.~Хлистунова: $T_{p1}\hm\leq \Delta/V$ и~$T_{p2}\hm\leq 
\sqrt{8\Delta/a}$.
  
  Для использования~(3) при аппроксимации сигнала~$p(t)$ ступенькой по одной точке 
необходимо правую часть выражения~(3) умножить на коэффициент~0,5:
  \begin{equation}
  T_{p2c}=\fr{\Delta}{V_{21}}+\fr{V_{21}}{2a}\,.
  \label{e4-m}
  \end{equation}
  
  Частный случай $T_{p1}\leq \Delta/V$ зависимости~(4) для ступенчатой аппроксимации 
сигнала $p(t)$ получается из~(4) при выполнении над~(4) операции нахождения предела 
($a\hm\to\infty$), если величина ускорения сигнала $p(t)$ неизвестна ($a\hm=?$).
  
  Использование выражений~(3) и~(4) вместо КНО для расчета величины шага 
равномерной дискретизации~$T_{p2c}$ сигнала~$p(t)$ по времени позволяет в~разы 
увеличить эту величину ($\tau_{2c}\hm=T_{p2c}/T_{p2}\hm\gg 1$) без потери точности 
восстановления~\cite{14-m}.
  
  Математическое выражение (траектория), которое описывает возможное изменение 
сигнала~$p(t)$ внутри интервала дискретизации, названа траекторией наибольшего 
отклонения сигнала~$p(t)$~\cite{14-m, 17-m} (далее~--- траектория отклонения). Здесь 
индекс~<<$p$>> обозначает параболический закон траектории отклонения сигнала $p(t)$ от 
двух соседних выборок. Эта математическая модель исследована достаточно подробно 
и~получены необходимые выражения для расчета величины шага равномерной 
дискретизации~$T_{pn}$ сигнала $p(t)$ по времени в~общем случае~\cite{15-m, 16-m}. 
Недостаток~1 параболического КНО не устранен в~явном виде и~в~этих работах. Для его 
устранения рассмотрим не параболическую, а~синусоидальную траекторию наибольшего 
отклонения сигнала~$p(t)$~\cite{17-m} от двух соседних выборок. При этом получим 
необходимые общие выражения для нахождения шага равномерной дискретизации~$T_{sn}$ 
сигнала $p(t)$ для произвольных значений $n \hm= 1, 2, 3,\ldots$ или найдем синусоидальный 
КНО. 
  
  \section{Cинусоидальная траектория наибольшего отклонения}
  
  Уравнение синусоидальной траектории наибольшего отклонения~\cite{17-m, 18-m, 19-m}:
  \begin{equation}
  p(t)=\Delta \sin\omega t\,.
  \label{e5-m}
  \end{equation}
Здесь $0\leq t\leq T_{sn}$, где
$T_{sn}=T/2$; $\omega\hm=2\pi f\hm= 2\pi/T\hm= \pi/T_{sn}$, где $f$~---
граничная частота в~спектре сигнала~$p(t)$, $T$~--- период граничной частоты.
  
  Выражение~(\ref{e5-m}) описывает математически половину ($T_{sn}\hm=T/2$) 
периода~$T$ гармоники частоты~$f$ в~спектре частот сигнала~$p(t)$, которая изображена на 
рис.~1.
  
  Первая выборка из сигнала $p(t)$ осуществлена в~момент времени $t\hm=0$, вторая~--- 
в~момент времени $t\hm=T_{sn}\hm=T/2$. Линейная аппроксимация между двумя 
выборками изображена штрихпунктирной линией. Погрешность такой 
аппроксимации~$\Delta$ достигает максимального значения в~точке $(0{,}5T_{sn}, \Delta)$, 
которая является вершиной траектории отклонения или вершиной полуволны гармоники 
частоты~$f$. Проходящая через вершину вертикальная линия 
$t\hm=0{,}5T_{sn}\hm=0{,}25T$ служит ее осью симметрии.
  
  В статье~\cite{18-m} дана формулировка аналога теоремы  
В.\,А.~Котельникова~\cite{6-m} для случая восстановления сигнала $p(t)$ при помощи 
линейной аппроксимации по выборкам, следующим через интервал Найквиста~$1/2f$.
   
   \smallskip
   
   \noindent
   \textbf{Теорема~1.}\ \textit{Любую функцию $p(t)$, состоящую из гармоник частотой 
от~0 до~$f$, можно восстановить при помощи линейной аппроксимации с~максимальной 
погрешностью~$\Delta$, равной амплитуде гармоники частоты~$f$ при помощи чисел, 
следующих друг за другом через $1/2f$ секунд}.
    
    \smallskip
    
    \begin{figure} %fig1
    \vspace*{1pt}
 \begin{center}
 \mbox{%
 \epsfxsize=85.196mm 
 \epsfbox{mai-1.eps}
 }
 \end{center}

  На основании~(\ref{e5-m}), рис.~1 и~теоремы~1 запишем выражение для определения 
постоянного максимального допустимого шага дискретизации сигнала по 
времени~$T_{sn}$:
  \begin{equation}
  T_{sn}=\fr{\pi}{\omega}=\fr{1}{2f}\,,
  \label{e6-m}
  \end{equation}
где $1/2f$~--- интервал Найквиста~\cite[с.~437]{4-m}. 
  
  Определим шаг дискретизации времени~$T_{sn}$ сигнала, или синусоидальный КНО, 
через максимальные параметры сигнала, которые измерены при исследовании 
сигнала~$p(t)$. Для этого найдем ряд производных от выражения~(\ref{e5-m}) и~приравняем 
их соответствующим максимальным значениям параметров сигнала $p(t)$ из выражения~(1):

\noindent
  \begin{alignat*}{2}
  p^{(0)}(t)&=\Delta \sin\omega t\,,\enskip \hspace*{8pt}\max p^{(0)}\left(t=0{,}5T_s\right)=\Delta\ 
&&\mbox{или}\ \Delta=\Delta\,;\\
  p^{(1)}(t)&=\Delta \omega \cos\omega t\,,\enskip \max p^{(1)}\left(t=0\right)=\Delta\omega=V\ 
&&\mbox{или}\ \ \omega=\fr{V}{\Delta}\,;
  \end{alignat*}

 \noindent
 \begin{alignat*}{2}
  p^{(2)}(t)&=-\Delta \omega^2 \sin\omega t\,,\enskip \max p^{(2)}\left(t=0{,}5T_s\right)=-
\Delta\omega^2=-a\ &\mbox{или}\ \omega&=\sqrt{\fr{a}{\Delta}}\,;\\
  p^{(3)}(t)&=-\Delta \omega^3 \cos\omega t\,,\enskip \max p^{(3)}\left(t=0\right)=-
\Delta\omega^3=-R\ &\mbox{или}\ \omega&=\sqrt[3]{\fr{R}{\Delta}}\,.
  \end{alignat*}
  
  В электромеханических СУРВ затруднительно определить величину частоты граничной 
гармоники в~спектре сигнала (или процесса) и~сам спектр не определен. При этом величина 
интервала равномерной дискретизации времени процесса~(\ref{e6-m}) зависит от 
максимальных параметров аппроксимируемого процесса (сигнала)~(1).
  
  Используем метод математической индукции и~запишем общую цепочку равенств для 
определения круговой частоты: 
  $$
  \omega=\fr{V}{\Delta} =\sqrt{\fr{a}{\Delta}} =
  \sqrt[3]{\fr{R}{\Delta}}=\cdots = \sqrt[n]{\fr{\max 
p^{(n)} (t)}{\Delta}}\,,
  $$
  где $(n)$~--- порядок старшей производной по времени от синусоидальной траектории 
отклонения.
  
  Подставим круговую частоту~$\omega$ в~(\ref{e6-m}) и~запишем цепочку равенств:
  \begin{equation}
  T_{si}= \pi \left[ \fr{\Delta}{\max p^{(i)}(t)}\right]^{1/i}\,,
  \label{e7-m}
  \end{equation}
где $1\leq i\leq n$.

  Цепочка равенств~(\ref{e7-m}) имеет важное свойство.
  
  \smallskip
  
  \noindent
  \textbf{Свойство~1.} Члены цепочки равенств~(\ref{e7-m}), содержащей $(n\hm-1)$ 
звено, повторяются в~цепочке равенств~(\ref{e7-m}), содержащей~$n$ звеньев, так как 
величина~$n$ входит только в~ограничительную часть~(\ref{e7-m}).
  
  \smallskip
  
  На основании свойства~1 запишем равенство ($i\hm-1$)-го и~$i$-го членов 
выражения~(\ref{e7-m}):
  $$
  \pi \left[ \fr{\Delta}{\max p^{(i-1)}(t)}\right]^{1/(i-1)}=\pi \left[ \fr{\Delta}{\max 
p^{(i)}(t)}\right]^{1/i}\,,
  $$
  которое возведем в~степень $i(i\hm-1)$. Найдем параметр~$\Delta$ и~подставим его 
в~\mbox{$(i\hm-1)$-й} член выражения~(\ref{e7-m}). После необходимых преобразований получим 
цепочку равенств:
  \begin{equation}
  T_{si}=\pi \fr{\max p^{(i-1)}(t)}{ \max p^{(i)}(t)}\,,
  \label{e8-m}
  \end{equation}
где $1\leq i\leq n$.

\smallskip

\noindent
\textbf{Пример~1.}\ В выражении~(\ref{e8-m}) зададим $n\hm=1$ и~$i\hm=1$ и~получим 
одиночное выражение для синусоидального КНО: $T_{s1}\hm=\pi \Delta/V$ , 
которое подобно параболическому КНО В.\,Н.~Хлистунова: $T_{p1}\hm=\Delta/V$, что 
указывает на схожесть этих двух типов КНО.

\smallskip

\noindent
\textbf{Пример~2.}\ В~выражении~(\ref{e8-m}) зададим $n\hm=2$ и~$i\hm=1,2$ и~получим 
цепочку равенств: 
$$
T_{s1}=\pi\fr{\Delta}{V}=T_{s2}=\pi\fr{V}{a}\,.
$$ 
Рассмотрим равенство:
$$
\pi\fr{\Delta}{V}=\pi\fr{V}{a}\,,
$$ 
после преобразований получим условие согласования максимальных параметров сигнала: 
$V^2\hm=\Delta a$, или условие справедливости равенства $T_{s1}\hm=T_{s2}$.

\smallskip

\noindent
\textbf{Пример~3.}\ В выражении~(\ref{e8-m}) зададим $n\hm=3$ и~ $i\hm=1,2,3$ 
и~получим  цепочку равенств:
$$
T_{s1}=\pi\fr{\Delta}{V}=T_{s2}=\pi\fr{V}{a}=T_{s3}=\pi\fr{a}{R}\,.
$$ 
Рассмотрим равенства
\begin{equation*}
\pi\fr{\Delta}{V}=\pi\fr{V}{a}\,;\quad
\pi\fr{V}{a}=\pi\fr{a}{R}\,,
\end{equation*} 
после преобразований получим два условия согласования параметров сигнала: 
$V^2\hm=\Delta a$ и~$a^2\hm=VR$. Произведение последних дает $Va\hm=\Delta R$, или 
условие справедливости равенств $T_{s1}\hm=T_{s2}\hm=T_{s3}$.
  
  \smallskip
  
  Из рассмотренных примеров и~выражения~(\ref{e8-m}) следует общее выражение для 
$(n\hm-1)$-го условия согласования параметров сигнала, выполнение которых является 
условием справедливости выражений~(\ref{e7-m}) и~(\ref{e8-m}):
  \begin{equation}
  \max p^{(i)}(t)=\left[ \max p^{(i-1)}(t)\cdot \max p^{(i+1)}(t)\right]^{0{,}5}\,,
  \label{e9-m}
  \end{equation}
  где $1\leq i\leq n\hm-1$, $n\geq 2$.
  
  Выражению~(\ref{e9-m}) соответствует правило:
  
  \textit{Максимальное значение $i$-й производной от синусоидальной траектории 
отклонения по времени равно среднему геометрическому максимальных значений  
$(i\hm-1)$-й и~$(i\hm+1)$-й производной от этой синусоидальной траектории отклонения.}
  
  Теорема~1 и~выражения~(\ref{e5-m}), (\ref{e8-m}) и~(\ref{e9-m}) подтверждают факт 
наличия математических связей всех параметров сигнала $p(t)$~(1).
  
  Недостаток выражений (\ref{e7-m})--(\ref{e9-m}) заключается в~том, они задают цепочки 
равенств~$T_{si}$, которые неудобны для использования, поэтому получим их запись в~виде 
одиночных выражений. Неудобство заключается в~том, что на практике цепочка равенств 
нарушается при подстановке в~нее максимальных параметров сигнала~(1) из-за 
возникновения погрешностей при измерении этих параметров при обследовании объекта 
управления СУРВ.
  
  \section{Преобразование цепочек равенств}
   
  К одиночному компактному выражению, или синусоидальному КНО, предъявим 
требование наличия в~его правой части всех известных максимальных значений параметров 
сигнала~(1) в~степени $\pm1$ и~отсутствие многократных повторов параметров.
  
  \smallskip
  
  \noindent
  \textbf{Теорема~2.}\ \textit{Максимально допустимая величина интервала равномерной 
дискретизации сигнала $p(t)$ по времени}~$T_{sn} (\textit{вместо цепочки  
равенств}~(\ref{e8-m}$)) \textit{определяется выражением}:
  \begin{equation}
  T_{sn}=\fr{\pi}{n}\sum\limits^n_{i=1} \fr{\max p^{(i-1)}(t)}{ \max p^{(i)}(t)}\,,
  \label{e10-m}
  \end{equation}
\textit{где} $\max p^{(0)}(t=0{,}5T_{s1})\hm=\Delta$; $\max p^{(i)}(t)\hm= 
[\max p^{i-1)}(t)\cdot \max p^{(i+1)}(t)]^{0{,}5}$.

\smallskip

\noindent
  Д\,о\,к\,а\,з\,а\,т\,е\,л\,ь\,с\,т\,в\,о\,.\ \ Запишем сумму~$n$~членов левой 
части выражения~(\ref{e8-m}) (для $1\hm\leq i\hm\leq n$): 
$$
\sum\limits^n_{i=1}  T_{si}=n T_{sn}\,,
$$
 где индекс~$i$ поменяем на индекс~$n$, так как в~соответствии со 
свойством~1 и~выражением~(\ref{e8-m}) каждый его член $T_{si}\hm=T_{sn}$. Найдем 
сумму~$n$~членов правой части выражения~(\ref{e8-m}):
  $$
  \pi\sum\limits^n_{i=1} \fr{\max p^{(i-1)}(t)}{\max p^{(i)}(t)}\,.
  $$
   В~результате явного равенства 
двух сумм получим доказательство существования компактного выражения~(\ref{e10-m}) 
для определения величины~$T_{sn}$.
  
  \smallskip
  
  Используем методику доказательства теоремы~2 и~запишем компактное выражение для 
цепочки равенств~(\ref{e7-m}):
  \begin{equation}
  T_{sn}=\fr{\pi}{n}\sum\limits^n_{i=1} \fr{\Delta^{1/i}}{\max p^{(i)}(t)}\,,
  \label{e11-m}
  \end{equation}
где %$1\leq i\hm\leq n$, 
$\max p^{(i)}(t)\hm=\left[\max p^{(i-1)}(t)\cdot \max p^{(i+1)}(t)\right]^{0{,}5}$.
  
  Выражение~(\ref{e11-m}) в~соответствии со свойством~1 эквивалентно 
выражению~(\ref{e10-m}), но имеет недостаток в~виде необходимости определения  
$(n\hm-1)$ корня из повторяющегося параметра~$\Delta$.
  
  \smallskip
  
  \noindent
  \textbf{Пример~4.}\ В~выражении~(\ref{e10-m}) зададим $n\hm=2$ и~$i\hm=1,2$
и~получим цепочку равенств: 
  $$
  T_{s1}=\pi\fr{\Delta}{V}=T_{s2}=\pi\fr{V}{a}\,.
  $$ 
  Запишем сумму: 
  $$
  T_{s1}+T_{s2} =\pi\left( \fr{\Delta}{V}+\fr{V}{a}\right)\,.
  $$ 
  Учтем доказательство теоремы~2 и~результат примера~2. Получим запись 
синусоидального КНО с~учетом известных максимальных значений параметров сигнала~(1) в~степени $\pm1$ и~с~однократным повтором параметров: 
  $$
  T_{s2}=\fr{\pi}{2}\left( \fr{\Delta}{V}+\fr{V}{a}\right)\,,
  $$ 
  где $V^2=\Delta a$. Полученное выражение подобно~(\ref{e3-m}).
  
  \smallskip
  
  \noindent
  \textbf{Пример~5.} В~выражении~(\ref{e10-m}) зададим $n\hm=3$ и~$i\hm=1,2,3$ 
  и~получим цепочку равенств:
  $$
  T_{s1}=\pi\fr{\Delta}{V}=T_{s2}=\pi\fr{V}{a}=T_{s3}=\pi\fr{a}{R}\,.
  $$ 
  Запишем сумму:
   $$
  T_{s1}+T_{s3}=\pi\left( \fr{\Delta}{V}+\fr{a}{R}\right)\,.
  $$ 
  Учтем доказательство теоремы~2 и~результат примера~3. Получим запись 
синусоидального КНО с~учетом известных максимальных значений параметров сигнала~(1) 
в~степени $\pm1$ и~с однократным повтором параметров: 
  $$
  T_{s3}=\fr{\pi}{2}\left( \fr{\Delta}{V}+\fr{a}{R}\right)\,,
  $$
   где $Va=\Delta R$.
  
  \smallskip
  
  \noindent
  \textbf{Пример~6.}\ Из цепочки равенств примера~5 запишем произведение:
  $$
  T_{s1} T_{s3}=\pi^2\fr{\Delta}{V}\,\fr{q}{R}\,.
  $$ 
  Учтем доказательство теоремы~2 и~результат примера~3. Получим запись 
синусоидального КНО с~учетом всех известных максимальных значений параметров 
сигнала~(1) в~степени $\pm0{,}5$ и~с~однократным повтором параметров: 
  $$
  T_{s3}= \pi \sqrt{\fr{\Delta}{V}\,\fr{a}{R}}\,,
  $$ 
  где $Va=\Delta R$.
  
  \smallskip
  
  Недостаток приведенной теоремы~1 и~выражений~(\ref{e10-m}) и~(\ref{e11-m}) 
заключается в~том, что величина максимальной погрешности~$\Delta$ (после 
восстановления сигнала $p(t)$ по выборкам при помощи ступенчатой и~линейной 
аппроксимации) равна амплитуде гармоники граничной частоты~$f$ в~спектре частот 
сигнала $p(t)$. Этот недостаток не позволяет обосновать или уточнить эмпирическое 
соотношение $T_{sn}\hm\leq (1/2f)/(8\div10)$, которое явно приводит к~уменьшению 
интервала дискретизации по сравнению с~интервалом Найквиста $(1/2f)$ в~$(8\div10)$~раз. 
  
  Получим выражение, которое связывает между собой заданную наперед величину 
максимальной погрешности ($\Delta_m\hm<\Delta$), меньшую амплитуды~$\Delta$ 
гармоники частоты~$f$, и~интервал дискретизации~$T_{ms}$, меньший интервала 
Найквиста $(1/2f)$.
  
  \section{Линейная аппроксимация траектории отклонения сигнала }
  
  Для решения этой задачи осуществим равномерную дискретизацию времени внутри 
половины периода граничной гармоники в~спектре сигнала.
  
  К.~Шеннон дает важный комментарий к~теореме НКШ~\cite[с.~435]{4-m}: <<\textit{Это 
общеизвестный в~теории связи факт. Интуитивное подтверждение состоит в~том, что 
если функция $p(t)$ не содержит частот выше~$f$, то она не может существенно 
изменить свое значение за время меньшее, чем половина периода наивысшей частоты, 
т.\,е.}\ $1/2f$>>. 
  
  Траектория синусоидального отклонения в~соответствии с~выражением~(\ref{e5-m}) 
и~рис.~1 описывает экстремальное поведение функции сигнала $p(t)$ внутри половины 
периода наивысшей частоты ($1/2f$) (чем пренебрегает К.~Шеннон). Тем самым 
учитываются отличия СУРВ от систем связи и~передачи звуковых сигналов. 
  
  \subsection{Доказательство теоремы об~уменьшении интервала Найквиста}
   
  Докажем теорему об уменьшении интервала Найквиста для аппроксимации траектории 
синусоидального отклонения (первой полуволны гармоники граничной частоты~$f$ 
в~спектре) отрезками прямых линий в~количестве~$m$ штук.
  
  На рис.~1 показан средний из $m$ штук аппроксимирующий отрезок $[c, d]$, параллельный 
оси абсцисс, проекция которого на ось абсцисс представляет собой отрезок $[t_c, t_d]$.
  
  В соответствии с~рис.~1 запишем выражение для максимальной относительной 
погрешности линейной аппроксимации $\delta_m\hm=\Delta_m/\Delta$.
  
  В соответствии с~рис.~1 и~(\ref{e6-m}) запишем выражение для определения величины 
интервала дискретизации времени:
  \begin{equation}
  T_{ms}=\fr{T_{sn}}{m}=\fr{1}{2fm}\,,
  \label{e12-m}
  \end{equation}
где $m$~--- коэффициент уменьшения интервала Найквиста.
  
  Докажем теорему об уменьшении интервала Найквиста ($1/2f$).
  
  \smallskip
  
  \noindent
  \textbf{Теорема~3.}\ \textit{Любую функцию $p(t)$, состоящую из гармоник частотой 
от~0 до~$f$, с~известной амплитудой~$\Delta$ гармоники~$f$ можно восстановить при 
помощи линейной аппроксимации с~максимальной относительной погрешностью~$\delta_m$ 
по выборкам с~интервалом времени, в} 
  \begin{equation}
  m=\fr{\pi}{2\arccos \left(1-\delta_m\right)}
  \label{e13-m}
  \end{equation}
\textit{раз меньшим, чем интервал Найквиста} ($T_{sn}\hm=1/2f$). 

\smallskip

\noindent
  Д\,о\,к\,а\,з\,а\,т\,е\,л\,ь\,с\,т\,в\,о\,.\ \
  Воспользуемся рис.~1 и~рассмотрим отрезок прямой $[c, d]$, который аппроксимирует 
траекторию синусоидального отклонения по двум соседним выборкам из нее в~моменты 
времени~$t_c$ и~$t_d$.
  
  Определим момент времени~$t_c$ начала горизонтального участка аппроксимации (см.\ 
точку~\textit{c} на рис.~1) с~учетом~(\ref{e12-m}): 
  \begin{equation}
  t_c=0{,}5T_{sn}-0{,}5T_{ms}=0{,}5 T_{sn}\left(1-\fr{1}{m}\right)\,.
  \label{e14-m}
  \end{equation}
  
  В выражение~(\ref{e5-m}) подставим~$t_c$~(\ref{e14-m}), учтем $\omega\hm=\pi/T_{sn}$ 
из~(\ref{e6-m}) и~получим  выражение горизонтального отрезка прямой, проходящей через 
точки~\textit{c} и~\textit{d} (см.\ отрезок $[c, d]$ на рис.~1):
  $$
  p(t_c)=\Delta\sin \left[ \fr{\pi}{2}\left( 1-\fr{1}{m}\right)\right] =\Delta \cos\left( 
\fr{\pi}{2m}\right)\,.
  $$
  
  Зависимость погрешности аппроксимации $\Delta_m$ от времени~$t$ определим как 
разность выражения~(\ref{e5-m}) и~выражения для~$p(t_c)$:
  \begin{equation}
  \Delta_m(t)=\Delta\sin\omega t-\Delta \cos\left( \fr{\pi}{2m}\right)\,.
  \label{e15-m}
  \end{equation}
  
  Выражение для максимального значения относительной погрешности восстановления 
$\delta_m\hm=\Delta_m/\Delta$ получим подстановкой $t\hm=0{,}5T_{sn}$ 
и~$\omega\hm=\pi/T_{sn}$ в~(\ref{e15-m}):
  \begin{equation}
  \delta_m= \fr{\Delta_m}{\Delta}=1-\cos \left( \fr{\pi}{2m}\right)\,.
  \label{e16-m}
  \end{equation}
  
  Из выражения~(\ref{e16-m}) получим число $m$ в~виде выражения~(\ref{e13-m}). 
Число~$m$~(\ref{e13-m}) входит в~выражение~(\ref{e12-m}) и~делит интервал Найквиста 
$T_s\hm=1/2f$ на~$m$~частей, что и~требовалось доказать.
  
  
  \smallskip
  
  \noindent
  \textbf{Пример~7.}\ Для проверки выражения~(\ref{e13-m}) зададим 
$\Delta_m\hm=\Delta$ (или $\delta_m\hm=1$), получим $m\hm=1$, из интервала выборок 
$T_{ms}\hm=T_{sn}/m$~(\ref{e12-m}) получим $T_{ms}\hm=T_{sn}$, или интервал 
Найквиста ($T_{sn}\hm=1/2f$), как частный случай. 
  
  
  Зададим $\Delta_m=0$ (или $\delta_m\hm=0$), получим $m\hm=\infty$, а~из интервала 
выборок $T_{ms}\hm=T_{sn}/m$~(\ref{e12-m}) получим $T_{ms}\hm=0$. 
  
  \subsection{Два эквивалентных варианта итоговых формул }
  
  Выражение~(\ref{e12-m}) для определения равномерного интервала 
дискретизации~$T_{ms}$ сигнала~$p(t)$ при условии использования линейной 
аппроксимации для восстановления по выборкам из~$p(t)$ состоит из двойного равенства, 
поэтому можно записать два эквивалентных выражения.
  
  Из первого равенства~(\ref{e12-m}) и~выражений~(\ref{e13-m}) и~(\ref{e10-m}) запишем:
  \begin{equation}
  T_{ms}=\fr{T_{sn}}{m} =\fr{2}{n}\left[ \arccos \left( 1-\delta_m\right) \right] 
\sum\limits^n_{i=1} \fr{\max p^{(i-1)}(t)}{\max p^{(i)}(t)}\,.
  \label{e17-m}
  \end{equation}
  
  Из второго равенства~(\ref{e12-m}) и~выражения~(\ref{e13-m}) запишем:
  \begin{equation}
  T_{ms}=\fr{1}{2fm}=\fr{\arccos (1-\delta_m)}{\pi f}\,.
  \label{e18-m}
  \end{equation}
  
  В выражения~(\ref{e17-m}) и~(\ref{e18-m}) входят все параметры сигнала $p(t)$, как 
и~в~функциональную зависимость в~общем виде~(1), что показывает достижение цели 
исследования.

  \section{Заключение}
  
  В СУРВ применяют в~основном ступенчатую или 
линейную аппроксимацию сигнала по равномерным выборкам из него. Это ограничивает 
применение в~СУРВ теоремы НКШ, по которой сигнал восстанавливают при помощи ряда 
В.\,А.~Котельникова, что приводит к~большим задержкам восстановления во времени.
  
  Показано, что замена аппроксимирующего ряда Котельникова на аппроксимацию 
ступеньками или отрезками прямых приводит к~абсолютной погрешности аппроксимации 
выборок, равной амплитуде граничной гармоники в~спектре сигнала. Рассмотрены два пути 
уменьшения этой погрешности и~больших задержек во времени:
  \begin{enumerate}[(1)]
  \item  использование общеизвестной эмпирической формулы   
уменьшает интервал Найквиста в~8--10~раз при использовании ступенчатой или 
линейной аппроксимации сигнала. При этом погрешность восстановления сигнала по 
выборкам ступеньками достигает 2,6\%--3,8\%;
  \item  предложена математическая модель: траектория наибольшего отклонения в~виде 
полуволны граничной гармоники в~спектре сигнала. Получен синусоидальный критерий 
наибольшего отклонения в~виде выражений для нахождения величины интервала 
равномерной дискретизации времени сигнала, который подобен авторскому 
параболическому критерию наибольшего отклонения~\cite{14-m, 17-m}. 
  \end{enumerate}
  
  Доказана теорема об уменьшении интервала Найквиста, которая позволяет определять 
величину интервала равномерной дискретизации времени сигнала через процедуру 
дискретизации экстремальной модели сигнала в~виде полуволны граничной гармоники 
в~спектре сигнала. При этом величина интервала равномерной дискретизации времени 
сигнала~(\ref{e18-m}) зависит от частоты граничной гармоники в~спектре сигнала 
и~необходимой величины относительной погрешности ступенчатой или линейной 
аппроксимации сигнала по выборкам.
  
  В электромеханических СУРВ сложно определить величину частоты граничной 
гармоники в~спектре сигнала (или процесса), да и~сам спектр не определен. Для этого случая 
предлагается использовать~(\ref{e17-m}) вместо~(\ref{e18-m}). При этом величина 
интервала равномерной дискретизации времени сигнала~(\ref{e17-m}) зависит от 
максимальных параметров аппроксимируемого процесса и~необходимой величины 
относительной погрешности ступенчатой аппроксимации или линейной аппроксимации 
процесса по выборкам.
