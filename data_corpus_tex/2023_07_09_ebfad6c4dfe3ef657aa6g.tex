ЭКСПЕРИМЕНТЫ С АВТОМАТАМИ - способ получения инфорорации о внутренней структуре автоматов по их поведению, причем такой информации, к-рую можно получить из внешних әкспериментов (т. е. таких эксшериментов, когда на вход автомата подаются входные слова, обозревается соответствующая последовательность выходных слов и на основе этих наблюдений делаются выводы).

При помощи Э. с а. можно искать подходы к решению слгедующих задач.

\begin{enumerate}
  \item Известно, что автомат находится в одном из состояний, наз. начальным. Требуется ошределить әто состояние автомата.

  \item Построение әксперимента, переводящего автомат из любого состояния в нек-рое наперед заданное (установочная задача).

  \item Проверка автомата на исправность. Путем эксперимента требуется узнать, правильно ли функционирует заданный автомат.

  \item Диагностика автомата. Требуется узнать не только то, исправен ли автомат, но также и то, какая пменно неисправность имеет место.

  \item Задача распознавания автомата из заданного классd (расшифровка), Известно, что «черный ящик» совпадает с одним из автоматов данного множества. Требуется узнать, с каким именно автоматом имеется совпадение.

\end{enumerate}

Некоторые результаты. Автомат Мура $A$ с $r$ состояниями, $m$ входными и $p$ выходными символіаи наз. $(r, m, p)$-автоматом. Справедлива те о р е м а $о$ т о т Л Иим ч с ти с остоя ти И ә к с п е р и м е н т о м: если $A$ есть $(r, m, p)$-автомат и все его состояния пошарно отличимы, то отличимость любых двух состояний может быть установлена простым әкспериментом длины $r-1$ и граница $r-1$ не может быть понижена (см. [4]).

Задачу определения начального состояния автомата можно решать с помощью простого безусловного әксперимента длины $\lambda$, где

\[
3^{\frac{r}{6}\left(1+\varepsilon_{1}\right)} \leqslant \lambda<3^{\frac{r}{6}\left(1+\varepsilon_{2}\right)}\left(\varepsilon_{1}, \varepsilon_{2} \rightarrow 0 \text { гіри } r \longrightarrow \infty\right) .
\]

Установочную задачу для автомата с $r$ состояниями, $k$ из к-рых являются допустимыми, всегда можно решать с помощью простого безусловного әксперимента длины $\lambda$, где $\lambda \leqslant(2 r-k)(k-1) / 2$, и эта граница не может быть улучшена.

Указанные выше оценки, как правило, достигаются јишь для небольшой доли автоматов. Установлено (см. [4]), что задачу определения начального состояния для почти всех $(r, m, p)$-автоматов с двумя допустимыми состояниями решаю' простым безусловным әкспериментом длины $\lambda$, где $\lambda \leqslant \log _{m} \cdot \log _{p} r+4$, а установочную задачу для почти всех $(r, m, p)$-dвтоматов можно решать с помощью шростого безусловного эксщеримента длины $\lambda$, где $\lambda<5 \log _{p} r$.

Не существует алгоритма, к-рый позволил бы расшифоровать инициальные автоматы Мили, для к-рых ничего не известно о числе состояний. Однако оказывается, что большую часть таких автоматов все-таки можно расшифровать.
