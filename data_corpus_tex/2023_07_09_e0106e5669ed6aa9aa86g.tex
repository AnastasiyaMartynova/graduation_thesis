ШІТИЕЛЯ МНОГООБРАЗИЕ (вещественное) - многообразие $V_{n, k}$ ортонормированных $k$-реперов в $n$-мерном евклидовом пространстве. Аналогично оиределяются комплексное III. м. $W_{n, k}$ и кватернионное ШІ. м. $X_{n, k}$. ІІІ. м. являются компактными вещественно-аналіттич. многообразиями, а также однородными пространствами классич. компактных групп $O(n), U(n)$ и $\mathrm{Sp}(n)$ соответственно. В частности, $V_{n, 1}=S^{n-1}, W_{n, 1}=S^{2 n-1}, X_{n, 1}=S^{4 n-1}$ являютея сферами, ШШ. м. $V_{n, 2}$ есть многообразие единІІчных касательных векторов к $S^{n-1}$, III. м. $V_{n, n}$, $W_{n, n}, X_{n, n}$ отождествляются с группамі $O(n), U(n)$, $\operatorname{Sp}(n)$, a $V_{n, n-1}-\mathrm{c}$ группой $S O(n)$. Рассматриваотся также некомпактные ІІ. м., состоящие из всевозможных $k$-реперов в $\mathbb{R}^{n}, \mathbb{C}^{n}$ или $\mathbb{H}^{n}$.

Эти многообразия были введены Э. Штифелем [1] в связи с изучением систем линейно независимых векторных полей на гладких многообразиях. Начатое в [1] изучение топологии III. м. привело затем к полному вычислению их когомологиіі (см. [2], [3]). В частности,

\[
H^{*}\left(W_{n, k}, \mathbb{Z}\right)=\Lambda_{\mathbb{Z}}\left(x_{2 n-1}, x_{2 n-3}, \ldots, x_{2(n-k)+1}\right),
\][

H\^{}\{*\}\textbackslash left(X\_\{n, k\}, \textbackslash mathbb\{Z\}\textbackslash right)=\textbackslash Lambda\_\{\textbackslash mathbb\{Z\}\}\textbackslash left(x\_\{4 n-1\}, x\_\{4 n-5\}, ···, x\_\{4(n-k)+3\}\textbackslash right),
]

$H^{*}\left(V_{n, k}, \mathbb{Z}_{2}\right)$ есть коммутативная алгебра с образующими $x_{n-k}, x_{n-k+1}, \ldots, x_{n-1}$ и соотношениями

\[
x_{i} x_{j}= \begin{cases}x_{i+j}, & \text { еслиг } i+j \leqslant n-1, \\ 0, & \text { если } i+j>n-1\end{cases}
\]

(через $x_{l}$ всюду обозначен элемент степени $l$ ). Вещественные, комплексные и кватернионные III. м. асферичны в размерностях не более $n-k-1,2(n-k)$ и $4(n-k)+2$ соответственно, причем

\[
\begin{gathered}
\pi_{n-k}\left(V_{n}, k\right) \cong\left\{\begin{array}{l}
\mathbb{Z}, \text { если } k=1 \text { пли } n-k \text { четно, } \\
\mathbb{Z}_{2}, \text { если } k>1 \text { или } n-k \text { нечетно; }
\end{array}\right. \\
\pi_{2(n-k)+1}\left(W_{n, k}\right) \cong \pi_{4}(n-k)+3\left(X_{n, k}\right) \cong \mathbb{Z} .
\end{gathered}
\]

По поводу вычисления цругих гомотопич. групп III. M. CM. [5].

\[

Здесь $\tau M$-касательное расслоение многообразия $M$, а $[M] \in H_{*}\left(M ; \mathbb{Z}_{2}\right)-$ фундаментальный класс. Для многообразий размерности $n$ III. ч. зависят лишь от однородной компоненты степени $n$ класса $x$. Группа $H^{n}\left(B O ; \mathbb{Z}_{2}\right)$ изоморфіа векторному пространству над полем $\mathbb{Z}_{2}$ с базисом, находящимся во взаимно однозначном соответствии с множеством всех разбиений $w=$ $=\left\{i_{1}, \ldots, i_{k}\right\}$ числа $n$, т. е. наборов $\left\{i_{1}, \ldots, i_{k}\right\}$ целых неотрицательных чисел с $i_{1}+\ldots+i_{k}=n$. В качестве базпса групшы $H^{n}\left(B O ; \mathbb{Z}_{2}\right)$ сстественно взять классы $\boldsymbol{w}_{\boldsymbol{\omega}}=w_{i_{1}} w_{i_{2}} \ldots w_{i_{k}}$. Поэтому с точки зрения характеризациіг многообразия его Ш. ч. достаточно рассматривать классы $w_{\omega}$, где $\omega$-разбиение размерности многообразия.

Бордантные многообразия имеют одинаковые Ш. ч., так что каждый характеристич. класс $x$ оиределяет гомоморфизм $x\left[\right.$ ]: $\mathfrak{\Re}^{n} \longrightarrow \mathbb{Z}_{2}$, где $\mathfrak{N}^{n}-$ группа классов бордантных неориентированных многообразий размерности $n$. Если для двух замкнутых многообразий $M, N$ имеет место равенство $w_{\omega}[M]=w_{\omega}[N]$ при всех разбиениях $\omega$ числа $n=\operatorname{dim} M=\operatorname{dim} N$, то многообразия $M$ и $N$ бордантны (теорем а Тома).
