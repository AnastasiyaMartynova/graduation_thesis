\section{ Введение}

Повышение эффективности транспортировки грузов по железнодорожным
путям требует решения задачи прогнозирования объемов и~времени перевозок грузов
с ветки на ветку и~загруженности железнодорожных узлов на
основании данных о времени прибытия и~отправления вагонов.
Решение этой задачи необходимо для повышения качества управления
в~сложных инфокоммуникативных средах~\cite{SSI1}. Управленческие решения
принимаются на основании работы систем сбора статистической информации
высокой точности и~доступности~\cite{SSI3, SSI2}.
Данная работа расширяет и~уточняет метод решения задачи прогнозирования,
изложенный в~статье~\cite{Valkov2012NP}. Используемый
в~ней алгоритм основан на алгоритме
квантильной регрессии~\cite{Koenker1978RQ, Postnikova2006KR},
модифицированном сверткой
гистограммы с~функцией потерь, что позволяет учитывать стоимость ошибок
в~реальной задаче.

Для получения прогноза по временн$\acute{\mbox{о}}$му ряду предлагается построить
гис\-то\-грам\-му.
Прогнозируемое значение (последующий элемент временного ряда) ищется как значение,
соответствующее оптимальному значению свертки гистограммы и~функции потерь,
которая задана исходя из экспертных предположений об экономических потерях при
недостаточном или избыточном наличии составов на железнодорожном узле.
В~работе~\cite{Valkov2012NP} показано, что данное решение находит более
точные прогнозы в~сравнении с~алгоритмом ARMA (autoregressive--moving-average)~\cite{Cortez2004ARMA,Shumway2006ARMA},
также используемым для решения подобных задач. Кроме того, данное решение
позволяет в~некоторых случаях решить задачу, когда алгоритм ARMA не может работать.

Согласно работе~\cite{Tihonov2006P}, в~настоящее время насчитывается
свыше 100 классов моделей прогнозирования, в~связи с~чем возникает
задача выбора моделей, которые давали бы адекватные прогнозы для
изучаемых процессов или систем. Одними из основных методов решения
подобных задач являются методы непараметрической регрессии
и~модификации, такие как ядерное сглаживание, сглаживание сплайнами,
авторегрессия, скользящее среднее и~др., описанные в~[10--13].
Они заключаются в~комбинации взвешенных значений элементов
временн$\acute{\mbox{о}}$го ряда для получения прогноза. Также для решения подобных
задач применяют нейронные сети ~\cite{Thiesing1997NN, Gheyas2009NN}.

Данные, описывающие объемы грузоперевозок, имеют следующий формат.
Для каждой станции для каждого дня запись содержит число вагонов с~грузами
различного типа с~указанием ветки прибытия и~отправления. Для построения
прогнозов используются временн$\acute{\mbox{ы}}$е ряды двух типов:
\begin{enumerate}[(1)]
    \item число отправленных с~ветки вагонов с~грузом конкретного типа;
    \item  число отправленных на заданную ветку вагонов с~грузом конкретного типа.
    \end{enumerate}

Основной идеей и~новизной работы является использование для прогноза временн$\acute{\mbox{ы}}$х
рядов грузоперевозок по парам веток, в~отличие от ранее предложенного метода,
использовавшего грузоперевозки по одному узлу. Это позволяет точнее отслеживать
особенности грузоперевозок между различными парами веток
и,~как следствие, точнее предсказывать будущие перевозки. В~данной работе
предполагается, что благодаря рассмотрению более детализированных данных
по перевозкам удастся выявить тренды и~периодичность. С~другой стороны, решение
этой задачи может сделать весь прогноз в~целом более точным.

\section{ Постановка задачи гистограммного прогнозирования}

Задан набор временн$\acute{\mbox{ы}}$х рядов, в~котором временной ряд $\mathbf{x} \hm=
\{x_i\}_{i=1}^T$, и~горизонт
отсрочки прогноза $h$ (число отсчетов от конца временн$\acute{\mbox{о}}$го ряда до
точки прогноза включительно). Требуется спрогнозировать следующую
точку~$x_{T+1}$ временн$\acute{\mbox{о}}$го ряда~$\mathbf{x}$ так, чтобы выполнялось условие
оптимальности функции потерь~($\ref{loss}$) и~свертки гистограммы~($\ref{hist_def}$), построенной по значениям
временн$\acute{\mbox{о}}$го ряда.

Гистограмма $\mathcal{H}$~--- набор пар
\begin{equation}
\label{hist_def}
\mathcal{H} = \{(y_k,g_k)\}_{k=1}^K,
\end{equation}
где $K$~--- число интервалов $\left[y_k^{\min},y_k^{\max}\right]$
%где $K$~--- число интервалов $[y_k^{\text{min}},y_k^{\text{max}}]$
со средним значением~$y_k$, на которые разбита ось значений ряда~\textbf{x};
$g_k$~--- высота столбца гистограммы на интервале $\bar y_k$,
равная взвешенной сумме количества точек ряда, попавших в~этот интервал.

Предполагается, что ряд $\mathbf{x} = \{x_i\}_{i=1}^T$
стационарен, т.\,е.\ совместное распределение вероятностей~$T$
наблюдений $x_1,x_2,x_3,\ldots,x_T$ совпадает с~распределением
$x_{1+\tau},x_{2+\tau},x_{3+\tau}\ldots ,x_{T+\tau}$ при любых~$T$
и~$\tau$.

Введем функцию потерь $L(\hat{y},y)$~--- штраф за несоответствие
прогнозируемого значения~$\hat{y}$ историческому значению~$y$.
Например:
\begin{enumerate}[(1)]
    \item  $L(z,x) = (z-x)^2$;
    \item  $L(z,x) = |z-x|$;
    \item  $L(z,x) = \displaystyle\begin{cases}
                           0, &\mbox{если} |z-x|<a\,;\\
                           |z-x|-a,  &\mbox{если} |z-a|\geq a\,,
                            \end{cases}$\newline
где  $a>0$~--- экспертно заданный параметр.
\end{enumerate}
В данной работе используется функция
\begin{equation}
\label{loss}
    L(z,x) = |z-x|\,.
\end{equation}

Задача нахождения прогнозируемого значения~$\hat{y}$
временн$\acute{\mbox{о}}$го ряда с~использованием функции~$L$ имеет вид:
\begin{equation*}
%\label{forecast}
   \hat{y} = \mathop{\mathrm{argmin}}\limits_{z\in\mathbb{N}}
   \sum\limits_{k=1}^K{L(z,y_k)}\,,
\end{equation*}
где связанная переменная $z$ принадлежит множеству натуральных
чисел, так как требуется спрогнозировать число вагонов.

Пусть построен прогноз значений ряда $\{\hat{y_1}, \hat{y_2},\ldots, \hat{y_k}\}$
в~некоторых точках, при этом реальные значения ряда~\textbf{x} в~этих же точках равны
$\{{y_1}, {y_2}, \ldots {y_k}\}$. Эти значения не использовались при
построении прогноза и~нужны для получения ретроспективной оценки
качества прогностической модели. Вычислим среднюю ошибку ретроспективного
прогноза:
\begin{equation}
\label{MeanEr}
\text{MeanError} = \fr{1}{k}\sum\limits_{i=1}^{k} L(\hat{y_i}, y_i) \to
\min\limits_{\hat{y_1},\ldots ,\hat{y_k}}.
\end {equation}

Чем меньше средняя ошибка, тем точнее прогноз. Таким образом, требуется
решить задачу минимизации средней ошибки прогнозирования, т.\,е.\
найти значения $\{\hat{y_1}, \hat{y_2}, \ldots ,\hat{y_k}\}$ такие, что
значение $\text{MeanError}$ минимально.


\section{Алгоритм прогнозирования}

Первым шагом работы алгоритма является разбиение исходных данных для
получения временн$\acute{\mbox{ы}}$х рядов. Для каждого дня~$\tau$
для всех возможных
комбинаций типа груза~$G$, веток отправления и~прибытия~$L$ и~$A$
считается число вагонов с~грузом~$G$, отправленных в~день~$\tau$
с~ветки~$L$ на ветку~$A$. При фиксированных значениях $G$, $L$ и~$A$
получаем зависимость числа вагонов от дня $\tau$, т.\,е.\ временн$\acute{\mbox{о}}$й
ряд~\textbf{x}. Если при фиксированных значениях~$G$ и~$L$ просуммировать
временн$\acute{\mbox{ы}}$е ряды для разных веток прибытия~$A$, то получим временной
ряд, соответствующий суммарному количеству отправленных грузов
определенного типа с~ветки~$L$.

Вторым шагом работы является применение базового алгоритма
к полученным на первом этапе временн$\acute{\mbox{ы}}$м рядам для построения прогнозов.
Базовый алгоритм основан на описанном в~\cite{Valkov2012NP} алгоритме
непараметрического прогнозирования вре\-мен\-н$\acute{\mbox{о}}$го ряда. Для построения
гистограммы~($\ref{hist_def}$) для каждой точки~$i$ временн$\acute{\mbox{о}}$го ряда~$\mathbf{x}$
определим ее вес
как произведение $w_i\hm=w_i^F w_i^H$. Сомножитель~$w_i^F$ задает
показательную весовую функцию
\begin{equation}
\label{forget}
w_i^F = v^{(-i+T+h)/{F}} \in(0\,,1]\,,
\end{equation}
убывающую к~началу временн$\acute{\mbox{о}}$го ряда и~равную~1 в~точке прогноза.
Сомножитель~$w_i^H$ задан как

\noindent
\begin{equation}
\label{period}
    w_i^H = \begin{cases}
                K(i_H, PH)\,, &\ \mbox{если }  H>0\,;\\
                1\,, &\ \mbox{если  } H=0\,,
            \end{cases}
\end{equation}
где индекс $H$ вычисляется в~результате решения оптимизационной
задачи
\begin{equation}
\label{optim}
i_H = \min\limits_{n=0,\ldots,\mbox{\scriptsize floor}\left((T+h)/P\right)}
\left\vert T+H-nP-i\right\vert \,.
\end{equation}
Эта формула задает вес $i$-й точки, соответствующей годовой
сезонности. Ядро задается выражением:

\noindent
$$
    K(x,z) = \begin{cases}
                \left( 1 - \left(\fr{x}{z}\right)^2\right)^2\,, &\
                \mbox{если } |x|<z\,;\\
                0 &\ \mbox{иначе}.
            \end{cases}
$$
Взвешенные точки $x_i w_i$ используются для построения~(\ref{hist_def})
гистограммы~$\mathcal{H}$.

Настраиваемые параметры:
 $v\hm\in[0,1]$ в~выражении~(\ref{forget})~--- параметр показательного
 взвешивания точек ряда, параметр <<забывания>>;
 $H\hm\in[0, 0,5]$ в~выражениях~(\ref{period}) и~(\ref{optim})~---
 параметр ядра весовой функции для годовой
    сезонности, половина  ширины <<шапки>> годовой сезонности.

Ненастраиваемые параметры: $P$ в~выражениях~(\ref{period}) и~(\ref{optim})~---
длина годового сезонного периода (обычно
    $P\hm=365$);
$w^{\min}$ в~выражении~(\ref{weighted_sum})~--- минимальный
допустимый вес; $F$~в~выражении~(\ref{forget})~--- нормировочная
константа <<забывания>>. Предлагается выбрать~$F$ следующим
образом: $F \hm= (T+H)\varepsilon\log_{10}(0,1)$, где $\varepsilon\hm =
10^{-3}$.

Выберем границы гистограммы, число столбцов и~разбиение на столбцы
следующим образом:
\begin{enumerate}[(1)]
    \item  пусть $n$~--- число точек~$x_i$, для которых
    $w_i>w^{\min}$;
    \item  выберем число столбцов (обоснование см.\ в~\cite{Scott1979HG})
    $K \hm= \lceil 3\sqrt[3]{n}\,\rceil$;
    если $K\hm<5$, то $K\hm=5$, если $K\hm>100$, то $K\hm=100$;
    \item  границы $y_1 = \min\limits_{i:w_i>w^{\min}}(x_i)$, $y_k \hm=
    \max\limits_{i:w_i>w^{\min}}(x_i)$;
    \item  столбцы выбираются равной ширины.
\end{enumerate}

Для каждого $k=1,\ldots,K$ высота столбца гистограммы~$g_k$ равна

\noindent
\begin{equation}
\label{weighted_sum}
    g_k = \sum\limits_{i=1}^T w_i\left[x_i\in y_k\right]\left[w_i>w^{\min}\right],
\end{equation}
где выражение $[\cdot]$ равно~1, если в~скобках стоит истинное
логическое выражение, и~0~в~противном случае.

Прогнозируемое значение ряда $x_{T+h}$ находится как значение
$\hat{y}\hm\in\{y_1,\ldots,y_K\}$, соответствующее оптимальному
значению свертки распределения $\{g_k\}_{k=1}^K$ и~функции
потерь~$L$:

\noindent
\begin{equation*}
%\label{forecast}
    \hat{y} =
    \mathop{\mathrm{argmin}}\limits_{z\in\{y_1,\ldots,y_K\}}\sum\limits_{k=1}^K{g_k
    L(z,y_k)}\,.
\end{equation*}

\section{Эксперимент}
\label{experiment}

\textit{Цель эксперимента.} Сделать прогноз для заданных комбинаций
<<пара ве\-ток\,--\,гру\-зы>>, проверить, что разбиение данных
по веткам повышает качество прогноза базового алгоритма.

железнодорожных узлов с~1~января 2007~г.\ по 22~апреля 2008~г.

последние 100~дней образовывали контрольную выборку, а~первые~300~--- обучающую.

\section{Оценка результатов}

На рис. \ref{fig:Mean_error} показано, что средняя относительная ошибка
прогноза для разных веток почти всегда меньше, чем ошибка прогноза для
суммарного числа вагонов. Это означает, что прогноз количества отправленных грузов
на определенную ветку в~среднем точнее, чем прогноз суммарного числа вагонов.
Однако есть и~грузы, для которых средняя ошибка прогноза для некоторой конкретной
ветки превосходит ошибку прогноза суммарного числа отправленных вагонов.

Это же подтверждают графики на рис.~\ref{fig:Error_comp}, которые дают более
подробную информацию о средней ошибке прогнозирования для некоторых грузов.
В~целом, средняя относительная ошибка для веток меньше, чем уровень ошибки для
суммарного количества. Тем не менее есть и~значения ошибок, б$\acute{\mbox{о}}$льшие уровня
ошибки для суммарного количества. С~другой стороны, видно, что веток, для
которых средняя ошибка прогноза превосходит ошибку для прогноза суммарного
количества грузов, немного (таких нет для груза~2, и~5--10 для остальных
рассмотренных типов грузов).



Результаты второго эксперимента~--- на рис.~\ref{fig:Mean_errors_comp}.
Таблица~\ref{table_errors} также подтверждает тот факт, что средняя ошибка
для прогноза количества грузов, отправленных на конкретные ветки, меньше,
чем такая же ошибка для прогноза суммарного количест\-ва отправленных грузов.
Однако средняя ошибка в~некоторых случаях меньше минимальной~--- минимум брался
по всем ненулевым значениям, иначе он был бы равен нулю для всех грузов,
поскольку для каждого груза есть ветка, на которую такой груз с~83-й ветки не
прибывает в~течение рассматриваемого периода. Рисунок~\ref{fig:Mean_errors_comp}
наглядно демонстрирует, что, во-пер\-вых, усредненная по всем веткам подсчитанная
ошибка существенно меньше, чем ошибка для суммарного количества грузов.
Во-вто\-рых, максимальная ошибка по веткам если и~превосходит ошибку для суммы,
то ненамного~--- более того, можно заметить, что они зачастую совпадают
или очень близки.



\section{Заключение}

Поставлен вычислительный эксперимент, который подтвердил предположение
о~том, что прогноз для отдельных веток точнее, чем прогноз суммарного
числа отправленных вагонов. Приведенные результаты подтверждают выдвинутое
предположение. Дальнейшие исследования данной задачи могут быть продолжены
в~следующих направлениях: во-пер\-вых, для прогноза количества отправленных
грузов можно попытаться в~рассматриваемых временн$\acute{\mbox{ы}}$х
рядах выделять тренд и,~если
возможно, искать периодическую компоненту. Во-вто\-рых,
для построения прогноза предлагается применить различные варианты алгоритма.
Например, использовать вариацию со скользящим средним.

\Abste{The article is devoted to research of the algorithm of nonparametric
forecasting of railway cargo transportation capacity.
The problem considered is\linebreak\vspace*{-12pt}}

\Abstend{forecasting the number of wagons with various goods,
following various routes. The topology of the railway network is given~---
for all possible pairs of railway lines, information about all blocks
of wagons, which have moved from one line to another, including the number
of wagons in a~block, the type of cargo, and the date of the route, is provided.
The algorithm, based on convolution of the empirical density distribution of
the values of time series with the loss function is used for prediction.
Previously, forecasting was carried out for each railway junction separately.
It is proposed to be improved by the quality of forecasting predicting
by pairs of lines instead of predicting departure of all wagons from the given
junction. The algorithm is illustrated by the daily data on transportation
of~38~types of cargo collected during a~year and a~half.}
