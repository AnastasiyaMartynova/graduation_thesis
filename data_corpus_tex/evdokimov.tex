\workabstract{С помощью интегрального преобразования Лапласа получены аналитические 
решения ряда циклических тепловых задач, включая задачи контактного 
теплообмена для системы двух бесконечных пластин с~термическим 
сопротивлением в~зоне контакта при различных условиях внешнего теплообмена. 
Для квазиустановившейся стадии процесса решения получены двумя методами 
в~форме систем интегральных уравнений Фредгольма. Решения учитывают 
циклическое инициирование разнородных по характеру теплообразующих 
источников. Тепловой поток трения локализован в пределах пограничного 
термического слоя.}

\engabstract{Analytic solutions to a number of cyclic heat problems, including those of contact heat exchange for a system of two infinite plates presenting thermal resistance within the contact zone under various conditions of external heat transfer, have been provided using the integral Laplace transformation.  Solutions for the quasi-steady-state process stage were provided, using two methods, as sets of Fredholm integral equations. The solutions allow for cyclic initiation of heterogeneous heat-generating sources, the thermal friction flow being within the boundary thermal layer.}

\maketitle


Вопросы управления и оптимизации большой группы процессов технологической 
теплофизики (это прежде всего процессы горячей обработки металлов давлением) 
связаны с необходимостью решения циклических тепловых задач контактного 
теплообмена с чередующимися краевыми условиями (IV$\rightleftarrows$II)-го 
(или (IV$\rightleftarrows$III)-го, (IV$\rightleftarrows$I)-го) рода на контактной поверхности. 
Обычно задачи такого класса решаются на 
основе редукции, а~это неизбежно приводит к~схематизации контактных систем 
разобщёнными (одноэлементными) моделями с~однородными граничными условиями 
II-го или I-го рода, при этом автоматически возникают (и~во многом 
остаются открытыми) вопросы выбора мощности и~точности разнородных 
и~одновременно действующих тепловых источников (определение которых требует 
решения обратных тепловых задач) как в~зонах контактирования объектов, так 
и~в~зонах их пространственной аккумуляции. К~последним следует прежде всего 
отнести тепловые потоки $q_v$ от трения тел по контактной поверхности, 
тепловые потоки $q_w$ от пластического формоизменения отдельных элементов 
и~тепловые потоки $q_f$  от начального теплосодержания элементов. 
С~позиций временной схематизации и~циклического характера реальных 
теплоконтактных систем в~математической модели циклическое температурное 
воздействие можно представить состоящим из непрерывной последовательности 
следующих друг за другом единичных циклов контактирования ($m$ "--- номер 
произвольного цикла), каждый цикл включает контактный период длительностью $\tau _c $ 
и~неконтактный  длительностью $\tau _r $ 
(длительность цикла $\tau ^ + = \tau _c + \tau _r $ ).

Наиболее важной с практической точки зрения является квазиустановившаяся 
стадия процесса ($m \to \infty $), когда достигаются предельно допустимые 
эксплуатационные температуры технических объектов, поэтому ниже предлагаются 
два возможных аналитических подхода определения указанных температур, причём 
первый из них учитывает некоторые специальные условия (последовательные 
допущения), а~второй "--- условия сопряжения. Каждый из методов может быть 
реализован как для одного теплоисточника, так и~для их совокупности, но 
в~последнем случае математические выкладки и~итоговые решения становятся 
весьма громоздкими. Поэтому в~первой из рассматриваемых ниже задач 
учитывается источник начального теплосодержания $q_f $ (соответствующим 
величинам приписывается индекс $f$ ), а~во второй $q_v$, и~при этом присваивается 
индекс $v$. С~целью наглядности и~возможности последующего численного анализа 
рассмотрим циклическое контактирование двух плоских объектов (пластины 
конечных размеров $l_{1}$ и~$l_{2}$), имеющих одну плоскость контактирования 
($x = 0$) в~принятой системе координат одномерной теплопередачи, при этом 
в~постановке первой краевой задачи учитывается, что $q_w = 0$, $q_v = 0$, $q_f \ne 0$:
\begin{equation}
\label{evdok:eq1}
\left( {\frac{\partial }{\partial t} - a_i \frac{\partial ^2}{\partial x^2}} 
\right)T_{fi}^{(m)} (x,\,t) = 0
\quad (i = 1,\, 2),
\quad t > 0,
\quad m \in \mathbb N,
\end{equation}
где  $t$ "--- время, $x$ "--- координата, 
$i =1$ "--- номер (индекс) пластины толщиной $l_{1}$  ($x \in [ - l_1,\,0]$);
$i =2$ "--- номер (индекс) пластины толщиной $l_{2}$  ($x \in [0,\, l_2 ]$);
$T_f^{(m)} $ "--- температура в $m$-ом цикле от действия циклического теплоисточника $q_f$; 
$\lambda_i$, $a_i$ "---
соответствующие номерам пластин коэффициенты тепло- и температуропроводности. 

Начальное условие для контактной системы записывается следующим образом:

-- при $t = 0$:
\begin{equation}
T_{f2}^{(1)} (x,\,t) = 0;
\end{equation}

-- для моментов времени $t = (m - 1)\tau ^ + $ в каждом  $m$-ом цикле:
\begin{equation}
T_{f1}^{(m)} (x,\,t) = f_1^{(m)} (x) = \rm const.
\end{equation}


\noindent
Граничные условия:

-- при $x = - l_1$, $t > 0$ (адиабатическое условие):
\begin{equation}
\lambda _1 \frac{\partial T_{f1}^{(m)} (x,\,t)}{\partial x} = 0;
\end{equation}

-- при $x = l_2$, $t > 0$:

\begin{equation}
\label{evdok:eq2}
 - \lambda _2 \frac{\partial T_{f2}^{(m)} (x,\,t)}{\partial x} = \alpha _2 \left[T_{f2}^{(m)} (x,\,t) - T_0 \right] = 0;
\end{equation}

-- при $x = 0$, $t \in \big[(m - 1)\tau ^ +,\, (m - 1)\tau ^ + + \tau _c \big]$:
\begin{equation}
\label{evdok:eq3}
 - \lambda _1 \frac{\partial T_{f1}^{(m)} (x,\,t)}{\partial x} + 
\lambda _2 \frac{\partial T_{f2}^{(m)} (x,\,t)}{\partial x} = 0;
\end{equation}

-- при $x =0$:
\begin{equation}
\label{evdok:eq4}
 - \lambda _2 \frac{\partial T_{f2}^{(m)} (x,\,t)}{\partial x} + 
H\left[T_{f1}^{(m)} (x,\,t) - T_{f2}^{(m)} (x,\,t)\right] = 0.
\end{equation}
Коэффициент теплообмена $H$ на контактной плоскости равен $\alpha $ для 
интервалов контактирования, а~в~периоды пауз ($t \in \big[(m - 1)\tau ^ + + 
\tau _c,\, m\tau ^ + \big]$) принимается  равным нулю;
$\alpha _2$ "--- коэффициент теплообмена по закону Ньютона на границе 
$x = l_2$; $T_0 = 0$ "--- температура окружающей среды.

Решение сформулированной задачи (чтобы исключить выполнения постадийных 
расчётов) осуществим для квазиустановившейся стадии теплообмена $(m\to \infty )$ 
методом последовательных допущений: на первом этапе решения 
допускаем, что в~период контактирования для некоторого произвольного $m$-го 
цикла известно начальное температурное распределение $f_2^{(m)} (x)$ 
в~пластине 2, аналогично считается заданной и~равномерной начальная 
температура первой пластины $f_1^{(m)} (x) = \rm const$ (в~общем случае 
температурное распределение может быть неравномерным). Тогда для единичного 
$m$-го акта теплопередачи температурные поля элементов системы можно выразить 
через $f_2^{(m)} (x)$, исходя из решения следующей краевой задачи:
\begin{equation}
\label{evdok:eq5}
\left( {\frac{\partial }{\partial t} - a_i \frac{\partial ^2}{\partial x^2}} 
\right)T_{fi}^{(m)} (x,\,t) = 0,\quad t > 0,\quad m \ne 1\quad  (i = 1,\,2) 
\end{equation}
с граничными и начальными условиями: 
\begin{gather}
\frac{\partial T_{f1}^{(m)} (x,\,t)}{\partial x}\Big|_{x = - l_1 } = 0, 
\qquad
\left( {\frac{\partial }{\partial x} + \frac{\alpha _2 }{\lambda _2 }} 
\right)T_{fi}^{(m)} (x,\,t)\Big|_{x = l_2 } = 0;\\
\label{evdok:eq6}
\lambda _1 \rho \frac{\partial T_{f1}^{(m)} (x,\,t)}{\partial x}\Big|_{x = 0 } -
\lambda _2 \rho \frac{\partial T_{f2}^{(m)} (x,\,t)}{\partial x}\Big|_{x = 0 }  = \left(
T_{f2}^{(m)} (x,\,t) - T_{f1}^{(m)} (x,\,t)\right)_{x=0};\\
\label{evdok:eq7}
T_{f1}^{(m)} (x,\,0) = f_{10}^{(m)} (x) = {\rm  const},\qquad T_{f2}^{(m)} (x,\,0) = f_{20}^{(m)} (x),
\end{gather}
где $\rho = \frac 1 H$ "--- термическое сопротивление в~зоне контакта.

Если на границе $x = 0$ дополнительно генерируется тепловой поток трения $q_v(t)$, 
то его можно учесть введением в~условие (\ref{evdok:eq6}) соответствующего 
теплового потока. Применяя к~системе (\ref{evdok:eq5})--(\ref{evdok:eq7}) преобразование Лапласа по 
времени $t$ [1,~2] (в предположении, что функции $T_{fi}^{(m)} (x,\,t)$ являются оригиналами) после соответствующих выкладок получим 
искомые решения в пространстве изображений:

-- для пластины 1:
\begin{multline}
\label{evdok:eq8}
\bar {T}_{f1}^{(m)} (x,\,p) = \frac{1}{p} \Bigg( f_{10}^{(m)}  +
 \frac{{\rm Bi}_{s1} \ch\varepsilon _1 (l_1 + x)}{ \mathcal{K}}\Bigg\{ \varepsilon _1 \int\limits_0^{l_2 } 
f_{20}^{(m)} (\xi )\bigg[ \varepsilon _1 l_1 \ch\varepsilon _2 (l_2  
- \xi )  + {\rm Bi}_2 \ch\varepsilon _2 (l_2 - \xi )\bigg]d\xi - \\ - f_{10}^{(m)} 
\bigg(\varepsilon _2 l_2 \sh(\varepsilon _2 l_2 ) + {\rm Bi}_2 \ch(\varepsilon _2 l_2 )\bigg)
\Bigg\} \Bigg);
\end{multline}


-- для пластины 2:

\begin{multline}
 \label{evdok:eq9}
\bar {T}_{f2}^{(m)} (x,\,p) =
\frac{1}{p\mathcal{K}}\Bigg(
K_\varepsilon {\rm Bi}_{s1} f_{10}^{(m)} 
\sh(\varepsilon _1 l_1) \big[ {\rm Bi}_2 \sh(\varepsilon _2 (l_2 - x)) + \varepsilon 
_2 l_2 \ch(\varepsilon _2 (l_2 - x) )\big] + \\
+\varepsilon _2\Big[ \varepsilon _1 l_1 
\sh(\varepsilon _1 l_1 )\ch(\varepsilon _2 x) + {\rm Bi}_{s1} \big[\ch(\varepsilon _1 l_1 )\ch(\varepsilon _2 x) + K_\varepsilon \sh(\varepsilon _1 l_1) \sh(\varepsilon _1 x)\big]\Big] \times
\\
\times
\int
\limits_0^{l_2 } f_{20}^{(m)} (\xi) \big[ {\rm Bi}_2 
\sh(\varepsilon _2 (l_2 - \xi )) + \varepsilon _2 l_2 \ch(\varepsilon _2 (l_2 - 
\xi )) \big]d\xi \Bigg) - 
\frac{a_2 }{\sqrt p }\int\limits_0^x {f_{20}^{(m)} (\xi )} \sh(\varepsilon _2 (x - \xi ))d\xi .
\end{multline}
Здесь используются следующие обозначения:
$$\bar {T}_{fi}^{(m)} (x,p) = \int\limits_0^\infty T_{fi}^{(m)} (x,\,t)\exp(- pt)dt $$ 
"--- изображение по Лаплассу функции"=оригинала $T_{fi}^{(m)}$, $i=1,\,2$;
$
{\rm Bi}_{s1} = \frac{\alpha }{\lambda _1 }l_1$, ${\rm Bi}_2 = \frac{\alpha _2 }{\lambda _2 }l_2$ "---
критерии Био; 
$K_\varepsilon = \frac{\lambda _1 }{\lambda _2 }\sqrt {\frac{a_2 }{a_1 }}$ "--- 
критерий характеризующий тепловую активность первого объекта по отношению ко второму; 
$ \varepsilon _1 = \sqrt {\frac{p}{a_1 }}$, $\varepsilon _2 = \sqrt {\frac{p}{a_2 }}$ "---
параметры;
\begin{multline*}\mathcal{K}=
 K_\varepsilon {\rm Bi}_{s1} \sh(\varepsilon _1 l_1) \big[\varepsilon _2 l_2 \ch(\varepsilon _2 l_2 ) + {\rm Bi}_2 \sh(\varepsilon _2 
l_2 )\big] + \\+ \big[\varepsilon _1 l_1 \ch(\varepsilon _1 l_1 ) + {\rm Bi}_{s1} 
\ch(\varepsilon _1 l_1 )\big]
\big[\varepsilon _2 l_2 \sh(\varepsilon _2 l_2 ) + {\rm Bi}_2 
\ch(\varepsilon _2 l_2 )\big].
\end{multline*}

  + \frac{1}{l_2 }\int\limits_0^{l_2 } {f_{20}^{(m)} (\xi )} \left[ 
{\frac{\mu _n }{H^\ast {\rm Bi}_2 }\cos \frac{\mu _n }{H^\ast }\left( {1 - 
\frac{\xi }{l_2 }} \right) + \sin \frac{\mu _n }{H^\ast }\left( {1 - 
\frac{\xi }{l_2 }} \right)} \right]d\xi  \Bigg\} \exp \left( { - \frac{\mu 
_n^2 }{(H^\ast )^2}{\rm Fo}_2 } \right).
\end{multline}


Отметим, что в выражении (\ref{evdok:eq14}) функционально взаимосвязаны две неизвестные 
функции: $f_{20}^{(m)} (x)$ и $q^{(m)} (t)$. Очевидно, для нахождения 
указанных функций необходимо иметь два функциональных уравнения. Второе 
искомое функциональное уравнение может быть получено на основе следующего 
последовательного допущения: предположим, что поток $q^{(m)} (t)$ известен 
и~циклически действует на контактную поверхность пластины~2 и~требуется 
найти её температурное поле (временные параметры теплового нагружения 
соответствуют их значениям для всей контактной системы). Для решения этой 
задачи в~общем виде предварительно рассмотрим частично редуцированную модель 
теплообмена: на пластину циклически действует поток с~закреплённой мощностью 
$q_c^{(m)} = q_c = \rm const$ в~периоды контактирования $\tau _{c}$. В~этом 
случае температурные поля для $m$-го цикла контактирования можно получить 
интегрированием уравнения теплопроводности 
\begin{equation}
\label{evdok:eq15}
\left( {\frac{\partial }{\partial t} - a_2 \frac{\partial ^2}{\partial x^2}} 
\right)T_c^{(m)} (x,\,t) = 0,\quad t > 0, \quad x \in [0,\, l_2 ],\quad m \in \mathbb N
\end{equation}
при следующих краевых условиях:
\begin{gather}
\label{evdok:eq16}
\lambda _2 \frac{\partial T_c^{(m)} (x,\,t)}{\partial x}\Big|_{x=0} = 
q_c \sum\limits_{\nu = 1}^m \Big\{ \eta \left[ t-\left(\nu - 1\right)\tau^+ - \tau _c\right] - 
\eta \left[ t - (\nu - 1)\tau ^ + \right] \Big\}_{x=0};
\\
\label{evdok:eq17}
\left( {\frac{\partial }{\partial x} + \frac{\alpha _2 }{\lambda _2 }} 
\right)T_c^{(m)} (x,\,t)\Big|_{x=l_2}  = 0
\qquad
T_c^{(1)} (x,\,0) = 0,
\end{gather}
где $\eta (t-\tau )$ "--- %обобщённая 
функция Хевисайда с~параметром запаздывания $\tau$. 

В постановке, аналогичной (\ref{evdok:eq15})--(\ref{evdok:eq17}), возможно рассмотрение и другого важного 
случая чередующихся граничных условий (IV--III)-го рода, когда на этапе 
($\tau _r )$ контактная поверхность охлаждается по закону Ньютона, в частном 
случае, с~постоянной интенсивностью. Тогда правая часть (\ref{evdok:eq16}) за\-даёт\-ся в~виде 
ступенчатой знакопеременной функции 
\[
( - q_c )\eta (t) + q\sum\limits_{\nu = 1}^m \Big\{ \eta \left[ {t - 
\left( {\nu - 1} \right)\tau ^ + - \tau _c } \right] - \eta \left[ t - (\nu 
- 1)\tau ^ +  \right] \Big\} ,
\]
где $q_r = q - q_c $ "--- постоянная интенсивность теплоотвода с~поверхности 
$x = 0$, определяемая величиной~$q$. 


Систему (\ref{evdok:eq15})--(\ref{evdok:eq17}) решаем для произвольного $m$-го цикла методом 
преобразования Лапласа и~выполняем предельный переход $m \to \infty $, в~результате получим 
для квазиустановившейся стадии процесса и периодов $\tau 
_c $ и $\tau _r $ соответственно решения, представляющие ряды по 
собственным функциям, зависящим от пространственной переменной:
\begin{gather}
\label{evdok:eq18}
T_c^{(\infty )} (x,t_c ) = \frac{q_c }{\lambda _2 }\left[ {\frac{\lambda _2 
+ (l_2 - x)\alpha _2 }{\alpha _2 } - 2\sum\limits_{n = 1}^\infty {C_n 
(x)\frac{\exp a_2 u_n^2 (\tau _c - t_c ) - \exp a_2 u_n^2 (\tau ^ + - t_c 
)}{1 - \exp a_2 u_n^2 \tau ^ + }} } \right],\\
\label{evdok:eq19}
T_r^{(\infty )} (x,t_r ) = \frac{2q_c }{\lambda _2 }\sum\limits_{n = 
1}^\infty {C_n (x)\frac{\exp a_2 u_n^2 (\tau _r - t_r ) - \exp a_2 u_n^2 
(\tau ^ + - t_r )}{1 - \exp a_2 u_n^2 \tau ^ + }} ,
\end{gather}
где обозначено
\[
C_n (x) = \frac{\lambda _2 u_n \cos u_n (l_2 - x) + \alpha _2 \sin u_n (l_2 
- x)}{u_n^2 \left[ {\lambda _2 l_2 u_n \cos u_n l_2 + (\lambda _2 + \alpha 
_2 l_2 )\sin u_n l_2 } \right]},
\]
$\tau _r = \tau ^ + - \tau _c$ "---
длительность этапа охлаждения пластины~2 с~поверхности $x=0$, причём $t_c \in [0,\,\tau _c ]$, $t_r \in [0,\,\tau _r ]$.

Положительные корни $u_{n}$, по которым ведётся суммирование в~(\ref{evdok:eq18}), (\ref{evdok:eq19}), 
определяются из характеристического уравнения 
\begin{equation}
\label{evdok:eq20}
\tg (u_n l_2) = \frac{\alpha _2 }{\lambda _2 u_n }.
\end{equation}

Приведённая выше постановка краевой задачи~(\ref{evdok:eq15})--(\ref{evdok:eq17}) и~её циклическое 
решение выгодно отличаются от известных тем, что предельный переход $m \to 
\infty $ совершается лишь после окончательного решения системы в~пространстве изображений, 
что позволяет легко определить циклические температурные поля с~использованием преобразования 
Лапласа. Одновременно отпадает необходимость в~трудоёмких вычислениях вычетов в~простых полюсах 
$\beta _n = \pm \frac{2\pi i}{\tau ^ + }n$  (здесь $i$ "--- мнимая единица, $n \in \mathbb  N$);
исключается получение и~последовательная численная обработка рядов Фурье, 
как правило, плохо сходящихся. 


На следующем заключительном этапе решения общей краевой задачи 
осуществляется переход от циклического потока $q_c^{(m)} $ постоянной 
интенсивности к~потоку переменной интенсивности $q^\ast (t)$ в~периоды 
контактирования всего процесса. С~этой целью, учитывая цикличность процесса, 
преобразуем ранее полученные решения (\ref{evdok:eq18}), (\ref{evdok:eq19}) согласно теореме Дюамеля. 
В~основу указанного преобразования естественно положить понятие переходной 
температурной циклической функции, представляющей собой реакцию системы 
(объекта) на конечную или бесконечную периодическую последовательность 
прямоугольных тепловых импульсов единичной мощности. Для рассматриваемой 
краевой задачи переходными циклическими функциями для этапов $\tau _c $ и~
$\tau _r $ являются 
\[
T_{1c} (x,\,t_c ) = \frac{1}{q_c }T_c^{(\infty )} (x,\,t_c ),\qquad 
T_{1r} (x,\,t_r ) = \frac{1}{q_c }T_r^{(\infty )} (x,\,t_r ).
\]

Схема получения интеграла Дюамеля для случая циклического воздействия 
остаётся традиционной [3]: действительный циклический процесс внешнего теплового 
воздействия в~виде импульсов произвольной формы разбивается на систему 
смещённых во времени элементарных периодических процессов с~прямоугольной 
формой импульсов с последующим их суммированием.

Пусть элементарный скачок $\Delta q^\ast $ циклического потока возникает 
в~момент времени $\tau + \Delta \tau = \tau _c $ каждого цикла, тогда значение 
искомой температуры от действия $\Delta q^\ast $ для квазиустановившейся 
стадии с~учётом введённых по аналогии обозначений и~переходных характеристик будет~[3]:

-- для периода нагрева (величина $\tau+\Delta \tau$ входит параметрически в функцию двух переменных):
\begin{multline*}
\Delta q^\ast T_{1c} (x,\,t_c;\,\tau + \Delta \tau ) = \frac{\Delta q^\ast 
}{\lambda _2 }\left[ \frac{\lambda _2 + (l_2 - x)\alpha _2 }{\alpha _2 } - \right.
\\
\left.
-
2\sum\limits_{n = 1}^\infty {C_n (x)\frac{\exp a_2 u_n^2 (\tau _c - t_c ) - 
\exp a_2 u_n^2 (\tau ^ + - t_c + \tau + \Delta \tau )}{1 - \exp a_2 u_n^2 
\tau ^ + }}  \right];
\end{multline*}

-- для периода охлаждения:
\[
\Delta q^\ast T_{1r} (x,\,t_r ;\,\tau + \Delta \tau ) = \frac{2\Delta q^\ast 
}{\lambda _2 }\sum\limits_{n = 1}^\infty {C_n (x)\frac{\exp a_2 u_n^2 (\tau 
_r - t_r + \tau + \Delta \tau ) - \exp a_2 u_n^2 (\tau ^ + - t_r )}{1 - \exp 
a_2 u_n^2 \tau ^ + }} .
\]



Суммируя по всем элементарным циклическим потокам $\Delta q^\ast $, 
включённым в~соответствующие моменты $\tau + \Delta \tau > \tau _c $, 
и~переходя к~пределу $\Delta \tau _{\max } \to 0$, с~учётом 
предельного соотношения 
\[
\Delta q^\ast \to dq^\ast (\tau ) = [q^\ast (\tau )]'d\tau 
\]
получим искомые температурные функции от воздействия циклического потока в виде
\begin{multline}
T_c^\ast (x,\,t_c ) = \frac{2a_2 }{\lambda _2 }\sum\limits_{n = 1}^\infty 
u_n^2 C_n (x)\exp \left( - a_2 u_n^2 t_c \right)\left[ \int\limits_0^{t_c } q^\ast 
(\tau )\exp \left(a_2 u_n^2 \tau \right)d\tau   \right] -  
\\
\label{evdok:eq21}
 - \frac1 { 1 - \exp \left(a_2 u_n^2 \tau ^ + \right) }\int\limits_0^{\tau 
_c } q^\ast (\tau )\exp \left(a_2 u_n^2 \tau \right)d\tau  ,
\end{multline}
\begin{equation}
\label{evdok:eq22}
T_r^\ast (x,\,t_r ) = 
\frac{2a_2 }{\lambda _2 }
\sum\limits_{n = 1}^\infty 
u_n^2 C_n (x)\frac{\exp \left(  - a_2 u_n^2 (\tau _c + t_r ) \right)}
{ 1 -\exp \left( - a_2 u_n^2 \tau ^ + \right)}
\int\limits_0^{\tau _c } q^\ast (\tau )\exp (a_2 u_n^2 \tau )d\tau.
\end{equation}





Любое из последних двух решений можно использовать для получения второго 
уравнения в~системе, связывающей функционально $q^\ast (t)$ и $f_{20}^{(m)}(x)$. 
Например, при $t_r = \tau _r $ из (\ref{evdok:eq22}) получим 
\begin{equation}
\label{evdok:eq23}
f_{20}^{(m)} (x) = 
\frac{2a_2 }{\lambda _2 }
\sum\limits_{n = 1}^\infty 
\frac{u_n^2 C_n (x)}
{\exp \left(a_2 u_n^2 \tau ^ + \right) - 1}
\int\limits_0^{\tau _c} q^\ast (\tau )\exp \left(a_2 u_n^2 \tau \right)d\tau.
\end{equation}

При рассмотрении квазиустановившейся стадии решения (\ref{evdok:eq21}), (\ref{evdok:eq22}) остаются 
справедливыми с~учётом предельных соотношений $f_{20}^{(m)} (x) \to 
f_{20}^{(\infty )} (x)$, $q^\ast (t) \to q^{(\infty )}(t)$, переход к $m \to 
\infty $ основывается на очевидных физических соображениях: 
квазиустановившаяся стадия теплообмена полностью предопределяется наличием 
периодической составляющей теплового нагружения и~не зависит от пути, по 
которому система выходит на неё (начальное температурное распределение 
в~пластине~2 в~первом цикле и~апериодическая составляющая действительного 
теплового потока, воздействующего на пластину, повлияют лишь на момент 
выхода на квазиустановившуюся стадию). Отмеченное вполне согласуется 
с~положениями и~выводами, которые имеют место в~теории электрических цепей~[3], 
где применяются специальные приёмы, использующие операторные 
представления передаточных функций, а~также свободной и~принуждённой реакций 
электрической цепи на периодическую (несинусоидальную) воздействующую 
функцию. 

Система уравнений (\ref{evdok:eq14}), (\ref{evdok:eq23}) для случая $m \to \infty $ однозначно 
разрешается относительно неизвестных функций $f_{20}^{(\infty )} 
(x)$, $q^{(\infty )}(t)$. После подстановки (\ref{evdok:eq23}) в~(\ref{evdok:eq14}) получим неоднородное 
интегральное уравнение Фредгольма второго рода, из которого временная 
функция $q^{(\infty )}(t)$ определяется методом итераций:
\begin{equation}
\label{evdok:eq24}
q^{(\infty )}(t) = F(t) + \frac{4a_2 \lambda _1 }{\lambda _2 l_2 l_1 
}\int\limits_0^{\tau _c } q^{(\infty )}(\tau )K(t,\,\tau )d\tau  ,
\end{equation}
где свободный член $F(t)$ и~ядро $K(t,\,\tau )$ уравнения записываются следующим образом:
\[
F(t) = \frac{2\lambda _1 }{l_1 }f_{10}^{(\infty )} \sum\limits_{n = 
1}^\infty {\mu _n \sin \mu _n \left( {\frac{H^\ast }{\mu _n }\cos \frac{\mu 
_n }{H^\ast } - \frac{1}{{\rm Bi}_2 }\sin \frac{\mu _n }{H^\ast }} \right)\exp 
\left( { - \frac{\mu _n^2 }{(H^\ast )^2}{\rm Fo}_c } \right)} ,
\]
\begin{multline*}
K(t,\tau ) = \sum\limits_{n = 1}^\infty {\mu _n \sin \mu _n \exp \left( { - 
\frac{\mu _n^2 }{(H^\ast )^2}{\rm Fo}_2 } \right)} \sum\limits_{n = 1}^\infty 
{\frac{u_n^2 \exp (a_2 u_n^2 \tau )}{\exp (a_2 u_n^2 \tau ^ + ) - 1}\times } 
\\
\times \int\limits_0^{l_2 } {C_n (\xi )\left[ {\frac{\mu _n }{H^\ast {\rm Bi}_2 
}\cos \frac{\mu _n }{H^\ast }\left( {1 - \frac{\xi }{l_2 }} \right) + \sin 
\frac{\mu _n }{H^\ast }\left( {1 - \frac{\xi }{l_2 }} \right)} \right]d\xi } 
.
\end{multline*}



Определив $q^{(\infty )}(t)$, по формулам (\ref{evdok:eq21}), (\ref{evdok:eq22}) вычисляются 
температуры в~любой момент единичного цикла на квазиустановившейся стадии. 
По аналогичной схеме вместо временной функции $q^{(\infty )}(t)$ находится 
координатная функция $f_{20}^{(\infty )} (x)$.

Для решения краевой задачи (\ref{evdok:eq1})--(\ref{evdok:eq4}) (в~предположении, что $q_w = 0$, 
$q_v \ne 0$, $q_f = 0$) можно использовать отмеченные выше условия сопряжения (метод 
сопряжения), в~основе которого лежат условия периодичности и~сопряжения 
температурных распределений по сечению пластины~2 от цикла к~циклу на 
квазиустановившейся стадии. Действительно, в~начале и~в~конце единичного 
циклов температуры должны совпадать (это минимальное распределение по сечению 
обозначим $f_{v2}^{(\infty )} (x)_{\min } )$, температуры также равны в~конце 
периода контактирования и~в~начале этапа охлаждения (это максимальное 
температурное распределение по сечению обозначим $f_{v2}^{(\infty )} 
(x)_{\max } )$. Тогда выполняются равенства
\begin{gather}
T_{v2}^{(\infty )} (x,\,t_c ) \Big|_{t_c = 0} = 
T_{v2}^{(\infty )} (x,\,t_r ) \Big|_{t_r = \tau _r } = 
f_{v2}^{(\infty )} (x)_{\min } ,\qquad t_c \in [0,\,\tau _c ],\\
\label{evdok:eq25}
T_{v2}^{(\infty )} (x,\,t_c ) \Big|_{t_c = \tau _c } = 
T_{v2}^{(\infty )} (x,\,t_r ) \Big|_{t_r = 0} = 
f_{v2}^{(\infty )} (x)_{\max } ,\qquad t_r \in [0,\,\tau _r ].
\end{gather}
Соотношения (29),\, (\ref{evdok:eq25}) полностью определяют цикличность процесса и~чтобы 
связать $f_{v2}^{(\infty )} (x)_{\min } $ и~$f_{v2}^{(\infty )} (x)_{\max } $ 
функциональной системой необходимо решить последовательно следующие две 
краевые задачи. 

Рассмотрим задачу одноразового контакта пластины~1 с~нулевой начальной 
температурой и~пластины~2 с~минимальной начальной температурой распределения 
по сечению при $m \to \infty $ и $q_v = \rm const$:
\begin{equation}
\label{evdok:eq26}
\left( {\frac{\partial }{\partial t} - a_i \frac{\partial ^2}{\partial x^2}} 
\right)T_{vi}^{(\infty )} (x,\,t_c ) = 0,\qquad t_c \in [0,\,\tau _c ].
\end{equation}

Граничные условия:
\begin{gather}
\label{evdok:eq27}
\left(\frac{\partial }{\partial x} + H_2  \right)
T_{v2}^{(\infty )} (x,\,t_c )\Big|_{x = l_2 } = 0,
\qquad
H_2 = \frac{\alpha _2}{\lambda _2};
\\
\label{evdok:eq28}
\frac{\partial T_{v1}^{(\infty )} (x,\,t_c )}{\partial x}\Big|_{x = -l_1 }  = 
0;
\\
\label{evdok:eq29}
\lambda _1 \frac{\partial T_{v1}^{(\infty )} (x,\,t_c )}{\partial x}\Big|_{x = 0} + 
\lambda _2 \frac{\partial T_{v2}^{(\infty )} (x,\,t_c )}{\partial x}\Big|_{x = 0}   + q_v = 0;
\\
\label{evdok:eq30}
\rho _1 \lambda _1 \frac{\partial T_{v1}^{(\infty )} (x,\,t_c )}{\partial x}\Big|_{x = 0} + 
\rho _2 \lambda _2 \frac{\partial T_{v2}^{(\infty )} (x,\,t_c )}{\partial x}\Big|_{x = 0} - 
T_{v2}^{(\infty )} (x,\,t_c )\Big|_{x = 0} + T_{v1}^{(\infty )} (x,\,t_c )\Big|_{x = 0} = 
0,
\end{gather}
где величины  $\rho _1 = \frac1{\alpha _1^v}$,
$\rho _2 = \frac1{\alpha _2^v}$ "--- учитывают локализацию потока трения в пределах пограничного термического слоя ($\rho _1 + \rho _2= \rho$).


Начальные условия при $t_c=0$:
\begin{equation}
\label{evdok:eq31}
T_{v1}^{(\infty )} (x,\,t_c ) = 0,\qquad T_{v2}^{(\infty )} (x,\,t_c ) = 
f_{v2}^{(\infty )} (x)_{\min }.
\end{equation}


Система (\ref{evdok:eq26})--(\ref{evdok:eq31}) интегрируется с~использованием преобразования Лапласа. Для 
дальнейшего потребуется температурное решение только для пластины~2, которое 
приведено ниже:
\begin{multline}
T_{v2}^{(\infty )} (x,t_c ) = \frac{q_v l_2 }{\lambda _2 {\rm Bi}_2 } + \frac{q_v 
(l_2 - x)}{\lambda _2 } + \sum\limits_{n = 1}^\infty {\psi _{vc}^{ - 1} 
(u_{nc} )\left\{ {\left( { - \frac{q_v l_2^3 K_l^3 }{\lambda _2 a_2 u_{nc}^3 
}} \right)\times } \phantom{\int\limits_0^{l_2 }} \right.} 
\\ 
\times \left( {\cos u_{nc} - \frac{u_{nc} }{{\rm Bi}_1^v }\sin u_{nc} } 
\right)\left[ {\sin \frac{u_{nc} }{H^\ast }\;\left( {1 - \frac{x}{l_2 }} 
\right) + \frac{u_{nc} }{H^\ast {\rm Bi}_2 }\cos \frac{u_{nc} }{H^\ast }\;\left( 
{1 - \frac{x}{l_2 }} \right)} \right] + 
\\
 + \left[ {\cos \frac{u_{nc} x}{H^\ast l_2 }\;\left( {\cos u_{nc} - 
\frac{u_{nc} }{{\rm Bi}_1^v }\sin u_{nc} } \right) - K_\varepsilon \sin u_{nc} 
\left( {\sin \frac{u_{nc} x}{H^\ast l_2 } + \;\frac{u_{nc} }{H^\ast {\rm Bi}_2^v 
}\cos \frac{u_{nc} x}{H^\ast l_2 }\;} \right)} \right]\times 
\\
\left. {\times \int\limits_0^{l_2 } {f_{v2}^{(\infty )} (\xi )_{\min } } 
\left[ {\frac{l_2 }{a_2 {\rm Bi}_2 }\cos \frac{u_{nc} }{H^\ast }\left( {1 - 
\frac{\xi }{l_2 }} \right) + \frac{l_2 H^\ast }{a_2 u_{nc} }\sin 
\frac{u_{nc} }{H^\ast }\left( {1 - \frac{\xi }{l_2 }} \right)} \right]d\xi } 
\right\} \times 
\\
\label{evdok:eq32}
\times \exp \left( { - \frac{u_{nc}^2 }{(H^\ast )^2}{\rm Fo}_2 } \right) + 
\frac{1}{\sqrt {\pi a_2 t} _c }\int\limits_0^x {f_{v2}^{(\infty )} (\xi 
)_{\min } } \exp \left( { - \frac{(x - \xi )^2}{4a_2 t_c }} \right)d\xi ,
\end{multline}
где ${\rm Fo}_2 = \frac{a_2 }{l_2^2 }t_c $ "--- критерий Фурье;
\begin{multline}
\psi _{vc} (u_{nc} ) = \left(- \frac{l_1^2 }{2u_{nc}^2 a_1 } \right)
\left\{ 
\sin u_{nc} \left[  - \left( \frac{u_{nc} }{H^\ast {\rm Bi}_2 } 
+ \frac{u_{nc} }{H^\ast {\rm Bi}_2^v } \right)
\cos  \frac{u_{nc} }H^\ast 
 +  
\left( {\frac{u_{nc} }{H^\ast {\rm Bi}_2 } + \frac{u_{nc} }{H^\ast {\rm Bi}_2^v }} 
\right)\frac{u_{nc} }{H^\ast }\sin \frac{u_{nc} }{H^\ast } + \right.\right.
\\ 
 \left.
+ \frac{2u_{nc}^2 }{H^\ast {\rm Bi}_2 {\rm Bi}_2^v }
\sin \frac{u_{nc} }{H^\ast } -    
\left( 1 - \frac{u_{nc}^2 }{(H^\ast )^2{\rm Bi}_2 {\rm Bi}_2^v } \right)
\frac{u_{nc} }{H^\ast }\cos \frac{u_{nc} }{H^\ast } \right] - u_{nc} \cos u_{nc} 
\left[ \left( \frac{u_{nc} }{H^\ast {\rm Bi}_2 } + \frac{u_{nc} }{H^\ast {\rm Bi}_2^v } \right) 
 \cos \frac{u_{nc} }{H^\ast } +
\right.
\\
\left. + 
\left( 1 - \frac{u_{nc}^2 }{(H^\ast )^2{\rm Bi}_2 {\rm Bi}_2^v } \right)
\sin \frac{u_{nc} }{H^\ast } \right] - 
\left( \frac{u_{nc} }{H^\ast }\sin \frac{u_{nc} }{H^\ast } + 
\frac{u_{nc} }{H^\ast {\rm Bi}_2 }%\times 
%\\
%\times 
\sin \frac{u_{nc} }{H^\ast } + \frac{u_{nc}^2 }{(H^\ast )^2{\rm Bi}_2 }\cos 
\frac{u_{nc} }{H^\ast } \right) \bigg( \cos u_{nc} -
%\right.
\\
\label{evdok:eq33}
- \frac{u_{nc} }{{\rm Bi}_1^v }\sin 
u_{nc}  \bigg) 
\left. { - \left( {\cos \frac{u_{nc} }{H^\ast } - \frac{u_{nc} }{H^\ast {\rm Bi}_2 
}\sin \frac{u_{nc} }{H^\ast }} \right)\left( {u_{nc} \sin u_{nc} + 
\frac{u_{nc} }{{\rm Bi}_1^v }\sin u_{nc} + \frac{u_{nc}^2 }{{\rm Bi}_1^v }\cos u_{nc} 
} \right)} \right\} ,
\end{multline}
${\rm Bi}_1^v = \frac{\alpha _1^v }{\lambda _1 }l_1$, ${\rm Bi}_2^v = \frac{\alpha _2^v }{\lambda _2 }l_2$ 
"--- критерии Био,
$K_\lambda = \frac{\lambda _1 }{\lambda _2 }$,
$K_a = \frac{a_1 }{a_2 }$,
$K_l = \frac{l_1 }{l_2 }$, 
$H^\ast = \frac{K_l }{\sqrt {K_a }}$,
$K_\varepsilon = \frac{K_\lambda }{\sqrt {K_a } }$ "--- 
безразмерные критерии.

Суммирование в (\ref{evdok:eq32}) ведётся по всему множеству корней характеристического 
уравнения 
\begin{multline}
\label{evdok:eq34}
\left( {\cos \frac{u_{nc} }{H^\ast } - \frac{u_{nc} 
}{H^\ast {\rm Bi}_2 }\sin \frac{u_{nc} }{H^\ast }} \right)\left( {\cos u_{nc} - 
\frac{u_{nc} }{{\rm Bi}_1^v }\sin u_{nc} } \right) - \\ 
 - K_\varepsilon \sin u_{nc} \left[ {\left( {\frac{1}{{\rm Bi}_2 } + 
\frac{1}{{\rm Bi}_2^v }} \right)\frac{u_{nc} }{H^\ast }\sin \frac{u_{nc} }{H^\ast 
} + \left( {1 - \frac{u_{nc}^2 }{(H^\ast )^2{\rm Bi}_2 {\rm Bi}_2^v }} \right)\sin 
\frac{u_{nc} }{H^\ast }} \right] = 0.
\end{multline}

Перепишем решение (\ref{evdok:eq32}) в более компактной интегральной форме:

\begin{multline}
\label{evdok:eq35}
 T_{v2}^{(\infty )} (x,\,t_c ) = \frac{q_v l_2 }{\lambda _2 {\rm Bi}_2 } + \frac{q_v 
(l_2 - x)}{\lambda _2 } + 
Q(x,\, {\rm Fo}_2)
+
\int\limits_0^{l_2 } f_{v2}^{(\infty )} (\xi )_{\min } 
K_{vc}(x,\,\xi,\,{\rm Fo}_2 )d\xi + \\ 
 + \frac{1}{\sqrt {\pi a_2 t_c } }\int\limits_0^x 
{f_{v2}^{(\infty )} (\xi )_{\min } } \exp \left( { - \frac{(x - \xi )^2}{4a_2 t_c }} \right)d\xi, 
\end{multline}
где функция $K_{vc}$ явно определяется из (\ref{evdok:eq32}) в виде ряда

\begin{multline*}
K_{vc}(x,\,\xi,\, {\rm Fo}_2)=
\sum\limits_{n = 1}^\infty \psi _{vc}^{-1} (u_{nc})\times
\\
\times 
\left[
\cos \frac{u_{nc}x}{H^*l_2}
\left( {\cos u_{nc} - \frac{u_{nc} }{{\rm Bi}_1^v }\sin u_{nc} } 
\right) 
-
K_\varepsilon \sin u_{nc}
\left( \sin \frac{u_{nc} x}{H^\ast l_2 } +\frac{u_{nc} }{H^\ast {\rm Bi}_2^v 
}\cos \frac{u_{nc} x}{H^\ast l_2 } \right)\right]\times
\\
\times 
\left[ \frac{l_2 }{a_2 {\rm Bi}_2 }\cos \frac{u_{nc} }{H^\ast }\left( {1 - 
\frac{\xi }{l_2 }} \right) + \frac{l_2 H^\ast }{a_2 u_{nc} }\sin 
\frac{u_{nc} }{H^\ast }\left( {1 - \frac{\xi }{l_2 }} \right) \right]
\exp \left( { - \frac{u_{nc}^2 }{(H^\ast )^2}{\rm Fo}_2 } \right),
\end{multline*}
а функция $Q(x, {\rm Fo}_2)$, соответственно, 
\begin{multline*}
 Q(x, {\rm Fo}_2) = 
\sum\limits_{n = 1}^\infty \psi _{vc}^{-1} (u_{nc}) 
\left( 
- \frac{q_v l_2^3K_l^3}{\lambda_2 a_2 u_{nc}^3}
\right) 
\times
\\
\times
\left(
\cos u_{nc} -\frac{u_{nc}}{{ \rm Bi}_1^v}
\right)
\left[
\sin \frac{u_{nc}}{H^*}\left(1-\frac x{l_2}\right) + \frac{u_{nc}}{H^*{\rm Bi}_2}
\cos \frac{u_{nc}}{H^*}\left(1-\frac x{l_2}\right)
\right]\exp \left( - \frac{u_{nc}^2 }{(H^\ast )^2}{\rm Fo}_2  \right).
\end{multline*}


Вторая вспомогательная задача формулируется только для пластины~2. 
Рассмотрим случай естественного (конвективного) охлаждения пластины 
с~произвольной начальной температурой $f_{v2}^{(\infty )} (x)_{\max } $ 
в~окружающую среду через обе ограничивающие поверхности ($x = 0$, $x = l_2$) 
по закону Ньютона. 

Обозначенная задача имеет постановку:
\begin{equation}
\label{evdok:eq36}
\left( {\frac{\partial }{\partial t} - a_2 \frac{\partial ^2}{\partial x^2}} 
\right)T_{v2}^{(\infty )} (x,\,t_r ) = 0,\quad t_r \in [0,\tau _r ],\quad x \in [0,\,l_2 ];
\end{equation}

-- граничные условия:
\begin{gather}
\label{evdok:eq37}
\left( {\frac{\partial }{\partial x} - H'_2 } \right)T_{v2}^{(\infty )} (x,\,t_r )\Big|_{x = 0} = 0,\\
\label{evdok:eq38}
\left( {\frac{\partial }{\partial x} + H_2 } \right)T_{v2}^{(\infty )} (x,\,t_r )\Big|_{x = l_2} = 0;
\end{gather}

-- начальное условие при $t_r=0$:
\begin{equation}
\label{evdok:eq39}
T_{v2}^{(\infty )} (x,\,t_r ) = f_{v2}^{(\infty )} (x)_{\max } 
\end{equation}
где $H_2 = \frac{\alpha _2 }{\lambda _2 }$, $H'_2 = \frac{\alpha' _2}{\lambda _2 }$ "--- относительные коэффициенты теплообмена.

Решение задачи после преобразований запишется так:
\begin{multline}
T_{v2}^{(\infty )} (x,\,t_r ) = 
\sum\limits_{n = 1}^\infty 
\psi _{vr}^{ - 1} (u_{nr} )
\Bigg\{ 
\left( \sin \frac{u_{nr} x}{l_2 } + \frac{u_{nr} }{{\rm Bi}'_2 }
\cos \frac{u_{nr} x}{l_2} \right)\times 
\\
\times 
\int\limits_0^{l_2 } 
f_{v2}^{(\infty )} (\xi )_{\max }  
\left[ \frac{l_2 }{a_2 u_{nr} }\sin u_{nr} 
\left( 1 - \frac{\xi }{l_2 }\right) + 
\frac{l_2 }{a_2 {\rm Bi}'_2}\cos u_{nr} 
\left( 1 - \frac{\xi }{l_2 }\right) 
\right]d\xi  \Bigg\} \exp \left(  - u_{nr}^2 {\rm Fo}_2  \right) + 
\\
\label{evdok:eq40}
 + \frac{1}{\sqrt {\pi a_2 t_r } }\int\limits_0^x 
f_{v2}^{(\infty )} (\xi )_{\max }  \exp \left(  - \frac{(x - \xi )^2}{4a_2 t_r} \right)d\xi,
\end{multline}

\noindent
где 
\begin{multline*}
\psi _{vr} (u_{nr} ) = 
\left(  - \frac{l_2^2 }{2u_{nr}^2 a_2 }\right)
\left[ \left( \frac{u_{nr} }{{\rm Bi}_2 } + \frac{u_{nr} }{{\rm Bi}'_2} \right)
\cos  u_{nr} - u_{nr} \left( \frac{u_{nr} }{{\rm Bi}_2 } + 
\frac{u_{nr} }{{\rm Bi}'_2 } \right)\sin u_{nr} -  \right.
\\
\left.  - \frac{2u_{nr}^2 }{{\rm Bi}_2 {\rm Bi}'_2}\sin u_{nr} + 
\left(1 - \frac{ u_{nr}^2 }{{\rm Bi}_2 {\rm Bi}'_2}\right)
u_{nr} \cos u_{nr}  \right],
\end{multline*}
${\rm Bi}'_2 = H'_2 l_2 = \frac{\alpha' _2}{\lambda _2 }l_2$,
${\rm Bi}_2 = H_2 l_2 = \frac{\alpha _2 }{\lambda _2 }l_2$.
Суммирование ведется по всем корням $u_{nr} $ трансцендентного уравнения
\begin{equation}
\label{evdok:eq41}
\sin u_{nr} \left( {1 - \frac{u_{nr}^2 }{{\rm Bi}_2 {\rm Bi}'_2 }} \right) + \cos 
u_{nr} \left( {\frac{u_{nr} }{{\rm Bi}_2 } + \frac{u_{nr} }{{\rm Bi}'_2 }} \right) = 0.
\end{equation}



Запишем (\ref{evdok:eq40}) в интегральной форме:
\begin{equation}
\label{evdok:eq42}
T_{v2}^{(\infty )} (x,\,t_r ) = 
\int\limits_0^{l_2 } 
f_{v2}^{(\infty )} (\xi )_{\max } K_{vr}  
\left( x,\xi ,{\rm Fo}_2  \right)d\xi 
 + \frac{1}{\sqrt {\pi a_2 t_r } }\int\limits_0^x 
f_{v2}^{(\infty )} (\xi )_{\max }  \exp \left(  - \frac{(x - \xi 
)^2}{4a_2 t_r } \right)d\xi ,
\end{equation}
где функция $K_{vr} $ представляет соответствующий ряд из (\ref{evdok:eq40}):
\begin{multline*}
 K_{vr} (x,\, \xi,\, {\rm Fo}_2)=
\sum\limits_{n = 1}^\infty 
\psi _{vr}^{ - 1} (u_{nr} )
\Bigg\{ 
\left( \sin \frac{u_{nr} x}{l_2 } + \frac{u_{nr} }{{\rm Bi}'_2 }
\cos \frac{u_{nr} x}{l_2} \right)\times 
\\
\left[ \frac{l_2 }{a_2 u_{nr} }\sin u_{nr} 
\left( 1 - \frac{\xi }{l_2 }\right) + 
\frac{l_2 }{a_2 {\rm Bi}'_2}\cos u_{nr} 
\left( 1 - \frac{\xi }{l_2 }\right) 
\right]\Bigg\} \exp \left(  - u_{nr}^2 {\rm Fo}_2  \right).
\end{multline*}



Полученные интегральные соотношения (\ref{evdok:eq35}), (\ref{evdok:eq42}) на заключительном этапе 
решения позволяют определить температурные функции $f_{v2}^{(\infty )} (x)_{\min }$, 
$f_{v2}^{(\infty )} (x)_{\max } $ и~тем самым решить задачу циклического контактного теплообмена 
для квазиустановившейся стадии. С~этой целью интегральные соотношения 
(\ref{evdok:eq35}), (\ref{evdok:eq42}) удовлетворяют условиям сопряжения 
(29), (\ref{evdok:eq25}). В~уравнении (\ref{evdok:eq35}) следует 
принять $t_c = \tau _c $, а~в~(\ref{evdok:eq42}) принять $t_r = \tau _r $. 
Тогда получим систему двух интегральных уравнений относительно двух искомых определяющих 
функций $f_{v2}^{(\infty )} (x)_{\min }$, $f_{v2}^{(\infty )} (x)_{\max } $:
\begin{multline}
\label{evdok:eq43}
 f_{v2}^{(\infty )} (x)_{\max } = \frac{q_v l_2 }{\lambda _2 {\rm Bi}_2 } + 
\frac{q_v (l_2 - x)}{\lambda _2 } + 
Q(x,\, {\rm Fo}_2)+
\int\limits_0^{l_2 } {f_{v2}^{(\infty )} 
(\xi )_{\min } K_{vc} } \left( {u_{nc} ,x,\xi ,{\rm Fo}_{2c} } \right)d\xi + \\ 
 + \frac{1}{\sqrt {\pi a_2 \tau _c } 
}\int\limits_0^x {f_{v2}^{(\infty )} (\xi )_{\min } } \exp \left( { - 
\frac{(x - \xi )^2}{4a_2 \tau _c }} \right)d\xi,
\end{multline}

\vspace{-4mm}

\begin{multline}
\label{evdok:eq44}
 f_{v2}^{(\infty )} (x)_{\min } = \int\limits_0^{l_2 } {f_{v2}^{(\infty )} 
(\xi )_{\max } K_{vr} } \left( x,\, \xi,\, {\rm Fo}_{2r}  \right)d\xi
  + \frac{1}{\sqrt {\pi a_2 \tau _r } 
}\int\limits_0^x {f_{v2}^{(\infty )} (\xi )_{\max } } \exp \left( { - 
\frac{(x - \xi )^2}{4a_2 \tau _r }} \right)d\xi,
\end{multline}
где ${\rm Fo}_{2c} = \frac{a_2 }{l_2^2 }\tau _c$, ${\rm Fo}_{2r} = \frac{a_2 }{l_2^2 }\tau _r $ "--- безразмерные 
числа Фурье. 

Составленная сложная система интегральных уравнений (\ref{evdok:eq43}), (\ref{evdok:eq44}) допускает лишь 
численное решение относительно искомых функций, знание которых позволяет 
определить переменные температуры и потоки в~любой точке контактной системы 
на квазиустановившейся стадии. Один из наиболее простых методов решения 
систем подобного типа "--- замена известных и~неизвестных функций ступенчатыми 
функциями с~последующим применением формул численного интегрирования 
и~получением систем рекуррентных уравнений. Полезно также отметить, что при 
наличии решений для квазиустановившейся стадии появляется возможность 
интерполяционного подхода к~решению циклической задачи, когда температуры 
и~потоки, рассчитанные постадийно для начальных циклов и~квазиустановившейся 
стадии рассматриваются как опорные (узловые) точки при построении 
интерполяционной модели процесса теплообмена для произвольного цикла, что 
является основой термонапряжённого анализа контактной системы, управления 
и~прогнозирования эксплуатационной стойкости объектов контактирования. 
Возможен переход к контактному теплообмену с~полуограниченным телом при $l_2 
\to \infty $.
