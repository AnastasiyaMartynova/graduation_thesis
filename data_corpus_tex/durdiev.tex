\workabstract{Исследуется многомерная обратная задача определения пространственной части ядра интегрального члена в~интегро-дифференциальном волновом уравнении. При~этом прямую задачу представляет начально-краевая задача для этого уравнения с~нулевыми начальными данными и граничным условием Неймана в~виде дельта-функции Дирака, сосредоточенной на~границе области \mbox{$(x,t)\in \mathbb R^{n+1}$},  $z>0$. В~качестве информации для решения обратной задачи на~границе рассматриваемой области задаются следы решения прямой задачи. Существенным моментом постановки задачи является то обстоятельство, что все заданные функции предполагаются вещественными аналитическими функциями действительных переменных $x\in \mathbb R^{n}$. Основной результат работы заключается в~получении теоремы локальной однозначной разрешимости обратной задачи в~классе функций, непрерывных по~переменной $z$ и аналитических по остальным пространственным переменным. Для этого с~использованием метода выделения особенностей прямая задача заменяется начально-краевой задачей для регулярной части решения этой задачи. Далее прямая и обратная задачи сводятся к~решению эквивалентной системы интегро-дифференциальных уравнений вольтерровского типа. Для решения последней применяется метод шкал банаховых пространств вещественных аналитических функций действительного переменного.}

\engabstract{The multidimensional inverse problem of determining spatial part of integral member kernel in integro-differential wave equation is considered. Herein, the direct problem is represented by the initial-boundary problem for this with zero initial data and Neyman's boundary condition as Dirac's delta-function concentrated on the boundary of the domain $(x,t)\in \mathbb R^{n+1}$,  $z>0$. As information in order to solve the inverse problem on the boundary of the considered domain the traces of direct problem solution are given. The significant moment of the problem setup is such a circumstance that all given functions are real analytical functions of variables $x\in \mathbb R^{n}$. The main result of the work is concluded in obtaining the local unique solvability of the inverse problem in the class of continuous functions on variable $z$ and analytical on other spatial variables. For this, by means of singularity separation method, the inverse problem is replaced by the initial-boundary problem for the regular part of the solution of this problem. Further, direct and inverse problems are reduced to the solution of equivalent system of Volterra type integro-differential equations. For the solution of the latter, the method of Banach space scale of real analytical functions is used.}

Рассмотрим начально"=краевую задачу
\begin{gather}
{u_{tt}} - {u_{zz}} - \Delta u = \int_0^t {k(t - \tau ,z,x)u(\tau ,z,x)d\tau ,}  \quad  (x,t) \in \mathbb R^{n + 1}, \; z > 0, 
\label{dur:1}
\\
u|_{t < 0} \equiv 0,\quad  u_z|_{z = 0} =  - \delta '(t) + f(t,x)\theta (t) , \quad  (x,t)\in \mathbb  R^{n + 1}. 
\label{dur:2}
\end{gather}
Здесь $\Delta$ "--- оператор Лапласа по переменным $\left( {{x_1},{x_2}, \cdots ,{x_n}} \right) = x$,  $\delta '(t)$ "--- производная дельта"=функции Дирака,
$\theta (t)$ "--- функция Хевисайда, $f$ "--- заданная гладкая функция.
Предполагается, что ядро интегрального члена уравнения \eqref{dur:1} имеет вид
$$k(t,z,x) = {k_0}(t)p(z,x),$$
где ${k_0}(t)$ "--- известная функция. Обратная задача заключается в определении функции $p(z,x)$
по известному дополнительному  условию относительно  решения  прямой задачи \eqref{dur:1}, \eqref{dur:2}:
\begin{equation}
u|_{z = 0} =  - \delta (t) + g(t,x)\theta (t) ,\quad  (x,t) \in {\mathbb R^{n + 1}},
\label{dur:3}
\end{equation}
$g(t,x)$ "--- заданная достаточно гладкая функция.


Идея применения  метода шкал банаховых пространств аналитических функций,
развитая в~работах Л.~В.~Овсянникова \cite{dur:bib:1} и Л.~Ниренберга \cite{dur:bib:2},
к многомерным обратным задачам принадлежит В.~Г.~Романову. В~работах~[\citen{dur:bib:3}--\citen{dur:bib:5}] он применил этот метод
(с некоторыми модификациями)        к вопросам локальной разрешимости многомерных обратных задач. 
На основе данного метода в \cite{dur:bib:6} изучена задача определения функции $k$ в уравнении \eqref{dur:1}, когда она не зависит от переменной $z$. В данной  работе исследуется обратная задача \eqref{dur:1}--\eqref{dur:3} об определении $(n+1)$-мерной пространственной части функции $k(t,z,x)$.
        Доказывается, что поставленная задача локально однозначно разрешима в классе функций, аналитических по переменной $x$.

         Следуя \cite[с. 92]{dur:bib:7}, введём в рассмотрение  банахово пространство $A_s$ аналитических функций  $h(x)$, $x \in \mathbb R$,  для которых  конечна норма
\[{\left\| h \right\|_s}(r) = \mathop {\sup }\limits_{\left| x \right| \leqslant r} \sum\limits_{\left| \alpha  \right| = 0}^\infty  {\frac{{{s^{\left| \alpha  \right|}}}}{{\alpha !}}} \left| {{D^\alpha }\phi (x)} \right| < \infty .\]
     Здесь $r > 0,s > 0$ и $D^\alpha = \frac{{{\partial ^{\left| \alpha  \right|}}}}{{\partial x_1^{{\alpha _1}} \cdots \partial x_n^{{\alpha _n}}}}$,      $\alpha  = \left( {{\alpha _1},{\alpha _2}, \cdots {\alpha _n}} \right)$,
      ${\alpha _i}$ "--- неотрицательные целые числа, $\left| \alpha  \right| = {\alpha _1} + {\alpha _2} +  \cdots  + {\alpha _n}$,   $\alpha ! = ({\alpha _1})! \cdot ({\alpha _2})! \cdot  \cdots  \cdot ({\alpha _n})!$.
      В дальнейшем параметр $r$ будет считаться фиксированным, в то время как параметр $s$ рассматривается как переменный параметр.
       Далее для простоты параметр $r$ будем опускать в обозначениях норм пространства  ${A_s}$. При изменении  параметра $s$ возникает шкала
       банаховых пространств ${A_s}$, $s > 0$.  Очевидно следующее   свойство: если $h(x) \in {A_s}$, то $h(x) \subset {A_{s'}}$  для всех $s' \in (0,s)$, следовательно, ${A_s} \subset {A_{s'}}$, если $s' < s$.
       Кроме того, если $h(x) \in {A_s}$, то  ${D^\alpha }h(x) \subset {A_{s'}}$ для  $s' \in (0,s)$, и в частности, справедливо неравенство
\begin{equation}
{\left\| {\Delta h} \right\|_s^{'}} \leqslant \frac{{4\pi }}{{\left( {s' - s} \right)}}{\left\| h \right\|_{s}},
\quad  s' > s > 0. 
\label{dur:4}
\end{equation}

   Пусть ${D_{0T}} = \{ ( t, z) \mid 0 \leqslant z \leqslant t \leqslant T - t \}$,   $T > 0$ "--- фиксированное число
    и ${D_T} = {D_{0T}} \times {\mathbb R^n}$. 

\begin{definition} Функция  $w = w(t,z,x) \in C\left( {{A_s},{D_{0T}}} \right)$, если $w \in {A_s}$ для   всех
      $(t,z) \in {D_{0T}}$, непрерывна в  ${D_{0T}}$  как элемент пространства ${A_s}$ и,  кроме того, удовлетворяет условию
\[\mathop {\sup }\limits_{(t,z) \in {D_{0T}}} {\left\| w \right\|_s}(t,z) < \infty .\]
\end{definition}

Из равенств \eqref{dur:1}, \eqref{dur:2}   следует, что
$u \equiv 0$, $0 < t < z$,    $x \in {\mathbb R^n}$.
Функция $u(t,z,x)$ как  решение задачи  \eqref{dur:1}, \eqref{dur:2} имеет в окрестности  характеристической поверхности $t = z$ следующую структуру:
\[u(t,z,x) =  - \delta (t - z) + v(t,z,x)\theta (t - z),\]
где  $v(t,z,x)$ "--- функция, непрерывная при переходе через поверхность $t = z$.  Из последнего уравнения следует равенство
\[v(z + 0,z,x) = 0.\]
 Из вышесказанного следует, что обратная задача \eqref{dur:1}--\eqref{dur:3} эквивалентна задаче  определения функции $p(z,x)$ из следующих уравнений:
\begin{gather}
{v_{tt}} - {v_{zz}} = \Delta v + {k_0}(t - z)p(z,x) + p(z,x)\int_0^{t - z}{{k_0}(\alpha )v(t - \alpha ,z,x)d\alpha }, 
\label{dur:5}
\\
(t,z,x) \in D = \{ (t, z, x) \mid 0 < z < t,\; x \in {\mathbb R^n} \},
\\
v\left| {_{z = 0} = g(x,t)} \right.,\quad  {v_z}\left| {_{z = 0} = f(x,t)} \right.,\quad  t > 0, \; x \in {\mathbb R^n},
\label{dur:6}
\\
u| {_{t = z + 0} = 0}, \quad  x \in {\mathbb R^n}.
\label{dur:7}
\end{gather}
Построим  исходя из этих равенств систему интегро"=дифференциальных уравнений для неизвестных функций.
Функция $v$ удовлетворяет уравнению:
\begin{multline}
v(t,z,x) = v_0(t,z,x)  
%\\
-\frac 12 \iint_{\Delta (z,t)} \biggl[ \Delta v\left( {\tau ,\xi ,x} \right) +k_0(\tau  - \xi )p(\xi ,x)+
\\
+p(\xi ,x)\int_0^{\tau  - \xi } {{k_0}(\alpha )v(\tau  - \alpha ,\xi ,x)d\alpha } \biggr]d\tau d\xi ,
\label{dur:8}
\end{multline}
в котором
\begin{equation}
{v_0}(t,z,x) = \frac 12 \left[ {g(t + z,x) + g(t - z,x)} \right] + \frac 12 \int_{t - z}^{t + z} f(\tau ,x)d\tau , 
\label{dur:9}
\end{equation}
$\Delta (z,t) = \{ (\xi ,\tau ) \mid 0 \leqslant \xi  \leqslant z,\; \xi  + t - z \leqslant \tau  \leqslant  - \xi  + t + z \}$ "---
характеристический треугольник в плоскости $(\xi,\tau)$ с вершиной в точке  $(z,t)$ и  основанием на оси $\tau $.
Выше  была использована формула Даламбера с данными Коши на плоскости $z = 0$.
 Из формулы \eqref{dur:8}, являющейся решением прямой задачи \eqref{dur:5}, \eqref{dur:6},  
с использованием условия \eqref{dur:7} на характеристике при $t \to z + 0$ имеем
\begin{multline}
2{v_0}(z + 0,z,x) =
\int_{\Delta (z,z + 0)} \biggl[ \Delta v(\tau ,\xi ,x) +
{k_0}(\tau  - \xi )p(\xi ,x) +
\\
+ p(\xi ,x)\int_0^{\tau  - \xi } {{k_0}(\alpha )v(\tau
 - \alpha ,\xi ,x)d\alpha }  \biggr] d\xi.
 \label{dur:10}
\end{multline}
 Полагая в \eqref{dur:10} $z = 0$,   находим условие, которому должна удовлетворять функция $g$:
\[g( + 0,x) = 0.\]
Дифференцируем равенство \eqref{dur:10} по $z$, получаем
\begin{multline}
\frac{d}{dz}v_0(z + 0,z,x) = \int_0^z [ \Delta v(2z - \xi ,\xi ,x) + p(\xi ,x)k_0[ 2(z - \xi ) ]+
\\
+ p(\xi ,x)\int_0^{2(z - \xi )} k_0(\alpha )v(2z - \xi  - \alpha ,\xi ,x)d\alpha ]d\xi.  
\label{dur:11}
\end{multline}

%\pagebreak

Из \eqref{dur:8} следует, что
\[\frac{d}{{dz}}{v_0}(z + 0,z,x) = {g_t}(t,x)\left| {_{t = 2z} + f(2z,x)}. \right.\]
 Отсюда и из предыдущего равенства находим условие согласования для заданных функций:
\[{g_t}( + 0,x) = f( + 0,x).\]

 Интегральное уравнение для неизвестной  функции $p(z,x)$ находим дифференцированием по $z$ соотношения \eqref{dur:11}:
\begin{multline}
p(z,x) = {p_0}(z,x)
- \frac{2}{k_0(0)}\int_0^z [ \Delta v_t(2z - \xi ,\xi ,x) + p(\xi ,x){k_0}^\prime (2z - 2\xi )+
\\
+ p(\xi ,x)\int_0^{2z - 2\xi } k_0(\alpha )v_t(2z - \xi  - \alpha ,\xi ,x)d\alpha]d\xi ,
\label{dur:12}
\end{multline}
где
\[{p_0}(z,x) = \frac{1}{k_0(0)}\frac{d^2}{dz^2}{v_0}(z + 0,z,x)
 = \frac{2}{{{k_0}(0)}}{\left[ {{g_{tt}}(t,x) + {f_t}(t,x)} \right]_{t = 2z}}.\]
Воспользуемся формулой \eqref{dur:8} для вычисления $v_t$. Дифференцируя  это уравнение по $t$, получим
\begin{multline}
{v_t}(t,z,x) = {v_{0t}}(t,z,x) - 
\\
-\frac 12 \int_0^z [\Delta v(\xi+t-z,\xi,z)+k_0(t-z)p(\xi,x)+p(\xi,x)\int_0^{t-z}k_0(\alpha )v(\xi+t-z-\alpha,\xi,x)d\alpha- 
\\
-\Delta v(-\xi+t+z,\xi,x)-k_0(t+z-2\xi)p(\xi,x)-
\\
-p(\xi,x)\int_0^{t+z-2\xi}k_0(\alpha)v(t+z-\xi-\alpha,\xi,x)d\alpha]d\xi, 
\label{dur:13}
\end{multline}
где
\begin{multline*}
{v_{0t}}(t,z,x) = \frac{\partial }{{\partial t}}{v_0}(t,z,x) = \\ = \frac 12 \left[ {{g_t}(t + z,x) + {g_t}(t - z,x)} \right] + \frac 12 \left[ {f(t + z,x) - f(t - z,x)} \right].
\end{multline*}

Основным результатом настоящей работы является следующая теорема о локальной разрешимости поставленной задачи.

\smallskip

\begin{theorem} Пусть ${k_0}(t)\in{C^1}[0, T],$   $k(0)\ne 0$ и выполнены условия согласования
$g( + 0, x) = 0,$   ${g_t}( + 0, x) = f( + 0 ,x),$    $x \in {\mathbb R^n},$
кроме того{\rm ,}
\begin{gather*}
\left[ {f(t,x),g(t,x),{g_t}(t,x),{f_t}(t,x),{g_{tt}}(t,x)} \right] \in C({A_{{s_0}}},\left[ {0,T} \right]),
\\
\max \left\{ {{{\left\| g \right\|}_{{s_0}}}(t),\max (1,\frac{T}{2}){{\left\| f \right\|}_{{s_0}}}(t),
{{\left\| {{g_t}}
\right\|}_{{s_0}}}(t)} \right\} \leqslant \frac{{{R_0}}}{2},
\\
\max \left\{ {{{\left\| {{f_t}} \right\|}_{{s_0}}}(t),{{\left\| {{g_{tt}}} \right\|}_{{s_0}}}(t)} \right\}{\left| {k(0)}
\right|^{ - 1}} \leqslant \frac{{{R_0}}}{4},\quad  t \in \left[ {0, T} \right],
\end{gather*}
$R_0$ "--- известное  положительное число{\rm .}
Тогда найдется $a \in (0, {T}/{2})$ такое{\rm ,} что для любого $s \in (0,{s_0})$ в области ${\Gamma _{ST}}: = {D_T} \cap \{ (t, z, s) \mid {0 \leqslant z \leqslant a({s_0} - s )}\}$ существует единственное
 решение системы уравнений \eqref{dur:8}{\rm ,} \eqref{dur:12}{\rm ,} \eqref{dur:13}{\rm ,} для которого
$(v,{v_t}) \in C({A_{{s_0}}},F),$ $p \in C({A_{{s_0}}},\left[ {0,a({s_0} - s)} \right]),$
$$F = \{ (t,z,s) \mid {(t,z) \in D_{0T},} \; 0 < z < a({s_0} - s) \},$$
    причём
$${\left\| {v - {v_0}} \right\|_s}(t,z) \leqslant {R_0}, \quad  {\left\| {{v_t} - {v_{0t}}} \right\|_s}
\leqslant \frac{{{R_0}}}{{{s_0} - s}},\quad 
{\left\| {p - {p_0}} \right\|_s} \leqslant \frac{{{R_0}}}{{{{({s_0} - s)}^2}}}.$$
\end{theorem}

\smallskip

\begin{proof}
 Для удобства дальнейших исследований введём обозначения:
\begin{gather*}
{\phi _1}(t, z, x)  = v(t, z, x) ,\quad  {\phi _2}(t, z, x)  = v_t (t, z, x) ,
\quad  {\phi _3}\left( {z,x} \right) = p\left( {z,x} \right),
\\
\phi _1^0(t,z,x) = {v_0}(t, z, x) ,\quad  \phi _2^0(t, z, x)  = {v_{0t}}(t, z, x) ,\quad 
\phi _3^0\left( {z,x} \right) = {p_0}\left( {z,x} \right).
\end{gather*}

 Уравнения  \eqref{dur:8}, \eqref{dur:12}, \eqref{dur:13} образуют полную систему равенств для неизвестных функций  в области ${D_T} = \left\{ {(t, z, x) \left|
  {0 \leqslant z \leqslant t \leqslant T - z, \;x \in {\mathbb R^n}} \right.} \right\}$. Согласно введённым обозначениям для вектор"=функций
   $\phi  = \left( {{\phi _1},{\phi _2},{\phi _3}} \right)$ запишем эту систему в операторном виде
\begin{equation}
\phi  = B\phi , 
\label{dur:14}
\end{equation}
где $B = \left( {{B_1},{B_2},{B_3}} \right)$, и компоненты оператора $B$ в соответствии
с интегро"=дифференциальными уравнениями \eqref{dur:8}, \eqref{dur:12}, \eqref{dur:13}
 определяются по формулам
\begin{multline*}
{B_1}\phi  = \phi _1^0(t, z, x)  - 
\frac 12 \iint_{\Delta (z,t)} \biggl[ \Delta {\phi _1}\left( {\tau ,\xi ,x} \right) + {k_0}(\tau  - \xi ){\phi _3}(\xi ,x) +
\\
+{\phi _3}(\xi ,x)\int_0^{\tau  - \xi } {{k_0}(\alpha ){\phi _1}(\tau  - \alpha ,\xi ,x)d\alpha }  \biggr]d\tau d\xi ,
\end{multline*}
\begin{multline*}
{B_2}\phi  = \phi _2^0(t, z, x)  
- \frac 12 \int_0^z \biggl[   \Delta {\phi _1}(\xi  + t - z,\xi ,x) + 
(  {k_0}(t - z) - {k_0}( t + z - 2\xi ){\phi _3}(\xi ,x) - 
\\
- \Delta {\phi _1}( - \xi  + t + z,\xi ,x) + {\phi _3}(\xi ,x)\int_0^{t - z} {k_0}(\alpha ) {\phi _1}(\xi  + t - z - \alpha , \xi ,x)d\alpha  - 
\\
 - {\phi _3}(\xi ,x)\int_0^{t + z - 2\xi } {{k_0}(\alpha ){\phi _1}(t + z - \xi  - \alpha ,\xi ,x)d\alpha    \biggr]d\xi }, 
\end{multline*}
\begin{multline*}
{B_3}\phi  = \phi _3^0( z,x) - \frac{2}{k_0(0)}\int_0^z \biggl[ \Delta \phi _2(2z - \xi ,\xi ,x) + \phi _3(\xi ,x)k'_0(2z - 2\xi ) +
\\
+ \phi _3(\xi ,x)\int_0^{2z - 2\xi } k_0(\alpha )\phi _2(2z - \xi  - \alpha ,\xi ,x)d\alpha  \biggr]d\xi . 
\end{multline*}


\noindent
  Пусть убывающая числовая последовательность $\{{a_n}\}_{n=0}^{\infty}$ определена соотношениями
$${a_{n + 1}} = {a_n}{\Bigl( {1 + \frac{1}{{{{(n + 1)}^2}}}} \Bigr)^{ - 1}},\quad n = 0, 1, 2, \ldots,$$
а число $a$ "--- формулой
\[a = \mathop {\lim }\limits_{n \to \infty } {a_n} = {a_0}{\prod\limits_{n = 0}^\infty  {\Bigl( {1 + \frac{1}{{{{(n + 1)}^2}}}} \Bigr)} ^{ - 1}}.\]
 Положительное число ${a_0} < {T}/({{2{s_0}}})$ будет выбрано позже. Для уравнения \eqref{dur:14} построим последовательные приближения:
$${\phi ^{n + 1}} = B{\phi ^n},\quad  n = 0, 1, 2, \ldots ,\quad  {\phi ^n} = (\phi _1^n, \phi _2^n,\phi _3^n),$$
и обозначим
$${\psi ^n} = {\phi ^{n + 1}} - {\phi ^n},\quad  n = 0, 1, 2, \ldots ,\quad  {\psi ^n} = \left( {\psi _1^n,\psi _2^n,\psi _3^n} \right).$$



Определим функцию $s'(z)$  формулой
\begin{equation}
s'(z) = \frac{{s + {v^n}(z)}}{2},\quad  {v^n}(z) = {s_0} - \frac{z}{{{a_n}}}. 
\label{dur:15}
\end{equation}
В дальнейшем нижний  индекс у $\phi $  означает номер компоненты вектор"=функции $\phi $, а верхний индекс "--- номер приближения.
 Докажем, что при подходящем выборе $a_0$ выполнены следующие неравенства:
\begin{multline}
\lambda _n = \max \biggl\{\mathop {\sup }\limits_{(t,z,s) \in {F_n}} \left[ {{{\left\| {\psi _1^n} \right\|}_s}(t,z)\frac{{{v^n}(z) - s}}{z}}
 \right],\mathop {\sup }\limits_{(t,z,s) \in {F_n}} \left[ {{{\left\| {{\psi _2}} \right\|}_s}(t,z)\frac{{{{\left( {{v^n}(z) - s} \right)}^2}}}{z}}
 \right],
 \\
 \mathop {\sup }\limits_{(t,z,s) \in {F_n}} \left[ {{{\left\| {{\psi _3}} \right\|}_s}(z)\frac{{{{\left( {{v^n}(z) - s} \right)}^3}}}{z}}
 \right]\biggr\} <  + \infty , 
 \label{dur:16}
\end{multline}
\begin{equation}
{\left\| {\phi _i^{n + 1} - \phi _i^0} \right\|_{{s_0}}}(t,z) \leqslant \frac{{{R_0}}}{{{{({s_0} - s)}^{i - 1}}}} ,\quad  i = 1, 2, 3,
\label{dur:17}
\end{equation}
для  $(t, z, s)  \in {F_{n + 1}}.$ 
Здесь   $${F_n} = \{   (t, z, s) \mid {(t, z) \in D_{0T}},
{0 < z < {a_n}(s_0 - s)}, {0 < s < s_0} \}.$$
  На самом деле для  $n = 0$ имеем
\begin{multline*}
\left\| {\psi _1^0} \right\|_s(t,z) \leqslant \frac 12 \int_0^z \int_{t - z + \xi }^{t + z - \xi }
\biggl[ \left\| \Delta \phi _1^0 \right\|_s  (\tau ,\xi )+ 
\left| {k_0}(\tau  - \xi ) \right|\left\| {\phi _3^0}
 \right\|_s(\xi ) + \\ 
 + {\left\| {\phi _3^0} \right\|_s}(\xi )\int_0^{\tau  - \xi } {{k_0}(\alpha )} {\left\| {\phi _1^0} \right\|_s}(\tau
  - \alpha ,\xi ) {d\alpha } \biggr]d\tau d\xi  \leqslant 
  \\
  \leqslant \frac 12 \int_0^z {\int_{t - z + \xi }^{t + z - \xi }
   { {\left( {\frac{{4\pi {R_0}}}{{{{(s'(\xi ) - s)}^2}}} + {k_1}{R_0}\left( {1 + {R_0}t} \right)} \right)} } } d\tau d\xi .
\end{multline*}
 Здесь использована оценка \eqref{dur:4} и введено обозначение ${k_1} = {\left\| {{k_0}(t)} \right\|_{{C^1}\left[ {0, T} \right]}}.$
Используя функцию $s'(\xi )$ из \eqref{dur:15},  для  $n = 0$ получим
\begin{multline*}
{\left\| {\psi _1^0} \right\|_s}(t,z) \leqslant \int_0^z {(z - \xi )} \left[ {\frac{{16\pi {R_0}}}{{{{({v^0}(\xi ) - s)}^2}}}
+ {k_1}{R_0}(1 + {R_0}t)} \right]d\xi  \leqslant 
\\
\leqslant{R_0}\left[ {16\pi  + s_0^2{k_1}(1 + {R_0}T)} \right]\int_0^z
{\frac{{(z - \xi )d\xi }}{{{{({v^0}(\xi ) - s)}^2}}} \leqslant } 
\\
\leqslant {R_0}\left[ {16\pi  + s_0^2{k_1}(1 + {R_0}T)} \right]\frac{z}{{{v^0}(z) - s}} ,\quad  (t, z, s)  \in {F_0}.
\end{multline*}
Поступая аналогично, находим
\begin{multline*}
{\left\| {\psi _2^0} \right\|_s}(t,z) \leqslant \frac 12 \int\limits_0^z   \left[ {\frac{{8\pi {R_0}}}{{{{(s'(\xi ) - s)}^2}}} + 2{k_1}{R_0}
(1 + 2{R_0}t)} \right]d\xi  \leqslant 
\\
\leqslant{R_0}\left[ {16\pi  + s_0^2{k_1}(1 + 2{R_0}T)} \right]\frac{z}{{{{({v^0}(z) - s)}^2}}},\quad 
   (t, z, s)  \in {F_0},
\end{multline*}
\[{\left\| {\psi _3^0} \right\|_s}(z) \leqslant  \frac{{2{s_0}{R_0}}}{{\left| {{k_0}(0)} \right|}}\left[ {16\pi  + s_0^2{k_1}(1 + 2{R_0}T)}
\right]\frac{z}{{{{({v^0}(z) - s)}^3}}},\quad  (t, z, s)  \in {F_0}.\]


В последних оценках были использованы неравенства  
$$\frac{1}{{v\left( \xi  \right) - s}} \leqslant \frac{1}{{{v^0}(z) - s}},\quad 
{v^0}(z) - s < {s_0},$$ справедливые для  $\xi  \in (0,z)$, $s \in (0,{s_0})$,  $(t, z, s)  \in {F_0}$.
Из полученных оценок следует выполнение неравенства \eqref{dur:16} при $n = 0$. Кроме того, для  $(t, z, s)  \in {F_1}$
находим \[{\left\| {\phi _i^1 - \phi _i^0} \right\|_s}(t,z) = {\left\| {\psi _i^0} \right\|_s}(t,s) \leqslant \frac{{{\lambda _0}z}}
{{{{\left( {{v^0}(z) - s} \right)}^i}}} \leqslant \frac{{{2^{i - 1}}{a_0}
{\lambda _0}}}{{{{\left( {{s_0} - s} \right)}^{i - 1}}}}, \quad  i=1, 2, 3.\]
При выборе $a_0$ так, что $4{a_0}{\lambda _0} \leqslant R,$ неравенства \eqref{dur:17} будут выполняться для $n = 0$.
Покажем методом индукции, что неравенства \eqref{dur:16}, \eqref{dur:17} имеют место и для других  $n$, если выбрать $a_0$ подходящим образом. 
Пусть  неравенства \eqref{dur:16}, \eqref{dur:17} справедливы для $n = 1, 2, 3, \ldots , j$. Тогда для $(t, z, s)  \in {F_{j + 1}}$
\begin{multline*}
\| {\psi _1^{j + 1}} \|(t,z) \leqslant \frac 12 
\int_0^z \int_{t - z + \xi }^{t + z - \xi } 
\biggl[ \| \Delta \psi _1^j\| (\tau ,\xi ) + k_1 \| \psi _3^j\|(\xi ) +
\\
+ {k_1}\| {\psi _3^j} \|_s(\xi ) \int_0^{\tau  - \xi }   
\| \phi _1^{j + 1}\|(\tau  - \alpha ,\xi )d\alpha  +  
{k_1}\| {\phi _3^j} \|\int_0^{\tau  - \xi } \| {\psi _1^j} \| (\tau  - \alpha ,\xi )d\alpha 
 \biggr]d\tau d\xi  \leqslant 
\\
\leqslant\frac 12 \int_0^z {\int_{t - z + \xi }^{t + z - \xi } 
\biggl[ \frac{{4\pi {\lambda _j}\xi }}{{{{ \left( {s'(\xi ) - s} \right)}^2}({v^j}(\xi ) - s)}}} 
+\frac{{{k_1}{\lambda _j}\xi }}{{{{({v^j}(\xi ) - s)}^3}}} +  \frac{{2{k_1}{R_0}{\lambda _j}t\xi }}{{{{(v^j(\xi ) - s)}^3}}}  + \\ +
\frac{{{k_1}{\lambda _j}t\xi {R_0}(1 + s_0^2)}}{{(v^j(\xi ) - s){{({s_0} - s)}^2}}}   \biggr]d\tau d\xi %\leqslant \\
\leqslant{\lambda _j}a_0^2\left[ {16\pi  + {k_1}\left( {1 + 3{R_0}T + {R_0}s_0^2T} \right)} \right]\frac{z}{{{v^{j + 1}}(z) - s}}.
\end{multline*} 
 Здесь в промежуточных выкладках функция $s'(\xi )$ взята в виде \eqref{dur:15} при $n = j$ и использованы неравенства
\begin{gather*}
\| {\phi _1^{j + 1}} \|_s(t,z) \leqslant 2{R_0}, \quad 
\| {\phi _3^j} \|_s (z) \leqslant 2{R_0}\frac{{1 + s_0^2}}{{{{\left( {{s_0} - s} \right)}^2}}},
\end{gather*} 
справедливые согласно индуктивному предположению, а также очевидные неравенства ${a_i} \leqslant {a_0}$, ${v^{j + 1}}(z) \leqslant {v^j}(z)$.
 Аналогичные рассуждения для $\psi _2^{j + 1}$, $\psi _3^{j + 1}$ приводят к следующим неравенствам:
\begin{multline*}
\| \psi _2^{j + 1} \|(t,z) \leqslant \frac 12 \int_0^z 
\biggl[ \frac{{8\pi {\lambda _j}\xi }}{{{{(s'(\xi ) - s )}^2}(v^j(\xi ) - s)}} + 
\frac{{2{k_1}{\lambda _j}\xi }}{{{{({v^j}(\xi ) - s)}^3}}} + \frac{{2{k_1}{R_0}  {\lambda _j}t\xi }}{{{{(v^j(\xi ) - s)}^3}}} + 
\\
 + \frac{{{k_1}{\lambda _j}t\xi {R_0}(1 + s_0^2)}}{{( v^j(\xi ) - s){{({s_0} - s)}^2}}}\biggr]d\xi  \leqslant {\lambda _j} a_0 \left[ {16\pi  + {k_1}\left( {1 + 2{R_0}T + {R_0}s_0^2T}
 \right)} \right]\frac{z}{{{{({v^{j + 1}}(z) - s)}^2}}},
\end{multline*}
\begin{multline*}
\| \psi _3^{j + 1} \|(z) \leqslant \frac{2}{{| {{k_0}(0)} |}}\int_0^z \biggl[ \frac{{4\pi {\lambda _j}\xi }} {{{{( s'(\xi ) - s)}^2}{{(v^j(\xi ) - s)}^2}}} +  \frac{{{k_1}{\lambda _j}\xi }}{{{{({v^j}(\xi ) - s)}^3}}} + \\ + \frac{{2{k_1}z{R_0}{\lambda _j}(1 + {s_0})\xi }}{{{{(v^j(\xi ) - s)}^3}{{({s_0} - s)}^2}}}  + \frac{{2{k_1}{\lambda _j}z\xi
  {R_0}(1 + s_0^2)}}{{{{(v^j(\xi ) - s)}^2}{{({s_0} - s)}^2}}}\biggr]d\xi  \leqslant \\
\leqslant\frac{{2{\lambda _j}{a_0}}}{{\left| {{k_0}(0)} \right|}}\left[ {16\pi  + {k_1}{s_0} + 2{k_1}{R_0}T\left( {2 + {s_0} + s_0^2} \right)}
   \right]\frac{z}{{{{({v^j}(z) - s)}^3}}},\quad (t, z, s)  \in {F_{j + 1}}.
\end{multline*} 
Из полученных оценок следует
${\lambda _{j + 1}} \leqslant {\lambda _j}\rho$,  ${\lambda _{j + 1}} < \infty$,  
\[\rho  = {a_0}\left[ {16\pi  + \max (1,{s_0})}\right.{k_1} + 2{k_1}{R_0}T(2 + {s_0} + \left. {s_0^2)} \right]\max (1,{a_0},2{\left| {{k_0}(0)} \right|^{-1}}).\]
Вместе с тем для $(t, z, s)  \in {F_{j + 2}}$ имеем
\begin{multline*}
\| {\phi _i^{j + 2} - \phi _i^0} \|_s(t,z) \leqslant \sum\limits_{n = 0}^{j + 1}   \| {\phi _i^{n + 1} - \phi _i^n} \|_s
(t,z) = 
\\
=\sum\limits_{n = 0}^{j + 1} {{{\left\| {\psi _i^n} \right\|}_s}} (t,z) \leqslant \sum\limits_{n = 0}^{j + 1} {\frac{{{\lambda _n}z}}{{{{\left(
{{v^n}(z) - s} \right)}^i}}}}  %\leqslant 
%\\
\leqslant \frac{1}{{{{\left( {{s_0} - s} \right)}^{i - 1}}}}\sum\limits_{n = 0}^{j + 1}
{\frac{{{\lambda _n}{a_{j + 2}}}}{{{{\left( {1 - {a_{j + 2}}a_n^{ - 1}} \right)}^i}}}}  \leqslant
\\
 \leqslant\frac{{{\lambda _0}{a_0}}}{{{{\left( {{s_0} - s}
 \right)}^{i - 1}}}}\sum\limits_{n = 0}^{j + 1} {{\rho ^n}} {(n + 1)^{2i}},\quad  i = 1, 2, 3.
\end{multline*} 
Выберем ${a_0} \in ( 0, {T}/{2})$ таким, что
\[\rho  \leqslant 1, \quad {\lambda _0}{a_0}\sum\limits_{n = 0}^\infty  {{\rho ^n}} {(n + 1)^6} \leqslant {R_0}.\]
Тогда  
$$\| {\phi _i^{j + 2} - \phi _i^0} \|_s(t,z) \leqslant \frac{{{R_0}}}{(s_0 - s)^{i - 1}},\quad 
(t, z, s)  \in {F_{j + 2}}, \quad  i = 1, 2, 3.$$
Так как выбор $a_0$ не зависит от номера приближения, последовательные приближения ${\phi ^n} = (\phi _1^n,\phi _2^n,\phi _3^n)$
принадлежат  $C(F,{A_s})$,     $F = \bigcap_{n = 0}^\infty  {{F_n}} $ и для них имеют место неравенства
\[{\left\| {\phi _i^n - \phi _i^0} \right\|_s}(t,z) \leqslant \frac{{{R_0}}}{{{{({s_0} - s)}^{i - 1}}}}, \quad  (t, z, s) 
 \in F,\quad  i = 1,2,3.\]



     При  $s \in (0,{s_0})$ ряды   $\sum_{n = 0}^\infty  {\left( {\phi _i^n - \phi _i^{n - 1}} \right)}$,   $i = 1, 2, 3$,
      сходятся равномерно    в норме пространства $C(F,{A_s})$,  поэтому ${\phi ^n} = (\phi _1^n,\phi _2^n,\phi _3^n) \to \phi  = (\phi _1,\phi _2,\phi_3)$  предельная функция $\phi $ является элементом  $C(F,{A_s})$ и   удовлетворяет уравнению \eqref{dur:14}.


Покажем, что найденное решение единственно. Пусть ${\phi ^{(1)}} = (\phi _1^{(1)},\phi _2^{(1)},\phi _3^{(1)})$ и ${\phi ^{(2)}} = (\phi _1^{(2)},
\phi _2^{(2)},\phi _3^{(2)})$ "--- любые два решения, удовлетворяющие неравенствам 
\[
\| \phi _i^{(j)} - \phi _i^0\|_s(t,z)
 \leqslant {R_0},\quad  i = 1, 2, 3;\quad  j = 1, 2,\quad  (t, z, s)  \in {F}.
 \]
 Обозначим ${w_i} = \phi _i^{(1)} - \phi _i^{(2)}$,  $i = 1, 2, 3$,   и пусть
\[\lambda  = \mathop {\max }\limits_{1 \leqslant i \leqslant 3} \left\{ {\mathop {\sup }\limits_{(t,z,s) \in F} \left[ {{{\left\| {{w_i}}
\right\|}_s}(t,z){{\frac{{\left( {v(z) - s} \right)}}{z}}^i}} \right]} \right\} < \infty, \]
 где  $v(z) = s_0 - s/a$, $a = {a_0}{\prod\limits_{n = 0}^\infty  {\left( {1 + \frac{1}{{{{(n + 1)}^2}}}} \right)} ^{ - 1}}$.
 Тогда из  формулы \eqref{dur:14} для функций ${w_i}$ можно  получить соотношения
\begin{multline*}
{w_1}(t,z,x) =  - \frac 12 \iint_{\Delta (z,t)}  \biggl[ {\Delta {w_1}(\tau ,\xi ,x)} + {k_0}(\tau  - \xi ){w_3}(\xi ,x)+ 
\\
+{w_3}(\xi ,x)\int_0^{\tau  - \xi } {{k_0}(\alpha )} \phi _1^{(1)}(\tau  - \alpha ,\xi ,x)d\alpha  +
\\
+ \phi _3^{(2)}(\xi ,x)\int_0^{\tau  - \xi } {{k_0}(\alpha )} {w_1}(\tau  - \alpha ,\xi ,x) {d\alpha } \biggr]d\tau d\xi ,
 \end{multline*}
\begin{multline*}
{w_2}(t,z,x) = - \frac 12 \int_0^z  \biggl[ \Delta {w_1}\left( {\xi  + t - z,\xi ,x} \right) + \left( {{k_0}(t - z) - {k_0}(t + z - 2\xi )}
 \right){w_3}(\xi ,x) -
\\ 
- \Delta {w_1}(\xi  + t - z,\xi ,x) + {w_3}(\xi ,x)\int_0^{\tau  - \xi } {{k_0}(\alpha )} \phi _1^{(1)}(\xi  + t + z - \alpha ,\xi ,x)d\alpha
 - 
\\
- \phi _3^{(2)}(\xi ,x)\int_0^{t + z - 2\xi } {{k_0}(\alpha )} {w_1}(t + z - \xi  - \alpha ,\xi ,x)d \alpha  \biggr]d\xi ,
\end{multline*}
\begin{multline*}
{w_3}(t,x) =  - \frac{2}{{{k_0}(0)}}\int_0^z \biggl[ \Delta {w_2}(2z - \xi ,\xi ,x) + {k'_0}(2z - 2\xi ){w_3}(\xi ,x) + 
\\
+ {w_3}\left( {\xi ,x} \right)\int_0^{2z - 2\xi } {{k_0}} (\alpha )\phi _2^{(1)}(2z - \xi  - \alpha ,\xi ,x)d\alpha  + 
\\
+\phi _3^{(2)}(\xi ,x)
\int_0^{2z - 2\xi } {{k_0}(\alpha )} {w_2}(2z - \xi  - \alpha ,\xi ,x)d \alpha  \biggr]d\xi. 
\end{multline*}

\noindent
Применяя к ним оценки, приведённые выше, имеем неравенство 
$\lambda  \leqslant \lambda \rho '$,
где 
\mbox{$\rho ' = a\left[ {16\pi  + \max (1,{s_0}){k_1} + 2{k_1}{R_0}{T_0}(2 + {s_0} + s_0^2)} \right]\max (1,{\alpha _0},{\left| {{k_0}(0)}
\right|^{ - 1}}) < \rho  < 1.$}
 Следовательно  $\lambda  = 0$.   Поэтому $\phi _i^{(1)} = \phi _i^{(2)}$, $i = 1,2,3$.
Теорема доказана. \end{proof}
