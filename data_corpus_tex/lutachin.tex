Мощность и развиваемый момент высокочастотных шаровых асинхронных
электродвигателей (ШАД) с разомкнутым магнитопроводом статора и полым
шаровым ферромагнитным ротором ограничиваются прежде всего допустимой
величиной нагрева их активных частей.
Температурный режим ротора, в свою очередь, ограничивается допустимым
значением его температурной деформации.

Основным источником тепловыделения в сплошном материале шарового ротора
являются вихревые токи, вектор плотности которых определяется законом Ома
\begin{equation*}
%\label{luta:eq1}
 \vec J_p =\sigma _p \vec {E}_p,
\end{equation*}
где $\vec {E}_p $ "--- вектор напряженности электрической составляющей
электромагнитного поля в $p$-среде материала ротора;
$\sigma _p $ "--- удельная электропроводность материала ротора.
Вектор электрической напряженности определяется зависимостью~[1]
\begin{equation*}
%\label{luta:eq2}
\vec {E}_p =-j\omega \vec {A}_p ,
\end{equation*}
где $\omega $ "--- угловая частота поля; $\vec {A}_p $ "--- вектор потенциала
магнитного поля.

Для упрощения задачи рассмотрим поле, создаваемое элементом магнитной
системы "--- круговым бесконечно тонким витком с~гармоническим током и~шаровым
ферромагнитным ротором. Для перехода к~реальной электромагнитной системе ШАД
необходимо дополнительно воспользоваться методом суперпозиции полей,
создаваемых системой витков, а~также алгоритмом математического
конструирования магнитного поля ШАД.

В рамках принятой к исследованию элементарной электромагнитной системы
\begin{equation*}
%\label{luta:eq3}
\vec {A}_p =\vec {l}_\varphi A_{p\varphi },
\quad
A_{p\varphi } ={\rm Re\,}A_{p\varphi} +j{\rm Im\,}A_{p\varphi } ,
\end{equation*}
где
${\rm Re\,}A_{p\varphi } =\left| {A_{p\varphi } } \right|\cos (\omega t+\psi)$,
${\rm Im\,}A_{p\varphi } =\left| {A_{p\varphi } } \right|\sin (\omega t+\psi )$,
соответственно, действительная и мнимая части функции комплексного
переменного.

Интенсивность источников тепловыделения, т.\,е. плотность потерь мощности,
возникающих при протекании вихревых токов в~роторе, определяется зависимостью
\begin{equation}
\label{luta:eq4}
q=\frac12 \sigma _p \omega ^2({\rm Re\,}\vec {A}_p )^2.
\end{equation}

Известно [2, 3], что задача стационарной теплопроводности сводится к~решению
дифференциального уравнения Пуассона:
\begin{equation}
\label{luta:eq5}
\Delta T=-q\lambda _p^{-1} ,
\end{equation}
где $T$ "--- температурное поле; $\lambda _p$ "--- коэффициент
теплопроводности материала ротора;
$\Delta $ "--- оператор Лапласа.

Лапласиан скалярной функции в~сферической системе координат при наличии
вращательной симметрии имеет вид
\begin{equation}
\label{luta:eq6}
\Delta T=\frac1{r^2}\frac\partial {\partial r}
\Bigl( r^2\frac{\partial T}{\partial r} \Bigr)+
\frac 1{r^2\sin \nu }\frac \partial {\partial \nu }
\Bigl( \sin \nu \frac{\partial T}{\partial \nu } \Bigr).
\end{equation}

Общим решением неоднородного дифференциального уравнения ({\ref{luta:eq5}) является сумма
общего решения однородного уравнения Лапласа
\begin{equation}
\label{luta:eq7}
\Delta T=0
\end{equation}
и частного решения исходного неоднородного уравнения~[4].
В~данном случае удобно решать однородное уравнение ({\ref{luta:eq7})
методом разделения переменных Фурье~[4]:
\begin{equation}
\label{luta:eq8}
T=R(r)\cdot \Theta (\nu ),
\end{equation}
преобразующим уравнение ({\ref{luta:eq7}) в~частных производных в~систему двух
обыкновенных дифференциальных уравнений второго порядка
\begin{gather}
\label{luta:eq9}
\frac{d^2R}{dr^2}+\frac2r\frac{dR}{dr}-\frac{p^2}{r^2}R=0,
\\
\label{luta:eq10}
\frac{d^2\Theta }{d\nu ^2}+\ctg\nu \frac{d\Theta }{d\nu }+p^2\Theta =0,
\end{gather}
которые имеют частные решения~[5]:
\begin{gather}
\label{luta:eq11}
R(r)=\sqrt r \left( l\cdot r^{\sqrt {p^2+\frac14}} +d\cdot r^{-\sqrt {p^2+\frac14} } \right),
\\
\label{luta:eq12}
\Theta (\nu )=cP_n (\cos \nu )+bQ_n (\cos \nu ),
\end{gather}
где $P_n(\cos\nu )$ и $Q_n(\cos\nu )$ "--- полиномы Лежандра первого и второго рода;
$l$, $d$, $c$, $b$ "--- произвольные действительные постоянные.
Решение ({\ref{luta:eq12}) требует выполнения зависимости
$p^{2}=n(n+1),$
где $n \in \{0\}\cup\mathbb N$.

Так как температурное поле во всем пространстве электромагнитной системы
должно быть конечным, то необходимо потребовать выполнение равенства $b = 0$.

Таким образом, общее решение однородного уравнения ({\ref{luta:eq7}) имеет вид
\begin{equation}
\label{luta:eq13}
T''=\sum\limits_{n=0}^\infty
( l_n r^n+d_n r^{-n-1} )P_n (\cos \nu ) ,
\end{equation}
где $l_n$ и $d_n$ "--- коэффициенты ряда, значения которых находятся в~результате решения краевой задачи.

В качестве частного решения уравнения ({\ref{luta:eq5}) принимается выражение для
скалярного теплового потенциала~в виде~[2]:
\begin{equation}
\label{luta:eq14}
T'=\frac1{\lambda _p }
\int_{\nu '=0}^{\nu '=\pi }
\int_{r'=r_{p-1; p} }^{r'=r_{p; p+1} } \!\!\!\!
q(r'; \nu ')r'^2\sin \nu dr' d\nu '
\int_{\varphi '=0}^{\varphi '=2\pi } \!\!\!\!
\bigl| \vec r-\vec r\,' \bigr|^{-1}d\varphi' ,
\end{equation}
где $| \vec r-\vec r\,'|^{-1}=\bigl(r^2+r'^2-2r' r \cos \nu ' \cos \nu -
2r'r \sin \nu '   \sin \nu \cos (\varphi -\varphi ')\bigr)^{-\frac12}$ "---
функция трёх пространственных координат $r$, $\nu$, $\varphi $ исследуемых
точек пространства и~координат $r'$, $\nu '$, $\varphi '$
точек области пространства, в~которой задано поле источников тепла.
Эта функция теряет регулярность в точках $r=r'$, $\nu =\nu '$, $\varphi =\varphi '$.
Для интегрирования этой функции целесообразно воспользоваться её
преобразованием, полученным в работе [1] с помощью разложения её
в~биноминальный степенной ряд.
Преобразованная функция имеет вид
\begin{multline}
\label{luta:eq15}
\bigl| \vec {r}-\vec {r}\,' \bigr|^{-1}=
\bigl(r^2+r'^2-2r'r\cos \nu '\cos \nu \bigr)^{-\frac12} \times \\
\times
\Bigl( 1+
\sum\limits_{n=0}^\infty
\frac{\frac12(\frac12+1)\cdots(\frac12+n-1)}{n!}x^n  \Bigr),
\end{multline}
где
$$
x=\bigl(r^2+r'^2-2r'r\cos \nu '\cos \nu \bigr)^{-1}
\bigl(2r'r\sin \nu '\sin \nu \cos (\varphi -\varphi ') \bigr);$$
неравенство $| x |<1$ является условием абсолютной
и~равномерной сходимости ряда~({\ref{luta:eq15}).

В результате интегрирования функции ({\ref{luta:eq15}) получаем выражение
\begin{equation}
\label{luta:eq16}
\int_0^{2\pi }
\frac{d\varphi '}{| \vec {r}-\vec r\,' |}=
\frac14
\sum\limits_{n=0}^\infty
\frac{(4n+1)!}{2^{6n}(n+1)(2n)!(n!)^2}\bigl(x\cos ^{-1}(\varphi -\varphi')\bigr)^{2n}.
\end{equation}
Дальнейшее интегрирование выражения ({\ref{luta:eq14}) выполняется численными методами.


Таким образом, температурное поле в материале ротора, занимающего область
пространства $\bigl\{ r\in [ r_{p-1; p};\, r_{p; p+1} ];\;
\nu \in [ 0; 2\pi];\; \varphi \in [0; 2\pi ] \bigr\}$,
является функцией
\begin{equation}
\label{luta:eq17}
T=T'+T'',
\end{equation}
определяемой формулами \eqref{luta:eq4}, \eqref{luta:eq13}--\eqref{luta:eq16}, а также формулами, полученными в
работе~[1] для вектор"=потенциала электромагнитного поля в материале ротора:
\begin{gather}
\label{luta:eq18}
{\rm Re\,}A_p' =
\frac{I_c  \rho _c x_c \,{\rm Re\,}\mu _p}{8\sqrt {r'^2+\rho _c^2 +z_c^2 -2r'z_c\cos \nu } }
\sum\limits_{n=0}^\infty
\frac{(4n+1)!x_c^{2n} }{2^{6n}(n+1)(2n)!(n!)^2} ,
\\
\label{luta:eq19}
{\rm Re\,}A''_p =\frac1{\sqrt {r'}}
{\rm Re\,}\biggl\{
\sum\limits_{n=1}^\infty
\left[ c_{pn} I_{n+\frac12} ( k_p r' )+F_{pn} Y_{n+\frac12}
(k_p r') \right] P_n' (\cos \nu )  \biggr\},
\end{gather}
\begin{equation}
\label{luta:eq20}
{\rm Re\,}A_p ={\rm Re\,}A_p' +{\rm Re\,}A_p'',
\end{equation}
где $\bigl\{ \rho =\rho_c;\; z=z_c;\; \varphi \in [0; 2\pi] \bigr\}$ "---
контур витка со сторонним током $I_c$, возбуждающим
электромагнитное поле, заданный в цилиндрической системе координат $(\rho, z, \varphi)$;
\begin{equation}
\label{luta:eq21}
x_c =\frac{2\rho _c r'\sin \nu '}{r'^2+\rho _c^2 +z_c^2 -2r'z_c \cos \nu '};
\end{equation}
$I_{n+\frac12} (k_p r')$, $Y_{n+\frac12} (k_p r')$ "--- функции Бесселя соответственно первого
и~второго рода полуцелого индекса $n+\frac12 \in  [1{,}5;\; 2{,}5;\; 3{,}5;\, \dots]$
и~комплексного аргумента~$k_{p}r'$;
$k_p =\sqrt {\varepsilon_{ep} \mu _p \omega } $ "--- комплексный волновой параметр;
\mbox{$\varepsilon _{ep} =\varepsilon_p -j\sigma_p \omega^{-1}$};
$\mu _p $ "--- комплексные, соответственно, эквивалентная диэлектрическая
и~магнитные проницаемости материала ротора, т.\,е. среды $p$;
$P_n' (\cos \nu )$ "--- присоединённые функции Лежандра первого рода;
$c_{pn}$, $F_{pn}$ "--- комплексные коэффициенты ряда ({\ref{luta:eq19}), определяемые
из краевых условий преломления электромагнитного поля на сферических
поверхностях, разделяющих среды электромагнитной системы ШАД~[1].

Для окончательного исследования стационарной теплопроводности ШАД необходимо
сформулировать и~решить краевую задачу, что позволит найти неизвестные
коэффициенты $l_{n}$ и~$d_{n}$ ряда ({\ref{luta:eq13}) и~спроектировать оптимальную
электромагнитную систему ШАД~[7, 9, 10].
В~дальнейшем предполагается такое конструктивное исполнение ротора,
при котором не происходит теплообмен на внутренней его поверхности.
На практике это означает использование внутри ротора совершенной
теплоизоляции, например, экранно"=вакуумной.
Применение последней позволяет избежать аккумулирования тепла во внутреннем
объёме ротора, а~также разогрева объекта разворота.
Этому обстоятельству соответствует краевое условие
\begin{equation}
\label{luta:eq22}
\frac{\partial T}{\partial r}\Big|_{r=r_{p-1; p} } =0
\end{equation}
на внутренней сферической поверхности
$\bigl\{ r=r_{p-1; p} ;\; \nu \in [0; p];\; \varphi \in [0; 2\pi ] \bigr\}$ ротора.
Теплообмен между ротором и~внешней средой, температура которой $T_0$,
через внешнюю сферическую поверхность ротора задаётся приближённо в~виде
закона Ньютона [2, 3]:
\begin{equation}
\label{luta:eq23}
\frac{\partial T}{\partial r}\Big|_{r=r_{p; p+1} }
=-\alpha \lambda _p^{-1}\bigl((T_{r=r_p; p+1})-T_0 \bigr),
\end{equation}
где $\alpha $ "--- коэффициент теплоотдачи, [Вт/(м$^{2}$К)].
Дифференцированием по радиусу $r$ функций \eqref{luta:eq13}, \eqref{luta:eq14}
устанавливаются необходимые частные производные:
\begin{equation}
\label{luta:eq24}
\frac{\partial T"}{\partial r}=
\sum\limits_{n=0}^\infty
\left( l_n nr^{n-1}-d_n (n+1)r^{-n-2} \right)P_n (\cos \nu ) ,
\end{equation}
\begin{multline}
\label{luta:eq25}
\frac{\partial T'}{\partial r}=
\frac1{4\lambda _p}
\sum\limits_{n=0}^\infty
\frac{(4n+1)!}{2^{6n}(n+1)(2n)!(n!)^2} \times \\ \times
\int_{\nu '=0}^{\nu '=\pi }
\int_{r'=r_{p-1; p}}^{r'=r_{p; p+1}}
\frac{\partial (x_0 ^{2n})}{\partial r} q(r'; \nu ')\, r' \sin \nu ' \, dr' d\nu ',
\end{multline}
где
\begin{equation}
\label{luta:eq26}
\frac{\partial (x_0 ^{2n})}{\partial r}=
2nx_0 ^{2n-1}
\frac{2r'\sin \nu '\sin \nu (r'^2-r^2)}{(r^2+r'^2-2rr'\cos \nu '\cos \nu )^2}.
\end{equation}
Использование выражений \eqref{luta:eq24}--\eqref{luta:eq26}
позволяет избежать численного дифференцирования, которое вносит погрешности;
последние могут привести к~не\-ус\-той\-чи\-вос\-ти всего алгоритма расчёта температурного поля.

После учета зависимостей \eqref{luta:eq13}, \eqref{luta:eq24}--\eqref{luta:eq26} краевое условие ({\ref{luta:eq23}) приобретает вид
\begin{equation}
\label{luta:eq27}
\sum\limits_{n=0}^\infty
\bigl( l_n nr_{p-1; p}^n -d_n (n+1)r_{p-1; p}^{-n-1}  \bigr)P_n (\cos \nu ) =r_{p-1; p}\cdot
\frac{\partial T'}{\partial r}\Big|_{r=r_{p-1; p}  }.
\end{equation}
Левую часть уравнения ({\ref{luta:eq27}) можно рассматривать в~качестве
специального разложения в~ряд по полиномам Лежандра функции, представленной
правой частью этого же уравнения.
Применение известной формулы [8] для определения коэффициентов такого разложения
к~конкретному случаю позволяет найти их в~виде
\begin{equation}
\label{luta:eq28}
c_n '=\frac{2n+1}{2}r_{p-1; p} \cdot \int_{-1}^1 \frac{\partial T'}{\partial r}
\Bigl|_{r=r_{p-1; p} } \!\!\!\! P_n (\cos \nu )d(\cos \nu ).
\end{equation}
Значение интеграла в полученном выражении ({\ref{luta:eq28}) находится численными методами.
Таким образом, краевое условие ({\ref{luta:eq27}) сводится к~следующей бесконечной системе
алгебраических уравнений:
\begin{equation}
\label{luta:eq29}
l_n nr_{p-1; p}^n - d_n r_{p-1;p}^{-n-1} (n+1)-c_n '=0.
\end{equation}

Вторая система алгебраических уравнений получается из краевого условия ({\ref{luta:eq23}),
которое формулами ({\ref{luta:eq23}), ({\ref{luta:eq24})--({\ref{luta:eq26})
приводится к~уравнению
\begin{multline}
\sum\limits_{n=0}^\infty
\biggl[  l_n \Bigl(nr_{p; p+1}^{n-1} +\frac{\alpha}{\lambda _p } r_{p; p+1}^n\Bigr)+
d_n \Bigl( \frac{\alpha }{\lambda _p } r_{p; p+1}^{-n-1}-
r_{p; p+1}^{-n-2} (n+1) \Bigr) \biggr] P_n (\cos \nu ) =
\\
\label{luta:eq30}
=\frac{\alpha }{\lambda _p }
\Bigl[ T_0 -T'_{r=r_{p; p+1} } \Bigr]-
\frac{\partial T'}{\partial r}\Big|_{r=r_{p; p+1} } .
\end{multline}
Решение данного уравнения аналогично решению уравнения ({\ref{luta:eq27}), сводится к~отысканию
коэффициентов разложения в ряд по полиномам Лежандра:
\begin{equation}
\label{luta:eq31}
c_n ''=\frac{2n+1}{2}
\int_{-1}^1 \biggl[
 \frac{\alpha }{\lambda _p } \Bigl[ T_0 -T'_{r=r_{p; p+1} } \Bigr]-
\frac{\partial T'}{\partial r}\Big|_{r=r_{p; p+1} }  \biggr] P_n (\cos \nu )d(\cos \nu ).
\end{equation}


Таким образом, находится и вторая бесконечная система алгебраических уравнений:
\begin{equation}
\label{luta:eq32}
l_n r_{p; p+1}^n      \Bigl( \frac{n}{r_{p; p+1} }+ \frac{\alpha }{\lambda _p }\Bigr)+
d_n r_{p; p+1}^{-n-1} \Bigl( \frac{\alpha}{\lambda_p}-\frac{n+1}{r_{p; p+1} }  \Bigr)-c_n ''=0.
\end{equation}

Совместное решение двух бесконечных систем алгебраических уравнений ({\ref{luta:eq29})
и~({\ref{luta:eq32}) возможно, так как общая система является бесконечной
совокупностью независимых друг от друга пар алгебраических уравнений,
то есть каждому $n$-ному члену ряда ({\ref{luta:eq13}) соответствует своя
пара алгебраических уравнений вида ({\ref{luta:eq29}) и~({\ref{luta:eq32}),
однозначно определяющая одну пару коэффициентов $l_n$ и $d_n$ этого члена ряда.

\textbf{Выводы.} Полученная математическая модель стационарной теплопроводности
в~роторе, выполненном в виде сферической оболочки, разогреваемой вихревыми
токами при работе трехстепенного ШАД, позволяет рассчитать при конкретно
заданных условиях температурное поле ротора в наиболее тяжелом случае
(длительная работа двигателя в пусковом режиме), и, следовательно,
определить необходимые условия охлаждения, или при заданных условиях
охлаждения "--- длительно допустимые значения момента, развиваемого
двигателем, при котором ротор имеет заданные температуру и температурные
деформации.
В свою очередь, решение этой задачи является исходной постановкой
задачи термоупругости, то есть задачи определения деформации ротора,
обусловленной его разогревом.
